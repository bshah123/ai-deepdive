# 33.1 — Inverted Index Construction & Postings List Compression

## Opening Motivation & Context

Inverted indices are a fundamental data structure in information retrieval and search engines. They map terms to their locations in documents, enabling efficient full-text search. Postings list compression is crucial for optimizing storage and retrieval performance. This lesson will explore how to construct an inverted index and compress postings lists.

## Core Concepts Breakdown

### Inverted Index

An inverted index is a data structure that maps terms to their locations in documents. It consists of two main components:

1. **Vocabulary**: A list of all unique terms in the document collection.
2. **Postings List**: For each term, a list of document IDs where the term appears.

> [!KEY-INSIGHT]
> Inverted indices enable efficient full-text search by allowing quick lookup of terms and their associated documents.

### Postings List Compression

Postings lists can be compressed to save storage space and improve retrieval performance. Common compression techniques include:

1. **Delta Encoding**: Store the difference between consecutive document IDs instead of the full IDs.
2. **Variable-Byte Encoding**: Use variable-length byte sequences to represent numbers, with smaller numbers using fewer bytes.

> [!BEST-PRACTICE]
> Use delta encoding followed by variable-byte encoding for efficient postings list compression.

> [!WARNING]
> Compression techniques can increase the complexity of the retrieval process, so it's essential to balance storage savings with retrieval performance.

## Code Demonstration & Runtime Output

```python
from typing import List, Dict, Tuple
import struct

def build_inverted_index(documents: List[str]) -> Dict[str, List[int]]:
    inverted_index = {}
    for doc_id, document in enumerate(documents):
        terms = document.split()
        for term in terms:
            if term not in inverted_index:
                inverted_index[term] = []
            if doc_id not in inverted_index[term]:
                inverted_index[term].append(doc_id)
    return inverted_index

def delta_encode(postings: List[int]) -> List[int]:
    delta_encoded = [postings[0]]
    for i in range(1, len(postings)):
        delta_encoded.append(postings[i] - postings[i-1])
    return delta_encoded

def variable_byte_encode(number: int) -> bytes:
    encoded = bytearray()
    while True:
        encoded.append(number & 0x7F)
        number >>= 7
        if number == 0:
            break
    encoded[0] |= 0x80
    return bytes(encoded)

def compress_postings(postings: List[int]) -> bytes:
    delta_encoded = delta_encode(postings)
    compressed = bytearray()
    for number in delta_encoded:
        compressed.extend(variable_byte_encode(number))
    return bytes(compressed)

def decompress_postings(compressed: bytes) -> List[int]:
    postings = []
    i = 0
    while i < len(compressed):
        number = 0
        shift = 0
        while True:
            byte = compressed[i]
            i += 1
            number |= (byte & 0x7F) << shift
            shift += 7
            if byte & 0x80:
                break
        postings.append(number)
    delta_decoded = [postings[0]]
    for i in range(1, len(postings)):
        delta_decoded.append(delta_decoded[i-1] + postings[i])
    return delta_decoded

if __name__ == "__main__":
    documents = [
        "the quick brown fox",
        "jumps over the lazy dog",
        "the quick brown fox jumps over the lazy dog"
    ]

    inverted_index = build_inverted_index(documents)
    print("Inverted Index:")
    for term, postings in inverted_index.items():
        print(f"{term}: {postings}")

    compressed_index = {}
    for term, postings in inverted_index.items():
        compressed_index[term] = compress_postings(postings)
    print("\nCompressed Index:")
    for term, compressed in compressed_index.items():
        print(f"{term}: {compressed}")

    decompressed_index = {}
    for term, compressed in compressed_index.items():
        decompressed_index[term] = decompress_postings(compressed)
    print("\nDecompressed Index:")
    for term, postings in decompressed_index.items():
        print(f"{term}: {postings}")
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: The code imports necessary modules, including `List`, `Dict`, and `Tuple` from the `typing` module, and `struct` for byte manipulation.
2. **build_inverted_index**: This function constructs an inverted index from a list of documents. It iterates over each document, splits it into terms, and updates the inverted index with the document IDs for each term.
3. **delta_encode**: This function applies delta encoding to a list of document IDs. It calculates the difference between consecutive IDs and stores these differences.
4. **variable_byte_encode**: This function encodes a number using variable-byte encoding. It splits the number into 7-bit chunks and sets the high bit of the last byte to indicate the end of the number.
5. **compress_postings**: This function compresses a list of document IDs by first applying delta encoding and then variable-byte encoding.
6. **decompress_postings**: This function decompresses a compressed postings list by first decoding the variable-byte encoding and then applying delta decoding.
7. **Main Block**: The main block demonstrates the construction, compression, and decompression of an inverted index. It prints the inverted index, compressed index, and decompressed index.

> [!ADVANCED]
> The variable-byte encoding and decoding process involves bit manipulation to split numbers into 7-bit chunks and set the high bit of the last byte. This allows for efficient storage of numbers with varying magnitudes.
