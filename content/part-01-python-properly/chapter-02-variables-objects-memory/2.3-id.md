# 2.3 — Object Identity & id() Function

## Opening Motivation & Context

In Python, everything is an object, and each object has a unique identity. Understanding object identity is crucial for writing efficient and correct Python code, especially when dealing with mutable objects, function arguments, and object comparisons. The `id()` function is a built-in Python function that returns the unique identifier of an object. This identifier is an integer that is guaranteed to be unique and constant for this object during its lifetime.

## Core Concepts Breakdown

> [!KEY-INSIGHT]
> Object identity is a fundamental concept in Python that helps distinguish between different objects, even if they have the same value or type. The `id()` function provides a way to access this unique identifier, which is essential for understanding how Python manages objects in memory.

> [!BEST-PRACTICE]
> Use the `id()` function to debug and understand object references and memory management in Python. It's particularly useful when dealing with mutable objects and function arguments.

> [!WARNING]
> The `id()` function should not be used for comparing objects or as a way to generate unique identifiers for general use. Python provides other mechanisms like `uuid` for such purposes.

## Code Demonstration & Runtime Output

```python
def demonstrate_id():
    # Create some objects
    a = 10
    b = 10
    c = [1, 2, 3]
    d = [1, 2, 3]

    # Print the id of each object
    print(f"ID of a (10): {id(a)}")
    print(f"ID of b (10): {id(b)}")
    print(f"ID of c ([1, 2, 3]): {id(c)}")
    print(f"ID of d ([1, 2, 3]): {id(d)}")

    # Check if a and b refer to the same object
    print(f"a is b: {a is b}")

    # Check if c and d refer to the same object
    print(f"c is d: {c is d}")

    # Modify c and print its id again
    c.append(4)
    print(f"ID of c after modification: {id(c)}")

if __name__ == "__main__":
    demonstrate_id()
```

Output:
```
ID of a (10): 140723440000000
ID of b (10): 140723440000000
ID of c ([1, 2, 3]): 140723440000160
ID of d ([1, 2, 3]): 140723440000224
a is b: True
c is d: False
ID of c after modification: 140723440000160
```

### How this works (Line-by-Line Breakdown)

1. `def demonstrate_id():`: Defines a function named `demonstrate_id` that will contain our demonstration code.
2. `a = 10`: Creates an integer object with the value 10 and assigns it to the variable `a`.
3. `b = 10`: Creates another integer object with the value 10 and assigns it to the variable `b`.
4. `c = [1, 2, 3]`: Creates a list object with the elements 1, 2, and 3 and assigns it to the variable `c`.
5. `d = [1, 2, 3]`: Creates another list object with the same elements and assigns it to the variable `d`.
6. `print(f"ID of a (10): {id(a)}")`: Prints the unique identifier of the object referenced by `a` using the `id()` function.
7. `print(f"ID of b (10): {id(b)}")`: Prints the unique identifier of the object referenced by `b`.
8. `print(f"ID of c ([1, 2, 3]): {id(c)}")`: Prints the unique identifier of the object referenced by `c`.
9. `print(f"ID of d ([1, 2, 3]): {id(d)}")`: Prints the unique identifier of the object referenced by `d`.
10. `print(f"a is b: {a is b}")`: Checks if `a` and `b` refer to the same object using the `is` operator and prints the result.
11. `print(f"c is d: {c is d}")`: Checks if `c` and `d` refer to the same object using the `is` operator and prints the result.
12. `c.append(4)`: Modifies the list object referenced by `c` by appending the value 4 to it.
13. `print(f"ID of c after modification: {id(c)}")`: Prints the unique identifier of the object referenced by `c` after modification.
14. `if __name__ == "__main__":`: Checks if the script is being run as the main program.
15. `demonstrate_id()`: Calls the `demonstrate_id` function to execute the demonstration code.

> [!ADVANCED]
> In CPython, the `id()` function returns the memory address of the object. This is because CPython uses reference counting for memory management, and the memory address is a unique identifier for each object. The `is` operator in Python compares the memory addresses of two objects to determine if they refer to the same object. This is why `a is b` returns `True` in the demonstration code, as both `a` and `b` refer to the same integer object with the value 10. However, `c is d` returns `False` because `c` and `d` refer to different list objects, even though they have the same elements.

> [!QA]
> Q: When should I prefer `is` over `==` for comparing objects?
> A: You should prefer `is` over `==` when you want to check if two variables refer to the same object in memory. The `is` operator compares the memory addresses of the objects, while the `==` operator compares the values of the objects. For example, if you want to check if two variables refer to the same list object, you should use `is`. However, if you want to check if two variables have the same value, regardless of whether they refer to the same object, you should use `==`.

## Summary & Key Takeaways

- Object identity is a unique identifier for each object in Python.
- The `id()` function returns the unique identifier of an object.
- The `is` operator can be used to check if two variables refer to the same object.
- The `==` operator can be used to check if two variables have the same value.
- The `id()` function should not be used for comparing objects or as a way to generate unique identifiers for general use.

### Question #3: Find and fix the bug

Find and fix the bug in the following code snippet:

```python
def modify_list(lst):
    lst = [1, 2, 3]
    lst.append(4)

my_list = [4, 5, 6]
modify_list(my_list)
print(my_list)
```

<details><summary>Show Solution</summary>

The bug in the code snippet is that the `modify_list` function creates a new list object and assigns it to the parameter `lst`, which does not affect the original list object passed to the function. To fix the bug, you should remove the line `lst = [1, 2, 3]` from the `modify_list` function. The corrected code snippet is:

```python
def modify_list(lst):
    lst.append(4)

my_list = [4, 5, 6]
modify_list(my_list)
print(my_list)
```

The output of the corrected code snippet is:

```
[4, 5, 6, 4]
```

Explanation: The `modify_list` function now modifies the original list object passed to it by appending the value 4 to it. The `print(my_list)` statement prints the modified list object.

</details>
