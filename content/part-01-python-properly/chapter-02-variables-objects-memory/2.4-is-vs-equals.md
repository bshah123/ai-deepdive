# 2.4 — Identity vs Equality (is vs ==)

## Opening Motivation & Context

In Python, understanding the difference between identity and equality is crucial for writing efficient and bug-free code. Identity refers to whether two objects are the same object in memory, while equality refers to whether two objects have the same value. This distinction is fundamental in computing and AI, as it affects how data is stored, compared, and manipulated.

## Core Concepts Breakdown

> [!KEY-INSIGHT]
> In Python, `is` checks for identity (whether two variables point to the same object in memory), while `==` checks for equality (whether two objects have the same value).

> [!BEST-PRACTICE]
> Use `is` to check if two variables refer to the same object, and use `==` to check if two objects have the same value. This helps avoid subtle bugs and ensures your code behaves as expected.

> [!WARNING]
> Be cautious when using `is` with mutable objects like lists or dictionaries, as their values can change over time, potentially leading to unexpected behavior.

## Code Demonstration & Runtime Output

```python
def demonstrate_identity_equality() -> None:
    # Create two lists with the same values
    list1: list[int] = [1, 2, 3]
    list2: list[int] = [1, 2, 3]

    # Create two variables pointing to the same list
    list3: list[int] = list1

    # Check identity and equality
    print(f"Identity check (list1 is list2): {list1 is list2}")
    print(f"Equality check (list1 == list2): {list1 == list2}")
    print(f"Identity check (list1 is list3): {list1 is list3}")
    print(f"Equality check (list1 == list3): {list1 == list3}")

    # Modify list1 and check again
    list1.append(4)
    print(f"After modification - Identity check (list1 is list3): {list1 is list3}")
    print(f"After modification - Equality check (list1 == list3): {list1 == list3}")

if __name__ == "__main__":
    demonstrate_identity_equality()
```

Output:
```
Identity check (list1 is list2): False
Equality check (list1 == list2): True
Identity check (list1 is list3): True
Equality check (list1 == list3): True
After modification - Identity check (list1 is list3): True
After modification - Equality check (list1 == list3): True
```

### How this works (Line-by-Line Breakdown)

1. `def demonstrate_identity_equality() -> None:`: Defines a function to demonstrate the difference between identity and equality.
2. `list1: list[int] = [1, 2, 3]`: Creates a list `list1` with values `[1, 2, 3]`.
3. `list2: list[int] = [1, 2, 3]`: Creates another list `list2` with the same values `[1, 2, 3]`.
4. `list3: list[int] = list1`: Creates a variable `list3` that points to the same object as `list1`.
5. `print(f"Identity check (list1 is list2): {list1 is list2}")`: Prints the result of the identity check between `list1` and `list2`. Since they are different objects in memory, this will be `False`.
6. `print(f"Equality check (list1 == list2): {list1 == list2}")`: Prints the result of the equality check between `list1` and `list2`. Since they have the same values, this will be `True`.
7. `print(f"Identity check (list1 is list3): {list1 is list3}")`: Prints the result of the identity check between `list1` and `list3`. Since they point to the same object, this will be `True`.
8. `print(f"Equality check (list1 == list3): {list1 == list3}")`: Prints the result of the equality check between `list1` and `list3`. Since they have the same values, this will be `True`.
9. `list1.append(4)`: Modifies `list1` by appending the value `4`.
10. `print(f"After modification - Identity check (list1 is list3): {list1 is list3}")`: Prints the result of the identity check between `list1` and `list3` after modification. Since they still point to the same object, this will be `True`.
11. `print(f"After modification - Equality check (list1 == list3): {list1 == list3}")`: Prints the result of the equality check between `list1` and `list3` after modification. Since they have the same values, this will be `True`.
12. `if __name__ == "__main__":`: Ensures the function is called only when the script is run directly.
13. `demonstrate_identity_equality()`: Calls the function to demonstrate the difference between identity and equality.

> [!ADVANCED]
> In CPython, the `is` operator checks if two variables have the same memory address, while the `==` operator calls the `__eq__` method of the object, which can be customized to define equality for specific types. This distinction is crucial for understanding how Python handles object comparisons and can impact performance, especially in large-scale applications.

> [!QA]
> Q: When should I prefer `is` over `==`?
> A: You should prefer `is` when you want to check if two variables refer to the same object in memory, such as when working with singletons or mutable objects that you want to ensure are not accidentally modified. Use `==` when you want to check if two objects have the same value, regardless of their memory address.

## Summary & Key Takeaways

- Identity (`is`) checks if two variables point to the same object in memory.
- Equality (`==`) checks if two objects have the same value.
- Use `is` to check for identity and `==` to check for equality.
- Be cautious when using `is` with mutable objects, as their values can change over time.


```
Equality check (a == b): True
Identity check (a is c): True
Equality check (a == c): True
```

### Question #3: Find and fix the bug

```python
def find_bug() -> None:
    list1: list[int] = [1, 2, 3]
    list2: list[int] = [1, 2, 3]

    if list1 is list2:
        print("The lists are the same object.")
    else:
        print("The lists are different objects.")

    list1.append(4)
    print(f"List1: {list1}")
    print(f"List2: {list2}")

if __name__ == "__main__":
    find_bug()
```

<details><summary>Show Solution</summary>

The bug is that the code incorrectly assumes `list1` and `list2` are the same object, which they are not. To fix the bug, you should use `==` to check for equality instead of `is` to check for identity.

Here is the fixed code:

```python
def find_bug() -> None:
    list1: list[int] = [1, 2, 3]
    list2: list[int] = [1, 2, 3]

    if list1 == list2:
        print("The lists have the same values.")
    else:
        print("The lists have different values.")

    list1.append(4)
    print(f"List1: {list1}")
    print(f"List2: {list2}")

if __name__ == "__main__":
    find_bug()
```

The fixed code outputs:
```
The lists have the same values.
List1: [1, 2, 3, 4]
List2: [1, 2, 3]
```

</details>
