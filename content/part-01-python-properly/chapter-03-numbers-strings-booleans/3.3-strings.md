# 3.3 — Strings, Unicode & String Interning

## Opening Motivation & Context

Strings are a fundamental data type in Python, used to represent textual data. Understanding how strings are handled in Python, particularly in the context of Unicode and string interning, is crucial for writing efficient and correct code. Unicode support allows Python to handle text from any language, while string interning can optimize memory usage and performance in certain scenarios.

## Core Concepts Breakdown

### Strings in Python

Strings in Python are sequences of Unicode characters. They are immutable, meaning once created, their contents cannot be changed. This immutability ensures that strings are safe to share between different parts of a program.

> [!KEY-INSIGHT]
> Strings in Python are sequences of Unicode characters and are immutable.

> [!BEST-PRACTICE]
> Use strings to represent textual data, and leverage their immutability to ensure data integrity.

### Unicode Support

Python 3 introduced full Unicode support, allowing strings to contain characters from any language. This is handled through the use of Unicode code points, which are numerical values that represent characters in the Unicode standard.

> [!KEY-INSIGHT]
> Python 3 strings support Unicode, allowing them to contain characters from any language.

> [!BEST-PRACTICE]
> Use Unicode strings to handle text from any language, ensuring compatibility and correctness.

### String Interning

String interning is a method of storing only one copy of each distinct string value, which must be immutable. Python uses a technique called "interning" to optimize memory usage and performance. Interned strings are not just a copy of the original string, but they are actually the same object in memory.

> [!KEY-INSIGHT]
> String interning in Python optimizes memory usage by storing only one copy of each distinct string value.

> [!BEST-PRACTICE]
> Leverage string interning to optimize memory usage and performance, especially when working with a large number of identical strings.

> [!WARNING]
> Be aware that string interning can lead to unexpected behavior when comparing strings, as interned strings are the same object in memory.

## Code Demonstration & Runtime Output

```python
def main() -> None:
    # String creation and Unicode support
    greeting: str = "Hello, 世界!"
    print(f"Greeting: {greeting}")

    # String immutability
    try:
        greeting[0] = "J"
    except TypeError as e:
        print(f"Error: {e}")

    # String interning
    str1: str = "hello"
    str2: str = "hello"
    print(f"str1 is str2: {str1 is str2}")

    # String interning with different objects
    str3: str = "hello world"
    str4: str = "hello " + "world"
    print(f"str3 is str4: {str3 is str4}")

    # String interning with sys.intern
    import sys
    str5: str = sys.intern("hello world")
    str6: str = sys.intern("hello world")
    print(f"str5 is str6: {str5 is str6}")

if __name__ == "__main__":
    main()
```

Output:
```
Greeting: Hello, 世界!
Error: 'str' object does not support item assignment
str1 is str2: True
str3 is str4: False
str5 is str6: True
```

> [!ADVANCED]
> In CPython, strings are implemented as objects with a reference count, type information, and a pointer to the actual string data. The string data is stored in a contiguous block of memory, and the length of the string is stored in the object. When strings are interned, they are stored in a dictionary, and the dictionary keys are the interned strings. This allows for efficient lookup and comparison of interned strings.

> [!QA]
> Q: When should I prefer string interning over creating new string objects?
> A: You should prefer string interning when you need to optimize memory usage and performance, especially when working with a large number of identical strings. However, be aware that string interning can lead to unexpected behavior when comparing strings, as interned strings are the same object in memory.

### Question #3: Find and fix the bug

```python
def main() -> None:
    greeting: str = "Hello, 世界!"
    greeting[0] = "J"
    print(greeting)

if __name__ == "__main__":
    main()
```

<details><summary>Show Solution</summary>

The bug in the code is that it attempts to modify the first character of the `greeting` string, which is immutable and cannot be changed. To fix the bug, you should create a new string with the desired modification:

```python
def main() -> None:
    greeting: str = "Hello, 世界!"
    greeting = "J" + greeting[1:]
    print(greeting)

if __name__ == "__main__":
    main()
```

</details>
