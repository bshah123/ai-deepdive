# 5.2 — Tuple Packing, Unpacking & Pattern Matching

## Opening Motivation & Context

Tuples are a fundamental data structure in Python that allow you to store multiple items in a single variable. They are immutable, meaning their contents cannot be changed after creation, which makes them useful for representing fixed collections of items. Understanding how to pack, unpack, and use pattern matching with tuples is crucial for writing efficient and readable Python code. These concepts are foundational in many areas of computing, including data processing, algorithm implementation, and even in artificial intelligence where fixed-size data structures are often used.

## Core Concepts Breakdown

### Tuple Packing

Tuple packing is the process of assigning multiple values to a single tuple variable. This is done automatically in Python when you separate values with commas.

> [!KEY-INSIGHT]
> Tuple packing allows you to group multiple values into a single tuple, which can be useful for returning multiple values from a function or for passing multiple arguments to a function.

> [!BEST-PRACTICE]
> Use tuple packing when you need to group related values together, such as coordinates (x, y) or RGB color values (r, g, b).

### Tuple Unpacking

Tuple unpacking is the process of extracting the values from a tuple and assigning them to individual variables. This is done by assigning the tuple to a sequence of variables separated by commas.

> [!KEY-INSIGHT]
> Tuple unpacking allows you to easily extract values from a tuple and assign them to separate variables, making your code more readable and concise.

> [!BEST-PRACTICE]
> Use tuple unpacking when you need to work with the individual values of a tuple separately, such as when processing data from a database or when parsing command-line arguments.

### Pattern Matching

Pattern matching is a feature in Python that allows you to match values against patterns and execute code based on the match. This can be particularly useful when working with tuples, as you can match against specific patterns of values.

> [!KEY-INSIGHT]
> Pattern matching with tuples allows you to write more concise and readable code by matching against specific patterns of values, rather than using multiple conditional statements.

> [!BEST-PRACTICE]
> Use pattern matching with tuples when you need to handle different cases based on the values in a tuple, such as when processing different types of events or when implementing a state machine.

## Code Demonstration & Runtime Output

```python
from typing import Tuple, Union

def get_coordinates() -> Tuple[int, int]:
    """Returns a tuple of coordinates (x, y)."""
    return 10, 20

def process_coordinates(coordinates: Tuple[int, int]) -> None:
    """Processes the given coordinates."""
    x, y = coordinates  # Tuple unpacking
    print(f"Processing coordinates: ({x}, {y})")

def match_coordinates(coordinates: Tuple[int, int]) -> str:
    """Matches the given coordinates against specific patterns."""
    match coordinates:
        case (0, 0):
            return "Origin"
        case (x, 0):
            return f"On the x-axis at {x}"
        case (0, y):
            return f"On the y-axis at {y}"
        case (x, y):
            return f"Point at ({x}, {y})"

if __name__ == "__main__":
    # Tuple packing
    coordinates = get_coordinates()
    print(f"Coordinates: {coordinates}")

    # Tuple unpacking
    process_coordinates(coordinates)

    # Pattern matching
    print(match_coordinates(coordinates))
    print(match_coordinates((0, 0)))
    print(match_coordinates((5, 0)))
    print(match_coordinates((0, 5)))
```

```text
Output:

Processing coordinates: (10, 20)
Point at (10, 20)
Origin
On the x-axis at 5
On the y-axis at 5
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: The `Tuple` and `Union` types from the `typing` module are imported to provide type hints for the functions.
2. **`get_coordinates` function**: This function returns a tuple of coordinates (x, y). The return type is specified as `Tuple[int, int]`.
3. **`process_coordinates` function**: This function takes a tuple of coordinates as input and unpacks it into individual variables `x` and `y`. The input type is specified as `Tuple[int, int]`.
4. **`match_coordinates` function**: This function uses pattern matching to match the input tuple against specific patterns. The input type is specified as `Tuple[int, int]`.
5. **`__main__` block**: The code inside this block is executed when the script is run directly.
   - **Tuple packing**: The `get_coordinates` function is called, and the returned tuple is assigned to the `coordinates` variable.
   - **Tuple unpacking**: The `process_coordinates` function is called with the `coordinates` tuple, which is unpacked inside the function.
   - **Pattern matching**: The `match_coordinates` function is called with different tuples to demonstrate pattern matching.

> [!ADVANCED]
> When you pack a tuple, Python creates a new tuple object in memory and stores the references to the packed values. When you unpack a tuple, Python retrieves the references to the values from the tuple and assigns them to the specified variables. Pattern matching with tuples is implemented using the `match` statement, which is compiled into bytecode that performs the pattern matching operations.

> [!QA]
> Q: When should I prefer tuple packing over list packing?
> A: You should prefer tuple packing when you need to create an immutable collection of values, such as coordinates or RGB color values. Tuples are more memory efficient than lists and provide better performance when used as dictionary keys or in sets.
