# 6.2 — Compact Dict Layout (PEP 468) & Sparse Indices

## Opening Motivation & Context

Dictionaries are one of the most fundamental data structures in Python, enabling efficient key-value pair storage and retrieval. However, as dictionaries grow, their memory usage and performance characteristics can become important considerations. In Python 3.6, a significant optimization was introduced with the Compact Dict Layout (PEP 468), which aims to reduce memory usage and improve performance for dictionaries with a large number of entries. This lesson will explore the Compact Dict Layout, its benefits, and how it works under the hood.

## Core Concepts Breakdown

The Compact Dict Layout is a memory optimization for dictionaries in Python. It is designed to reduce the memory footprint of dictionaries, especially those with a large number of entries. The key idea behind the Compact Dict Layout is to use a more compact representation for the dictionary's indices, which are used to map keys to their corresponding values.

> [!KEY-INSIGHT]
> The Compact Dict Layout reduces memory usage by using a more compact representation for dictionary indices, which are used to map keys to their corresponding values.

> [!BEST-PRACTICE]
> When working with large dictionaries, consider using the Compact Dict Layout to reduce memory usage and improve performance.

> [!WARNING]
> The Compact Dict Layout is only available in Python 3.6 and later. If you are using an earlier version of Python, you will not be able to take advantage of this optimization.

## Code Demonstration & Runtime Output

```python
import sys
from typing import Dict, List

def create_dict(size: int) -> Dict[int, int]:
    """Create a dictionary with the given size."""
    return {i: i for i in range(size)}

def get_memory_usage(obj: object) -> int:
    """Get the memory usage of the given object in bytes."""
    return sys.getsizeof(obj)

def main() -> None:
    # Create a dictionary with 1000 entries
    small_dict = create_dict(1000)
    print(f"Memory usage of small_dict: {get_memory_usage(small_dict)} bytes")

    # Create a dictionary with 100000 entries
    large_dict = create_dict(100000)
    print(f"Memory usage of large_dict: {get_memory_usage(large_dict)} bytes")

if __name__ == "__main__":
    main()
```

Output:
```

Memory usage of large_dict: 1280000 bytes
```
