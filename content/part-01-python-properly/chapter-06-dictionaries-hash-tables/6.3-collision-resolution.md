# 6.3 — Collision Resolution: Open Addressing & Probing

## Opening Motivation & Context

Collision resolution is a critical aspect of hash table implementation. When two keys hash to the same index, we need a strategy to handle this collision. Open addressing and probing are two popular collision resolution techniques. In this lesson, we'll explore open addressing and probing, their mechanics, and how to implement them in Python.

## Core Concepts Breakdown

### Open Addressing

Open addressing is a collision resolution technique where each element is stored in the hash table itself. When a collision occurs, the algorithm probes for the next available slot in the hash table.

> [!KEY-INSIGHT]
> Open addressing guarantees that each element has a unique slot in the hash table, ensuring no collisions occur.

> [!BEST-PRACTICE]
> Use open addressing when you need to ensure that each element has a unique slot in the hash table.

> [!WARNING]
> Open addressing can lead to clustering, where multiple elements are stored in the same neighborhood, reducing the efficiency of the hash table.

### Probing

Probing is the process of finding the next available slot in the hash table when a collision occurs. There are several probing techniques, including linear probing, quadratic probing, and double hashing.

> [!KEY-INSIGHT]
> Probing techniques aim to minimize clustering and ensure that the hash table remains efficient.

> [!BEST-PRACTICE]
> Use double hashing for probing to minimize clustering and ensure that the hash table remains efficient.

> [!WARNING]
> Poorly chosen probing techniques can lead to clustering and reduce the efficiency of the hash table.

## Code Demonstration & Runtime Output

```python
from typing import List, Optional, Tuple

class OpenAddressingHashTable:
    def __init__(self, size: int) -> None:
        self.size: int = size
        self.table: List[Optional[Tuple[int, str]]] = [None] * size

    def hash_function(self, key: int) -> int:
        return key % self.size

    def insert(self, key: int, value: str) -> None:
        index: int = self.hash_function(key)
        i: int = 1
        while self.table[index] is not None:
            index = (index + i) % self.size  # Linear probing
            i += 1
        self.table[index] = (key, value)

    def search(self, key: int) -> Optional[str]:
        index: int = self.hash_function(key)
        i: int = 1
        while self.table[index] is not None:
            if self.table[index][0] == key:
                return self.table[index][1]
            index = (index + i) % self.size  # Linear probing
            i += 1
        return None

    def delete(self, key: int) -> None:
        index: int = self.hash_function(key)
        i: int = 1
        while self.table[index] is not None:
            if self.table[index][0] == key:
                self.table[index] = None
                return
            index = (index + i) % self.size  # Linear probing
            i += 1

if __name__ == "__main__":
    hash_table = OpenAddressingHashTable(10)
    hash_table.insert(1, "One")
    hash_table.insert(2, "Two")
    hash_table.insert(11, "Eleven")  # Collision with key 1
    print(hash_table.search(1))  # Output: One
    print(hash_table.search(2))  # Output: Two
    print(hash_table.search(11))  # Output: Eleven
    hash_table.delete(2)
    print(hash_table.search(2))  # Output: None
```

Output:
```
One
Two
Eleven
None
```

## Summary & Key Takeaways

- Open addressing is a collision resolution technique where each element is stored in the hash table itself.
- Probing is the process of finding the next available slot in the hash table when a collision occurs.
- Linear probing is a simple probing technique that can lead to clustering.
- Double hashing is a more efficient probing technique that minimizes clustering.
- Open addressing guarantees that each element has a unique slot in the hash table.
