# 6.4 — Dict Resizing, Load Factor & defaultdict/Counter

## Opening Motivation & Context

Dictionaries are fundamental data structures in Python, enabling efficient key-value pair storage and retrieval. However, their performance characteristics are deeply tied to their underlying implementation, which involves hash tables. Understanding how dictionaries resize, their load factor, and specialized variants like `defaultdict` and `Counter` is crucial for writing efficient and scalable Python code, especially in data-intensive applications and AI systems.

## Core Concepts Breakdown

### Dictionary Resizing and Load Factor

Dictionaries in Python are implemented using hash tables, which provide average-case O(1) time complexity for insertions, deletions, and lookups. However, as the number of elements in the dictionary grows, the hash table may need to be resized to maintain performance. This resizing is triggered when the load factor exceeds a certain threshold.

> [!KEY-INSIGHT]
> The load factor of a dictionary is the ratio of the number of elements in the dictionary to the size of the underlying hash table. When the load factor exceeds a threshold (typically 2/3), the dictionary is resized to a larger hash table, which involves rehashing all existing elements.

> [!BEST-PRACTICE]
> To minimize the overhead of resizing, it's a good practice to initialize dictionaries with a reasonable estimate of the number of elements they will eventually contain. This can be done using the `dict()` constructor with a list of key-value pairs or by using a dictionary comprehension.

> [!WARNING]
> Resizing a dictionary can be an expensive operation, as it involves allocating a new hash table and rehashing all existing elements. Therefore, it's important to avoid frequent resizing by providing an accurate initial size estimate or by using other data structures when the number of elements is highly variable.

### defaultdict and Counter

Python's `collections` module provides two specialized dictionary variants: `defaultdict` and `Counter`. These variants offer additional functionality that can simplify common tasks and improve code readability.

> [!KEY-INSIGHT]
> `defaultdict` is a dictionary subclass that provides a default value for missing keys, eliminating the need for key existence checks. `Counter` is a dictionary subclass designed for counting hashable objects, providing methods for common counting operations.

> [!BEST-PRACTICE]
> Use `defaultdict` when you need to group elements by a key and want to avoid checking if the key exists before appending to its value. Use `Counter` when you need to count the occurrences of elements in an iterable or perform common counting operations.

> [!WARNING]
> While `defaultdict` and `Counter` can simplify code, they may introduce subtle bugs if not used carefully. For example, `defaultdict` will create a new entry for any missing key, which may not be the desired behavior. Similarly, `Counter` will count all elements, including those that may not be relevant to the task at hand.

## Code Demonstration & Runtime Output

```python
import sys
from collections import defaultdict, Counter

def demonstrate_dict_resizing():
    # Initialize a dictionary with a small size to force resizing
    d = dict()
    d.__init__([(i, i) for i in range(5)])

    print(f"Initial dictionary size: {sys.getsizeof(d)} bytes")
    print(f"Initial dictionary load factor: {len(d) / ((1 << d._PyObject_VAR_SIZE) - 1):.2f}")

    # Add elements to trigger resizing
    for i in range(5, 100):
        d[i] = i

    print(f"Dictionary size after resizing: {sys.getsizeof(d)} bytes")
    print(f"Dictionary load factor after resizing: {len(d) / ((1 << d._PyObject_VAR_SIZE) - 1):.2f}")

def demonstrate_defaultdict():
    # Create a defaultdict with a list as the default factory
    dd = defaultdict(list)

    # Group elements by their first letter
    words = ["apple", "banana", "cherry", "date", "elderberry", "fig", "grape"]
    for word in words:
        dd[word[0]].append(word)

    print("Grouped words using defaultdict:")
    for key, value in dd.items():
        print(f"{key}: {value}")

def demonstrate_counter():
    # Create a Counter from an iterable
    c = Counter("abracadabra")

    print("Counter from an iterable:")
    print(c)

    # Common counting operations
    print("\nMost common elements:")
    print(c.most_common(3))

    print("\nTotal count of elements:")
    print(sum(c.values()))

if __name__ == "__main__":
    demonstrate_dict_resizing()
    demonstrate_defaultdict()
    demonstrate_counter()
```

### Question #3: Find and fix the bug

```python
from collections import Counter

def count_elements(iterable):
    c = Counter()
    for element in iterable:
        c[element] += 1
    return c

iterable = "abracadabra"
counts = count_elements(iterable)
print(counts)
```

<details><summary>Show Solution</summary>

The bug in the code is that the `Counter` is not initialized with the iterable, so the counts are not calculated correctly. To fix the bug, the `Counter` should be initialized with the iterable. The fixed code is:

```python
from collections import Counter

def count_elements(iterable):
    c = Counter(iterable)
    return c

iterable = "abracadabra"
counts = count_elements(iterable)
print(counts)
```

The fixed code outputs the correct counts of each element in the iterable:

```
Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})
```

</details>
