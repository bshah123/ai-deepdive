# 7.2 — Argument Passing Mechanics (*args, **kwargs)

## Opening Motivation & Context

In Python, functions are the building blocks of your code. They allow you to encapsulate reusable logic and make your programs more modular and easier to understand. One of the most powerful features of Python functions is their ability to accept arguments. Arguments are the values you pass to a function so that it can perform its task. Understanding how arguments are passed to functions is crucial for writing efficient and bug-free code.

In this lesson, we will explore the mechanics of argument passing in Python, with a special focus on the `*args` and `**kwargs` syntax. These features allow you to pass a variable number of positional and keyword arguments to a function, respectively. We will also discuss the implications of argument passing on the function's behavior and performance.

## Core Concepts Breakdown

### Argument Passing Mechanics

When you call a function in Python, the arguments you pass are bound to the function's parameters. The process of binding arguments to parameters is known as argument passing. Python supports several types of argument passing, including positional arguments, keyword arguments, default arguments, and variable-length arguments.

> [!KEY-INSIGHT]
> In Python, arguments are passed by object reference. This means that when you pass an object to a function, the function receives a reference to the object, not a copy of the object. This can have important implications for mutable objects, such as lists and dictionaries, which can be modified in place.

> [!BEST-PRACTICE]
> When writing functions that accept mutable objects as arguments, it is a good practice to create a copy of the object before modifying it. This can help prevent unintended side effects and make your code more robust.

> [!WARNING]
> Be careful when passing mutable objects as arguments to functions. Since the function receives a reference to the object, any modifications made to the object inside the function will affect the original object outside the function. This can lead to bugs that are difficult to track down.

### Variable-Length Arguments

Python allows you to define functions that accept a variable number of positional and keyword arguments. This is done using the `*args` and `**kwargs` syntax, respectively. The `*args` syntax allows you to pass a variable number of positional arguments to a function, while the `**kwargs` syntax allows you to pass a variable number of keyword arguments.

> [!KEY-INSIGHT]
> The `*args` and `**kwargs` syntax allows you to write functions that are more flexible and can handle a wider range of inputs. This can be particularly useful when working with APIs or libraries that accept a variable number of arguments.

> [!BEST-PRACTICE]
> When using the `*args` and `**kwargs` syntax, it is a good practice to document the expected arguments in the function's docstring. This can help other developers understand how to use the function and make it easier to maintain and update the code.

> [!WARNING]
> Be careful when using the `*args` and `**kwargs` syntax, as it can make your code more difficult to read and understand. It is important to use this syntax judiciously and only when necessary.

## Code Demonstration & Runtime Output

Let's look at a code example that demonstrates the mechanics of argument passing in Python, with a special focus on the `*args` and `**kwargs` syntax.

```python
def greet(*args, **kwargs):
    """
    Greet a person with a variable number of positional and keyword arguments.

    Args:
        *args: A variable number of positional arguments representing the person's name.
        **kwargs: A variable number of keyword arguments representing additional information about the person.

    Returns:
        None
    """
    if args:
        print(f"Hello, {' '.join(args)}!")
    else:
        print("Hello, stranger!")

    if kwargs:
        print("Additional information:")
        for key, value in kwargs.items():
            print(f"{key}: {value}")

if __name__ == "__main__":
    greet("John", "Doe", age=30, occupation="Software Engineer")
    greet()
    greet("Alice", city="New York")
```

Output:
```
Hello, John Doe!
Additional information:
age: 30
occupation: Software Engineer

Hello, stranger!

Hello, Alice!
Additional information:
city: New York
```

3. `if args:` - This line checks if the `args` tuple is not empty. If it is not empty, the function will greet the person using the provided names.
4. `print(f"Hello, {' '.join(args)}!")` - This line prints a greeting message that includes the person's names, which are joined together using the `join` method.
5. `else:` - This line is executed if the `args` tuple is empty. In this case, the function will greet a stranger.

11. `if __name__ == "__main__":` - This line checks if the script is being run as the main program. If it is, the code inside the `if` block will be executed.
12. `greet("John", "Doe", age=30, occupation="Software Engineer")` - This line calls the `greet` function with the positional arguments `"John"` and `"Doe"`, and the keyword arguments `age=30` and `occupation="Software Engineer"`.
13. `greet()` - This line calls the `greet` function without any arguments.
14. `greet("Alice", city="New York")` - This line calls the `greet` function with the positional argument `"Alice"` and the keyword argument `city="New York"`.

> [!ADVANCED]
> When you call a function in Python, the arguments you pass are bound to the function's parameters. The process of binding arguments to parameters is known as argument passing. Python supports several types of argument passing, including positional arguments, keyword arguments, default arguments, and variable-length arguments. The `*args` and `**kwargs` syntax allows you to define functions that accept a variable number of positional and keyword arguments, respectively. When you call a function with variable-length arguments, the positional arguments are collected into a tuple, and the keyword arguments are collected into a dictionary. These objects are then passed to the function as the `args` and `kwargs` parameters, respectively.

> [!QA]
> Q: When should I prefer `*args` over `**kwargs`?
> A: You should prefer `*args` when you need to accept a variable number of positional arguments, and `**kwargs` when you need to accept a variable number of keyword arguments. However, it is important to use these syntaxes judiciously and only when necessary, as they can make your code more difficult to read and understand.

### Question #3: Find and fix the bug

```python
def print_kwargs(**kwargs):
    for key, value in kwargs:
        print(f"{key}: {value}")

print_kwargs(name="John", age=30, occupation="Software Engineer")
```

<details><summary>Show Solution</summary>

The bug in the code is that the `for` loop is trying to iterate over the `kwargs` dictionary directly, which is not the correct way to iterate over the key-value pairs in a dictionary. The correct way to iterate over the key-value pairs in a dictionary is to use the `items` method.

Here is the fixed code:

```python
def print_kwargs(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_kwargs(name="John", age=30, occupation="Software Engineer")
```

The fixed code will output the following:

```
name: John
age: 30
occupation: Software Engineer
```

</details>
