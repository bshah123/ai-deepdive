# 8.2 — Closures & Free Variables (__closure__)

## Opening Motivation & Context

Closures and free variables are fundamental concepts in Python that enable powerful programming patterns. They are particularly useful in functional programming, event handling, and creating decorators. Understanding closures helps you write more concise, modular, and maintainable code.

## Core Concepts Breakdown

### Closures

A closure is a function object that remembers values in enclosing scopes even if they are not present in memory. It's a record that stores a function together with an environment: a mapping associating each free variable of the function with the value or storage location it is bound to.

> [!KEY-INSIGHT]
> Closures allow functions to access variables from their enclosing scope even after the outer function has finished executing.

> [!BEST-PRACTICE]
> Use closures to create functions with "memory" that can maintain state between calls.

> [!WARNING]
> Be cautious with closures that modify mutable objects, as changes can affect subsequent calls unexpectedly.

### Free Variables

Free variables are variables that are not local to the function and not global either. They are variables that are used in the function but defined in an enclosing scope.

> [!KEY-INSIGHT]
> Free variables are the variables that a closure function remembers from its enclosing scope.

> [!BEST-PRACTICE]
> Use free variables to pass configuration or state to a closure function.

> [!WARNING]
> Avoid using mutable free variables in closures, as they can lead to unexpected behavior.

## Code Demonstration & Runtime Output

```python
def outer_function(text: str) -> callable:
    def inner_function() -> None:
        print(text)
    return inner_function

closure = outer_function('Hello, World!')
closure()

def counter() -> callable:
    count = 0
    def increment() -> None:
        nonlocal count
        count += 1
        print(f'Count: {count}')
    return increment

increment_counter = counter()
increment_counter()
increment_counter()

def power(exponent: int) -> callable:
    def power_of(base: int) -> int:
        return base ** exponent
    return power_of

square = power(2)
cube = power(3)
print(f'Square of 5: {square(5)}')
print(f'Cube of 5: {cube(5)}')

if __name__ == '__main__':
    print('Closure demonstration:')
    closure()
    print('\nCounter demonstration:')
    increment_counter()
    increment_counter()
    print('\nPower demonstration:')
    print(f'Square of 5: {square(5)}')
    print(f'Cube of 5: {cube(5)}')
```

> [!ADVANCED]
> Closures in Python are implemented using the `PyFunctionObject` structure in CPython. The `func_closure` attribute of a function object holds a tuple of cell objects, each containing a reference to a free variable. When a closure is created, the free variables are captured in these cell objects, allowing the closure to access them even after the outer function has finished executing.

## Summary & Key Takeaways

- Closures are functions that remember values from their enclosing scope.
- Free variables are variables used in a function but defined in an enclosing scope.
- Closures can maintain state between calls, making them useful for counters and accumulators.
- Be cautious with mutable free variables in closures, as they can lead to unexpected behavior.
- Use closures to create functions with "memory" that can be configured with different parameters.

### Question #3: Find and fix the bug

```python
def counter() -> callable:
    count = 0
    def increment() -> None:
        count += 1
        print(f'Count: {count}')
    return increment

increment_counter = counter()
increment_counter()
increment_counter()
```

<details><summary>Show Solution</summary>
The bug is that `count` is not declared as `nonlocal` in the `increment` function, causing an `UnboundLocalError`. Here's the fixed code:

```python
def counter() -> callable:
    count = 0
    def increment() -> None:
        nonlocal count
        count += 1
        print(f'Count: {count}')
    return increment

increment_counter = counter()
increment_counter()
increment_counter()
```
</details>
