# 8.3 — Function Decorators & functools.wraps

## Opening Motivation & Context

Function decorators are a powerful and expressive feature in Python that allow you to modify or enhance the behavior of functions or methods. They are widely used in frameworks, libraries, and applications to add cross-cutting concerns such as logging, timing, authentication, and more. Understanding decorators is crucial for writing clean, maintainable, and reusable code in Python.

## Core Concepts Breakdown

### Function Decorators

A decorator is a function that takes another function as an argument and extends its behavior without explicitly modifying it. Decorators are applied using the `@decorator` syntax, which is syntactic sugar for `function = decorator(function)`.

> [!KEY-INSIGHT]
> Decorators allow you to separate cross-cutting concerns from the core logic of your functions, leading to cleaner and more modular code.

> [!BEST-PRACTICE]
> Use decorators to add logging, timing, or other cross-cutting concerns to your functions without modifying their source code.

> [!WARNING]
> Decorators can make code harder to debug if not used carefully. Ensure that your decorators preserve the original function's metadata, such as its name and docstring, using `functools.wraps`.

### functools.wraps

The `functools.wraps` decorator is used to preserve the original function's metadata when creating a decorator. Without `functools.wraps`, the decorated function will have the name and docstring of the wrapper function, which can be confusing and make debugging more difficult.

## Code Demonstration & Runtime Output

```python
import functools
import time

def timer(func):
    """Print the runtime of the decorated function."""
    @functools.wraps(func)
    def wrapper_timer(*args, **kwargs):
        start_time = time.perf_counter()    # 1
        value = func(*args, **kwargs)
        end_time = time.perf_counter()
        run_time = end_time - start_time
        print(f"Finished {func.__name__!r} in {run_time:.4f} secs")
        return value
    return wrapper_timer

@timer
def waste_some_time(num_times):
    """Waste some time by sleeping."""
    for _ in range(num_times):
        sum([i**2 for i in range(10000)])

if __name__ == "__main__":
    waste_some_time(1)
    waste_some_time(999)
```

Output:
```
Finished 'waste_some_time' in 0.0012 secs
Finished 'waste_some_time' in 0.1198 secs
```

### How this works (Line-by-Line Breakdown)

1. **`start_time = time.perf_counter()`**: Record the start time using `time.perf_counter()`, which provides the highest resolution timer available.
2. **`value = func(*args, **kwargs)`**: Call the original function with the provided arguments and store the result.
3. **`end_time = time.perf_counter()`**: Record the end time.
4. **`run_time = end_time - start_time`**: Calculate the runtime of the function.
5. **`print(f"Finished {func.__name__!r} in {run_time:.4f} secs")`**: Print the runtime of the function.
6. **`return value`**: Return the result of the original function.
7. **`@functools.wraps(func)`**: Preserve the original function's metadata, such as its name and docstring.
8. **`@timer`**: Apply the `timer` decorator to the `waste_some_time` function.
9. **`if __name__ == "__main__":`**: Ensure that the code is only executed when the script is run directly, not when imported as a module.

> [!ADVANCED]
> The `time.perf_counter()` function is used instead of `time.time()` because it provides a higher resolution timer, which is more suitable for measuring short durations. The `functools.wraps` decorator copies the metadata from the original function to the wrapper function, which is stored in the `__wrapped__` attribute of the wrapper function.

> [!QA]
> Q: When should I prefer using a decorator over a regular function?
> A: Use decorators when you want to add cross-cutting concerns to multiple functions or methods without modifying their source code. Decorators are particularly useful for adding logging, timing, authentication, and other cross-cutting concerns to your code.

## Summary & Key Takeaways

- Decorators are functions that modify or enhance the behavior of other functions.
- Decorators are applied using the `@decorator` syntax.
- The `functools.wraps` decorator is used to preserve the original function's metadata.
- Decorators can be used to add cross-cutting concerns such as logging, timing, and authentication.

<details><summary>Show Solution</summary>
The bug is that the `debug` decorator does not preserve the original function's metadata, such as its name and docstring. To fix this, use the `functools.wraps` decorator:

```python
import functools

def debug(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        value = func(*args, **kwargs)
        print(f"{func.__name__} returned {value}")
        return value
    return wrapper

@debug
def make_greeting(name, age=None):
    if age is None:
        return f"Howdy {name}!"
    else:
        return f"Whoa {name}! {age} already, you are growing up!"

if __name__ == "__main__":
    print(make_greeting("Jane"))
    print(make_greeting("Jane", age=30))
```
</details>
