# 8.4 — Parameterized Decorators & Class Decorators

## Opening Motivation & Context

Decorators in Python are a powerful feature that allows you to modify or extend the behavior of functions or classes without permanently modifying them. They are widely used in frameworks like Django and Flask for tasks such as authentication, logging, and caching. Parameterized decorators take this a step further by allowing you to customize the behavior of the decorator itself. Class decorators, on the other hand, enable you to modify or extend the behavior of classes in a similar manner to function decorators.

Understanding parameterized decorators and class decorators is crucial for writing clean, maintainable, and reusable code. They help in separating concerns, reducing code duplication, and making your code more modular. This lesson will cover the core concepts, provide code demonstrations, and include interactive quizzes to reinforce your understanding.

## Core Concepts Breakdown

### Parameterized Decorators

Parameterized decorators are decorators that accept arguments. They are useful when you need to customize the behavior of the decorator based on the arguments passed to it. The syntax for a parameterized decorator involves an additional layer of nesting.

> [!KEY-INSIGHT]
> A parameterized decorator is a function that returns a decorator function. The outer function accepts the parameters, and the inner function is the actual decorator that modifies the target function.

> [!BEST-PRACTICE]
> Use parameterized decorators when you need to customize the behavior of a decorator based on specific arguments. This makes your decorators more flexible and reusable.

> [!WARNING]
> Forgetting to return the decorator function from the outer function can lead to subtle bugs where the decorator does not behave as expected.

### Class Decorators

Class decorators are similar to function decorators but operate on classes instead of functions. They are used to modify or extend the behavior of classes. Class decorators are applied using the `@decorator` syntax just like function decorators.

> [!KEY-INSIGHT]
> A class decorator is a function that takes a class as an argument and returns a modified class. It can be used to add methods, attributes, or modify existing ones.

> [!BEST-PRACTICE]
> Use class decorators to add common functionality to multiple classes, such as logging, authentication, or caching. This helps in reducing code duplication and makes your code more modular.

> [!WARNING]
> Modifying the class in place within the decorator can lead to unexpected behavior, especially if the same class is decorated multiple times. It is generally better to create a new class and return it.

## Code Demonstration & Runtime Output

```python
from functools import wraps
from typing import Callable, Any, Type

def repeat(num_times: int) -> Callable:
    def decorator_repeat(func: Callable) -> Callable:
        @wraps(func)
        def wrapper(*args: Any, **kwargs: Any) -> Any:
            for _ in range(num_times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator_repeat

def debug(cls: Type) -> Type:
    class DebuggedClass(cls):
        def __getattribute__(self, name: str) -> Any:
            print(f"Accessing attribute: {name}")
            return super().__getattribute__(name)

        def __setattr__(self, name: str, value: Any) -> None:
            print(f"Setting attribute: {name} to {value}")
            super().__setattr__(name, value)
    return DebuggedClass

@repeat(num_times=3)
def greet(name: str) -> str:
    print(f"Hello, {name}!")
    return f"Hello, {name}!"

@debug
class Person:
    def __init__(self, name: str, age: int) -> None:
        self.name = name
        self.age = age

    def greet(self) -> str:
        return f"Hello, my name is {self.name} and I am {self.age} years old."

if __name__ == "__main__":
    greet("Alice")
    print("\n")

    person = Person("Bob", 30)
    print(person.greet())
```

Output:
```
Hello, Alice!
Hello, Alice!
Hello, Alice!

Accessing attribute: name
Accessing attribute: age
Setting attribute: name to Bob
Setting attribute: age to 30
Accessing attribute: greet
Accessing attribute: name
Accessing attribute: age
Hello, my name is Bob and I am 30 years old.
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: The `functools` module is imported to use the `wraps` decorator, which helps in preserving the metadata of the original function. The `Callable`, `Any`, and `Type` types are imported from the `typing` module for type hints.
2. **Parameterized Decorator `repeat`**: The `repeat` function is a parameterized decorator that takes an integer `num_times` as an argument. It returns the `decorator_repeat` function, which is the actual decorator.
3. **Decorator `decorator_repeat`**: The `decorator_repeat` function takes a function `func` as an argument and returns the `wrapper` function. The `wrapper` function calls `func` `num_times` times and returns the result of the last call.
4. **Class Decorator `debug`**: The `debug` function is a class decorator that takes a class `cls` as an argument and returns a new class `DebuggedClass` that inherits from `cls`. The `DebuggedClass` overrides the `__getattribute__` and `__setattr__` methods to print messages when attributes are accessed or set.
5. **Function `greet`**: The `greet` function is decorated with `@repeat(num_times=3)`, which means it will be called three times when invoked.
6. **Class `Person`**: The `Person` class is decorated with `@debug`, which means it will print messages when attributes are accessed or set.
7. **Main Block**: The `greet` function is called with the argument "Alice", and the `Person` class is instantiated with the arguments "Bob" and 30. The `greet` method of the `Person` instance is called and printed.

> [!ADVANCED]
> The `repeat` decorator uses the `functools.wraps` decorator to preserve the metadata of the original function. The `debug` class decorator creates a new class that inherits from the original class and overrides the `__getattribute__` and `__setattr__` methods to add debugging functionality. The `dis` module can be used to inspect the bytecode of the decorated functions and classes for a deeper understanding of how they work.

## Summary & Key Takeaways

- Parameterized decorators are functions that return decorator functions and allow customization based on arguments.
- Class decorators modify or extend the behavior of classes and are applied using the `@decorator` syntax.
- Use parameterized decorators to customize decorator behavior and class decorators to add common functionality to multiple classes.
- Be cautious when modifying classes in place within class decorators to avoid unexpected behavior.

<details><summary>Show Solution</summary>

The bug is that the `__getattribute__` and `__setattr__` methods are not properly defined within the `debug` decorator. Here is the fixed code:

```python
def debug(cls):
    class DebuggedClass(cls):
        def __getattribute__(self, name):
            print(f"Accessing attribute: {name}")
            return super().__getattribute__(name)

        def __setattr__(self, name, value):
            print(f"Setting attribute: {name} to {value}")
            super().__setattr__(name, value)
    return DebuggedClass

@debug
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        return f"Hello, my name is {self.name} and I am {self.age} years old."

if __name__ == "__main__":
    person = Person("Alice", 30)
    print(person.greet())
```

</details>
