# 9.1 — The Iteration Protocol (__iter__ and __next__)

## Opening Motivation & Context

In Python, iteration is a fundamental concept that allows you to traverse through elements of a collection, such as lists, tuples, or dictionaries. The iteration protocol is a set of rules that objects must follow to be iterable. This protocol is implemented using two special methods: `__iter__` and `__next__`. Understanding these methods is crucial for writing efficient and clean code, especially when working with custom data structures or implementing your own iterators.

## Core Concepts Breakdown

### The Iteration Protocol

The iteration protocol consists of two main methods:

1. `__iter__`: This method returns an iterator object. An iterator is an object that implements the `__next__` method, which is used to retrieve the next item from the collection.
2. `__next__`: This method returns the next item from the collection. When there are no more items to return, it raises the `StopIteration` exception.

> [!KEY-INSIGHT]
> The iteration protocol allows you to create custom iterable objects by implementing the `__iter__` and `__next__` methods. This is a powerful feature that enables you to define your own iteration behavior for any object.

> [!BEST-PRACTICE]
> When implementing custom iterators, always remember to raise the `StopIteration` exception when there are no more items to iterate over. This signals to the interpreter that the iteration is complete.

> [!WARNING]
> Forgetting to raise the `StopIteration` exception in your `__next__` method will result in an infinite loop, as the interpreter will keep calling `__next__` until it encounters an exception.

## Code Demonstration & Runtime Output

```python
from typing import Iterator, Any

class CountUpTo:
    def __init__(self, max_num: int) -> None:
        self.max_num = max_num
        self.current = 0

    def __iter__(self) -> Iterator[int]:
        return self

    def __next__(self) -> int:
        if self.current < self.max_num:
            self.current += 1
            return self.current
        else:
            raise StopIteration

if __name__ == "__main__":
    counter = CountUpTo(5)
    for num in counter:
        print(num)
```

Output:
```
1
2
3
4
5
```

### How this works (Line-by-Line Breakdown)

1. `from typing import Iterator, Any`: Import the `Iterator` type from the `typing` module for type hints.
2. `class CountUpTo:`: Define a new class `CountUpTo` that will implement the iteration protocol.
3. `def __init__(self, max_num: int) -> None:`: The constructor method that initializes the `max_num` and `current` attributes.
4. `def __iter__(self) -> Iterator[int]:`: The `__iter__` method returns the iterator object itself, which is `self` in this case.
5. `def __next__(self) -> int:`: The `__next__` method returns the next item in the iteration.
6. `if self.current < self.max_num:`: Check if the current number is less than the maximum number.
7. `self.current += 1`: Increment the current number.
8. `return self.current`: Return the current number.
9. `else: raise StopIteration`: Raise the `StopIteration` exception when there are no more items to iterate over.
10. `if __name__ == "__main__":`: The main block that demonstrates the usage of the `CountUpTo` class.
11. `counter = CountUpTo(5)`: Create an instance of the `CountUpTo` class with a maximum number of 5.
12. `for num in counter: print(num)`: Iterate over the `counter` object and print each number.

> [!ADVANCED]
> The `__iter__` method returns an iterator object, which is an object that implements the `__next__` method. In this case, the `CountUpTo` class itself is the iterator object. The `__next__` method is called repeatedly to retrieve the next item in the iteration until the `StopIteration` exception is raised.

> [!QA]
> Q: When should I prefer using a generator function over implementing the iteration protocol with `__iter__` and `__next__`?
> A: Generator functions are a more concise and readable way to create iterators. They automatically handle the iteration protocol and the `StopIteration` exception. Use generator functions when you need a simple iterator, and implement the iteration protocol when you need more control over the iteration behavior.

## Summary & Key Takeaways

- The iteration protocol consists of the `__iter__` and `__next__` methods.
- The `__iter__` method returns an iterator object.
- The `__next__` method returns the next item in the iteration and raises `StopIteration` when there are no more items.
- Custom iterators can be created by implementing the iteration protocol.
- Generator functions provide a more concise way to create iterators.
