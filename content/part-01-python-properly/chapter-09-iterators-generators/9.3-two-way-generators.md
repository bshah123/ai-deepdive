# 9.3 — Two-Way Generators: send(), throw(), and close()

## Opening Motivation & Context

In Python, generators are a powerful tool for creating iterators. They allow you to iterate over a set of values without having to create a full list in memory, which can be particularly useful for large or infinite sequences. However, generators are not just one-way streets; they can also receive values and handle exceptions, making them two-way communication channels. This lesson will explore the `send()`, `throw()`, and `close()` methods, which enable this two-way communication.

## Core Concepts Breakdown

### [!KEY-INSIGHT]
Generators can act as coroutines, allowing them to receive values and handle exceptions. This makes them a versatile tool for implementing cooperative multitasking and other advanced patterns.

### [!BEST-PRACTICE]
When using `send()`, always handle the initial `None` value that the generator yields before the first `send()` call. This is because the generator starts by yielding its first value, and `send()` is used to send values to the generator after it has yielded.

### [!WARNING]
Using `throw()` to send an exception to a generator can lead to unexpected behavior if the generator does not handle the exception. Always ensure that the generator is prepared to handle the exceptions you might throw.

## Code Demonstration & Runtime Output

```python
import sys

def two_way_generator():
    try:
        value = yield "Initial value"
        while True:
            print(f"Received: {value}")
            value = yield f"Processed: {value}"
    except ValueError as e:
        print(f"Caught ValueError: {e}")
    finally:
        print("Generator closing")

def main():
    gen = two_way_generator()

    # Start the generator and get the initial value
    initial_value = next(gen)
    print(f"Initial value: {initial_value}")

    # Send values to the generator
    print(gen.send("First message"))
    print(gen.send("Second message"))

    # Throw an exception to the generator
    try:
        gen.throw(ValueError("Something went wrong"))
    except StopIteration:
        print("Generator stopped")

    # Close the generator
    gen.close()

if __name__ == "__main__":
    main()
```

Output:
```
Initial value: Initial value
Received: First message
Processed: First message
Received: Second message
Processed: Second message
Caught ValueError: Something went wrong
Generator closing
Generator stopped
```

### How this works (Line-by-Line Breakdown)

2. **def two_way_generator()**: This line defines a generator function named `two_way_generator`.
3. **try**: This line starts a try block to handle exceptions that might be thrown to the generator.
4. **value = yield "Initial value"**: This line yields the initial value "Initial value" and assigns the value sent to the generator to the variable `value`.
5. **while True**: This line starts an infinite loop that will continue until the generator is closed or an exception is thrown.
6. **print(f"Received: {value}")**: This line prints the value received from the generator.
7. **value = yield f"Processed: {value}"**: This line yields a processed version of the received value and assigns the next value sent to the generator to the variable `value`.
8. **except ValueError as e**: This line catches a `ValueError` exception and assigns it to the variable `e`.
9. **print(f"Caught ValueError: {e}")**: This line prints the caught `ValueError`.
10. **finally**: This line starts a finally block that will execute regardless of whether an exception was thrown.
11. **print("Generator closing")**: This line prints a message indicating that the generator is closing.
12. **def main()**: This line defines the `main` function, which will be executed when the script is run.
13. **gen = two_way_generator()**: This line creates an instance of the `two_way_generator` generator.
14. **initial_value = next(gen)**: This line starts the generator and gets the initial value.
15. **print(f"Initial value: {initial_value}")**: This line prints the initial value.
16. **print(gen.send("First message"))**: This line sends the string "First message" to the generator and prints the yielded value.
17. **print(gen.send("Second message"))**: This line sends the string "Second message" to the generator and prints the yielded value.
18. **try**: This line starts a try block to handle the `StopIteration` exception that will be raised when the generator is closed.
19. **gen.throw(ValueError("Something went wrong"))**: This line throws a `ValueError` to the generator.
20. **except StopIteration**: This line catches the `StopIteration` exception that is raised when the generator is closed.
21. **print("Generator stopped")**: This line prints a message indicating that the generator has stopped.
22. **gen.close()**: This line closes the generator.
23. **if __name__ == "__main__"**: This line checks if the script is being run directly.
24. **main()**: This line calls the `main` function.

## Summary & Key Takeaways

- Generators can act as coroutines, allowing them to receive values and handle exceptions.
- The `send()` method is used to send values to a generator and get the next yielded value.
- The `throw()` method is used to throw an exception to a generator.
- The `close()` method is used to close a generator.
- Always handle the initial `None` value that the generator yields before the first `send()` call.
- Ensure that the generator is prepared to handle the exceptions you might throw.

### Question #3: Find and fix the bug

```python
def buggy_generator():
    try:
        value = yield "Start"
        while True:
            value = yield f"Received: {value}"
    except ValueError:
        print("Caught ValueError")

def main():
    gen = buggy_generator()
    print(next(gen))
    print(gen.send("First"))
    gen.throw(ValueError("Oops"))
    print(gen.send("Second"))

if __name__ == "__main__":
    main()
```

<details><summary>Show Solution</summary>

The bug is that the generator does not handle the `StopIteration` exception that is raised when the generator is closed after throwing the `ValueError`. Here is the fixed code:

```python
def buggy_generator():
    try:
        value = yield "Start"
        while True:
            value = yield f"Received: {value}"
    except ValueError:
        print("Caught ValueError")

def main():
    gen = buggy_generator()
    print(next(gen))
    print(gen.send("First"))
    try:
        gen.throw(ValueError("Oops"))
    except StopIteration:
        pass
    print(gen.send("Second"))

if __name__ == "__main__":
    main()
```

</details>
