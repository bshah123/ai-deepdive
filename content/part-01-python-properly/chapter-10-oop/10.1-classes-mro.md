# 10.1 — Classes, Instances & __dict__ vs __slots__

## Opening Motivation & Context

In Python, object-oriented programming (OOP) is a fundamental paradigm that allows you to structure your code in a way that models real-world entities and their interactions. Classes and instances are the building blocks of OOP in Python. Understanding how they work and the differences between `__dict__` and `__slots__` is crucial for writing efficient and maintainable code, especially in performance-critical applications or when working with large datasets.

## Core Concepts Breakdown

### Classes and Instances

> [!KEY-INSIGHT]
> A class is a blueprint for creating objects (instances), and an instance is a concrete occurrence of a class. Classes define attributes and methods that instances will have.

> [!BEST-PRACTICE]
> Use classes to model real-world entities and their behaviors. This makes your code more organized, reusable, and easier to understand.

> [!WARNING]
> Avoid creating too many instances of a class if it's not necessary, as this can lead to increased memory usage.

### `__dict__` vs `__slots__`

> [!KEY-INSIGHT]
> `__dict__` is a dictionary that stores an object's writable attributes, while `__slots__` is a sequence of strings that specifies the attributes an instance of a class can have. Using `__slots__` can save memory and improve attribute access speed.

> [!BEST-PRACTICE]
> Use `__slots__` in classes where you know the set of attributes in advance and want to save memory or improve performance.

> [!WARNING]
> Avoid using `__slots__` in classes where you need dynamic attribute creation, as it will prevent the creation of `__dict__` and `__weakref__`.

## Code Demonstration & Runtime Output

```python
class Person:
    __slots__ = ['name', 'age']

    def __init__(self, name: str, age: int) -> None:
        self.name = name
        self.age = age

    def introduce(self) -> None:
        print(f"Hi, I'm {self.name} and I'm {self.age} years old.")

class DynamicPerson:
    def __init__(self, name: str, age: int) -> None:
        self.name = name
        self.age = age

    def introduce(self) -> None:
        print(f"Hi, I'm {self.name} and I'm {self.age} years old.")

if __name__ == "__main__":
    # Create instances of Person and DynamicPerson
    person = Person("Alice", 30)
    dynamic_person = DynamicPerson("Bob", 25)

    # Introduce the persons
    person.introduce()
    dynamic_person.introduce()

    # Access __dict__ and __slots__
    print("Person __dict__:", hasattr(person, '__dict__'))
    print("DynamicPerson __dict__:", hasattr(dynamic_person, '__dict__'))
    print("Person __slots__:", hasattr(person, '__slots__'))
    print("DynamicPerson __slots__:", hasattr(dynamic_person, '__slots__'))

    # Try to add a new attribute to Person
    try:
        person.address = "123 Main St"
    except AttributeError as e:
        print("Error:", e)

    # Add a new attribute to DynamicPerson
    dynamic_person.address = "456 Oak Ave"
    print("DynamicPerson address:", dynamic_person.address)
```

```text
Output:
Hi, I'm Alice and I'm 30 years old.
Hi, I'm Bob and I'm 25 years old.
Person __dict__: False
DynamicPerson __dict__: True
Person __slots__: True
DynamicPerson __slots__: False
Error: 'Person' object has no attribute 'address'
DynamicPerson address: 456 Oak Ave
```

> [!ADVANCED]
> When you define a class with `__slots__`, Python uses a more memory-efficient structure for instances of that class. Instead of creating a `__dict__` for each instance, Python uses a fixed-size array to store the attributes specified in `__slots__`. This can save memory and improve attribute access speed, especially when you have a large number of instances. However, using `__slots__` prevents the creation of `__dict__` and `__weakref__`, which can be problematic if you need dynamic attribute creation or weak references.

> [!QA]
> Q: When should I prefer `__slots__` over `__dict__`?
> A: You should prefer `__slots__` when you know the set of attributes in advance and want to save memory or improve performance. However, you should avoid using `__slots__` in classes where you need dynamic attribute creation, as it will prevent the creation of `__dict__` and `__weakref__`.

## Summary & Key Takeaways

- Classes are blueprints for creating objects (instances).

- `__slots__` is a sequence of strings that specifies the attributes an instance of a class can have.
- Using `__slots__` can save memory and improve attribute access speed.
- Avoid using `__slots__` in classes where you need dynamic attribute creation.

### Question #3: Find and fix the bug

```python
class Book:
    __slots__ = ['title', 'author']

    def __init__(self, title: str, author: str) -> None:
        self.title = title
        self.author = author

if __name__ == "__main__":
    book = Book("The Great Gatsby", "F. Scott Fitzgerald")
    book.publisher = "Scribner"
    print("Book publisher:", book.publisher)
```

<details><summary>Show Solution</summary>

The bug in the code is that it tries to add a new attribute `publisher` to an instance of `Book`, which has `__slots__` defined. This will raise an `AttributeError`. To fix the bug, you should either remove the `__slots__` definition or add `publisher` to the `__slots__` list.

```python
class Book:
    __slots__ = ['title', 'author', 'publisher']

    def __init__(self, title: str, author: str) -> None:
        self.title = title
        self.author = author

if __name__ == "__main__":
    book = Book("The Great Gatsby", "F. Scott Fitzgerald")
    book.publisher = "Scribner"
    print("Book publisher:", book.publisher)
```

</details>
