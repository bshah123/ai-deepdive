# 10.4 — Property Descriptors (__get__, __set__, __delete__)

## Opening Motivation & Context

Property descriptors are a powerful feature in Python that allow you to customize the behavior of attribute access. They are used to create managed attributes, where you can add logic to get, set, or delete an attribute. This is particularly useful when you want to enforce constraints, validate data, or perform additional actions when an attribute is accessed or modified.

Property descriptors are the backbone of properties in Python, which we discussed in the previous lesson. They are also used extensively in frameworks like Django and SQLAlchemy to manage database fields and relationships.

## Core Concepts Breakdown

Property descriptors are implemented using three special methods: `__get__`, `__set__`, and `__delete__`. These methods are called when an attribute is accessed, modified, or deleted, respectively. The `__get__` method is called when the attribute is accessed, the `__set__` method is called when the attribute is modified, and the `__delete__` method is called when the attribute is deleted.

> [!KEY-INSIGHT]
> Property descriptors allow you to customize the behavior of attribute access, making it possible to enforce constraints, validate data, and perform additional actions when an attribute is accessed or modified.

> [!BEST-PRACTICE]
> Use property descriptors to create managed attributes that enforce constraints and validate data. This helps ensure that your objects maintain a consistent state and prevents invalid data from being stored.

> [!WARNING]
> Property descriptors can make your code more complex and harder to understand. Use them judiciously and only when necessary. Overuse of property descriptors can lead to spaghetti code that is difficult to maintain.

## Code Demonstration & Runtime Output

```python
class ManagedAttribute:
    def __init__(self, name: str) -> None:
        self.name = name

    def __get__(self, obj, objtype=None) -> int:
        if obj is None:
            return self
        value = obj.__dict__.get(self.name, 0)
        print(f"Getting {self.name} with value {value}")
        return value

    def __set__(self, obj, value: int) -> None:
        if not isinstance(value, int):
            raise ValueError(f"{self.name} must be an integer")
        if value < 0:
            raise ValueError(f"{self.name} must be non-negative")
        print(f"Setting {self.name} to {value}")
        obj.__dict__[self.name] = value

    def __delete__(self, obj) -> None:
        print(f"Deleting {self.name}")
        del obj.__dict__[self.name]

class MyClass:
    x = ManagedAttribute('x')
    y = ManagedAttribute('y')

    def __init__(self, x: int, y: int) -> None:
        self.x = x
        self.y = y

if __name__ == "__main__":
    obj = MyClass(10, 20)
    print(f"Initial values: x={obj.x}, y={obj.y}")

    obj.x = 30
    print(f"Updated x: {obj.x}")

    try:
        obj.x = -5
    except ValueError as e:
        print(f"Error: {e}")

    try:
        obj.x = "hello"
    except ValueError as e:
        print(f"Error: {e}")

    del obj.y
    print(f"After deleting y: x={obj.x}, y={getattr(obj, 'y', 'deleted')}")
```

Output:
```

Setting y to 20
Initial values: x=10, y=20
Setting x to 30
Updated x: 30
Error: x must be non-negative
Error: x must be an integer
Deleting y
After deleting y: x=30, y=deleted
```

## How this works (Line-by-Line Breakdown)

1. **ManagedAttribute Class**: This class implements the property descriptor. It has three special methods: `__get__`, `__set__`, and `__delete__`.
2. **__init__ Method**: The constructor initializes the name of the attribute that the descriptor will manage.
3. **__get__ Method**: This method is called when the attribute is accessed. It retrieves the value of the attribute from the object's `__dict__` dictionary. If the attribute is not found, it returns 0.
4. **__set__ Method**: This method is called when the attribute is modified. It validates the value to ensure it is an integer and non-negative. If the validation fails, it raises a `ValueError`.
5. **__delete__ Method**: This method is called when the attribute is deleted. It removes the attribute from the object's `__dict__` dictionary.
6. **MyClass**: This class uses the `ManagedAttribute` descriptor to manage the `x` and `y` attributes.
7. **__init__ Method**: The constructor initializes the `x` and `y` attributes using the descriptor.
8. **Main Block**: The main block demonstrates the usage of the `ManagedAttribute` descriptor. It creates an instance of `MyClass`, accesses and modifies the attributes, and handles exceptions when invalid values are provided.

## Summary & Key Takeaways

- Property descriptors allow you to customize the behavior of attribute access.
- They are implemented using the `__get__`, `__set__`, and `__delete__` methods.
- Property descriptors are useful for enforcing constraints, validating data, and performing additional actions when an attribute is accessed or modified.
- Use property descriptors judiciously and only when necessary.
- Property descriptors can make your code more complex and harder to understand.
