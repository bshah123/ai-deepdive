# 10.5 — The Descriptor Protocol, Attribute Lookup Precedence & Metaclasses

## Opening Motivation & Context

In Python, everything is an object, and understanding how attributes are accessed and managed is crucial for writing efficient and maintainable code. The Descriptor Protocol, Attribute Lookup Precedence, and Metaclasses are advanced concepts that provide powerful tools for controlling attribute access and object creation. These concepts are foundational for building frameworks, libraries, and complex systems in Python.

## Core Concepts Breakdown

### The Descriptor Protocol

The Descriptor Protocol is a set of rules that define how attribute access is managed. Objects that implement the descriptor protocol can customize the behavior of attribute access. The protocol includes the following methods:

- `__get__(self, instance, owner)`: Called when the attribute is accessed.
- `__set__(self, instance, value)`: Called when the attribute is assigned a value.
- `__delete__(self, instance)`: Called when the attribute is deleted.

> [!KEY-INSIGHT]
> Descriptors allow you to create managed attributes, which can be used to enforce constraints, validate data, and implement lazy evaluation.

> [!BEST-PRACTICE]
> Use descriptors to encapsulate attribute access logic, making your code more modular and maintainable.

> [!WARNING]
> Descriptors can be tricky to implement correctly, especially when dealing with inheritance and multiple descriptors.

### Attribute Lookup Precedence

Attribute lookup in Python follows a specific precedence order. When you access an attribute, Python searches for it in the following order:

1. **Instance attributes**: Attributes defined in the instance itself.
2. **Class attributes**: Attributes defined in the class.
3. **Parent class attributes**: Attributes defined in parent classes.
4. **Descriptors**: If the attribute is a descriptor, its `__get__` method is called.
5. **`__getattr__` method**: If the attribute is not found, the `__getattr__` method is called.

> [!KEY-INSIGHT]
> Understanding attribute lookup precedence is essential for debugging and optimizing attribute access in Python.

> [!BEST-PRACTICE]
> Use instance attributes for mutable data and class attributes for immutable data to avoid unexpected behavior.

> [!WARNING]
> Overriding `__getattr__` can lead to performance issues if not used carefully, as it is called for every attribute lookup that fails.

### Metaclasses

Metaclasses are classes that create other classes. They allow you to customize the creation of classes, enabling you to implement advanced patterns such as singleton, interface checking, and more. Metaclasses are specified using the `__metaclass__` attribute or by inheriting from a metaclass.

> [!KEY-INSIGHT]
> Metaclasses provide a way to intercept and modify class creation, allowing for powerful and flexible class customization.

> [!BEST-PRACTICE]
> Use metaclasses sparingly, as they can make code harder to understand and maintain. Prefer using class decorators or inheritance for simpler customizations.

> [!WARNING]
> Metaclasses can lead to complex and hard-to-debug code if not used carefully. Ensure you have a good understanding of Python's class creation process before using metaclasses.

## Code Demonstration & Runtime Output

```python
from typing import Any, Optional

class Descriptor:
    def __get__(self, instance: Any, owner: Any) -> str:
        return f"Descriptor value for {instance}"

    def __set__(self, instance: Any, value: Any) -> None:
        print(f"Setting descriptor value for {instance} to {value}")

class MyClass:
    descriptor = Descriptor()
    class_attr = "Class attribute"

    def __init__(self, value: str) -> None:
        self.instance_attr = value

    def __getattr__(self, name: str) -> str:
        return f"Dynamic attribute {name}"

def main() -> None:
    obj = MyClass("Instance attribute")
    print(obj.descriptor)  # Descriptor __get__
    obj.descriptor = "New value"  # Descriptor __set__
    print(obj.instance_attr)  # Instance attribute
    print(obj.class_attr)  # Class attribute
    print(obj.non_existent_attr)  # __getattr__

if __name__ == "__main__":
    main()
```

Output:
```
Descriptor value for <__main__.MyClass object at 0x7f8c1c0b3d30>
Setting descriptor value for <__main__.MyClass object at 0x7f8c1c0b3d30> to New value
Instance attribute
Class attribute
Dynamic attribute non_existent_attr
```

### How this works (Line-by-Line Breakdown)

1. **Descriptor Class**: The `Descriptor` class implements the descriptor protocol with `__get__` and `__set__` methods.
2. **MyClass**: The `MyClass` class includes a descriptor instance, a class attribute, and an instance attribute.
3. **`__init__` Method**: Initializes the instance attribute `instance_attr`.
4. **`__getattr__` Method**: Called when an attribute is not found, returning a dynamic attribute string.
5. **main Function**: Demonstrates attribute lookup precedence by accessing the descriptor, instance attribute, class attribute, and a non-existent attribute.

## Summary & Key Takeaways

- The Descriptor Protocol allows customization of attribute access.
- Attribute lookup precedence determines the order in which attributes are searched.
- Metaclasses provide advanced control over class creation.
- Use descriptors for managed attributes, understand attribute lookup precedence for debugging, and use metaclasses sparingly for complex customizations.

### Question #3: Find and Fix the Bug

```python
class Descriptor:
    def __get__(self, instance, owner):
        return "Descriptor value"

class MyClass:
    descriptor = Descriptor()

    def __getattr__(self, name):
        return "Dynamic attribute"

obj = MyClass()
print(obj.descriptor)
print(obj.non_existent_attr)
```

The code above has a bug. What is it, and how can you fix it?

<details><summary>Show Solution</summary>

The bug is that the `__getattr__` method is not called for the `descriptor` attribute because it is a descriptor. To fix this, you can modify the `Descriptor` class to handle the attribute lookup:

```python
class Descriptor:
    def __get__(self, instance, owner):
        if instance is None:
            return self
        return "Descriptor value"

class MyClass:
    descriptor = Descriptor()

    def __getattr__(self, name):
        return "Dynamic attribute"

obj = MyClass()
print(obj.descriptor)
print(obj.non_existent_attr)
```

Output:
```
Descriptor value
Dynamic attribute
```

</details>
