# 11.1 — Magic Methods: __getitem__, __len__, __call__

## Opening Motivation & Context

Magic methods, also known as dunder methods (double underscore methods), are special methods in Python that allow you to define how your objects behave with built-in operations. They are the backbone of Python's data model, enabling you to create objects that interact seamlessly with Python's syntax and built-in functions. Understanding magic methods is crucial for writing clean, Pythonic code and for creating classes that behave like built-in types.

In this lesson, we will explore three essential magic methods: `__getitem__`, `__len__`, and `__call__`. These methods allow you to define how your objects are accessed, how their length is determined, and how they are called, respectively. Mastering these methods will enable you to create more flexible and intuitive classes.

## Core Concepts Breakdown

### `__getitem__`

The `__getitem__` method allows you to define how your objects are accessed using the square bracket notation (e.g., `obj[key]`). This is particularly useful for creating container-like objects, such as lists, dictionaries, or custom data structures.

> [!KEY-INSIGHT]
> The `__getitem__` method enables your objects to behave like containers, allowing you to use Python's built-in indexing and slicing operations.

> [!BEST-PRACTICE]
> Always implement `__getitem__` when your class represents a container or a collection of items. This makes your class more intuitive and easier to use.

> [!WARNING]
> If you implement `__getitem__`, you should also consider implementing `__setitem__` and `__delitem__` to support item assignment and deletion, respectively.

### `__len__`

The `__len__` method allows you to define how the length of your object is determined when the built-in `len()` function is called on it. This is essential for any class that represents a collection of items.

> [!KEY-INSIGHT]
> The `__len__` method provides a way to define the length of your object, making it compatible with Python's built-in functions and operations.

> [!BEST-PRACTICE]
> Implement `__len__` for any class that represents a collection of items. This makes your class more intuitive and easier to use.

> [!WARNING]
> Ensure that the `__len__` method returns a non-negative integer. Returning a negative value or a non-integer type will raise a `TypeError`.

### `__call__`

The `__call__` method allows you to define how your objects are called like functions. This is useful for creating callable objects, such as decorators, function wrappers, or custom function-like objects.

> [!KEY-INSIGHT]
> The `__call__` method enables your objects to behave like functions, allowing you to create more flexible and reusable code.

> [!BEST-PRACTICE]
> Implement `__call__` when your class needs to be callable, such as for decorators or function wrappers. This makes your class more intuitive and easier to use.

> [!WARNING]
> Ensure that the `__call__` method returns a value if the callable object is expected to return a value. Omitting the return statement will result in `None` being returned.

## Code Demonstration & Runtime Output

Let's create a custom class `Vector` that demonstrates the use of `__getitem__`, `__len__`, and `__call__`.

```python
from typing import List, Union

class Vector:
    def __init__(self, components: List[float]) -> None:
        self.components = components

    def __getitem__(self, index: Union[int, slice]) -> Union[float, List[float]]:
        return self.components[index]

    def __len__(self) -> int:
        return len(self.components)

    def __call__(self, scalar: float) -> 'Vector':
        return Vector([x * scalar for x in self.components])

    def __repr__(self) -> str:
        return f"Vector({self.components})"

if __name__ == "__main__":
    v = Vector([1.0, 2.0, 3.0])
    print("Vector:", v)
    print("Length of Vector:", len(v))
    print("First component:", v[0])
    print("Slice of Vector:", v[1:])
    print("Scaled Vector:", v(2.0))
```

```text
Output:
Vector: Vector([1.0, 2.0, 3.0])
Length of Vector: 3
First component: 1.0
Slice of Vector: [2.0, 3.0]
Scaled Vector: Vector([2.0, 4.0, 6.0])
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: We import the `List` and `Union` types from the `typing` module to provide type hints.
2. **Class Definition**: We define the `Vector` class with an `__init__` method that initializes the vector components.
3. **`__getitem__` Method**: This method allows us to access vector components using the square bracket notation. It supports both integer indices and slices.
4. **`__len__` Method**: This method returns the length of the vector, which is the number of components.
5. **`__call__` Method**: This method allows the vector to be called like a function, scaling each component by the provided scalar.
6. **`__repr__` Method**: This method provides a string representation of the vector for printing.
7. **Main Block**: We create a `Vector` instance and demonstrate the use of `__getitem__`, `__len__`, and `__call__` methods.

> [!ADVANCED]
> The `__getitem__` method is implemented using Python's built-in indexing and slicing operations, which are highly optimized for performance. The `__len__` method simply delegates to the `len` function of the underlying list, ensuring efficiency. The `__call__` method uses a list comprehension to scale the vector components, which is both concise and efficient.

> [!QA]
> Q: When should I prefer implementing `__getitem__` over using a regular method?
> A: You should prefer implementing `__getitem__` when your class represents a container or a collection of items. This makes your class more intuitive and easier to use, as it allows you to use Python's built-in indexing and slicing operations. Regular methods should be used for operations that do not fit the container metaphor.

## Summary & Key Takeaways

- Magic methods enable you to define how your objects behave with built-in operations.
- `__getitem__` allows you to define how your objects are accessed using the square bracket notation.
- `__len__` allows you to define how the length of your object is determined.
- `__call__` allows you to define how your objects are called like functions.
- Implement these methods when your class represents a container, a collection of items, or a callable object.
