# 14.2 — Generics, TypeVar, Protocol & Structural Subtyping

## Opening Motivation & Context

In the world of computing and AI, the ability to write flexible, reusable code is crucial. Type systems play a significant role in achieving this flexibility while maintaining code correctness. Generics, TypeVar, Protocol, and structural subtyping are advanced concepts in Python's type system that enable you to write more flexible and reusable code. These concepts allow you to create functions, classes, and interfaces that can work with a variety of types while maintaining type safety.

## Core Concepts Breakdown

### Generics

Generics allow you to write code that can work with multiple types. They provide a way to create type-safe functions, classes, and interfaces that can work with a variety of types while maintaining type safety. Generics are a powerful tool for writing flexible and reusable code.

> [!KEY-INSIGHT]
> Generics enable you to write type-safe code that can work with multiple types, promoting code reuse and flexibility.

> [!BEST-PRACTICE]
> Use generics to create functions, classes, and interfaces that can work with a variety of types while maintaining type safety.

### TypeVar

TypeVar is a special type that allows you to create a generic type variable. It is used to specify the type of a generic function or class. TypeVar is a powerful tool for creating flexible and reusable code.

> [!KEY-INSIGHT]
> TypeVar allows you to create generic type variables, enabling you to write flexible and reusable code.

> [!BEST-PRACTICE]
> Use TypeVar to create generic type variables for functions and classes that need to work with multiple types.

### Protocol

Protocol is a special type that allows you to define an interface using structural subtyping. It is used to specify the structure of a type without explicitly defining a class. Protocol is a powerful tool for creating flexible and reusable code.

> [!KEY-INSIGHT]
> Protocol allows you to define interfaces using structural subtyping, enabling you to write flexible and reusable code.

> [!BEST-PRACTICE]
> Use Protocol to define interfaces that can be implemented by any type that matches the specified structure.

### Structural Subtyping

Structural subtyping is a type system concept where a type is considered a subtype of another type if it has the same structure. It is used to determine if a type can be used in place of another type. Structural subtyping is a powerful tool for creating flexible and reusable code.

> [!KEY-INSIGHT]
> Structural subtyping allows you to use a type in place of another type if it has the same structure, enabling you to write flexible and reusable code.

> [!BEST-PRACTICE]
> Use structural subtyping to create flexible and reusable code that can work with a variety of types.

## Code Demonstration & Runtime Output

```python
from typing import TypeVar, Generic, Protocol, runtime_checkable

# Define a generic type variable
T = TypeVar('T')

# Define a generic function
def generic_function(x: T, y: T) -> T:
    return x if x > y else y

# Define a generic class
class GenericClass(Generic[T]):
    def __init__(self, value: T):
        self.value = value

    def get_value(self) -> T:
        return self.value

# Define a protocol
@runtime_checkable
class MyProtocol(Protocol):
    def method(self) -> int:
        ...

# Define a class that implements the protocol
class MyClass:
    def method(self) -> int:
        return 42

# Define a function that uses the protocol
def protocol_function(obj: MyProtocol) -> int:
    return obj.method()

# Define a function that uses structural subtyping
def structural_subtyping_function(obj: MyProtocol) -> int:
    if isinstance(obj, MyProtocol):
        return obj.method()
    else:
        raise TypeError("Object does not implement MyProtocol")

if __name__ == "__main__":
    # Test the generic function
    print(generic_function(1, 2))  # Output: 2
    print(generic_function("a", "b"))  # Output: b

    # Test the generic class
    generic_obj = GenericClass(42)
    print(generic_obj.get_value())  # Output: 42

    # Test the protocol function
    my_obj = MyClass()
    print(protocol_function(my_obj))  # Output: 42

    # Test the structural subtyping function
    print(structural_subtyping_function(my_obj))  # Output: 42
```

## How this works (Line-by-Line Breakdown)

1. `from typing import TypeVar, Generic, Protocol, runtime_checkable`: Import the necessary types from the typing module.
2. `T = TypeVar('T')`: Define a generic type variable `T`.
3. `def generic_function(x: T, y: T) -> T:`: Define a generic function that takes two arguments of type `T` and returns a value of type `T`.
4. `return x if x > y else y`: Return the larger of the two arguments.
5. `class GenericClass(Generic[T]):`: Define a generic class that takes a type variable `T`.
6. `def __init__(self, value: T):`: Define the constructor for the generic class.
7. `self.value = value`: Store the value in the instance variable.
8. `def get_value(self) -> T:`: Define a method that returns the value of type `T`.
9. `return self.value`: Return the stored value.
10. `@runtime_checkable`: Decorate the protocol to enable runtime type checking.
11. `class MyProtocol(Protocol):`: Define a protocol that specifies the structure of a type.
12. `def method(self) -> int: ...`: Define a method that returns an integer.
13. `class MyClass:`: Define a class that implements the protocol.
14. `def method(self) -> int:`: Define a method that returns an integer.
15. `return 42`: Return the integer 42.
16. `def protocol_function(obj: MyProtocol) -> int:`: Define a function that takes an object of type `MyProtocol` and returns an integer.
17. `return obj.method()`: Return the result of calling the method on the object.
18. `def structural_subtyping_function(obj: MyProtocol) -> int:`: Define a function that takes an object of type `MyProtocol` and returns an integer.
19. `if isinstance(obj, MyProtocol):`: Check if the object is an instance of `MyProtocol`.
20. `return obj.method()`: Return the result of calling the method on the object.
21. `else: raise TypeError("Object does not implement MyProtocol")`: Raise a type error if the object does not implement the protocol.
22. `if __name__ == "__main__":`: Check if the script is being run directly.
23. `print(generic_function(1, 2))`: Test the generic function with integers.
24. `print(generic_function("a", "b"))`: Test the generic function with strings.
25. `generic_obj = GenericClass(42)`: Create an instance of the generic class.
26. `print(generic_obj.get_value())`: Test the generic class method.
27. `my_obj = MyClass()`: Create an instance of the class that implements the protocol.
28. `print(protocol_function(my_obj))`: Test the protocol function.
29. `print(structural_subtyping_function(my_obj))`: Test the structural subtyping function.
