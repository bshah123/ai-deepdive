# 15.1 — NumPy Memory Layout: C-Contiguous, Fortran & Strides

## Opening Motivation & Context

Understanding NumPy's memory layout is crucial for efficient numerical computing. The way data is stored in memory can significantly impact performance, especially when dealing with large datasets or complex operations. NumPy provides two primary memory layouts: C-contiguous and Fortran-contiguous. Additionally, strides play a vital role in determining how elements are accessed in memory. This lesson will delve into these concepts, providing a clear understanding of how they work and why they matter.

## Core Concepts Breakdown

### Memory Layouts

NumPy arrays can be stored in two primary memory layouts:

1. **C-contiguous**: Data is stored in row-major order, meaning elements of a row are stored contiguously. This is the default layout for NumPy arrays.
2. **Fortran-contiguous**: Data is stored in column-major order, meaning elements of a column are stored contiguously.

> [!KEY-INSIGHT]
> The memory layout of a NumPy array determines how elements are accessed and can significantly impact performance. Understanding these layouts helps in optimizing array operations.

> [!BEST-PRACTICE]
> When working with large datasets, consider the memory layout of your arrays. For operations that access rows sequentially, C-contiguous arrays are more efficient. For operations that access columns sequentially, Fortran-contiguous arrays are more efficient.

> [!WARNING]
> Changing the memory layout of an array can be expensive in terms of both time and memory. Avoid unnecessary layout changes to maintain performance.

### Strides

Strides refer to the number of bytes one must skip in memory to move to the next element in a given dimension. For a 2D array, strides are typically represented as a tuple `(stride_row, stride_col)`, where `stride_row` is the number of bytes to skip to move to the next row, and `stride_col` is the number of bytes to skip to move to the next column.

> [!KEY-INSIGHT]
> Strides provide a low-level view of how elements are stored in memory and are crucial for understanding array operations. They can also be used to create views of arrays without copying data.

> [!BEST-PRACTICE]
> When creating views of arrays, be mindful of strides. Ensure that the strides align with the intended memory layout to avoid unexpected behavior.

> [!WARNING]
> Modifying strides directly can lead to undefined behavior if not done carefully. It is generally safer to use NumPy's built-in functions to change array layouts.

## Code Demonstration & Runtime Output

```python
import numpy as np

def main() -> None:
    # Create a 2D array
    arr = np.array([[1, 2, 3], [4, 5, 6]], dtype=np.int32)

    # Print the array
    print("Array:")
    print(arr)

    # Check the memory layout
    print("\nMemory Layout:")
    print("C-contiguous:", arr.flags['C_CONTIGUOUS'])
    print("Fortran-contiguous:", arr.flags['F_CONTIGUOUS'])

    # Print the strides
    print("\nStrides (in bytes):")
    print(arr.strides)

    # Create a transposed view of the array
    transposed_arr = arr.T

    # Print the transposed array
    print("\nTransposed Array:")
    print(transposed_arr)

    # Check the memory layout of the transposed array
    print("\nMemory Layout of Transposed Array:")
    print("C-contiguous:", transposed_arr.flags['C_CONTIGUOUS'])
    print("Fortran-contiguous:", transposed_arr.flags['F_CONTIGUOUS'])

    # Print the strides of the transposed array
    print("\nStrides of Transposed Array (in bytes):")
    print(transposed_arr.strides)

    # Create a Fortran-contiguous array
    fortran_arr = np.asfortranarray(arr)

    # Print the Fortran-contiguous array
    print("\nFortran-Contiguous Array:")
    print(fortran_arr)

    # Check the memory layout of the Fortran-contiguous array
    print("\nMemory Layout of Fortran-Contiguous Array:")
    print("C-contiguous:", fortran_arr.flags['C_CONTIGUOUS'])
    print("Fortran-contiguous:", fortran_arr.flags['F_CONTIGUOUS'])

    # Print the strides of the Fortran-contiguous array
    print("\nStrides of Fortran-Contiguous Array (in bytes):")
    print(fortran_arr.strides)

if __name__ == "__main__":
    main()
```

## Advanced

Understanding the memory layout of NumPy arrays is essential for optimizing performance in numerical computing. The C-contiguous and Fortran-contiguous layouts determine how elements are stored in memory, which can significantly impact the performance of array operations. Strides provide a low-level view of how elements are accessed in memory and are crucial for understanding array operations.

In CPython, NumPy arrays are implemented as C-structs with a rich set of attributes and methods. The memory layout of an array is determined by its strides, which specify the number of bytes to skip to move to the next element in a given dimension. The `flags` attribute of a NumPy array provides information about the memory layout, including whether the array is C-contiguous, Fortran-contiguous, or neither.

## Q&A

### Q: When should I prefer C-contiguous arrays over Fortran-contiguous arrays?

A: C-contiguous arrays are preferred when operations access rows sequentially. This is because C-contiguous arrays store elements of a row contiguously, which allows for efficient row-wise operations. For example, matrix multiplication is typically more efficient with C-contiguous arrays.

### Q: How can I change the memory layout of a NumPy array?

A: You can change the memory layout of a NumPy array using functions like `np.ascontiguousarray` and `np.asfortranarray`. These functions create new arrays with the specified memory layout. For example, `np.asfortranarray(arr)` creates a Fortran-contiguous array from `arr`.

### Question #3: Find and fix the bug in the following code:

```python
import numpy as np

def main() -> None:
    arr = np.array([[1, 2, 3], [4, 5, 6]], dtype=np.int32)
    transposed_arr = arr.T
    transposed_arr[0, 0] = 10
    print(arr)

if __name__ == "__main__":
    main()
```

<details><summary>Show Solution</summary>

The bug in the code is that the transposed array `transposed_arr` is a view of the original array `arr`. Modifying `transposed_arr` also modifies `arr`. To fix this, you should create a copy of the transposed array using `np.copy` or `np.array`.

```python
import numpy as np

def main() -> None:
    arr = np.array([[1, 2, 3], [4, 5, 6]], dtype=np.int32)
    transposed_arr = np.array(arr.T)
    transposed_arr[0, 0] = 10
    print(arr)

if __name__ == "__main__":
    main()
```
