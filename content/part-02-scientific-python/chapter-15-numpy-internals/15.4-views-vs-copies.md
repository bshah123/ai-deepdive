# 15.4 — Views vs Copies, Slicing & Advanced Indexing

## Opening Motivation & Context

Understanding the distinction between views and copies in NumPy is crucial for efficient memory usage and performance optimization in scientific computing and AI applications. When you perform operations on NumPy arrays, you often create either a view or a copy of the original array. Views share the same memory as the original array, while copies allocate new memory. This distinction is particularly important when working with large datasets or performing operations that modify array elements.

## Core Concepts Breakdown

### Views vs Copies

> [!KEY-INSIGHT]
> A view is a new array object that looks at the same data as the original array. Changes made to the view will affect the original array, and vice versa. A copy is a new array object with its own data, which is a copy of the original array. Changes made to the copy will not affect the original array.

> [!BEST-PRACTICE]
> Use views when you need to work with a subset of the original array and want to save memory. Use copies when you need to perform operations that should not affect the original array.

> [!WARNING]
> Be cautious when modifying views, as changes will propagate to the original array. Always use copies when you need to ensure that the original array remains unchanged.

## Code Demonstration & Runtime Output

```python
import numpy as np

def main() -> None:
    # Create a 1D array
    arr = np.array([1, 2, 3, 4, 5])

    # Create a view of the array
    view = arr[1:4]
    print("Original array:", arr)
    print("View of the array:", view)

    # Modify the view
    view[0] = 20
    print("Modified view:", view)
    print("Original array after modifying view:", arr)

    # Create a copy of the array
    copy = arr.copy()
    print("Copy of the array:", copy)

    # Modify the copy
    copy[0] = 10
    print("Modified copy:", copy)
    print("Original array after modifying copy:", arr)

if __name__ == "__main__":
    main()
```

Output:
```
Original array: [1 2 3 4 5]
View of the array: [2 3 4]
Modified view: [20  3  4]
Original array after modifying view: [ 1 20  3  4  5]
Copy of the array: [ 1 20  3  4  5]
Modified copy: [10 20  3  4  5]
Original array after modifying copy: [ 1 20  3  4  5]
```

> [!ADVANCED]
> Views in NumPy are implemented using the same memory buffer as the original array. This allows views to be created and manipulated efficiently without allocating new memory. Copies, on the other hand, allocate new memory and copy the data from the original array. This ensures that modifications to the copy do not affect the original array.

> [!QA]
> Q: When should I prefer a view over a copy?
> A: You should prefer a view when you need to work with a subset of the original array and want to save memory. Views are particularly useful when working with large datasets or performing operations that do not require modifying the original array.

## Summary & Key Takeaways

- Views share the same memory as the original array.
- Copies allocate new memory and copy the data from the original array.
- Changes made to a view will affect the original array.
- Changes made to a copy will not affect the original array.
- Use views when you need to save memory and work with subsets of the original array.
- Use copies when you need to perform operations that should not affect the original array.

### Question #3: Find and fix the bug

```python
import numpy as np

def main() -> None:
    arr = np.array([1, 2, 3, 4, 5])
    copy = arr[1:4]
    copy[0] = 20
    print(arr)

if __name__ == "__main__":
    main()
```

<details><summary>Show Solution</summary>

The bug is that `copy` is actually a view of the original array `arr`, not a copy. To fix the bug, you should use the `copy()` method to create a true copy of the array.

```python
import numpy as np

def main() -> None:
    arr = np.array([1, 2, 3, 4, 5])
    copy = arr[1:4].copy()
    copy[0] = 20
    print(arr)

if __name__ == "__main__":
    main()
```

The fixed code outputs `[1 2 3 4 5]`. The copy `copy` is now a true copy of the original array `arr`, and modifying the copy does not affect the original array.

</details>
