# 16.3 — Memory Optimization: Categoricals, Downcasting & Chunking

## Opening Motivation & Context

In the realm of data science and machine learning, memory optimization is a critical concern. Large datasets can consume significant amounts of RAM, leading to slower processing times and potential crashes. Pandas, a powerful data manipulation library in Python, offers several techniques to optimize memory usage. This lesson will explore three key methods: using categorical data types, downcasting numerical data, and processing data in chunks.

## Core Concepts Breakdown

### Categoricals

Categorical data represents variables that can take on a limited number of possible values. In Pandas, the `category` data type is used to store such data more efficiently.

> [!KEY-INSIGHT]
> Categorical data is stored as integers, with a mapping to the actual values. This reduces memory usage, especially when dealing with a large number of repeated values.

> [!BEST-PRACTICE]
> Use the `category` data type for columns with a limited number of unique values to save memory.

### Downcasting

Downcasting refers to converting numerical data to a smaller data type that can still represent the same values. This can significantly reduce memory usage.

> [!KEY-INSIGHT]
> Downcasting is particularly useful for large datasets with numerical columns. It can reduce memory usage without losing any information.

> [!WARNING]
> Downcasting can lead to unexpected behavior if the data type is not large enough to represent the values. Always verify the data after downcasting.

### Chunking

Chunking involves processing data in smaller, more manageable pieces. This technique is useful when dealing with very large datasets that cannot fit into memory all at once.

> [!KEY-INSIGHT]
> Chunking allows you to process data in smaller batches, reducing memory usage and improving performance.

> [!BEST-PRACTICE]
> Use chunking when working with very large datasets that cannot fit into memory. Choose an appropriate chunk size based on your system's memory constraints.

## Code Demonstration & Runtime Output

```python
import pandas as pd
import numpy as np

def create_sample_dataframe() -> pd.DataFrame:
    """Create a sample DataFrame with various data types."""
    data = {
        'id': range(1, 10001),
        'category': np.random.choice(['A', 'B', 'C', 'D'], size=10000),
        'value': np.random.randint(1, 1000, size=10000),
        'float_value': np.random.rand(10000) * 1000
    }
    return pd.DataFrame(data)

def optimize_memory(df: pd.DataFrame) -> pd.DataFrame:
    """Optimize the memory usage of a DataFrame."""
    # Convert categorical columns
    df['category'] = df['category'].astype('category')

    # Downcast numerical columns
    df['id'] = pd.to_numeric(df['id'], downcast='integer')
    df['value'] = pd.to_numeric(df['value'], downcast='integer')
    df['float_value'] = pd.to_numeric(df['float_value'], downcast='float')

    return df

def process_in_chunks(file_path: str, chunk_size: int) -> pd.DataFrame:
    """Process a large CSV file in chunks."""
    chunks = pd.read_csv(file_path, chunksize=chunk_size)
    processed_chunks = []

    for chunk in chunks:
        # Optimize memory for each chunk
        chunk = optimize_memory(chunk)
        processed_chunks.append(chunk)

    # Concatenate all processed chunks
    return pd.concat(processed_chunks, ignore_index=True)

if __name__ == '__main__':
    # Create a sample DataFrame
    df = create_sample_dataframe()
    print("Original DataFrame memory usage:")
    print(df.memory_usage(deep=True))

    # Optimize memory usage
    optimized_df = optimize_memory(df.copy())
    print("\nOptimized DataFrame memory usage:")
    print(optimized_df.memory_usage(deep=True))

    # Save the DataFrame to a CSV file
    csv_path = 'sample_data.csv'
    df.to_csv(csv_path, index=False)

    # Process the CSV file in chunks
    chunk_size = 1000
    processed_df = process_in_chunks(csv_path, chunk_size)
    print("\nProcessed DataFrame memory usage:")
    print(processed_df.memory_usage(deep=True))
```

### Question #3: Find and fix the bug

```python
import pandas as pd

df = pd.DataFrame({'A': [1, 2, 3, 4, 5]})
df['A'] = pd.to_numeric(df['A'], downcast='float')
print(df['A'].dtype)
```

<details><summary>Show Solution</summary>

The bug is that the `downcast` parameter is set to 'float', which is not a valid option for integer data. The fixed code is:

```python
import pandas as pd

df = pd.DataFrame({'A': [1, 2, 3, 4, 5]})
df['A'] = pd.to_numeric(df['A'], downcast='integer')
print(df['A'].dtype)
```

</details>
