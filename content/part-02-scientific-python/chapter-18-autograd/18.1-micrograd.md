# 18.1 — Reverse-Mode Automatic Differentiation & GradTape

## Opening Motivation & Context

Automatic differentiation is a cornerstone of modern machine learning and scientific computing. It allows us to compute gradients of complex functions efficiently, which is essential for training neural networks and optimizing scientific models. Reverse-mode automatic differentiation, also known as backpropagation, is particularly powerful because it computes gradients in a way that scales well with the number of inputs, making it suitable for high-dimensional problems.

In this lesson, we'll explore reverse-mode automatic differentiation and how to implement it using `GradTape` in Python. We'll cover the core concepts, demonstrate how to use `GradTape` with practical examples, and provide a deep dive into how it works under the hood.

## Core Concepts Breakdown

### Reverse-Mode Automatic Differentiation

Reverse-mode automatic differentiation is a method for computing the gradient of a function by first evaluating the function at a given point and then propagating the gradient backward through the computation graph. This approach is efficient for functions with many inputs and few outputs, which is common in machine learning.

> [!KEY-INSIGHT]
> Reverse-mode automatic differentiation is like building a roadmap of your calculations and then driving backward to find the steepest path downhill. It's efficient for problems with many inputs and few outputs.

> [!BEST-PRACTICE]
> Use reverse-mode automatic differentiation when you need to compute gradients for functions with many inputs and few outputs, such as neural networks.

> [!WARNING]
> Reverse-mode automatic differentiation requires storing intermediate values during the forward pass, which can consume significant memory. Be mindful of memory usage when working with large models.

## Code Demonstration & Runtime Output

Let's start by demonstrating how to use `GradTape` to compute gradients. We'll define a simple function and compute its gradient using `GradTape`.

```python
import tensorflow as tf

def compute_gradient(x: tf.Tensor) -> tf.Tensor:
    """
    Compute the gradient of the function f(x) = x^2 + 2x + 1.

    Args:
        x: Input tensor.

    Returns:
        Gradient of the function with respect to x.
    """
    with tf.GradientTape() as tape:
        tape.watch(x)
        f = x ** 2 + 2 * x + 1
    return tape.gradient(f, x)

if __name__ == "__main__":
    x = tf.constant(3.0)
    gradient = compute_gradient(x)
    print(f"Gradient at x = {x.numpy()}: {gradient.numpy()}")
```

Output:
```
Gradient at x = 3.0: 8.0
```

### How this works (Line-by-Line Breakdown)

1. **Import TensorFlow**: We import TensorFlow, which provides the `GradientTape` functionality.
2. **Define the function**: We define a simple function `f(x) = x^2 + 2x + 1` that we want to differentiate.
3. **Create a GradientTape context**: We use `tf.GradientTape()` to create a context manager that records operations for automatic differentiation.
4. **Watch the input tensor**: We call `tape.watch(x)` to tell TensorFlow to watch the input tensor `x` for differentiation.
5. **Compute the function**: Inside the `GradientTape` context, we compute the value of the function `f` at the input `x`.
6. **Compute the gradient**: We call `tape.gradient(f, x)` to compute the gradient of `f` with respect to `x`.
7. **Print the result**: We print the gradient at the given input `x`.

> [!ADVANCED]
> When you use `GradientTape`, TensorFlow creates a computation graph that records all the operations performed on the input tensors. During the forward pass, TensorFlow evaluates the function and stores intermediate values. During the backward pass, TensorFlow uses the chain rule to compute the gradient by propagating the gradient backward through the computation graph.

## Summary & Key Takeaways

- Reverse-mode automatic differentiation is efficient for functions with many inputs and few outputs.
- `GradientTape` is a powerful tool for computing gradients in TensorFlow.
- Be mindful of memory usage when using `GradientTape` for large models.

### Question #3: Find and fix the bug

```python
import tensorflow as tf

def compute_gradient(x: tf.Tensor) -> tf.Tensor:
    with tf.GradientTape() as tape:
        f = x ** 2 + 2 * x + 1
    return tape.gradient(f, x)

if __name__ == "__main__":
    x = tf.constant(3.0)
    gradient = compute_gradient(x)
    print(f"Gradient at x = {x.numpy()}: {gradient.numpy()}")
```

<details><summary>Show Solution</summary>

The bug in the code is that the input tensor `x` is not being watched by `GradientTape`. To fix this, we need to call `tape.watch(x)` before computing the function `f`. Here is the corrected code:

```python
import tensorflow as tf

def compute_gradient(x: tf.Tensor) -> tf.Tensor:
    with tf.GradientTape() as tape:
        tape.watch(x)
        f = x ** 2 + 2 * x + 1
    return tape.gradient(f, x)

if __name__ == "__main__":
    x = tf.constant(3.0)
    gradient = compute_gradient(x)
    print(f"Gradient at x = {x.numpy()}: {gradient.numpy()}")
```

</details>
