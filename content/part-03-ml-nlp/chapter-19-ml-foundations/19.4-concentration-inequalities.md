# 19.4 — Statistical Learning Theory: Concentration Inequalities

## Opening Motivation & Context

In machine learning, we train models on a finite sample of $n$ training points $S = \{(x_1, y_1), \dots, (x_n, y_n)\}$ drawn from an unknown data distribution $\mathcal{D}$. However, our true objective is to perform well on the entire distribution $\mathcal{D}$ (the **true risk** or expected error). How can we be mathematically confident that the average performance on a finite sample is close to the true expectation?

**Concentration inequalities** provide the foundational mathematical bedrock for answering this question. They bound the probability that a random variable (or an empirical average of independent random variables) deviates from its expected value by more than a specified tolerance $\epsilon$.

In this lesson, we will build the mathematical progression from first principles:
1. **Markov's Inequality** (First-order bound for non-negative random variables)
2. **Chebyshev's Inequality** (Second-order variance bound)
3. **Hoeffding's Lemma & Hoeffding's Inequality** (Exponential tail bounds for bounded variables)
4. **McDiarmid's Bounded Differences Inequality** (Extension to non-linear functions)

---

## Core Theoretical Framework

### 1. Markov's Inequality (First-Order Bound)
Let $X$ be a non-negative random variable ($X \ge 0$) with finite expectation $\mathbb{E}[X] < \infty$. For any threshold $a > 0$:

\[
\mathbb{P}(X \ge a) \;\le\; \frac{\mathbb{E}[X]}{a}
\]

> [!KEY-INSIGHT]
> **Markov Proof Intuition**:
> We decompose the expectation: $\mathbb{E}[X] = \int_0^\infty x p(x) dx \ge \int_a^\infty x p(x) dx \ge a \int_a^\infty p(x) dx = a \mathbb{P}(X \ge a)$. Dividing both sides by $a$ yields the inequality. It requires only non-negativity and knowledge of the first moment $\mathbb{E}[X]$.

### 2. Chebyshev's Inequality (Second-Order Variance Bound)
Let $X$ be any random variable with mean $\mu = \mathbb{E}[X]$ and variance $\sigma^2 = \text{Var}(X) < \infty$. By applying Markov's inequality to the non-negative random variable $(X - \mu)^2$ with threshold $\epsilon^2$:

\[
\mathbb{P}(|X - \mu| \ge \epsilon) \;=\; \mathbb{P}\big((X - \mu)^2 \ge \epsilon^2\big) \;\le\; \frac{\mathbb{E}[(X - \mu)^2]}{\epsilon^2} \;=\; \frac{\sigma^2}{\epsilon^2}
\]

For an empirical average $\bar{X}_n = \frac{1}{n} \sum_{i=1}^n X_i$ of $n$ i.i.d. random variables with variance $\sigma^2$, $\text{Var}(\bar{X}_n) = \frac{\sigma^2}{n}$:

\[
\mathbb{P}(|\bar{X}_n - \mu| \ge \epsilon) \;\le\; \frac{\sigma^2}{n \epsilon^2}
\]

> [!WARNING]
> While Chebyshev's inequality guarantees convergence as $n \to \infty$ (Weak Law of Large Numbers), its decay rate is only polynomial ($\mathcal{O}(1/n)$). For tight generalization bounds in machine learning, we require **exponential decay**.

### 3. Hoeffding's Inequality (Exponential Tail Bounds)
Let $X_1, X_2, \dots, X_n$ be independent random variables such that $X_i \in [a_i, b_i]$ almost surely. Let $\bar{X}_n = \frac{1}{n} \sum_{i=1}^n X_i$ and $\mu = \mathbb{E}[\bar{X}_n]$. Then for any $\epsilon > 0$:

\[
\mathbb{P}(\bar{X}_n - \mu \ge \epsilon) \;\le\; \exp\left(-\frac{2n^2\epsilon^2}{\sum_{i=1}^n (b_i - a_i)^2}\right)
\]

For identical intervals $X_i \in [a, b]$ (such as binary 0-1 loss $X_i \in [0, 1]$ where $b - a = 1$), the two-sided Hoeffding bound becomes:

\[
\mathbb{P}(|\bar{X}_n - \mu| \ge \epsilon) \;\le\; 2 \exp\left(-\frac{2n\epsilon^2}{(b - a)^2}\right)
\]

> [!BEST-PRACTICE]
> In empirical risk minimization, let $\hat{R}_n(h) = \frac{1}{n}\sum_{i=1}^n \ell(h(x_i), y_i)$ be the empirical error on $n$ samples, and $R(h) = \mathbb{E}[\ell(h(X), Y)]$ be the true risk. If the loss is bounded in $[0, 1]$, Hoeffding's inequality gives:
> \[
> \mathbb{P}\big(|\hat{R}_n(h) - R(h)| \ge \epsilon\big) \;\le\; 2 e^{-2n\epsilon^2}
> \]

## Code Demonstration & Empirical Simulation

Below is a complete Python simulation comparing the theoretical bounds (Markov, Chebyshev, Hoeffding) against the empirical tail probability of sample averages across 50,000 Monte Carlo trials.

```python
import numpy as np
from typing import Dict, Tuple

def compare_concentration_bounds(
    n_samples: int = 100,
    epsilon: float = 0.08,
    n_trials: int = 50000,
    seed: int = 42
) -> Dict[str, float]:
    """
    Simulates empirical risk convergence and computes theoretical bounds.
    Variables are Bernoulli(p=0.5) scaled in [0, 1].
    """
    np.random.seed(seed)
    p_true = 0.5
    a, b = 0.0, 1.0  # Bounded support interval
    var_true = p_true * (1.0 - p_true)  # 0.25

    # 1. Generate Monte Carlo trials: shape (n_trials, n_samples)
    trials = np.random.binomial(n=1, p=p_true, size=(n_trials, n_samples)).astype(np.float64)
    sample_means = np.mean(trials, axis=1)

    # 2. Empirical Probability of deviation >= epsilon
    deviations = np.abs(sample_means - p_true)
    empirical_prob = float(np.mean(deviations >= epsilon))

    # 3. Theoretical Bounds for |X_bar - mu| >= epsilon:
    # Chebyshev bound: Var(X_bar) / epsilon^2 = (sigma^2 / n) / epsilon^2
    chebyshev_bound = min(1.0, float(var_true / (n_samples * (epsilon ** 2))))

    # Hoeffding two-sided bound: 2 * exp(-2 * n * epsilon^2 / (b - a)^2)
    hoeffding_bound = min(1.0, float(2.0 * np.exp(-2.0 * n_samples * (epsilon ** 2) / ((b - a) ** 2))))

    return {
        "n_samples": n_samples,
        "epsilon": epsilon,
        "empirical_prob": empirical_prob,
        "chebyshev_bound": chebyshev_bound,
        "hoeffding_bound": hoeffding_bound,
        "tightness_ratio_chebyshev": chebyshev_bound / max(1e-9, empirical_prob),
        "tightness_ratio_hoeffding": hoeffding_bound / max(1e-9, empirical_prob)
    }

if __name__ == "__main__":
    res = compare_concentration_bounds(n_samples=100, epsilon=0.08)
    print("=== CONCENTRATION INEQUALITIES: SIMULATION VS THEORY ===")
    print(f"Sample Size (n)       : {res['n_samples']}")
    print(f"Deviation Margin (eps): {res['epsilon']:.4f}")
    print(f"Empirical P(|X-mu|>=e): {res['empirical_prob']:.6f}")
    print(f"Chebyshev Upper Bound : {res['chebyshev_bound']:.6f}")
    print(f"Hoeffding Upper Bound : {res['hoeffding_bound']:.6f}")
    print(f"Hoeffding Tightness   : {res['tightness_ratio_hoeffding']:.2f}x of empirical")
```

```text
Deviation Margin (eps): 0.0800
Empirical P(|X-mu|>=e): 0.108540
Chebyshev Upper Bound : 0.390625
Hoeffding Upper Bound : 0.556277
Hoeffding Tightness   : 5.12x of empirical
```

### How this works (Line-by-Line Breakdown)

1. **`compare_concentration_bounds`**: Sets up a controlled environment with true mean $\mu = 0.5$ and variance $\sigma^2 = 0.25$.
2. **`np.random.binomial(...)`**: Generates 50,000 independent datasets of size $n=100$ to compute empirical ground truth deviations.
3. **`deviations >= epsilon`**: Tracks the fraction of runs where sample average deviated by $\ge 0.08$ from the true mean.
4. **`chebyshev_bound`**: Computes $\frac{\sigma^2}{n \epsilon^2} = \frac{0.25}{100 \times 0.08^2} \approx 0.3906$.
5. **`hoeffding_bound`**: Computes $2 \exp\left(-2 \times 100 \times 0.08^2 / 1^2\right) = 2 \exp(-1.28) \approx 0.5563$.
6. **Exponential Scaling**: As $n$ increases from $100 \to 1000$, Chebyshev decays linearly ($1/n$), while Hoeffding decays exponentially ($e^{-2n\epsilon^2} \to 10^{-7}$), demonstrating why Hoeffding is the backbone of statistical machine learning.

> [!ADVANCED]
> **McDiarmid's Inequality (Method of Bounded Differences)**:
> What if our function $f(X_1, \dots, X_n)$ is not a simple linear sum of $X_i$, but a complex algorithm output (e.g., cross-validation error, decision tree depth, or leave-one-out error)?
> If $f$ satisfies the bounded difference property:
> \[
> \sup_{x_1, \dots, x_n, x_i'} |f(x_1, \dots, x_i, \dots, x_n) - f(x_1, \dots, x_i', \dots, x_n)| \;\le\; c_i
> \]
> Then for independent $X_i$:
> \[
> \mathbb{P}\big(|f(X) - \mathbb{E}[f(X)]| \ge \epsilon\big) \;\le\; 2 \exp\left(-\frac{2\epsilon^2}{\sum_{i=1}^n c_i^2}\right)
> \]
> This allows us to prove generalization bounds for arbitrary stable learning algorithms.

---

> [!QA]
> **Q: Why does Hoeffding's inequality require bounded random variables ($X_i \in [a, b]$)?**  
> **A**: The proof relies on **Hoeffding's Lemma**, which upper bounds the moment generating function $\mathbb{E}[e^{s(X-\mu)}] \le \exp\left(\frac{s^2 (b-a)^2}{8}\right)$. For unbounded random variables (like Gaussians or Sub-Exponentials), we instead use **Sub-Gaussian** or **Bernstein's inequalities**, which incorporate the variance parameter $\sigma^2$.

## Summary & Key Takeaways

- **Markov's Inequality**: $\mathbb{P}(X \ge a) \le \frac{\mathbb{E}[X]}{a}$ (requires $X \ge 0$).
- **Chebyshev's Inequality**: $\mathbb{P}(|X - \mu| \ge \epsilon) \le \frac{\sigma^2}{n \epsilon^2}$ (polynomial $1/n$ decay).
- **Hoeffding's Inequality**: $\mathbb{P}(|\bar{X}_n - \mu| \ge \epsilon) \le 2\exp\left(-\frac{2n\epsilon^2}{(b-a)^2}\right)$ (exponential $e^{-cn}$ decay for bounded variables).
- **Machine Learning Invariant**: Hoeffding allows us to compute the exact minimum dataset size $n$ required to guarantee that empirical training error is within $\epsilon$ of test risk with probability at least $1 - \delta$.

### Question 1 (Conceptual)
Suppose you are evaluating an LLM classifier on a test set of size $n=1000$ with 0-1 loss ($b-a=1$). You want to be $99\%$ confident ($\delta = 0.01$) that the test set accuracy is within $\pm 0.05$ ($\epsilon = 0.05$) of its true expected accuracy. According to Hoeffding's bound, does $n=1000$ suffice?

<details>
<summary>Show Solution</summary>

**Solution**:
Using Hoeffding's inequality:
\[
\delta \;\ge\; 2 \exp\left(-2 n \epsilon^2\right) \implies n \;\ge\; \frac{1}{2\epsilon^2} \ln\left(\frac{2}{\delta}\right)
\]
Plugging in $\epsilon = 0.05$ and $\delta = 0.01$:
\[
n \;\ge\; \frac{1}{2 \times (0.05)^2} \ln\left(\frac{2}{0.01}\right) \;=\; \frac{1}{0.005} \ln(200) \;=\; 200 \times 5.2983 \;\approx\; 1060
\]
Since $1000 < 1060$, $n=1000$ is slightly below the strict Hoeffding sample size requirement for $99\%$ confidence at $\epsilon=0.05$ (we need at least $n=1060$).

<details>
<summary>Show Solution</summary>

**Corrected Code**:

```python
def chebyshev_sample_mean_bound(var_single_sample: float, n: int, epsilon: float) -> float:
    """
    Computes Chebyshev's bound: P(|X_bar - mu| >= eps) <= Var(X_bar) / eps^2 = (sigma^2 / n) / eps^2
    """
    if n <= 0 or epsilon <= 0:
        raise ValueError("n and epsilon must be strictly positive")
    var_mean = var_single_sample / n
    bound = var_mean / (epsilon ** 2)
    return min(1.0, bound)
```
