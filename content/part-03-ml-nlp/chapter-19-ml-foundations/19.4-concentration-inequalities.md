Concentration inequalities turn "my sample average is probably close to the truth" into a number. In this lesson you will bound how often an average of random values strays from its expected value, using Markov, Chebyshev and Hoeffding inequalities. You will check each bound against an exact calculation, and end with a rule for how large a test set must be.

**You need:** the expectation of a random variable (Lesson 19.1), its variance (the mean squared distance from the mean), and the 0-1 loss, which is 1 for a wrong prediction and 0 for a right one (Lesson 19.1).

## The problem a finite test set creates

You train a classifier and measure its error on $n$ held-out examples. That measured error is a sample average. What you want is the **true risk** $R(h)$: the error on the whole data distribution. With $n = 100$ examples, the measured error can differ from the true error by chance. How often, and by how much?

Concentration inequalities answer this without running a simulation. They bound $\mathbb{P}(|\bar{X}_n - \mu| \ge \epsilon)$: the probability that a sample average $\bar{X}_n$ lands $\epsilon$ or more away from its mean $\mu$. The samples are assumed **independent and identically distributed** (i.i.d.): drawn independently from one distribution.

## Intuition: sample means cluster

Flip a fair coin 100 times and record the fraction of heads. Repeat this 50,000 times and the fractions pile up around 0.5 (Figure 1). The red tails are the runs that miss by 0.1 or more. A concentration inequality bounds the size of those tails.

![Histogram of 50,000 sample means of 100 fair coin flips, one bar per count; bars more than 0.1 from 0.5 are coloured red](diagrams/19.4-tail-intuition.svg "Figure 1. The tail is what the inequalities bound. Bars are counts out of 50,000 runs.")

A simulation of this experiment (NumPy, seed 42) gives the tail, and the exact binomial value to compare with:

```python
import math
import numpy as np

np.random.seed(42)
n, p, trials = 100, 0.5, 50000
S = np.random.binomial(n, p, size=trials)          # heads in each of 50,000 runs of 100 flips
eps = 0.1
measured = np.mean(np.abs(S - n * p) >= n * eps)   # compare integer counts, not floats
exact = sum(math.comb(n, k) for k in range(n + 1) if abs(k - n * p) >= n * eps) / 2**n
chebyshev = (p * (1 - p) / n) / eps**2             # 0.25 / (100 * 0.01)
hoeffding = 2 * np.exp(-2 * n * eps**2)            # two-sided
print("measured        :", round(float(measured), 5))
print("exact           :", round(exact, 5))
print("Chebyshev       :", round(float(chebyshev), 5))
print("Hoeffding       :", round(float(hoeffding), 5))
```

```output
measured        : 0.05734
exact           : 0.05689
Chebyshev       : 0.25
Hoeffding       : 0.27067
```

The measured tail (0.05734) matches the exact value (0.05689) within Monte Carlo error. The two bounds, 0.25 and 0.27067, are valid but loose by a factor of about 4 to 5.

## Worked example by hand

Each of 100 predictions is wrong with probability $p = 0.1$, independently. Let $X$ be the number of errors. Then $\mu = 100 \times 0.1 = 10$ and $\sigma^2 = 100 \times 0.1 \times 0.9 = 9$. The question is $\mathbb{P}(X \ge 20)$, an error rate of at least 0.2.

1. **Markov:** $\mathbb{P}(X \ge 20) \le \mu / 20 = 10/20 = 0.5$.
2. **Chebyshev:** $X \ge 20$ implies $|X - 10| \ge 10$, so $\mathbb{P}(X \ge 20) \le 9 / 10^2 = 0.09$.
3. **Hoeffding:** the error rate $\bar{X} = X/100$ is an average of values in $[0, 1]$. The event $\bar{X} \ge 0.2$ is a deviation of $\epsilon = 0.1$ above $p = 0.1$. The bound is $e^{-2 \cdot 100 \cdot 0.1^2} = e^{-2} \approx 0.1353$.
4. **Exact:** $\mathbb{P}(X \ge 20) \approx 0.00198$ (binomial sum).

![Four horizontal bars on a log scale: Markov 0.5, Chebyshev 0.09, Hoeffding 0.1353, exact 0.00198, with the ratio of each bound to the exact value](diagrams/19.4-worked-bounds.svg "Figure 2. Four answers to the same question. Log scale: each gridline is ten times the one before.")

Figure 2 shows the four numbers. Markov is 253 times the exact value, Chebyshev 45 times, Hoeffding 68 times. Hoeffding is not the tightest here, and the reason matters: its constant depends only on the range of each value (here 0 to 1), not on the variance, which is 0.09.

Check the numbers in code (standard library only):

```python
import math

n, p = 100, 0.1                      # X = errors in 100 independent predictions
mu, var = n * p, n * p * (1 - p)     # mean 10, variance 9
a = 20                               # the event X >= 20 (an error rate of 0.2)
eps = 0.1                            # deviation of the rate from p: 0.2 - 0.1

markov = mu / a                      # needs X >= 0 and the mean
chebyshev = var / (a - mu) ** 2      # needs the variance; X >= 20 implies |X - mu| >= 10
hoeffding = math.exp(-2 * n * eps ** 2)  # one-sided; each prediction is an indicator in [0, 1]

exact = sum(math.comb(n, k) * p**k * (1 - p) ** (n - k) for k in range(a, n + 1))

print("Markov          :", round(markov, 6))
print("Chebyshev       :", round(chebyshev, 6))
print("Hoeffding       :", round(hoeffding, 6))
print("exact P(X >= 20):", round(exact, 6))
```

```output
Markov          : 0.5
Chebyshev       : 0.09
Hoeffding       : 0.135335
exact P(X >= 20): 0.001979
```

## Markov and Chebyshev, derived

**Assumptions:** $X \ge 0$ and $\mathbb{E}[X] < \infty$. For any $a > 0$, the expectation is at least the part of it that comes from values above $a$:

$$
\mathbb{E}[X] = \int_0^\infty x\,p(x)\,dx \;\ge\; \int_a^\infty x\,p(x)\,dx \;\ge\; a\,\mathbb{P}(X \ge a)
$$

Dividing by $a$ gives Markov's inequality, $\mathbb{P}(X \ge a) \le \mathbb{E}[X]/a$. This is reasoning from first principles.

Chebyshev's inequality applies Markov to $Y = (X - \mu)^2 \ge 0$ with threshold $\epsilon^2$:

$$
\mathbb{P}(|X - \mu| \ge \epsilon) = \mathbb{P}(Y \ge \epsilon^2) \le \frac{\mathbb{E}[Y]}{\epsilon^2} = \frac{\sigma^2}{\epsilon^2}
$$

For the average of $n$ i.i.d. values, $\mathrm{Var}(\bar{X}_n) = \sigma^2/n$, so $\mathbb{P}(|\bar{X}_n - \mu| \ge \epsilon) \le \sigma^2 / (n\epsilon^2)$. This needs a finite variance.

Markov's bound does not depend on $n$: for the error-rate event it stays at $p/(p+\epsilon) = 0.5$ for every $n$. Chebyshev shrinks as $1/n$. Both decay only polynomially.

## Hoeffding: exponential tails for bounded values

**Statement (established result).** Let $X_1, \dots, X_n$ be independent with $a_i \le X_i \le b_i$, and $S = \sum_i X_i$. For $t > 0$,

$$
\mathbb{P}(S - \mathbb{E}[S] \ge t) \le \exp\left(-\frac{2t^2}{\sum_{i=1}^n (b_i - a_i)^2}\right)
$$

The two-sided version has a factor 2 in front. For the sample mean $\bar{X}_n$ with all intervals of width $b - a$, take $t = n\epsilon$:

$$
\mathbb{P}(|\bar{X}_n - \mu| \ge \epsilon) \le 2\exp\left(-\frac{2n\epsilon^2}{(b-a)^2}\right)
$$

I took this from the statement in the Wikipedia article on Hoeffding's inequality (Reference 1), which cites Hoeffding (1963). I could not open the 1963 paper itself.

**Derivation (reasoning from first principles).** For $s > 0$, apply Markov's inequality to $e^{s(S - \mathbb{E}S)}$. This is Chernoff's method:

$$
\mathbb{P}(S - \mathbb{E}S \ge t) \le e^{-st}\,\mathbb{E}\!\left[e^{s(S - \mathbb{E}S)}\right]
$$

Independence turns the expectation of a sum into a product of per-term expectations. Hoeffding's lemma bounds each factor: $\mathbb{E}[e^{s(X_i - \mathbb{E}X_i)}] \le e^{s^2(b_i - a_i)^2/8}$. I took this lemma from Hoeffding (1963) without checking its proof. With $C = \sum_i (b_i - a_i)^2$, the bound becomes $\exp(-st + s^2 C/8)$. Choosing $s = 4t/C$ gives exponent $-4t^2/C + 2t^2/C = -2t^2/C$.

**Assumptions and limits.** The values must be independent and bounded. Heavy-tailed or unbounded losses are outside this result.

> [!KEY-INSIGHT]
> The bound decays as $e^{-2n\epsilon^2}$, which is exponential in $n$. Chebyshev decays as $1/n$. For $\epsilon = 0.1$, each extra sample multiplies the Hoeffding bound by $e^{-0.02} \approx 0.980$.

## Sweep: when does the exponential win?

Fix $p = 0.1$ and $\epsilon = 0.1$, and bound $\mathbb{P}(\bar{X}_n \ge 0.2)$ for $n$ from 10 to 500 (Figure 3).

![Log-scale plot of tail bounds against sample size n from 10 to 500: Markov flat at 0.5, Chebyshev falling as 1/n, Hoeffding falling exponentially, exact tail falling fastest; a dashed line marks the crossover at n = 136](diagrams/19.4-bound-sweep.svg "Figure 3. Tail bounds for P(mean >= 0.2) with p = 0.1. Hoeffding overtakes Chebyshev at n = 136.")

The code below finds the crossover and the decay rate. The exact tail is a binomial survival function, which needs SciPy.

<details><summary>Run locally: needs pip install scipy</summary>

```python
import math
from scipy import stats

p, eps = 0.1, 0.1

def cheb(n):
    return p * (1 - p) / (n * eps**2)

def hoeff(n):
    return math.exp(-2 * n * eps**2)

def exact(n):
    k = round((p + eps) * n)                       # Xbar >= 0.2 is the same event as X >= 0.2 n
    return stats.binom.sf(k - 1, n, p)             # P(X >= k)

cross = next(n for n in range(1, 1001) if all(hoeff(m) < cheb(m) for m in range(n, 1001)))
kl = 0.2 * math.log(0.2 / 0.1) + 0.8 * math.log(0.8 / 0.9)
slope = (math.log(exact(1000)) - math.log(exact(500))) / 500
print("crossover n     :", cross)
print("KL(0.2 || 0.1)  :", round(kl, 6), "  2 eps^2:", round(2 * eps**2, 6))
print("exact decay/n   :", round(-slope, 6))
for n in (100, 136, 200):
    print(n, "Chebyshev", round(cheb(n), 6), "Hoeffding", round(hoeff(n), 6), "exact", f"{exact(n):.3e}")
```

```output
crossover n     : 136
KL(0.2 || 0.1)  : 0.044403   2 eps^2: 0.02
exact decay/n   : 0.045081
100 Chebyshev 0.09 Hoeffding 0.135335 exact 1.979e-03
136 Chebyshev 0.066176 Hoeffding 0.065875 exact 4.130e-04
200 Chebyshev 0.045 Hoeffding 0.018316 exact 1.701e-05
```

Library versions used: SciPy 1.18.1, Python 3.12.

</details>

For $12 \le n \le 135$, Chebyshev is the smaller bound. From $n = 136$ on, Hoeffding stays below it. (For $n \le 11$ both bounds exceed 0.8, so neither is useful.) The exact tail falls faster than either: its measured decay rate per sample, 0.0451 between $n = 500$ and $n = 1000$, is within 2% of the Kullback–Leibler divergence $\mathrm{KL}(0.2 \| 0.1) = 0.0444$. That agreement is my own numerical check of the Chernoff exponent, not a result I verified in a source. Hoeffding's rate $2\epsilon^2 = 0.02$ is less than half of it. Hoeffding is valid but leaves a gap, because it ignores the variance.

## From a bound to a sample size

For a fixed classifier $h$ and the 0-1 loss, the empirical risk $R_n(h)$ is a sample average of i.i.d. losses in $[0, 1]$. Two-sided Hoeffding gives $\mathbb{P}(|R_n(h) - R(h)| \ge \epsilon) \le 2e^{-2n\epsilon^2}$. Setting this to a failure probability $\delta$ and solving for $n$:

$$
n \ge \frac{\ln(2/\delta)}{2\epsilon^2}
$$

![Chain of four boxes: Markov, Chebyshev, Hoeffding, union bound, each with what it needs and its tail bound; a caption gives the sample size for eps 0.05, delta 0.01, and a finite class of 1000 hypotheses](diagrams/19.4-proof-chain.svg "Figure 4. Each step needs more assumptions and gives a faster decay in n.")

For $\epsilon = 0.05$ and $\delta = 0.01$, the fixed-classifier rule gives 1060 examples. Chebyshev with $\sigma^2 \le 1/4$ gives $n \ge \sigma^2/(\delta\epsilon^2) = 10000$. The gap between $1/\delta$ and $\ln(1/\delta)$ is why exponential bounds matter for ML.

```python
import math

eps, delta = 0.05, 0.01
H = 1000                                        # size of the hypothesis class
chebyshev = 0.25 / (delta * eps**2)             # sigma^2 <= 1/4 for a 0-1 loss
hoeffding = math.log(2 / delta) / (2 * eps**2)  # one fixed hypothesis, two-sided
union = math.log(2 * H / delta) / (2 * eps**2)  # all H hypotheses at once
print("Chebyshev       n >=", math.ceil(chebyshev))
print("Hoeffding       n >=", math.ceil(hoeffding))
print("Union, |H|=1000 n >=", math.ceil(union))
```

```output
Chebyshev       n >= 10000
Hoeffding       n >= 1060
Union, |H|=1000 n >= 2442
```

## Common traps

> [!TRAP]
> **The fixed-classifier bound does not cover the classifier training picks.** Empirical risk minimisation (ERM) chooses $\hat{h}$ after seeing the data, so its error is not a fixed-$h$ average. For a finite class $\mathcal{H}$, the union bound gives $\mathbb{P}(\exists h \in \mathcal{H}: |R_n(h) - R(h)| \ge \epsilon) \le 2|\mathcal{H}|e^{-2n\epsilon^2}$, so $n \ge \ln(2|\mathcal{H}|/\delta)/(2\epsilon^2)$. For $|\mathcal{H}| = 1000$ this is 2442 examples, not 1060. This step is my own derivation from the union bound, not a quoted theorem.

> [!TRAP]
> **Hoeffding is not always tighter.** At $n = 100$ with $p = 0.1$, Chebyshev (0.09) beats Hoeffding (0.135). In the sweep, Chebyshev is the smaller bound for $12 \le n \le 135$ (Figure 3).

> [!TRAP]
> **Check one-sided against two-sided.** The factor 2 appears only for the two-sided event. Using the one-sided bound for $|\bar{X}_n - \mu|$ understates the risk by a factor of 2, and the sample-size formula then changes from $\ln(2/\delta)$ to $\ln(1/\delta)$.

> [!TRAP]
> **The range must be known.** Hoeffding needs each $X_i$ to lie in a known interval $[a_i, b_i]$. Squared error on unbounded regression targets has no finite $b$, so the inequality does not apply directly.

> [!TRAP]
> **Compare counts, not floats.** In Python, `0.6 - 0.5 == 0.1` is `False` (the difference is `0.09999999999999998`). Our first simulation, which compared means with 0.1, reported 0.0354 instead of 0.0573 for this reason. Compare integer counts, as the code above does.

## Summary

- Markov's inequality needs only a non-negative variable and its mean. Its bound does not shrink with $n$.
- Chebyshev's inequality uses the variance and decays as $1/n$.
- Hoeffding's inequality needs independent bounded values and decays as $e^{-2n\epsilon^2}$ (two-sided: factor 2). It ignores the variance, so Chebyshev can be tighter at small $n$.
- For a finite hypothesis class, the union bound multiplies by $|\mathcal{H}|$ and gives $n \ge \ln(2|\mathcal{H}|/\delta)/(2\epsilon^2)$.

### Question 1 (Calculation)
A classifier is evaluated on a test set of $n = 1000$ examples with 0-1 loss. You want, with 99% confidence ($\delta = 0.01$), that the measured error is within $\epsilon = 0.05$ of the true error for this fixed classifier. Does $n = 1000$ suffice by two-sided Hoeffding?

<details><summary>Show Solution</summary>

**Solution.** Solve $n \ge \ln(2/\delta)/(2\epsilon^2)$: $\ln(200)/(2 \times 0.0025) = 5.2983/0.005 = 1059.7$, so $n = 1060$ is needed. With $n = 1000$ the bound is $2e^{-2 \times 1000 \times 0.0025} = 2e^{-5} \approx 0.0135 > 0.01$. So no: $n = 1000$ does not suffice, although it is close.

</details>

### Question 3 (Bug-spotting)
This function is meant to return Chebyshev's bound on $\mathbb{P}(|\bar{X}_n - \mu| \ge \epsilon)$ for $n$ i.i.d. values with variance `var`. What is wrong with it?

```python
def chebyshev_mean_bound(var, n, eps):
    return var / eps**2
```

<details><summary>Show Solution</summary>

**Solution.** The variance of the sample mean is $\sigma^2/n$, not $\sigma^2$, so the function forgets to divide by $n$. For `var = 0.25`, `n = 100`, `eps = 0.1` it returns 25.0, which is not a probability. The fix is `return min(1.0, var / (n * eps**2))`, which gives 0.25.

</details>

### Question 4 (Explanation)
In the worked example, Chebyshev (0.09) beats Hoeffding (0.1353) at $n = 100$. Explain why, and say which bound you would trust more for a 0-1 loss at $n = 10^5$.

<details><summary>Show Solution</summary>

**Solution.** Hoeffding depends only on the range of each value, which is 1 for a 0-1 loss, and ignores the variance. Chebyshev uses the variance, which is 0.09 here, so it is tighter at this $n$. At $n = 10^5$ and $\epsilon = 0.1$ with $p = 0.5$, Hoeffding gives $2e^{-2000}$, while Chebyshev gives $0.25/(10^5 \times 0.01) = 0.00025$. Both are valid, and Hoeffding is far smaller because its decay is exponential in $n$ while Chebyshev decays only as $1/n$.

</details>
