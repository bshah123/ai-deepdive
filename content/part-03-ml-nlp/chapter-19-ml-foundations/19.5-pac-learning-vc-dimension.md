When can low error on training data be trusted as low error on new data? In this lesson you will state the PAC (probably approximately correct) guarantee, derive the sample size for a finite hypothesis class, count shattered labelings by hand, and check each count in code.

**You need:** empirical risk and loss functions (Lesson 19.1 and 19.2), and Hoeffding's inequality from Lesson 19.4.

## The problem: training error is not the goal

Training error is measured on $n$ examples you already have. What you care about is the **true risk** $R(h) = \mathbb{P}_{x \sim \mathcal{D}}\big(h(x) \neq c(x)\big)$, the chance of a wrong answer on a fresh input drawn from an unknown distribution $\mathcal{D}$, labelled by a target $c$. The training error $R_S(h)$ is the fraction of the $n$ sample points that $h$ gets wrong.

A flexible enough class can always reach $R_S(h) = 0$ on a fixed sample, so a low training error alone proves nothing. The question is: for which hypothesis classes $\mathcal{H}$, and how many samples, does low training error imply low true risk?

The learner that minimises training error is **empirical risk minimisation (ERM)**: output any $\hat{h} \in \mathcal{H}$ with the smallest $R_S$.

![Samples from an unknown distribution feed ERM, which outputs a hypothesis; the guarantee is about the error of that output](diagrams/19.5-pac-pipeline.svg "The only random object is the sample S. The guarantee holds over the draw of S.")

## PAC learning: what the two parameters mean

A class $\mathcal{H}$ is **PAC-learnable** if for every accuracy $\epsilon \in (0, \tfrac{1}{2})$ and confidence $\delta \in (0, \tfrac{1}{2})$ there is a sample size $n(\epsilon, \delta)$ such that, for every distribution $\mathcal{D}$ and every target $c \in \mathcal{H}$ (the **realizable** setting), a learner that sees $n$ i.i.d. labelled points returns $\hat{h}$ with

$$
\mathbb{P}_{S \sim \mathcal{D}^n}\big(R(\hat{h}) \le \epsilon\big) \ge 1 - \delta.
$$

The parameter $\epsilon$ says how wrong you allow the output to be. The parameter $\delta$ says how often you accept an unlucky sample. The sample size must hold for every $\mathcal{D}$, so it can depend only on $\epsilon$, $\delta$ and properties of $\mathcal{H}$. The task is to find which properties matter.

## Finite classes: the union bound

Fix one hypothesis $h$. Its loss on each sample point is 0 or 1, and the points are i.i.d. Hoeffding's inequality (Lesson 19.4) gives

$$
\mathbb{P}\big(|R(h) - R_S(h)| \ge \epsilon\big) \le 2e^{-2n\epsilon^2}.
$$

We need the deviation to be small for *every* $h$ at once, because ERM can pick any of them. The union bound (reasoning from first principles: the probability of a union is at most the sum of the probabilities) gives

$$
\mathbb{P}\big(\exists h \in \mathcal{H} : |R(h) - R_S(h)| \ge \epsilon\big) \le 2|\mathcal{H}|e^{-2n\epsilon^2}.
$$

Set the right side to $\delta$ and solve for $n$:

$$
n \ge \frac{\ln(2|\mathcal{H}|) + \ln(1/\delta)}{2\epsilon^2}.
$$

**Worked example.** Take $|\mathcal{H}| = 2^{10}$, $\epsilon = 0.05$, $\delta = 0.01$. Then $\ln(2^{11}) = 7.625$ and $\ln(100) = 4.605$. The numerator is 12.230, and the denominator is $2 \times 0.05^2 = 0.005$. So $n \ge 2446$.

![Bar chart of the required sample size: 2446, 3833, 6605 and 9932 for hypothesis classes of size 2 to the 10, 20, 40 and 64](diagrams/19.5-finite-bars.svg "Sample size grows with log of the class size, not with the class size.")

The dependence on $|\mathcal{H}|$ is through $\ln|\mathcal{H}|$. Each extra bit of $\log_2 |\mathcal{H}|$ adds $\ln 2 / (2\epsilon^2) \approx 139$ samples at $\epsilon = 0.05$. This bound is conservative: it covers all of $\mathcal{H}$ at once, not only the output of ERM.

## Infinite classes: shattering and VC dimension

Linear classifiers, or networks with real weights, have $|\mathcal{H}| = \infty$, so the union bound is useless. The Vapnik–Chervonenkis (VC) dimension replaces $|\mathcal{H}|$ with a count of labelings.

A set of $m$ points is **shattered** by $\mathcal{H}$ if every one of the $2^m$ labelings of those points is realized by some $h \in \mathcal{H}$. The **VC dimension** $d_{\text{VC}}$ is the largest $m$ for which some $m$-point set is shattered.

Lines in the plane first. Three non-collinear points are shattered: all 8 labelings are realized (code below). The four XOR points $(0,0), (1,1), (0,1), (1,0)$ are not: the two labelings in which the $+1$ points lie on one diagonal cannot be split by a line. So 14 of 16 are realized.

![Left: three points with one line realizing one labeling. Right: four XOR points, where a diagonal labeling cannot be separated by any line](diagrams/19.5-shatter.svg "One failing set shows that set is not shattered; it does not, by itself, show that no 4-point set is.")

The statement that lines in $\mathbb{R}^2$ have $d_{\text{VC}} = 3$ is the standard $d+1$ result for affine classifiers in $\mathbb{R}^d$. I did not open a primary source for it. The code supports it only for the sets tested.

Axis-aligned rectangles, with points inside labelled $+1$, have $d_{\text{VC}} = 4$. A cross of four points (top, bottom, left, right) is shattered: all 16 labelings are realized (brute-force count below). No 5-point set is shattered. My own argument: the four extreme points of any 5-point set (leftmost, rightmost, topmost, bottommost) span the bounding box of all five. Any rectangle containing those four also contains the fifth point. So "four outer points $+1$, centre point $-1$" is never realized. In 3000 random 5-point trials, the most labelings realized was 28 of 32, which agrees with this but is not a proof.

Parameter count is not capacity. The family $f_\theta(x) = \text{sign}(\sin(\theta x))$ has one parameter, yet it shatters every finite set. Take $x_i = 10^{-i}$ for $i = 1, \dots, n$. For labels $y_i \in \{-1, +1\}$, set $\theta = \pi\big(1 + \sum_i 10^i (1 - y_i)/2\big)$. For each $j$, the terms with $i > j$ are multiples of $2\pi$, the $i = j$ term is $\pi$ exactly when $y_j = -1$, and the rest is a small positive offset. So $\text{sign}(\sin(\theta x_j)) = y_j$. The code checks all 64 labelings for $n = 6$; the general argument is my own reasoning.

## The growth function and the Sauer–Shelah lemma

Let $\Pi_{\mathcal{H}}(n)$ be the largest number of labelings that $\mathcal{H}$ realizes on any $n$ points. The Sauer–Shelah lemma says that if $d_{\text{VC}} = d$, then $\Pi_{\mathcal{H}}(n) \le \sum_{i=0}^{d} \binom{n}{i}$ for every $n$, and for $n \ge d$ this sum is at most $(en/d)^d$. I did not open a primary source for this lemma; the code below only checks the sum against counts that were measured.

For rectangles ($d = 4$), the sum is $2^n$ for $n \le 4$, then falls below $2^n$. At $n = 10$ it is 386 against 1024 labelings.

![Grouped bars for n from 1 to 10: 2 to the n labelings versus the Sauer-Shelah sum with d = 4. The two curves split at n = 5. Amber dots are the largest count from random point sets](diagrams/19.5-growth.svg "The sum grows polynomially once n is past d.")

The polynomial form $(en/d)^d$ is only meant for $n \ge d$. At $n = 1$ it gives $0.21$, which is below the 2 labelings that a single point always has.

## Checking the counts in code

The first block counts realized labelings for lines (with a Perceptron, which converges exactly when the labeling is linearly separable) and for axis-aligned rectangles (by brute force over subsets).

```python
import itertools
import numpy as np

def perceptron_separable(X, y, max_epochs=1000):
    """True if the Perceptron finds a line w.x + b that separates +1 from -1."""
    w = np.zeros(X.shape[1])
    b = 0.0
    for _ in range(max_epochs):
        mistakes = 0
        for xi, yi in zip(X, y):
            if yi * (w @ xi + b) <= 0:
                w = w + yi * xi
                b += yi
                mistakes += 1
        if mistakes == 0:
            return True
    return False  # not separable, or not found within max_epochs

def count_line_labelings(points):
    """How many of the 2^n labelings of these points a 2D line can realize."""
    X = np.asarray(points, dtype=float)
    labelings = list(itertools.product([-1, 1], repeat=len(X)))
    realized = sum(perceptron_separable(X, np.array(l, dtype=float)) for l in labelings)
    return realized, len(labelings)

triangle = [[0, 1], [1, 0], [0, 0]]
xor_square = [[0, 0], [1, 1], [0, 1], [1, 0]]
print("3 points   :", count_line_labelings(triangle))
print("4 XOR pts  :", count_line_labelings(xor_square))

def rectangle_labelings(points):
    """Labelings an axis-aligned rectangle can realize (brute force).
    A subset T is realizable iff the points inside the bounding box of T are exactly T."""
    P = np.asarray(points, dtype=float)
    n = len(P)
    count = 0
    for mask in range(2 ** n):
        T = [i for i in range(n) if mask >> i & 1]
        if not T:
            count += 1  # the empty labeling: a rectangle placed away from all points
            continue
        lo, hi = P[T].min(axis=0), P[T].max(axis=0)
        inside = [i for i in range(n) if np.all(P[i] >= lo) and np.all(P[i] <= hi)]
        count += int(inside == T)
    return count

cross = [[0, 1], [0, -1], [1, 0], [-1, 0]]
print("rectangles, cross:", rectangle_labelings(cross), "of 16")
```

```output
3 points   : (8, 8)
4 XOR pts  : (14, 16)
rectangles, cross: 16 of 16
```

The second block checks the Sauer–Shelah sums, the sine construction for $n = 6$, and the finite-class sample sizes.

```python
import math
import itertools

d = 4
for n in [4, 5, 6, 10]:
    poly = sum(math.comb(n, i) for i in range(d + 1))
    print(f"n={n:2d}  2^n={2 ** n:5d}  Sauer-Shelah sum={poly:4d}")

n = 6
xs = [10.0 ** -i for i in range(1, n + 1)]
realized = 0
for ys in itertools.product([-1, 1], repeat=n):
    theta = math.pi * (1 + sum(10.0 ** i * (1 - y) / 2 for i, y in zip(range(1, n + 1), ys)))
    if all((math.sin(theta * x) > 0) == (y > 0) for x, y in zip(xs, ys)):
        realized += 1
print("sine, 6 points:", realized, "of", 2 ** n)

eps, delta = 0.05, 0.01
for log2H in [10, 20, 40, 64]:
    n_req = math.ceil((math.log(2 * 2.0 ** log2H) + math.log(1 / delta)) / (2 * eps ** 2))
    print(f"|H| = 2^{log2H}: n >= {n_req}")
```

## From growth to generalization, and where it stops

Combining the growth function with a union-bound argument over the labelings gives a bound of the form

$$
R(h) \le R_S(h) + C\sqrt{\frac{d_{\text{VC}}\ln(n/d_{\text{VC}}) + \ln(1/\delta)}{n}}
$$

for a universal constant $C$. I have not checked the constant against a source, so I give no value. The useful reading is that the gap shrinks like $\sqrt{d_{\text{VC}}/n}$, so the sample needed grows roughly linearly in $d_{\text{VC}}$.

These bounds are worst-case over distributions, and they can be very loose. Zhang et al. (2017) show that convolutional networks trained with SGD can fit random labels on the training set, so a parameter-count argument cannot separate them from classes that do not generalize. Bartlett and Foster (2017) give margin bounds for neural networks whose scale depends on the product of the spectral norms of the weight matrices, not on the number of parameters.

## Measured failure rate versus the union bound

Take the realizable setting with 101 threshold classifiers $h_t(x) = \mathbb{1}[x \ge t]$ for $t \in \{0, 0.01, \dots, 1\}$. The target is $t^* = 0.37$, and $\mathcal{D}$ is uniform on $[0,1]$. Then $R(h_t) = |t - t^*|$. With $\epsilon = 0.05$, there are $B = 90$ hypotheses with $R > \epsilon$. Any hypothesis consistent with the sample has probability at most $(1 - \epsilon)^n$ of being one of them, so the union bound on failure is $B(1-\epsilon)^n$.

The code below draws 4000 samples for each $n$, takes the first consistent threshold as the output, and counts how often its error exceeds $\epsilon$.

```python
import numpy as np

rng = np.random.default_rng(3)
grid = np.arange(101) / 100          # 101 threshold classifiers h_t(x) = 1[x >= t]
t_star, eps = 0.37, 0.05
true_err = np.abs(grid - t_star)     # error under Uniform[0, 1]
bad = int(np.sum(true_err > eps + 1e-12))
print("bad hypotheses B =", bad)
for n in [10, 20, 50, 100]:
    fails = 0
    for _ in range(4000):
        x = rng.random(n)
        y = (x >= t_star).astype(int)
        preds = (x[None, :] >= grid[:, None]).astype(int)
        consistent = np.all(preds == y[None, :], axis=1)
        k = int(np.argmax(consistent))  # first hypothesis that fits the sample
        fails += int(true_err[k] > eps)
    bound = min(1.0, bad * (1 - eps) ** n)
    print(f"n={n:3d}  measured P(error>eps)={fails / 4000:.4f}  union bound={bound:.4f}")
```

```output
bad hypotheses B = 90
n= 10  measured P(error>eps)=0.5450  union bound=1.0000
n= 20  measured P(error>eps)=0.2960  union bound=1.0000
n= 50  measured P(error>eps)=0.0408  union bound=1.0000
n=100  measured P(error>eps)=0.0025  union bound=0.5328
```

With $\delta = 0.01$, the union bound needs $n \ge \ln(B/\delta)/\ln(1/(1-\epsilon)) = 178$ to be guaranteed. At $n = 50$ the measured failure rate is 4.1%, above $\delta$, so 50 samples are not enough for this class. At $n = 100$ it is 0.25%, below $\delta$. The bound is valid but conservative by roughly 200 times at $n = 100$ (0.53 against 0.0025).

## Common traps

> [!TRAP]
> **"VC dimension counts parameters."** The sine family has one parameter and infinite VC dimension. Capacity is about the labelings a class can realize, not the number of weights.

> [!TRAP]
> **"One failing set proves the VC dimension."** The XOR square shows that one 4-point set is not shattered by lines. Showing $d_{\text{VC}} = 3$ needs every 4-point set to fail, which is a separate claim.

> [!TRAP]
> **"The polynomial bound applies for every $n$."** The form $(en/d)^d$ is only for $n \ge d$. At $n = 1$ with $d = 4$ it gives 0.21, but a single point already has 2 labelings.

> [!TRAP]
> **"VC bounds give a sample-size rule."** The VC bound has an unknown constant $C$, so it gives no fixed multiple of $d_{\text{VC}}$. A "10 times $d$" rule has no basis in these bounds.

> [!TRAP]
> **"The guarantee holds for any target."** Every result here assumes the target lies in $\mathcal{H}$ (realizable setting). With label noise, the sample sizes change and the statements need the agnostic form.

## Summary

- **PAC guarantee:** with probability at least $1-\delta$, the output of a learner has true risk at most $\epsilon$, for every distribution.
- **Finite classes:** Hoeffding plus the union bound gives $n \ge (\ln(2|\mathcal{H}|) + \ln(1/\delta))/(2\epsilon^2)$, which is logarithmic in $|\mathcal{H}|$.
- **VC dimension:** the largest number of points that $\mathcal{H}$ can shatter. Lines in $\mathbb{R}^2$ shatter 3 points; rectangles shatter 4; the sine family shatters any finite set.
- **Sauer–Shelah:** once $n$ exceeds $d_{\text{VC}}$, the number of realizable labelings grows polynomially, not as $2^n$.

### Question 3 (Bug-spotting)
This function is meant to return the sample size from the finite-class bound, where `log_H` is $\ln|\mathcal{H}|$.

```python
import math

def n_needed(log_H, eps, delta):
    return math.ceil((log_H + math.log(1 / delta)) / (2 * eps))
```

<details>
<summary>Show Solution</summary>

**Two errors.** The Hoeffding exponent is $2n\epsilon^2$, so the denominator must be $2\epsilon^2$, not $2\epsilon$. The union bound also gives $\ln(2|\mathcal{H}|) = \ln 2 + \ln|\mathcal{H}|$, and the $\ln 2$ is missing.

Corrected:

```python
def n_needed(log_H, eps, delta):
    return math.ceil((math.log(2) + log_H + math.log(1 / delta)) / (2 * eps ** 2))
```

A unit check catches the first error: $\epsilon$ is a probability, and $n$ must scale like $1/\epsilon^2$. With $|\mathcal{H}| = 2^{10}$, $\epsilon = 0.05$, $\delta = 0.01$, the buggy version gives about 115 (by hand), about 21 times too small. The corrected version gives 2446.
</details>
