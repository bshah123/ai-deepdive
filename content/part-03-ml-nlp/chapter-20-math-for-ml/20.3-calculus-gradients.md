# 20.3 — Multivariable Calculus: Jacobians, Hessians & Taylor Series

## Opening Motivation & Context

Multivariable calculus is a fundamental branch of mathematics that extends the concepts of single-variable calculus to functions of multiple variables. In the context of machine learning and natural language processing, multivariable calculus is essential for understanding and optimizing complex models. This lesson will focus on three key concepts: Jacobians, Hessians, and Taylor series.

- **Jacobians**: These are matrices of partial derivatives that describe how a vector-valued function changes with respect to its input variables. They are crucial for understanding the behavior of gradient-based optimization algorithms.
- **Hessians**: These are matrices of second-order partial derivatives that describe the local curvature of a function. They are used in optimization algorithms to determine the direction of steepest ascent or descent.
- **Taylor Series**: These are polynomial approximations of functions around a point. They are used to simplify complex functions and to understand the behavior of functions near a specific point.

## Core Concepts Breakdown

### Jacobians

> [!KEY-INSIGHT]
> The Jacobian matrix is a generalization of the derivative to functions of multiple variables. It provides a linear approximation of the function's behavior around a point.

> [!BEST-PRACTICE]
> When working with gradient-based optimization algorithms, always compute the Jacobian to understand how the function changes with respect to its input variables.

> [!WARNING]
> Be careful when computing Jacobians for functions with discontinuities or non-differentiable points, as these can lead to numerical instability.

### Hessians

> [!KEY-INSIGHT]
> The Hessian matrix provides information about the local curvature of a function. It is used to determine the direction of steepest ascent or descent in optimization algorithms.

> [!BEST-PRACTICE]
> When using second-order optimization algorithms, such as Newton's method, always compute the Hessian to improve the convergence rate.

> [!WARNING]
> Be cautious when computing Hessians for functions with rapidly changing curvature, as this can lead to numerical instability.

### Taylor Series

> [!KEY-INSIGHT]
> Taylor series provide polynomial approximations of functions around a point. They are useful for simplifying complex functions and understanding the behavior of functions near a specific point.

> [!BEST-PRACTICE]
> When working with complex functions, always consider using Taylor series to simplify the analysis and improve computational efficiency.

> [!WARNING]
> Be careful when using Taylor series for functions with singularities or infinite values, as these can lead to inaccurate approximations.

## Code Demonstration & Runtime Output

```python
import numpy as np
from typing import Callable, Tuple

def compute_jacobian(f: Callable[[np.ndarray], np.ndarray], x: np.ndarray, h: float = 1e-5) -> np.ndarray:
    """
    Compute the Jacobian matrix of a vector-valued function f at point x.

    Args:
        f: A vector-valued function that takes a numpy array and returns a numpy array.
        x: The point at which to compute the Jacobian.
        h: The step size for numerical differentiation.

    Returns:
        The Jacobian matrix of f at x.
    """
    n = len(x)
    m = len(f(x))
    jacobian = np.zeros((m, n))

    for i in range(n):
        x_plus_h = x.copy()
        x_plus_h[i] += h
        jacobian[:, i] = (f(x_plus_h) - f(x)) / h

    return jacobian

def compute_hessian(f: Callable[[np.ndarray], float], x: np.ndarray, h: float = 1e-5) -> np.ndarray:
    """
    Compute the Hessian matrix of a scalar-valued function f at point x.

    Args:
        f: A scalar-valued function that takes a numpy array and returns a float.
        x: The point at which to compute the Hessian.
        h: The step size for numerical differentiation.

    Returns:
        The Hessian matrix of f at x.
    """
    n = len(x)
    hessian = np.zeros((n, n))

    for i in range(n):
        for j in range(n):
            x_plus_h_i = x.copy()
            x_plus_h_i[i] += h
            x_plus_h_j = x.copy()
            x_plus_h_j[j] += h
            x_plus_h_i_j = x.copy()
            x_plus_h_i_j[i] += h
            x_plus_h_i_j[j] += h

            hessian[i, j] = (f(x_plus_h_i_j) - f(x_plus_h_i) - f(x_plus_h_j) + f(x)) / (h ** 2)

    return hessian

def taylor_series(f: Callable[[np.ndarray], float], x: np.ndarray, a: np.ndarray, n: int) -> float:
    """
    Compute the Taylor series approximation of a scalar-valued function f around point a.

    Args:
        f: A scalar-valued function that takes a numpy array and returns a float.
        x: The point at which to evaluate the Taylor series.
        a: The point around which to expand the Taylor series.
        n: The order of the Taylor series.

    Returns:
        The value of the Taylor series approximation at x.
    """
    result = 0.0
    for k in range(n + 1):
        result += (np.linalg.norm(x - a) ** k) * (compute_hessian(f, a)[k] / np.math.factorial(k))
    return result

if __name__ == "__main__":
    # Example usage
    def f(x: np.ndarray) -> np.ndarray:
        return np.array([x[0] ** 2 + x[1] ** 2, x[0] * x[1]])

    x = np.array([1.0, 2.0])
    jacobian = compute_jacobian(f, x)
    print("Jacobian:")
    print(jacobian)

    def g(x: np.ndarray) -> float:
        return x[0] ** 2 + x[1] ** 2

    hessian = compute_hessian(g, x)
    print("\nHessian:")
    print(hessian)

    a = np.array([0.0, 0.0])
    taylor = taylor_series(g, x, a, 2)
    print("\nTaylor series approximation:")
    print(taylor)
```

## How this works (Line-by-Line Breakdown)

1. **Imports**: We import the necessary libraries, including `numpy` for numerical computations and `typing` for type hints.
2. **compute_jacobian**: This function computes the Jacobian matrix of a vector-valued function `f` at point `x` using numerical differentiation.
   - We first determine the dimensions of the input and output of the function.
   - We then iterate over each input variable and compute the partial derivative using the central difference method.
3. **compute_hessian**: This function computes the Hessian matrix of a scalar-valued function `f` at point `x` using numerical differentiation.
   - We first determine the dimension of the input of the function.
   - We then iterate over each pair of input variables and compute the second-order partial derivative using the central difference method.
4. **taylor_series**: This function computes the Taylor series approximation of a scalar-valued function `f` around point `a`.
   - We first initialize the result to zero.
   - We then iterate over each term in the Taylor series and compute the contribution of that term to the approximation.
5. **Example usage**: We define a vector-valued function `f` and a scalar-valued function `g`, and we compute the Jacobian, Hessian, and Taylor series approximation for these functions at a specific point.

> [!ADVANCED]
> The `compute_jacobian` and `compute_hessian` functions use numerical differentiation to approximate the derivatives of the functions. This approach is simple and easy to implement, but it can be numerically unstable for functions with discontinuities or non-differentiable points. For more accurate results, consider using symbolic differentiation or automatic differentiation.

> [!QA]
> Q: When should I prefer the Jacobian over the Hessian?
> A: The Jacobian is used to compute the gradient of a vector-valued function, while the Hessian is used to compute the second-order derivatives of a scalar-valued function. If you are working with a scalar-valued function, you should use the Hessian. If you are working with a vector-valued function, you should use the Jacobian.
