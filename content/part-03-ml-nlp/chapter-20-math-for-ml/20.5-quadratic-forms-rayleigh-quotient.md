# 20.5 — Quadratic Forms, Positive Definiteness & Rayleigh Quotient Optimization

## Opening Motivation & Context

In multivariable calculus and machine learning, nearly every smooth loss function $\mathcal{L}(\theta)$ can be locally approximated around a stationary point $\theta^*$ by its second-order Taylor expansion:

\[
\mathcal{L}(\theta) \;\approx\; \mathcal{L}(\theta^*) \;+\; \nabla \mathcal{L}(\theta^*)^T (\theta - \theta^*) \;+\; \frac{1}{2} (\theta - \theta^*)^T \mathbf{H} (\theta - \theta^*)
\]

At a critical point ($\nabla \mathcal{L} = 0$), the behavior of the entire function—whether it is a local minimum, a local maximum, or a saddle point—is entirely dictated by the **quadratic form** $(\Delta \theta)^T \mathbf{H} (\Delta \theta)$.

Quadratic forms are the mathematical bridge connecting matrix algebra, curvature, convex optimization, and dimensionality reduction (PCA). In this lesson, we explore symmetric quadratic forms, positive definiteness, and the **Rayleigh Quotient**.

---

## Core Theoretical Framework

### 1. Quadratic Forms & Matrix Symmetry
A **quadratic form** on $\mathbb{R}^n$ associated with matrix $A \in \mathbb{R}^{n \times n}$ is a scalar function:

\[
f(x) \;=\; x^T A x \;=\; \sum_{i=1}^n \sum_{j=1}^n A_{ij} x_i x_j
\]

> [!KEY-INSIGHT]
> **Why we can always assume $A$ is symmetric**:
> Because $x^T A x$ is a scalar, $(x^T A x) = (x^T A x)^T = x^T A^T x$. Thus:
> \[
> x^T A x \;=\; x^T \left(\frac{A + A^T}{2}\right) x
> \]
> Any skew-symmetric part vanishes identically! Hence, without loss of generality, we always analyze quadratic forms using **symmetric matrices** $A = A^T$.

---

### 2. Matrix Definiteness & The Eigenvalue Test
For a real symmetric matrix $A = A^T \in \mathbb{R}^{n \times n}$:

| Classification | Condition on $x^T A x$ ($\forall x \ne 0$) | Eigenvalue Criterion | Geometry of Loss Surface |
| :--- | :--- | :--- | :--- |
| **Positive Definite ($A \succ 0$)** | $x^T A x > 0$ | All $\lambda_i > 0$ | Strict Bowl (Unique Minimum) |
| **Positive Semidefinite ($A \succeq 0$)** | $x^T A x \ge 0$ | All $\lambda_i \ge 0$ | Valley / Flat Trough |
| **Negative Definite ($A \prec 0$)** | $x^T A x < 0$ | All $\lambda_i < 0$ | Inverted Bowl (Unique Maximum) |
| **Indefinite** | Takes both positive & negative values | Mixed signs ($\lambda_i > 0$ and $\lambda_j < 0$) | **Saddle Point** (Col) |

---

### 3. The Rayleigh Quotient & Rayleigh-Ritz Theorem
For a symmetric matrix $A \in \mathbb{R}^{n \times n}$ and non-zero vector $x \ne 0$, the **Rayleigh Quotient** is:

\[
R_A(x) \;=\; \frac{x^T A x}{x^T x} \;=\; \left(\frac{x}{\|x\|_2}\right)^T A \left(\frac{x}{\|x\|_2}\right)
\]

#### The Rayleigh-Ritz Theorem:
Let $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_n$ be the sorted eigenvalues of symmetric matrix $A$ with corresponding orthonormal eigenvectors $v_1, \dots, v_n$. Then:

\[
\lambda_n \;\le\; R_A(x) \;\le\; \lambda_1 \quad \forall x \ne 0
\]

Furthermore:
\[
\max_{x \ne 0} R_A(x) \;=\; \max_{\|x\|_2 = 1} x^T A x \;=\; \lambda_1 \quad (\text{achieved at } x = v_1)
\]
\[
\min_{x \ne 0} R_A(x) \;=\; \min_{\|x\|_2 = 1} x^T A x \;=\; \lambda_n \quad (\text{achieved at } x = v_n)
\]

#### Derivation via Lagrange Multipliers:
To maximize $x^T A x$ subject to $\|x\|_2^2 = x^T x = 1$:
\[
\mathcal{L}(x, \lambda) \;=\; x^T A x \;-\; \lambda (x^T x - 1)
\]
Taking the vector derivative and setting to zero:
\[
\nabla_x \mathcal{L} \;=\; 2 A x - 2 \lambda x \;=\; 0 \implies A x \;=\; \lambda x
\]
The critical points are precisely the **eigenvectors of $A$**, and the value of the objective at critical point $v_i$ is $v_i^T A v_i = v_i^T (\lambda_i v_i) = \lambda_i \|v_i\|^2 = \lambda_i$.

> [!BEST-PRACTICE]
> **Fundamental Connection to Principal Component Analysis (PCA)**:
> In PCA, we seek the unit direction $v$ that maximizes the sample variance of projected data $X v$:
> \[
> \text{Var}(X v) \;=\; \frac{1}{n} (X v)^T (X v) \;=\; v^T \left(\frac{1}{n} X^T X\right) v \;=\; v^T \mathbf{C} v
> \]
> By the Rayleigh-Ritz Theorem, the direction of maximum variance is the **principal eigenvector** $v_1$ of sample covariance matrix $\mathbf{C}$, and the maximum variance achieved is the largest eigenvalue $\lambda_{\max}$!

## Code Demonstration & Runtime Output

Below is a complete Python script demonstrating quadratic form evaluation, definiteness classification, and Rayleigh quotient optimization.

```python
import numpy as np
from typing import Tuple, Dict

def analyze_quadratic_form(A: np.ndarray, x_sample: np.ndarray) -> Dict[str, any]:
    """
    Symmetrizes matrix A, computes eigenvalues, tests definiteness,
    and computes Rayleigh Quotient bounds.
    """
    # 1. Symmetrize A: A_sym = (A + A^T) / 2
    A_sym = 0.5 * (A + A.T)

    # 2. Eigendecomposition (Hermitian/Symmetric solver)
    eigenvalues, eigenvectors = np.linalg.eigh(A_sym)
    
    # Sort in descending order
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]

    # 3. Classify definiteness
    tol = 1e-10
    if np.all(eigenvalues > tol):
        definiteness = "Positive Definite (Strict Minimum)"
    elif np.all(eigenvalues >= -tol):
        definiteness = "Positive Semidefinite (Non-strict Valley)"
    elif np.all(eigenvalues < -tol):
        definiteness = "Negative Definite (Strict Maximum)"
    elif np.all(eigenvalues <= tol):
        definiteness = "Negative Semidefinite (Non-strict Ridge)"
    else:
        definiteness = "Indefinite (Saddle Point)"

    # 4. Rayleigh Quotient for x_sample
    norm_sq = np.dot(x_sample, x_sample)
    rq = float(np.dot(x_sample, np.dot(A_sym, x_sample)) / norm_sq)

    return {
        "A_sym": A_sym,
        "eigenvalues": eigenvalues,
        "principal_eigenvector": eigenvectors[:, 0],
        "definiteness": definiteness,
        "rayleigh_quotient": rq,
        "lambda_max": float(eigenvalues[0]),
        "lambda_min": float(eigenvalues[-1]),
        "rq_in_bounds": (eigenvalues[-1] - 1e-9 <= rq <= eigenvalues[0] + 1e-9)
    }

if __name__ == "__main__":
    # Test matrix from EEC351 Problem Set: A = [[5, -2], [-2, 2]]
    A_test = np.array([[5.0, -2.0], [-2.0, 2.0]])
    x_test = np.array([3.0, 1.0])

    res = analyze_quadratic_form(A_test, x_test)

    print("=== QUADRATIC FORM & RAYLEIGH QUOTIENT ANALYSIS ===")
    print(f"Matrix A:\n{res['A_sym']}")
    print(f"\nEigenvalues (lambda): {res['eigenvalues']}")
    print(f"Definiteness        : {res['definiteness']}")
    print(f"Principal Eigenvector (v1): {res['principal_eigenvector']}")
    print(f"\nRayleigh Quotient R_A(x=[3, 1]) : {res['rayleigh_quotient']:.4f}")
    print(f"Theoretical Bounds [min, max]  : [{res['lambda_min']:.4f}, {res['lambda_max']:.4f}]")
    print(f"R_A(x) lies within [l_min, l_max]: {res['rq_in_bounds']}")
```

### How this works (Line-by-Line Breakdown)

1. **`A_sym = 0.5 * (A + A.T)`**: Extracts the purely symmetric tensor component that governs the quadratic form.
2. **`np.linalg.eigh`**: Computes exact real eigenvalues ($\lambda_1 = 6.0, \lambda_2 = 1.0$) and orthonormal eigenvectors.
3. **Definiteness Test**: Both $\lambda_1, \lambda_2 > 0 \implies A \succ 0$ (Positive Definite). The quadratic form $f(x_1, x_2) = 5 x_1^2 - 4 x_1 x_2 + 2 x_2^2$ is strictly positive $\forall x \ne 0$ and forms an upward-opening elliptic paraboloid.
4. **Rayleigh Quotient**: For $x = [3, 1]^T$, $x^T A x = 5(9) - 4(3) + 2(1) = 35$. $\|x\|^2 = 3^2 + 1^2 = 10 \implies R_A(x) = 3.5000$.
5. **Rayleigh Bounds**: $1.00 \le 3.50 \le 6.00$, confirming the Rayleigh-Ritz theorem.

---

> [!ADVANCED]
> **Courant-Fischer Minimax Theorem (Generalized Eigenvalues)**:
> The $k$-th eigenvalue $\lambda_k$ can be characterized variationaly as:
> \[
> \lambda_k \;=\; \max_{\substack{S \subseteq \mathbb{R}^n \\ \dim(S) = k}} \min_{x \in S, x \ne 0} \frac{x^T A x}{x^T x}
> \]
> This minimax characterization enables spectral graph theory, spectral clustering, and low-rank matrix approximation proofs.

## Summary & Key Takeaways

- **Symmetric Invariance**: $x^T A x = x^T \left(\frac{A + A^T}{2}\right) x$.
- **Positive Definiteness**: $A \succ 0 \iff$ all eigenvalues $\lambda_i > 0 \iff$ strictly convex loss surface.
- **Rayleigh-Ritz Theorem**: $\lambda_{\min} \le \frac{x^T A x}{x^T x} \le \lambda_{\max}$.
- **PCA Invariance**: Maximizing projected variance $\max_{\|v\|=1} v^T \mathbf{C} v$ directly leads to the principal eigenvector $v_1$ corresponding to $\lambda_{\max}(\mathbf{C})$.

### Question 1 (Conceptual)
Given a sample covariance matrix $\mathbf{C} = \frac{1}{n} X^T X$ where $X \in \mathbb{R}^{n \times d}$, prove that $\mathbf{C}$ is always positive semidefinite ($\mathbf{C} \succeq 0$).

<details>
<summary>Show Solution</summary>

**Proof**:
For any non-zero vector $v \in \mathbb{R}^d$:
\[
v^T \mathbf{C} v \;=\; v^T \left(\frac{1}{n} X^T X\right) v \;=\; \frac{1}{n} (X v)^T (X v) \;=\; \frac{1}{n} \|X v\|_2^2
\]
Since the Euclidean norm squared $\|u\|_2^2 \ge 0$ for all vectors $u = X v$, and $n > 0$:
\[
v^T \mathbf{C} v \;\ge\; 0 \quad \forall v \in \mathbb{R}^d
\]
Therefore, by definition, any sample covariance matrix $\mathbf{C}$ is guaranteed to be **positive semidefinite** ($\mathbf{C} \succeq 0$).

### Question 3 (Bug-Fixing)
The following function attempts to verify if a matrix is positive definite using Cholesky decomposition, but fails on non-symmetric inputs. Fix it.

```python
# BUGGY CODE:
import numpy as np

def is_positive_definite(A: np.ndarray) -> bool:
    try:
        # Bug: Cholesky requires a symmetric matrix!
        np.linalg.cholesky(A)
        return True
    except np.linalg.LinAlgError:
        return False
```

<details>
<summary>Show Solution</summary>

**Corrected Code**:

```python
import numpy as np

def is_positive_definite(A: np.ndarray, tol: float = 1e-8) -> bool:
    """
    Checks if a real matrix is symmetric and positive definite (all eigenvalues > 0).
    """
    # 1. Verify symmetry: A == A.T
    if not np.allclose(A, A.T, atol=tol):
        return False
    
    # 2. Test positive definiteness via Cholesky decomposition
    try:
        np.linalg.cholesky(A)
        return True
    except np.linalg.LinAlgError:
        return False
```
</details>
