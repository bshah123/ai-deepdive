# 21.3 — Optimizers: SGD, Momentum, RMSprop & AdamW Deep Dive

## Opening Motivation & Context

Optimizers are the backbone of training neural networks. They determine how the model's weights are updated during training, directly impacting the model's convergence speed and final performance. Understanding the different optimizers and their underlying mechanics is crucial for any machine learning practitioner.

## Core Concepts Breakdown

### Stochastic Gradient Descent (SGD)

SGD is the most basic and foundational optimizer. It updates the weights in the opposite direction of the gradient of the loss function with respect to the weights.

> [!KEY-INSIGHT]
> SGD is simple but can be inefficient, especially in high-dimensional spaces or when the loss landscape is noisy.

> [!BEST-PRACTICE]
> Use SGD with a learning rate scheduler to adapt the learning rate during training.

> [!WARNING]
> SGD can get stuck in local minima or saddle points, especially in complex loss landscapes.

### Momentum

Momentum builds upon SGD by adding a fraction of the previous update to the current update. This helps accelerate the optimizer in relevant directions and dampens oscillations.

> [!KEY-INSIGHT]
> Momentum helps the optimizer navigate through flat regions and escape local minima.

> [!BEST-PRACTICE]
> Use a momentum value between 0.8 and 0.99 for most problems.

> [!WARNING]
> High momentum values can cause the optimizer to overshoot and diverge.

### RMSprop

RMSprop (Root Mean Square Propagation) adapts the learning rate for each weight individually based on the magnitudes of recent gradients. This helps the optimizer handle non-stationary objectives and noisy gradients.

> [!KEY-INSIGHT]
> RMSprop is particularly effective for recurrent neural networks (RNNs) and other models with noisy gradients.

> [!BEST-PRACTICE]
> Use a decay rate of 0.9 for most problems.

> [!WARNING]
> RMSprop can be sensitive to the choice of hyperparameters, especially the decay rate.

### AdamW

AdamW (Adam with Weight Decay) is an improved version of the Adam optimizer that decouples the weight decay from the gradient update. This leads to better generalization and more stable training.

> [!KEY-INSIGHT]
> AdamW is a robust choice for many problems, offering good convergence properties and stability.

> [!BEST-PRACTICE]
> Use a learning rate of 3e-4 and weight decay of 1e-2 for most problems.

> [!WARNING]
> AdamW can be sensitive to the choice of hyperparameters, especially the learning rate.

## Code Demonstration & Runtime Output

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset

# Generate synthetic data
X = torch.randn(1000, 10)
y = torch.randn(1000, 1)

# Create a simple neural network
class SimpleNN(nn.Module):
    def __init__(self):
        super(SimpleNN, self).__init__()
        self.fc1 = nn.Linear(10, 5)
        self.fc2 = nn.Linear(5, 1)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x

# Initialize models and optimizers
models = {
    'SGD': SimpleNN(),
    'Momentum': SimpleNN(),
    'RMSprop': SimpleNN(),
    'AdamW': SimpleNN()
}

optimizers = {
    'SGD': optim.SGD(models['SGD'].parameters(), lr=0.01),
    'Momentum': optim.SGD(models['Momentum'].parameters(), lr=0.01, momentum=0.9),
    'RMSprop': optim.RMSprop(models['RMSprop'].parameters(), lr=0.01),
    'AdamW': optim.AdamW(models['AdamW'].parameters(), lr=0.01)
}

# Training loop
def train_model(model, optimizer, epochs=100):
    dataset = TensorDataset(X, y)
    dataloader = DataLoader(dataset, batch_size=32, shuffle=True)
    criterion = nn.MSELoss()

    for epoch in range(epochs):
        for batch_X, batch_y in dataloader:
            optimizer.zero_grad()
            outputs = model(batch_X)
            loss = criterion(outputs, batch_y)
            loss.backward()
            optimizer.step()

# Train all models
for name in models:
    print(f"Training {name}...")
    train_model(models[name], optimizers[name])

print("Training complete!")
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: We import necessary libraries including PyTorch for neural network and optimization utilities.
2. **Data Generation**: We create synthetic data for demonstration purposes.
3. **Neural Network Definition**: We define a simple neural network with two fully connected layers.
4. **Model Initialization**: We initialize four instances of the neural network, one for each optimizer.
5. **Optimizer Initialization**: We initialize four different optimizers: SGD, SGD with momentum, RMSprop, and AdamW.
6. **Training Loop**: We define a training loop that iterates over the data, computes the loss, and updates the model parameters using the specified optimizer.
7. **Model Training**: We train each model using its respective optimizer and print the training progress.

> [!ADVANCED]
> The training loop involves forward and backward passes, which are implemented efficiently using PyTorch's autograd system. The backward pass computes the gradients of the loss with respect to the model parameters, and the optimizer updates the parameters based on these gradients. The choice of optimizer affects the gradient update rule, which in turn affects the convergence properties of the training process.

## Summary & Key Takeaways

- **SGD** is the simplest optimizer but can be inefficient in complex loss landscapes.
- **Momentum** helps accelerate the optimizer and dampens oscillations.
- **RMSprop** adapts the learning rate for each weight individually, making it effective for noisy gradients.
- **AdamW** is a robust choice for many problems, offering good convergence properties and stability.
- **Hyperparameter Tuning**: The choice of hyperparameters (learning rate, momentum, decay rate, etc.) is crucial for the performance of the optimizer.

<details><summary>Show Solution</summary>

**A: The bug is that the optimizer's step method is called twice without zeroing the gradients in between. This will result in incorrect parameter updates. The fixed code is:**

```python
import torch
import torch.optim as optim

# Create a simple parameter tensor
params = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)

# Initialize optimizer
optimizer = optim.SGD([params], lr=0.1)

# Perform a single update
grad = torch.tensor([0.1, 0.2, 0.3])
params.grad = grad

optimizer.step()
optimizer.zero_grad()  # Zero the gradients before the next update
optimizer.step()

print(params)
```

</details>
