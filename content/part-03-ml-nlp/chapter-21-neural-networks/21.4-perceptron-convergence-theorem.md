# 21.4 — The Perceptron Learning Algorithm & Novikoff's Convergence Theorem

## Opening Motivation & Context

In 1958, Frank Rosenblatt created the **Perceptron**, the biological precursor to all modern artificial neural networks. The Perceptron was accompanied by a groundbreaking theoretical result: if a dataset is linearly separable, the Perceptron Learning Algorithm (PLA) is mathematically guaranteed to find a separating hyperplane in a **finite number of steps**.

In 1962, Albert Novikoff provided the rigorous formal proof of the **Perceptron Convergence Theorem**. This proof remains one of the most elegant and fundamental results in computational learning theory, introducing the geometric concept of the **margin** $\gamma$, which later formed the theoretical foundation of Support Vector Machines (SVMs).

---

## Core Theoretical Framework

### 1. The Perceptron Model
Let the input space be $\mathcal{X} = \mathbb{R}^d$ and target binary labels $y_i \in \{-1, +1\}$.
Using homogeneous coordinates by absorbing bias $b$ into weight vector $w \in \mathbb{R}^{d+1}$ and appending $1$ to inputs $x = [x_1, \dots, x_d, 1]^T$:

\[
\hat{y} \;=\; \text{sign}(w^T x) \;=\; \begin{cases} +1 & \text{if } w^T x \ge 0 \\ -1 & \text{if } w^T x < 0 \end{cases}
\]

---

### 2. The Perceptron Learning Algorithm (PLA)
1. Initialize weight vector $w_0 = \mathbf{0} \in \mathbb{R}^{d+1}$, step counter $k = 0$.
2. In each iteration, find a misclassified training sample $(x_i, y_i)$ such that:
   \[
   y_i (w_k^T x_i) \;\le\; 0
   \]
3. Update weights:
   \[
   w_{k+1} \;=\; w_k \;+\; y_i x_i
   \]
4. Increment $k \leftarrow k + 1$ and repeat until no misclassified points remain.

---

### 3. Novikoff's Perceptron Convergence Theorem

#### Theorem Statement:
Let $S = \{(x_1, y_1), \dots, (x_n, y_n)\}$ be a training set. Assume:
1. **Linear Separability**: There exists a unit-norm weight vector $w^*$ ($\|w^*\|_2 = 1$) and margin $\gamma > 0$ such that:
   \[
   y_i (w^{*T} x_i) \;\ge\; \gamma \quad \forall i \in \{1, \dots, n\}
   \]
2. **Bounded Radius**: All data points are contained within a ball of radius $R$:
   \[
   \|x_i\|_2 \;\le\; R \quad \forall i \in \{1, \dots, n\}
   \]

Then the Perceptron algorithm terminates after making at most $k_{\max}$ mistakes/updates, where:

\[
k \;\le\; \left(\frac{R}{\gamma}\right)^2
\]

---

### 4. Step-by-Step Mathematical Proof

We establish two opposing bounds on the squared norm $\|w_k\|_2^2$ after $k$ weight updates:

#### Part A: Lower Bounding the Projection $w_k^T w^*$
Consider the inner product $w_k^T w^*$. On the $k$-th mistake on sample $(x_i, y_i)$:
\[
w_k^T w^* \;=\; (w_{k-1} + y_i x_i)^T w^* \;=\; w_{k-1}^T w^* \;+\; y_i (w^{*T} x_i)
\]
Since $y_i (w^{*T} x_i) \ge \gamma$:
\[
w_k^T w^* \;\ge\; w_{k-1}^T w^* \;+\; \gamma
\]
By induction starting from $w_0 = \mathbf{0}$:
\[
w_k^T w^* \;\ge\; k \gamma
\]
Using Cauchy-Schwarz inequality $\|w_k\|_2 \|w^*\|_2 \ge w_k^T w^*$ with $\|w^*\|_2 = 1$:
\[
\|w_k\|_2 \;\ge\; k \gamma \implies \|w_k\|_2^2 \;\ge\; k^2 \gamma^2 \quad \text{--- (Equation 1)}
\]

#### Part B: Upper Bounding the Norm Squared $\|w_k\|_2^2$
Now we compute the Euclidean norm of the update directly:
\[
\|w_k\|_2^2 \;=\; \|w_{k-1} + y_i x_i\|_2^2 \;=\; \|w_{k-1}\|_2^2 \;+\; 2 y_i (w_{k-1}^T x_i) \;+\; y_i^2 \|x_i\|_2^2
\]
Because an update is only triggered when $(x_i, y_i)$ is misclassified by $w_{k-1}$, we have $y_i (w_{k-1}^T x_i) \le 0$. Furthermore, $y_i^2 = 1$ and $\|x_i\|_2^2 \le R^2$:
\[
\|w_k\|_2^2 \;\le\; \|w_{k-1}\|_2^2 \;+\; 0 \;+\; R^2
\]
By induction starting from $w_0 = \mathbf{0}$:
\[
\|w_k\|_2^2 \;\le\; k R^2 \quad \text{--- (Equation 2)}
\]

#### Part C: Combining the Bounds
Combining Equation (1) and Equation (2):
\[
k^2 \gamma^2 \;\le\; \|w_k\|_2^2 \;\le\; k R^2
\]
Dividing both sides by $k \gamma^2$ (since $k > 0$ and $\gamma > 0$):
\[
k \;\le\; \frac{R^2}{\gamma^2} \;=\; \left(\frac{R}{\gamma}\right)^2 \quad \blacksquare
\]

> [!KEY-INSIGHT]
> **Geometric Intuition of the Proof**:
> 1. With every update, the weight vector aligns closer with the optimal direction $w^*$, growing along $w^*$ at a rate of at least $\mathcal{O}(k)$.
> 2. However, because each update occurs on a misclassified point, the perpendicular components grow at a much slower rate of at most $\mathcal{O}(\sqrt{k})$.
> 3. These two conflicting rates force the algorithm to terminate in at most $(R/\gamma)^2$ steps!

## Code Demonstration & Empirical Verification

Below is a complete Python implementation verifying Novikoff's theorem on synthetic linearly separable data.

```python
import numpy as np
from typing import Tuple, Dict

class PerceptronTrainer:
    def __init__(self):
        self.w = None
        self.b = 0.0

    def fit(self, X: np.ndarray, y: np.ndarray, max_iters: int = 10000) -> int:
        """
        Runs Perceptron Learning Algorithm and returns total update count k.
        """
        n, d = X.shape
        self.w = np.zeros(d)
        self.b = 0.0
        updates = 0

        for _ in range(max_iters):
            mistake_found = False
            for i in range(n):
                pred = np.dot(self.w, X[i]) + self.b
                if y[i] * pred <= 0:
                    self.w += y[i] * X[i]
                    self.b += y[i]
                    updates += 1
                    mistake_found = True
                    break  # Standard PLA: update on first mistake encountered
            if not mistake_found:
                break

        return updates

def verify_novikoff_bound(n_samples: int = 100, seed: int = 42) -> Dict[str, float]:
    """
    Generates separable dataset with known margin gamma and verifies k <= (R / gamma)^2.
    """
    np.random.seed(seed)
    
    # 1. True separating hyperplane w* = [1/sqrt(2), 1/sqrt(2)]
    w_true = np.array([1.0, 1.0]) / np.sqrt(2.0)
    
    # 2. Generate points with guaranteed margin gamma = 0.2
    gamma_target = 0.2
    X_list, y_list = [], []
    
    while len(X_list) < n_samples:
        pt = np.random.uniform(-5.0, 5.0, size=2)
        dist = np.dot(w_true, pt)
        if abs(dist) >= gamma_target:
            X_list.append(pt)
            y_list.append(1 if dist > 0 else -1)

    X = np.array(X_list)
    y = np.array(y_list)

    # 3. Compute empirical R and exact margin gamma
    # Augmented coordinates [x1, x2, 1] to account for bias
    X_aug = np.hstack([X, np.ones((n_samples, 1))])
    R = float(np.max(np.linalg.norm(X_aug, axis=1)))
    
    # True augmented normal: w*_aug = [1/sqrt(2), 1/sqrt(2), 0]
    w_star_aug = np.array([1.0 / np.sqrt(2.0), 1.0 / np.sqrt(2.0), 0.0])
    margins = y * np.dot(X_aug, w_star_aug)
    exact_gamma = float(np.min(margins))

    # 4. Train Perceptron
    model = PerceptronTrainer()
    actual_updates = model.fit(X, y)
    
    # Theoretical Novikoff bound
    theoretical_max = (R / exact_gamma) ** 2

    return {
        "n_samples": n_samples,
        "R": R,
        "gamma": exact_gamma,
        "actual_updates": actual_updates,
        "theoretical_max": theoretical_max,
        "bound_satisfied": actual_updates <= theoretical_max
    }

if __name__ == "__main__":
    res = verify_novikoff_bound(n_samples=200)
    print("=== NOVIKOFF PERCEPTRON CONVERGENCE THEOREM VERIFICATION ===")
    print(f"Sample Size (n)               : {res['n_samples']}")
    print(f"Radius Bound (R)              : {res['R']:.4f}")
    print(f"Separating Margin (gamma)     : {res['gamma']:.4f}")
    print(f"Actual PLA Updates (k)        : {res['actual_updates']}")
    print(f"Novikoff Theoretical Bound (R/g)^2: {res['theoretical_max']:.1f}")
    print(f"Is k <= (R/gamma)^2           : {res['bound_satisfied']}")
```

```text
Output:
=== NOVIKOFF PERCEPTRON CONVERGENCE THEOREM VERIFICATION ===
Sample Size (n)               : 200
Radius Bound (R)              : 6.9405
Separating Margin (gamma)     : 0.2018
Actual PLA Updates (k)        : 23
Novikoff Theoretical Bound (R/g)^2: 1183.0
Is k <= (R/gamma)^2           : True
```

### How this works (Line-by-Line Breakdown)

1. **Synthetic Data Generation**: Creates 200 samples in $\mathbb{R}^2$ with a guaranteed geometric margin $\gamma \ge 0.20$.
2. **Radius $R$**: Maximum Euclidean distance of any augmented sample is $R \approx 6.94$.
3. **Novikoff Bound**: Theoretical upper bound on mistakes is $(6.94 / 0.2018)^2 \approx 1183$ updates.
4. **Empirical Performance**: The Perceptron converged in just **23 updates**, well within the theoretical ceiling.
5. **Takeaway**: If data is separable, convergence is guaranteed regardless of dimension $d$—it depends only on the geometric ratio $(R/\gamma)^2$.

---

> [!WARNING]
> **What happens if data is NOT linearly separable?**
> If data is non-separable (e.g. XOR or overlapping noise), the Perceptron algorithm will **loop infinitely without converging**. In practice, early stopping or the **Pocket Algorithm** (which keeps the best weight vector encountered so far) is required.

---

## Summary & Key Takeaways

- **Novikoff's Bound**: Total mistakes $k \le \left(\frac{R}{\gamma}\right)^2$.
- **Dimension Independence**: The convergence bound does not explicitly depend on dimension $d$, only on the geometry of the margin $\gamma$ and radius $R$.
- **Proof Structure**: Lower bounds $w_k^T w^* \ge k \gamma$ (linear growth) against upper bound $\|w_k\|^2 \le k R^2$ (sub-linear growth).

### Question 1 (Conceptual)
If we scale all feature vectors by a constant factor $c > 1$ (i.e. $x_i \to c x_i$), does the Novikoff convergence bound $(R/\gamma)^2$ change?

<details>
<summary>Show Solution</summary>

**Solution**:
**No, the bound remains unchanged**.
When $x_i \to c x_i$:
- The radius scales by $c$: $R' = c R$.
- The geometric margin also scales by $c$: $\gamma' = c \gamma$.
- The ratio $(R' / \gamma')^2 = (c R / c \gamma)^2 = (R / \gamma)^2$.
Thus, Novikoff's convergence bound is completely **scale-invariant**.
</details>

<details>
<summary>Show Solution</summary>

**Corrected Code**:

```python
import numpy as np

def perceptron_step(w: np.ndarray, x: np.ndarray, y: int) -> np.ndarray:
    """
    Perceptron update rule: only updates weights when sample is misclassified (y * (w . x) <= 0).
    """
    # A mistake occurs when the sign does not match (<= 0)
    if y * np.dot(w, x) <= 0:
        return w + y * x
    return w
```
