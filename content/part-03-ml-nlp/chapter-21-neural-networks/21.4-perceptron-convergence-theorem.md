You will implement the perceptron learning algorithm (PLA), trace it by hand on four points, and prove Novikoff's theorem, which bounds the number of mistakes the algorithm can make on separable data. After this lesson you can compute the bound for a dataset and say when it does not apply.

**You need:** dot products and the sign of a linear score (Lesson 20.1), and the single artificial neuron from Lesson 21.1.

## The problem

A linear classifier predicts $\hat y = \text{sign}(w^\top x + b)$. Given labelled points, we want weights $w$ and bias $b$ that classify all of them correctly. The perceptron rule does this one point at a time: when a point is misclassified, move the boundary toward it.

Two questions follow. Does the rule ever stop? If it does, how long does it take? Novikoff's theorem answers both for **linearly separable** data, meaning data for which some hyperplane classifies every point correctly.

## Augmentation: the bias as one more weight

Append a constant 1 to every input, $x \leftarrow [x_1, \dots, x_d, 1]$, and let $w$ hold the bias as its last entry. Then $w^\top x = \sum_j w_j x_j + b$, and the bias needs no special case. Every result below uses augmented vectors, so the radius and the margin are measured in $d+1$ dimensions.

Labels are $y \in \{-1, +1\}$. Start from $w = 0$. Whenever a point is misclassified, meaning $y\,(w^\top x) \le 0$, set

$$
w \leftarrow w + y\,x.
$$

Zero counts as a mistake. At $w = 0$ every score is zero, so a strict "$< 0$" test would never update and would stop at $w = 0$ (quiz question 2 checks this).

Lesson 21.1 used labels 0 and 1, with a step that outputs 1 at $z = 0$. There a positive point with score zero was not an error. Here the labels are $\pm 1$ and zero is an error for both labels. On a mistake, Lesson 21.1's update $w \leftarrow w + \eta\,(t - \hat y)\,x$ has $t - \hat y = \pm 1$, which is the same step as $w \leftarrow w + yx$ with $\eta = 1$.

Why does the update help on the point it was fixing? The new score on that point is

$$
y\,(w + yx)^\top x = y\,(w^\top x) + y^2\,\|x\|^2 = y\,(w^\top x) + \|x\|^2,
$$

using $y^2 = 1$. The score rises by $\|x\|^2 > 0$. This is a local fix. It can move other points the wrong way, which is why a global argument is needed.

## Worked example, by hand

Take four points, augment them to $\mathbb{R}^3$, and cycle through them in order:

| Point | Augmented $x$ | Label $y$ |
|---|---|---|
| 1 | $(1, 0, 1)$ | $+1$ |
| 2 | $(0, 1, 1)$ | $-1$ |
| 3 | $(1, 1, 1)$ | $+1$ |
| 4 | $(-1, -1, 1)$ | $-1$ |

Start with $w = (0, 0, 0)$. Point 1 scores 0, which counts as a mistake, so $w = (1, 0, 1)$. Point 2 scores $+1$ but its label is $-1$, so $w = (1, -1, 0)$. Point 3 scores 0, so $w = (2, 0, 1)$. The first pass has three mistakes. On the second pass, point 2 is still misclassified and gives the fourth update, $w = (2, -1, 0)$. The third pass has no mistakes, so the loop stops.

Check the final weights: the signed scores $y\,(w^\top x)$ are $2, 1, 1, 1$ for points 1 to 4, all positive.

Now the bound. $R$ is the largest augmented norm, $\sqrt{3}$, reached by points 3 and 4. For the margin, take the unit vector $w/\|w\|$ for the final $w = (2, -1, 0)$. The smallest signed score is 1, so $\gamma = 1/\sqrt{5} \approx 0.447$ and $(R/\gamma)^2 = 15$. Four updates fit under 15. The tightest margin is the maximum-margin separator, $\gamma^* = \sqrt{2}/3 \approx 0.471$, which gives 13.5 (computed in the local block below).

```python
import numpy as np

def augment(X):
    return np.hstack([X, np.ones((len(X), 1))])

def perceptron(Xa, y, max_epochs=1000):
    w = np.zeros(Xa.shape[1])
    trace, per_epoch = [], []
    for epoch in range(1, max_epochs + 1):
        mistakes = 0
        for i in range(len(Xa)):
            score = float(w @ Xa[i])
            if y[i] * score <= 0:                      # zero counts as a mistake
                w = w + y[i] * Xa[i]
                trace.append((epoch, i + 1, score, w.copy()))
                mistakes += 1
        per_epoch.append(mistakes)
        if mistakes == 0:                              # a clean pass: w separates every point
            break
    return w, trace, per_epoch

def certificate(Xa, y, w):
    R = np.linalg.norm(Xa, axis=1).max()
    gamma = (y * (Xa @ w)).min() / np.linalg.norm(w)   # margin of the unit vector w/||w||
    return R, gamma, (R / gamma) ** 2

X = np.array([[1., 0.], [0., 1.], [1., 1.], [-1., -1.]])
y = np.array([1, -1, 1, -1])
Xa = augment(X)
w, trace, per_epoch = perceptron(Xa, y)
for k, (epoch, point, score, w_new) in enumerate(trace, 1):
    print(f"update {k} (epoch {epoch}, point {point}): score {score:+.0f}, w -> {w_new}")
print("mistakes per epoch:", per_epoch)
print("final w:", w, "| all points correct:", bool(np.all(y * (Xa @ w) > 0)))
R, gamma, bound = certificate(Xa, y, w)
print(f"R = {R:.4f}, gamma = {gamma:.4f}, bound (R/gamma)^2 = {bound:.2f}, updates = {len(trace)}")

print("--- scaling ---")
for c in [0.1, 10.0]:
    _, tr_all, _ = perceptron(c * Xa, y)
    Xs = Xa.copy()
    Xs[:, :2] *= c                                     # scale the features, leave the constant 1
    w_s, tr_feat, _ = perceptron(Xs, y)
    _, _, b_feat = certificate(Xs, y, w_s)
    print(f"c = {c:>5}: scale whole vector -> {len(tr_all)} updates | "
          f"features only -> {len(tr_feat)} updates, bound {b_feat:.1f}")

print("--- XOR (not separable) ---")
X_x = np.array([[1., 1.], [-1., -1.], [1., -1.], [-1., 1.]])
y_x = np.array([1, 1, -1, -1])
_, tr_x, per_x = perceptron(augment(X_x), y_x, max_epochs=20)
print("mistakes per epoch (20 epochs):", per_x)
```

## Novikoff's theorem and its proof

**Assumptions.**

1. **Separability with margin.** There is a unit vector $w^*$ ($\|w^*\| = 1$) and a margin $\gamma > 0$ such that $y_i\,(w^{*\top} x_i) \ge \gamma$ for every point $i$.
2. **Bounded radius.** $\|x_i\| \le R$ for every point $i$.

**Claim.** Under these assumptions, the perceptron makes at most $k \le (R/\gamma)^2$ updates, in any order of the points, provided every update is made on a misclassified point.

**Proof.** Let $w_k$ be the weights after the $k$-th update, which is made on a point $(x, y)$.

*Lower bound on the projection.* Taking the inner product with $w^*$,

$$
w_k^\top w^* = w_{k-1}^\top w^* + y\,(w^{*\top} x) \ \ge\ w_{k-1}^\top w^* + \gamma.
$$

Starting from $w_0 = 0$, induction gives $w_k^\top w^* \ge k\gamma$. By Cauchy–Schwarz with $\|w^*\| = 1$, $\|w_k\| \ge w_k^\top w^* \ge k\gamma$.

*Upper bound on the norm.* Expanding the square,

$$
\|w_k\|^2 = \|w_{k-1}\|^2 + 2\,y\,(w_{k-1}^\top x) + \|x\|^2.
$$

The update happened because $y\,(w_{k-1}^\top x) \le 0$, so the middle term is non-positive. Also $\|x\|^2 \le R^2$. Hence $\|w_k\|^2 \le \|w_{k-1}\|^2 + R^2$, and by induction $\|w_k\|^2 \le kR^2$.

*Combine.* $k^2\gamma^2 \le \|w_k\|^2 \le kR^2$, so $k \le R^2/\gamma^2$. $\blacksquare$

![One update drawn against the separator w star: the new weights w(k) equal w(k-1) plus the update y x; the projection on w star grows by at least gamma while the update's length is at most R.](diagrams/21.4-update-geometry.svg "The two inequalities in one picture. The projection grows linearly; the squared norm grows by at most R squared per update.")

The margin $\gamma$ controls how fast the weights grow in the direction of $w^*$. The radius $R$ controls how fast their norm can grow. The sign of the mistake condition is what keeps the norm growth small. The bound is a worst-case statement under assumptions 1 and 2; it says nothing about data that violates them.

## Measured behaviour on random data

We generated 300 random separable datasets. Inputs are uniform in $[-3, 3]^2$, each dataset has 10 to 59 points, and labels come from a random hyperplane, with points kept at least 0.05 from it. For each dataset we computed the exact maximum-margin $\gamma^*$ with a hard-margin support vector machine (SVM), then ran the perceptron and counted updates. The code is in the block below, which needs scipy.

![Scatter on log-log axes of the perceptron update count against the Novikoff bound for 300 datasets. All points lie below the diagonal where updates equal the bound.](diagrams/21.4-bound-vs-actual.svg "Each point is one dataset. Points below the dashed line satisfy the bound.")

Across the 300 datasets there are zero violations. The updates divided by the bound have median 0.0315 and maximum 0.4204. The median update count is 7.5 and the maximum is 144. The bound's median is 268.7. The bound is loose by a factor of about 30 at the median. It is a guarantee, not a prediction of the count.

<details><summary>Run locally: needs pip install scipy</summary>

```python
import numpy as np
import scipy
from scipy.optimize import minimize

def augment(X):
    return np.hstack([X, np.ones((len(X), 1))])

def perceptron_updates(Xa, y, max_epochs=1000):
    w = np.zeros(Xa.shape[1])
    updates = 0
    for epoch in range(1, max_epochs + 1):
        mistakes = 0
        for i in range(len(Xa)):
            if y[i] * float(w @ Xa[i]) <= 0:
                w = w + y[i] * Xa[i]
                updates += 1
                mistakes += 1
        if mistakes == 0:
            return updates
    raise RuntimeError("no convergence")

def max_margin(Xa, y):
    # hard-margin SVM in augmented space: min 0.5||w||^2 s.t. y_i w.x_i >= 1, so gamma* = 1/||w||
    dim = Xa.shape[1]
    cons = {"type": "ineq", "fun": lambda w: y * (Xa @ w) - 1.0, "jac": lambda w: y[:, None] * Xa}
    res = minimize(lambda w: 0.5 * w @ w, np.full(dim, 0.1), jac=lambda w: w,
                   constraints=[cons], method="SLSQP", options={"ftol": 1e-12, "maxiter": 1000})
    assert np.all(y * (Xa @ res.x) >= 1 - 1e-6), "SVM infeasible"
    return 1.0 / np.linalg.norm(res.x)

print("scipy", scipy.__version__, "numpy", np.__version__)
rng = np.random.default_rng(2024)
rows = []
for t in range(300):
    n = int(rng.integers(10, 60))
    u = rng.normal(size=3)
    u /= np.linalg.norm(u)
    pts = []
    while len(pts) < n:
        p = rng.uniform(-3.0, 3.0, size=2)
        if abs(float(u @ np.append(p, 1.0))) >= 0.05:
            pts.append(p)
    Xa = augment(np.array(pts))
    y = np.where(Xa @ u > 0, 1, -1)
    R = np.linalg.norm(Xa, axis=1).max()
    gamma_gen = (y * (Xa @ u)).min()
    g_star = max_margin(Xa, y)
    assert g_star >= gamma_gen - 1e-7
    k = perceptron_updates(Xa, y)
    rows.append((k, (R / g_star) ** 2, k / (R / g_star) ** 2))
ks = np.array([r[0] for r in rows]); bs = np.array([r[1] for r in rows]); rs = np.array([r[2] for r in rows])
print("datasets:", len(rows), "| violations of the bound:", int(np.sum(ks > bs + 1e-9)))
print(f"updates/bound: min {rs.min():.4f}, median {np.median(rs):.4f}, max {rs.max():.4f}")
print(f"updates: min {ks.min()}, median {np.median(ks):.1f}, max {ks.max()}")
print(f"bound: median {np.median(bs):.1f}, max {bs.max():.1f}")

X = np.array([[1., 0.], [0., 1.], [1., 1.], [-1., -1.]])
y = np.array([1, -1, 1, -1])
print("worked example: gamma* =", round(max_margin(augment(X), y), 4), "bound =", round((np.sqrt(3) / max_margin(augment(X), y)) ** 2, 2))
```

## Scaling and where the bound stops holding

The visible code also tests scaling. Multiplying every augmented coordinate by $c$ multiplies $R$ and $\gamma$ by $c$, so $(R/\gamma)^2$ is unchanged. The perceptron itself is unchanged too: each score is multiplied by $c^2$, which keeps its sign, and the weights are multiplied by $c$. The count stays at 4.

Scaling only the features leaves the constant 1 alone, so $R$ and $\gamma$ no longer scale together. At $c = 0.1$ the update count rises from 4 to 201. The bound computed from the final $w$ is still valid, since $201 \le 1{,}050{,}702$, but it is far too loose to be useful.

When the data are not separable, the theorem says nothing. The exclusive-or (XOR) points, $(1,1)$ and $(-1,-1)$ labelled $+1$, and $(1,-1)$ and $(-1,1)$ labelled $-1$, cannot be split by any line. The output shows four mistakes in every one of 20 epochs. A loop that stops only at zero mistakes would never end here, so the code caps the number of epochs.

![Two bar panels of mistakes per epoch. Separable data falls to zero in the third epoch. The XOR data stays at four mistakes in every one of 20 epochs.](diagrams/21.4-nonseparable.svg "The stopping rule matters: zero mistakes is reached only when the data are separable.")

## Common traps

> [!TRAP]
> **Forgetting the constant 1.** If you compute $R$ from the raw features, you get $\sqrt{2}$ here instead of $\sqrt{3}$. The bound becomes 10 instead of 15, and it is no longer guaranteed, because the theorem is stated for augmented vectors.

> [!TRAP]
> **Strict inequality at zero.** Testing $y\,(w^\top x) < 0$ never updates from $w = 0$. The loop then reports "no mistakes" and returns a zero vector that has learned nothing.

> [!TRAP]
> **Scaling only some coordinates.** Shrinking the features but not the constant 1 changes the geometry. Here the update count went from 4 to 201 for $c = 0.1$.

> [!TRAP]
> **Reading the bound as a prediction.** On the 300 random datasets the median ratio of updates to bound was 0.0315. The bound caps the count; it does not estimate it.

> [!TRAP]
> **Running non-separable data without a cap.** The theorem gives no bound, and the XOR output shows that the mistake count never falls to zero. Always cap the number of epochs.

## Summary

- The PLA updates $w \leftarrow w + yx$ on each misclassified point. Zero counts as a mistake, and the bias is a constant-1 input.
- Novikoff's theorem: if the data are separable with margin $\gamma$ and radius $R$, at most $(R/\gamma)^2$ updates occur, in any order of the points.
- The proof has two steps. The projection on $w^*$ grows by at least $\gamma$ per update, and the squared norm grows by at most $R^2$ per update.
- The bound is worst-case. It needs separability, and the XOR run never reaches zero mistakes.

## Quiz time

### Question 1 (Calculation)
Weights $w = (1, -1, 0)$, point $x = (1, 1, 1)$, label $y = +1$. Is this a mistake, and what are the weights after the update?

<details>
<summary>Show Solution</summary>

**Solution**: The score is $w^\top x = 1 - 1 + 0 = 0$. Since $y\,(w^\top x) = 0 \le 0$, it is a mistake. The update gives $w = (1, -1, 0) + (1, 1, 1) = (2, 0, 1)$.
</details>

### Question 2 (Prediction)
Suppose the test in `perceptron` is changed to `if y[i] * score < 0:`. What does the worked example return?

<details>
<summary>Show Solution</summary>

**Solution**: Starting from $w = 0$, every score is 0, and $y \cdot 0 = 0$ is not less than 0. There are no updates, so the first epoch has zero mistakes and the loop stops. The result is $w = (0, 0, 0)$ with zero updates. This is why zero must count as a mistake.
</details>

### Question 3 (Bug-spotting)
A student computes the bound with `R = np.linalg.norm(X, axis=1).max()`, where `X` is the raw two-column array of the worked example. What is wrong?

<details>
<summary>Show Solution</summary>

**Solution**: The raw points have norms $1, 1, \sqrt{2}, \sqrt{2}$, so `R` is $\sqrt{2}$. The theorem needs the augmented norm, which includes the constant 1, giving $\sqrt{3}$. With $\sqrt{2}$ the bound would be 10 instead of 15. The number can then fall below the true update count on other data, so the guarantee is lost.
</details>

### Question 4 (Explanation)
Why does the lower bound use $w_0 = 0$, and why does the upper bound depend on the update being made on a mistake?

<details>
<summary>Show Solution</summary>

**Solution**: With $w_0 = 0$, the projection $w_0^\top w^*$ starts at zero, so after $k$ updates it is at least $k\gamma$. The mistake condition $y\,(w_{k-1}^\top x) \le 0$ makes the cross term in $\|w_k\|^2$ non-positive. Without it, the norm could grow by more than $R^2$ per step and the bound would fail.
</details>

### Question 5 (Calculation)
A dataset has radius $R = 2$ and margin $\gamma = 0.5$. What is the largest number of updates the theorem allows?

<details>
<summary>Show Solution</summary>

**Solution**: $(R/\gamma)^2 = (2 / 0.5)^2 = 16$. The perceptron makes at most 16 updates on this dataset, in any order.
</details>
