# 22.1 — Statistical NLP: N-Grams, TF-IDF & Cosine Similarity

## Opening Motivation & Context

Statistical Natural Language Processing (NLP) is a branch of NLP that uses statistical methods to analyze and process human language. It's a foundational technique in many AI applications, including machine translation, sentiment analysis, and information retrieval. In this lesson, we'll explore three key statistical NLP techniques: N-Grams, TF-IDF (Term Frequency-Inverse Document Frequency), and Cosine Similarity.

## Core Concepts Breakdown

### N-Grams

N-Grams are contiguous sequences of n items from a sample of text. They can be words, characters, or syllables, depending on the application. N-Grams are widely used in statistical NLP for various tasks, including language modeling, text generation, and machine translation.

> [!KEY-INSIGHT]
> N-Grams capture the local structure of language, which is crucial for many NLP tasks.

> [!BEST-PRACTICE]
> When using N-Grams, consider the context of your application. For example, character-level N-Grams might be more appropriate for languages with complex orthography, while word-level N-Grams might be better for languages with simpler orthography.

> [!WARNING]
> Be careful when choosing the value of n. A small n might not capture enough context, while a large n might lead to data sparsity.

### TF-IDF

TF-IDF is a numerical statistic that reflects the importance of a word in a document relative to a collection of documents. It's calculated as the product of two metrics: Term Frequency (TF) and Inverse Document Frequency (IDF). TF-IDF is widely used in information retrieval and text mining.

> [!KEY-INSIGHT]
> TF-IDF helps to identify the most relevant words in a document, which is crucial for tasks like document classification and information retrieval.

> [!BEST-PRACTICE]
> When using TF-IDF, consider normalizing the term frequencies to account for document length. This can be done using techniques like cosine normalization.

> [!WARNING]
> Be aware that TF-IDF can be sensitive to the size of the document collection. For small collections, the IDF values might not be reliable.

### Cosine Similarity

Cosine Similarity is a measure of similarity between two non-zero vectors of an inner product space. It's widely used in information retrieval and text mining to measure the similarity between documents. Cosine Similarity is calculated as the cosine of the angle between the two vectors.

> [!KEY-INSIGHT]
> Cosine Similarity is a robust measure of similarity that's less sensitive to document length than other measures like Euclidean distance.

> [!BEST-PRACTICE]
> When using Cosine Similarity, consider normalizing the vectors to unit length. This can be done using techniques like cosine normalization.

> [!WARNING]
> Be aware that Cosine Similarity can be sensitive to the choice of features. For example, using raw word counts might lead to poor results, while using TF-IDF might lead to better results.

## Code Demonstration & Runtime Output

```python
import re
from collections import Counter
from math import log
from typing import List, Dict, Tuple

def generate_ngrams(text: str, n: int) -> List[str]:
    """
    Generate n-grams from a given text.

    Args:
        text: The input text.
        n: The size of the n-grams.

    Returns:
        A list of n-grams.
    """
    words = re.findall(r'\w+', text.lower())
    ngrams = [' '.join(words[i:i+n]) for i in range(len(words)-n+1)]
    return ngrams

def calculate_tf(ngrams: List[str]) -> Dict[str, float]:
    """
    Calculate the term frequency (TF) for a list of n-grams.

    Args:
        ngrams: A list of n-grams.

    Returns:
        A dictionary mapping n-grams to their term frequencies.
    """
    ngram_counts = Counter(ngrams)
    total_ngrams = len(ngrams)
    tf = {ngram: count/total_ngrams for ngram, count in ngram_counts.items()}
    return tf

def calculate_idf(documents: List[List[str]]) -> Dict[str, float]:
    """
    Calculate the inverse document frequency (IDF) for a list of documents.

    Args:
        documents: A list of documents, where each document is a list of n-grams.

    Returns:
        A dictionary mapping n-grams to their inverse document frequencies.
    """
    total_documents = len(documents)
    ngram_doc_counts = Counter(ngram for document in documents for ngram in document)
    idf = {ngram: log(total_documents/(1+count)) for ngram, count in ngram_doc_counts.items()}
    return idf

def calculate_tfidf(tf: Dict[str, float], idf: Dict[str, float]) -> Dict[str, float]:
    """
    Calculate the TF-IDF for a list of n-grams.

    Args:
        tf: A dictionary mapping n-grams to their term frequencies.
        idf: A dictionary mapping n-grams to their inverse document frequencies.

    Returns:
        A dictionary mapping n-grams to their TF-IDF values.
    """
    tfidf = {ngram: tf[ngram]*idf[ngram] for ngram in tf}
    return tfidf

def calculate_cosine_similarity(tfidf1: Dict[str, float], tfidf2: Dict[str, float]) -> float:
    """
    Calculate the cosine similarity between two TF-IDF vectors.

    Args:
        tfidf1: A dictionary mapping n-grams to their TF-IDF values.
        tfidf2: A dictionary mapping n-grams to their TF-IDF values.

    Returns:
        The cosine similarity between the two TF-IDF vectors.
    """
    dot_product = sum(tfidf1[ngram]*tfidf2.get(ngram, 0) for ngram in tfidf1)
    magnitude1 = sum(tfidf1[ngram]**2 for ngram in tfidf1)**0.5
    magnitude2 = sum(tfidf2[ngram]**2 for ngram in tfidf2)**0.5
    cosine_similarity = dot_product/(magnitude1*magnitude2)
    return cosine_similarity

if __name__ == '__main__':
    # Example usage
    text1 = "The quick brown fox jumps over the lazy dog."
    text2 = "The lazy dog jumps over the quick brown fox."

    # Generate n-grams
    ngrams1 = generate_ngrams(text1, 2)
    ngrams2 = generate_ngrams(text2, 2)

    # Calculate TF
    tf1 = calculate_tf(ngrams1)
    tf2 = calculate_tf(ngrams2)

    # Calculate IDF
    documents = [ngrams1, ngrams2]
    idf = calculate_idf(documents)

    # Calculate TF-IDF
    tfidf1 = calculate_tfidf(tf1, idf)
    tfidf2 = calculate_tfidf(tf2, idf)

    # Calculate cosine similarity
    cosine_similarity = calculate_cosine_similarity(tfidf1, tfidf2)

    print(f"Cosine Similarity: {cosine_similarity:.2f}")
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: We import the necessary libraries, including `re` for regular expressions, `Counter` from the `collections` module for counting n-grams, `log` from the `math` module for calculating IDF, and `List`, `Dict`, and `Tuple` from the `typing` module for type hints.

2. **generate_ngrams**: This function takes a text and an integer `n` as input and returns a list of n-grams. It first uses a regular expression to extract all words from the text, converts them to lowercase, and then generates n-grams by joining `n` consecutive words.

3. **calculate_tf**: This function takes a list of n-grams as input and returns a dictionary mapping n-grams to their term frequencies. It first counts the occurrences of each n-gram using `Counter`, and then calculates the term frequency for each n-gram by dividing its count by the total number of n-grams.

4. **calculate_idf**: This function takes a list of documents as input, where each document is a list of n-grams, and returns a dictionary mapping n-grams to their inverse document frequencies. It first counts the number of documents in which each n-gram appears, and then calculates the inverse document frequency for each n-gram using the formula `log(total_documents/(1+count))`.

5. **calculate_tfidf**: This function takes a dictionary of term frequencies and a dictionary of inverse document frequencies as input and returns a dictionary mapping n-grams to their TF-IDF values. It calculates the TF-IDF for each n-gram by multiplying its term frequency by its inverse document frequency.

6. **calculate_cosine_similarity**: This function takes two dictionaries of TF-IDF values as input and returns the cosine similarity between the two TF-IDF vectors. It first calculates the dot product of the two vectors, and then calculates the magnitudes of the two vectors. The cosine similarity is then calculated by dividing the dot product by the product of the magnitudes.

7. **Example usage**: In the `__main__` block, we demonstrate how to use the functions to calculate the cosine similarity between two documents. We first generate n-grams for each document, calculate the term frequencies and inverse document frequencies, and then calculate the TF-IDF values for each document. Finally, we calculate the cosine similarity between the two documents.

> [!ADVANCED]
> The `generate_ngrams` function uses a regular expression to extract words from the text. The regular expression `r'\w+'` matches any sequence of word characters (letters, digits, and underscores). The `findall` method is then used to find all matches of the regular expression in the text. The resulting list of words is then used to generate n-grams.

> [!QA]
> Q: When should I prefer N-Grams over TF-IDF?
> A: N-Grams are typically preferred when you need to capture the local structure of language, such as in language modeling or text generation. TF-IDF is typically preferred when you need to identify the most relevant words in a document, such as in document classification or information retrieval.
