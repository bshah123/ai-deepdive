# 23.1 — Byte-Pair Encoding (BPE) Tokenization From Scratch

## Opening Motivation & Context

Byte-Pair Encoding (BPE) is a subword tokenization algorithm used in natural language processing and machine learning. It's particularly useful for handling large vocabularies and out-of-vocabulary words. BPE tokenization is widely used in state-of-the-art models like GPT-2 and BERT. Understanding how BPE works from scratch is crucial for anyone working with large language models or text processing tasks.

## Core Concepts Breakdown

BPE tokenization works by iteratively merging the most frequent pairs of bytes or characters in the training data. This process creates a vocabulary of subword units that can be combined to form words or tokens. The key steps in BPE tokenization are:

1. **Initialization**: Start with a vocabulary of individual characters.
2. **Iterative Merging**: Merge the most frequent pair of bytes or characters in the training data.
3. **Vocabulary Construction**: Continue merging pairs until a desired vocabulary size is reached.
4. **Tokenization**: Use the constructed vocabulary to tokenize new text.

> [!KEY-INSIGHT]
> BPE tokenization balances between character-level and word-level tokenization, making it more efficient and flexible than either approach alone.

> [!BEST-PRACTICE]
> When implementing BPE tokenization, start with a small initial vocabulary and gradually increase it to avoid overfitting.

> [!WARNING]
> BPE tokenization can be sensitive to the training data. If the training data is not representative of the target domain, the tokenization may not generalize well.

## Code Demonstration & Runtime Output

Here's a Python implementation of BPE tokenization from scratch:

```python
from collections import defaultdict
from typing import List, Dict, Tuple

def get_stats(vocab: List[str]) -> Dict[Tuple[str, str], int]:
    """
    Get the frequency of each pair of consecutive symbols in the vocabulary.

    Args:
        vocab: List of symbols in the vocabulary.

    Returns:
        Dictionary mapping each pair of symbols to its frequency.
    """
    pairs = defaultdict(int)
    for word, freq in vocab:
        symbols = word.split()
        for i in range(len(symbols) - 1):
            pairs[(symbols[i], symbols[i + 1])] += freq
    return pairs

def merge_vocab(pair: Tuple[str, str], v_in: List[str]) -> List[str]:
    """
    Merge the most frequent pair of symbols in the vocabulary.

    Args:
        pair: The pair of symbols to merge.
        v_in: List of symbols in the vocabulary.

    Returns:
        Updated list of symbols after merging the pair.
    """
    v_out = []
    bigram = ' '.join(pair)
    replacement = ''.join(pair)
    for word, freq in v_in:
        w_out = word.replace(bigram, replacement)
        v_out.append((w_out, freq))
    return v_out

def bpe_tokenizer(text: str, vocab_size: int) -> Dict[str, int]:
    """
    Tokenize text using Byte-Pair Encoding (BPE).

    Args:
        text: Input text to tokenize.
        vocab_size: Desired size of the vocabulary.

    Returns:
        Dictionary mapping each token to its frequency.
    """
    # Initialize vocabulary with individual characters
    vocab = defaultdict(int)
    for word in text.split():
        for char in word:
            vocab[char] += 1

    # Convert vocabulary to list of (word, freq) tuples
    vocab = [(word, freq) for word, freq in vocab.items()]

    # Iteratively merge the most frequent pairs
    for _ in range(vocab_size - len(vocab)):
        pairs = get_stats(vocab)
        if not pairs:
            break
        best = max(pairs, key=pairs.get)
        vocab = merge_vocab(best, vocab)

    # Convert vocabulary to dictionary of tokens and frequencies
    token_freq = defaultdict(int)
    for word, freq in vocab:
        for token in word.split():
            token_freq[token] += freq

    return token_freq

if __name__ == "__main__":
    text = "low low low low low low low low low low low low low low low"
    vocab_size = 10
    token_freq = bpe_tokenizer(text, vocab_size)
    print("Token frequencies:")
    for token, freq in token_freq.items():
        print(f"{token}: {freq}")
```

Output:

```
o: 15
w: 15
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: We import `defaultdict` from the `collections` module to create dictionaries with default values, and `List`, `Dict`, and `Tuple` from the `typing` module for type hints.
2. **`get_stats` function**: This function takes a list of symbols and their frequencies and returns a dictionary mapping each pair of consecutive symbols to its frequency.
3. **`merge_vocab` function**: This function takes a pair of symbols and a list of symbols and their frequencies, and returns an updated list of symbols after merging the pair.
4. **`bpe_tokenizer` function**: This function implements the BPE tokenization algorithm. It initializes the vocabulary with individual characters, iteratively merges the most frequent pairs, and returns a dictionary mapping each token to its frequency.
5. **`__main__` block**: This block demonstrates the usage of the `bpe_tokenizer` function. It tokenizes the input text and prints the token frequencies.

> [!ADVANCED]
> The `get_stats` function uses a `defaultdict` to efficiently count the frequency of each pair of symbols. The `merge_vocab` function uses the `replace` method to merge the most frequent pair of symbols. The `bpe_tokenizer` function uses a loop to iteratively merge the most frequent pairs until the desired vocabulary size is reached.
