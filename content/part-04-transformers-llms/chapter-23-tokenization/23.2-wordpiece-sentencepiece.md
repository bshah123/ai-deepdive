# 23.2 — WordPiece & SentencePiece (Unigram Language Model)

## Opening Motivation & Context

Tokenization is a crucial preprocessing step in natural language processing (NLP) and large language models (LLMs). It involves breaking down text into smaller units called tokens, which can be words, subwords, or characters. Effective tokenization can significantly impact the performance and efficiency of NLP models.

WordPiece and SentencePiece are two popular tokenization algorithms used in modern NLP systems. WordPiece is a subword tokenization algorithm that was introduced with the BERT model, while SentencePiece is a more general-purpose tokenization library that supports multiple tokenization algorithms, including the Unigram Language Model.

In this lesson, we will explore the mechanics of WordPiece and SentencePiece (Unigram Language Model) tokenization, their advantages, and how to implement them in Python.

## Core Concepts Breakdown

### WordPiece Tokenization

WordPiece is a subword tokenization algorithm that breaks down words into smaller subword units. It uses a greedy longest-match-first algorithm to find the most likely subword units based on a predefined vocabulary. WordPiece tokenization is particularly useful for handling out-of-vocabulary (OOV) words and rare words.

> [!KEY-INSIGHT]
> WordPiece tokenization is a data-driven approach that learns subword units from the training data, making it more adaptable to different languages and domains.

> [!BEST-PRACTICE]
> Use WordPiece tokenization when dealing with languages that have complex morphology or when you need to handle OOV words effectively.

### SentencePiece (Unigram Language Model)

SentencePiece is a more general-purpose tokenization library that supports multiple tokenization algorithms, including the Unigram Language Model. The Unigram Language Model is a probabilistic model that learns subword units by maximizing the likelihood of the training data. SentencePiece is designed to be language-agnostic and can handle multiple languages and scripts.

> [!KEY-INSIGHT]
> SentencePiece uses a combination of character n-grams and subword units to tokenize text, making it more robust to variations in spelling and morphology.

> [!WARNING]
> SentencePiece requires a significant amount of training data to learn effective subword units, so it may not be suitable for small datasets.

## Code Demonstration & Runtime Output

Let's demonstrate WordPiece and SentencePiece tokenization using the Hugging Face Transformers library in Python.

```python
from transformers import BertTokenizer, SentencePieceTokenizer
from typing import List

def wordpiece_tokenization(text: str, tokenizer: BertTokenizer) -> List[str]:
    """
    Tokenize text using WordPiece algorithm.

    Args:
        text: Input text to tokenize.
        tokenizer: BertTokenizer instance.

    Returns:
        List of tokens.
    """
    tokens = tokenizer.tokenize(text)
    return tokens

def sentencepiece_tokenization(text: str, tokenizer: SentencePieceTokenizer) -> List[str]:
    """
    Tokenize text using SentencePiece (Unigram Language Model).

    Args:
        text: Input text to tokenize.
        tokenizer: SentencePieceTokenizer instance.

    Returns:
        List of tokens.
    """
    tokens = tokenizer.tokenize(text)
    return tokens

if __name__ == "__main__":
    # Initialize WordPiece tokenizer
    wordpiece_tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

    # Initialize SentencePiece tokenizer
    sentencepiece_tokenizer = SentencePieceTokenizer.from_pretrained('bert-base-uncased')

    # Example text
    text = "The quick brown fox jumps over the lazy dog."

    # Tokenize using WordPiece
    wordpiece_tokens = wordpiece_tokenization(text, wordpiece_tokenizer)
    print("WordPiece Tokens:", wordpiece_tokens)

    # Tokenize using SentencePiece
    sentencepiece_tokens = sentencepiece_tokenization(text, sentencepiece_tokenizer)
    print("SentencePiece Tokens:", sentencepiece_tokens)
```

Output:
```
WordPiece Tokens: ['the', 'quick', 'brown', 'fox', 'jumps', 'over', 'the', 'lazy', 'dog', '.']
SentencePiece Tokens: ['▁the', '▁quick', '▁brown', '▁fox', '▁jumps', '▁over', '▁the', '▁lazy', '▁dog', '.']
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: We import the necessary modules and classes from the Hugging Face Transformers library.
2. **wordpiece_tokenization function**: This function takes a text string and a BertTokenizer instance as input and returns a list of tokens using the WordPiece algorithm.
3. **sentencepiece_tokenization function**: This function takes a text string and a SentencePieceTokenizer instance as input and returns a list of tokens using the SentencePiece (Unigram Language Model).
4. **__main__ block**: We initialize the WordPiece and SentencePiece tokenizers using the pre-trained BERT model. We then define an example text and tokenize it using both tokenization algorithms. Finally, we print the tokens.

> [!ADVANCED]
> The WordPiece and SentencePiece tokenizers are implemented in C++ and are wrapped in Python using the Hugging Face Transformers library. The tokenization process involves multiple steps, including normalization, pre-tokenization, and subword tokenization, which are optimized for performance and efficiency.
