# 24.3 — Rotary Position Embeddings (RoPE) & Complex Rotation Math

## Opening Motivation & Context

Rotary Position Embeddings (RoPE) are a novel approach to incorporating positional information into transformer models. Unlike traditional positional embeddings that are added to the input tokens, RoPE applies a rotation to the token embeddings based on their position in the sequence. This approach has several advantages, including better generalization to longer sequences and reduced computational overhead.

## Core Concepts Breakdown

### Rotary Position Embeddings (RoPE)

RoPE works by applying a rotation to the token embeddings based on their position in the sequence. This rotation is implemented using complex numbers, where each dimension of the embedding is rotated by a different angle. The angle of rotation is determined by the position of the token in the sequence and the dimension of the embedding.

> [!KEY-INSIGHT]
> RoPE can be thought of as a way to encode positional information by rotating the token embeddings in a complex plane. This rotation allows the model to learn relative positional relationships between tokens.

> [!BEST-PRACTICE]
> When implementing RoPE, it's important to ensure that the rotation angles are consistent across the model. This can be achieved by using a shared set of rotation angles for all layers of the transformer.

> [!WARNING]
> Incorrect implementation of RoPE can lead to poor performance, especially when dealing with longer sequences. It's crucial to verify the correctness of the rotation angles and the application of the rotation to the token embeddings.

## Code Demonstration & Runtime Output

```python
import numpy as np
import torch

def apply_rotary_embeddings(x: torch.Tensor, position_ids: torch.Tensor, dim: int = 64) -> torch.Tensor:
    """
    Apply rotary position embeddings to the input tensor.

    Args:
        x: Input tensor of shape (batch_size, seq_len, dim)
        position_ids: Tensor of position indices of shape (batch_size, seq_len)
        dim: Dimension of the embeddings

    Returns:
        Tensor with rotary position embeddings applied
    """
    # Generate rotation angles
    angles = 1.0 / (10000 ** (2 * (np.arange(dim) // 2) / dim))
    angles = torch.tensor(angles, dtype=torch.float32)

    # Compute rotation angles for each position
    pos_angles = position_ids.unsqueeze(-1) * angles.unsqueeze(0).unsqueeze(0)

    # Split the input tensor into real and imaginary parts
    x_real = x[..., ::2]
    x_imag = x[..., 1::2]

    # Apply rotation
    rotated_real = x_real * torch.cos(pos_angles) - x_imag * torch.sin(pos_angles)
    rotated_imag = x_real * torch.sin(pos_angles) + x_imag * torch.cos(pos_angles)

    # Combine the rotated parts
    x_rotated = torch.stack([rotated_real, rotated_imag], dim=-1).flatten(-2, -1)

    return x_rotated

if __name__ == "__main__":
    # Example usage
    batch_size, seq_len, dim = 2, 4, 64
    x = torch.randn(batch_size, seq_len, dim)
    position_ids = torch.arange(seq_len).unsqueeze(0).expand(batch_size, -1)

    x_rotated = apply_rotary_embeddings(x, position_ids, dim)
    print("Rotated tensor shape:", x_rotated.shape)
```

> The rotation operation in RoPE can be efficiently implemented using complex numbers. This allows for a more concise and efficient implementation of the rotation operation.

> [!QA]
> Q: When should I prefer RoPE over traditional positional embeddings?
> A: RoPE is particularly useful when dealing with longer sequences or when you want to reduce the computational overhead of positional embeddings. However, traditional positional embeddings may be more suitable for certain tasks or when you need to explicitly model absolute positional information.
