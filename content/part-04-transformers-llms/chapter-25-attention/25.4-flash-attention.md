# 25.4 — FlashAttention 1, 2 & 3: GPU SRAM Tiling & Online Softmax

## Opening Motivation & Context

The attention mechanism is a cornerstone of modern large language models, enabling them to process and generate human-like text. However, as the size of these models grows, so does the computational cost of the attention mechanism. FlashAttention is a series of optimizations designed to make the attention mechanism more efficient on GPUs by leveraging tiling and online softmax techniques. This lesson will explore the core concepts behind FlashAttention 1, 2, and 3, and demonstrate how they work with Python code.

## Core Concepts Breakdown

### FlashAttention 1: GPU SRAM Tiling

FlashAttention 1 introduces the concept of tiling, which involves breaking down the attention computation into smaller chunks that fit into the GPU's SRAM (also known as shared memory). This reduces the amount of data that needs to be transferred between the GPU's global memory and SRAM, which can significantly improve performance.

> [!KEY-INSIGHT]
> Tiling is a form of data locality optimization that reduces memory bandwidth usage by reusing data in SRAM.

> [!BEST-PRACTICE]
> Choose tile sizes that are a power of two to align with GPU memory access patterns.

> [!WARNING]
> If the tile size is too large, it may not fit into the GPU's SRAM, leading to performance degradation.

### FlashAttention 2: Online Softmax

FlashAttention 2 introduces the concept of online softmax, which involves computing the softmax operation incrementally as the attention scores are being computed. This reduces the amount of memory required to store intermediate results and can improve performance by allowing the GPU to overlap computation and memory access.

> [!KEY-INSIGHT]
> Online softmax is a form of computation reuse that reduces memory usage and improves performance.

> [!BEST-PRACTICE]
> Use online softmax when the attention scores are being computed incrementally, such as in a streaming or online setting.

> [!WARNING]
> Online softmax can be more complex to implement than standard softmax, so it may not be suitable for all attention mechanisms.

### FlashAttention 3: GPU SRAM Tiling with Online Softmax

FlashAttention 3 combines the tiling and online softmax techniques to create a highly efficient attention mechanism. By breaking down the computation into smaller chunks and computing the softmax operation incrementally, FlashAttention 3 can achieve significant performance improvements on GPUs.

> [!KEY-INSIGHT]
> Combining tiling and online softmax can lead to significant performance improvements by reducing memory bandwidth usage and improving computation reuse.

> [!BEST-PRACTICE]
> Use FlashAttention 3 when the attention mechanism is being implemented on a GPU and performance is critical.

> [!WARNING]
> FlashAttention 3 can be more complex to implement than standard attention mechanisms, so it may not be suitable for all use cases.

import numpy as np

def flash_attention_1(query: np.ndarray, key: np.ndarray, value: np.ndarray, tile_size: int) -> np.ndarray:
    """
    Compute the attention mechanism using FlashAttention 1 with GPU SRAM tiling.

    Args:
        query: The query matrix of shape (batch_size, num_heads, seq_len, head_dim).
        key: The key matrix of shape (batch_size, num_heads, seq_len, head_dim).
        value: The value matrix of shape (batch_size, num_heads, seq_len, head_dim).
        tile_size: The size of the tiles used for tiling.

    Returns:
        The output of the attention mechanism of shape (batch_size, num_heads, seq_len, head_dim).
    """
    batch_size, num_heads, seq_len, head_dim = query.shape
    output = np.zeros_like(query)

    for i in range(0, seq_len, tile_size):
        for j in range(0, seq_len, tile_size):
            query_tile = query[:, :, i:i+tile_size, :]
            key_tile = key[:, :, j:j+tile_size, :]
            value_tile = value[:, :, j:j+tile_size, :]

            scores = np.matmul(query_tile, key_tile.transpose(0, 1, 3, 2)) / np.sqrt(head_dim)
            attention_weights = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
            attention_weights = attention_weights / np.sum(attention_weights, axis=-1, keepdims=True)

            output[:, :, i:i+tile_size, :] += np.matmul(attention_weights, value_tile)

    return output

        The output of the attention mechanism of shape (batch_size, num_heads, seq_len, head_dim).

        attention_weights = attention_weights / np.sum(attention_weights, axis=-1, keepdims=True)
