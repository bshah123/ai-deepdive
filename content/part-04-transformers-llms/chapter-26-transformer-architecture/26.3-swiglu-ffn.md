# 26.3 — Feed-Forward Networks: Standard MLP, GeLU & SwiGLU Gating

## Opening Motivation & Context

Feed-forward networks, particularly the Multi-Layer Perceptron (MLP), are a fundamental component of transformer architectures. These networks serve as the "thinking" part of the transformer, processing the information from the attention mechanism and producing the final output. The choice of activation function in these networks can significantly impact the performance and efficiency of the transformer. In this lesson, we will explore three types of feed-forward networks: the standard MLP, the MLP with GeLU activation, and the MLP with SwiGLU gating.

## Core Concepts Breakdown

### Standard MLP

The standard Multi-Layer Perceptron (MLP) is a simple feed-forward network consisting of one or more layers of linear transformations followed by non-linear activation functions. The standard MLP uses the ReLU (Rectified Linear Unit) activation function, which is defined as:

\[ \text{ReLU}(x) = \max(0, x) \]

> [!KEY-INSIGHT]
> The ReLU activation function is computationally efficient and helps mitigate the vanishing gradient problem, making it a popular choice for deep neural networks.

> [!BEST-PRACTICE]
> When designing a standard MLP, it is recommended to use a hidden layer size that is 4 times the size of the input dimension. This provides a good balance between model capacity and computational efficiency.

### GeLU Activation

The Gaussian Error Linear Unit (GeLU) is a smooth, non-monotonic activation function that has been shown to improve the performance of transformer models. The GeLU function is defined as:

\[ \text{GeLU}(x) = x \cdot \Phi(x) \]

where \(\Phi(x)\) is the cumulative distribution function of the standard Gaussian distribution.

> [!KEY-INSIGHT]
> The GeLU activation function introduces a smooth, non-linear transformation that can capture more complex patterns in the data compared to ReLU.

> [!WARNING]
> GeLU can be more computationally expensive than ReLU due to the need to compute the cumulative distribution function of the Gaussian distribution. This can impact the training speed of large transformer models.

### SwiGLU Gating

SwiGLU (Swish-Gated Linear Unit) is a gating mechanism that combines the benefits of the Swish activation function and the linear transformation. The SwiGLU function is defined as:

\[ \text{SwiGLU}(x, W, V, b, c) = \text{Swish}(xW + b) \otimes (xV + c) \]

where \(\text{Swish}(x) = x \cdot \sigma(x)\), \(\sigma(x)\) is the sigmoid function, and \(\otimes\) denotes element-wise multiplication.

> [!KEY-INSIGHT]
> SwiGLU gating allows the network to learn both the transformation and the gating pattern simultaneously, leading to improved performance and efficiency.

> [!BEST-PRACTICE]
> When using SwiGLU gating, it is recommended to initialize the weights of the linear transformations with a small standard deviation (e.g., 0.02) to ensure stable training.

## Code Demonstration & Runtime Output

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class StandardMLP(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, output_dim: int):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x

class GeLUMLP(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, output_dim: int):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = F.gelu(self.fc1(x))
        x = self.fc2(x)
        return x

class SwiGLUMLP(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, output_dim: int):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)
        self.fc_gate = nn.Linear(input_dim, hidden_dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        gate = F.silu(self.fc_gate(x))
        x = self.fc1(x) * gate
        x = F.relu(x)
        x = self.fc2(x)
        return x

if __name__ == "__main__":
    input_dim = 128
    hidden_dim = 512
    output_dim = 64

    x = torch.randn(32, input_dim)

    standard_mlp = StandardMLP(input_dim, hidden_dim, output_dim)
    gelu_mlp = GeLUMLP(input_dim, hidden_dim, output_dim)
    swiglu_mlp = SwiGLUMLP(input_dim, hidden_dim, output_dim)

    print("Standard MLP Output:")
    print(standard_mlp(x))

    print("\nGeLU MLP Output:")
    print(gelu_mlp(x))

    print("\nSwiGLU MLP Output:")
    print(swiglu_mlp(x))
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: We import the necessary libraries, including PyTorch for neural network operations.
2. **StandardMLP Class**: This class defines a standard MLP with two linear layers and ReLU activation.
   - `__init__`: Initializes the linear layers with the specified dimensions.
   - `forward`: Defines the forward pass of the network, applying ReLU activation after the first linear layer.
3. **GeLUMLP Class**: This class defines an MLP with GeLU activation.
   - `__init__`: Similar to StandardMLP, initializes the linear layers.
   - `forward`: Defines the forward pass with GeLU activation after the first linear layer.
4. **SwiGLUMLP Class**: This class defines an MLP with SwiGLU gating.
   - `__init__`: Initializes the linear layers and an additional gate layer.
   - `forward`: Defines the forward pass with SwiGLU gating, applying the gate to the output of the first linear layer before ReLU activation.
5. **Main Block**: Creates instances of each MLP type, generates random input data, and prints the outputs of each network.

> [!ADVANCED]
> The SwiGLU gating mechanism involves element-wise multiplication of the output of the first linear layer with the output of the gate layer, which is computed using the SiLU (Sigmoid Linear Unit) activation function. This gating mechanism allows the network to learn both the transformation and the gating pattern simultaneously, leading to improved performance and efficiency.

> [!QA]
> Q: When should I prefer GeLU over ReLU in a transformer model?
> A: GeLU is generally preferred over ReLU in transformer models because it introduces a smooth, non-monotonic transformation that can capture more complex patterns in the data. However, GeLU can be more computationally expensive than ReLU, so it may not be the best choice for very large models or when training speed is a critical concern.

## Summary & Key Takeaways

- The standard MLP uses ReLU activation and is computationally efficient.
- GeLU activation introduces a smooth, non-linear transformation that can capture more complex patterns in the data.
- SwiGLU gating combines the benefits of the Swish activation function and the linear transformation, leading to improved performance and efficiency.
- The choice of activation function and gating mechanism can significantly impact the performance and efficiency of a transformer model.

import torch
import torch.nn as nn
import torch.nn.functional as F

class BuggyMLP(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, output_dim: int):

        self.fc1 = nn.Linear(input_dim, hidden_dim)

        x = self.fc2(x)
        return x

if __name__ == "__main__":

    hidden_dim = 4
    output_dim = 2
