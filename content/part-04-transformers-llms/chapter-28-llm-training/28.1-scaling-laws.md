# 28.1 — Pre-training at Scale: Chinchilla Scaling Laws & Compute Budgets

## Opening Motivation & Context

Pre-training large language models (LLMs) at scale is a critical step in developing state-of-the-art AI systems. However, the process is computationally expensive and requires careful consideration of scaling laws and compute budgets. This lesson explores the Chinchilla scaling laws, which provide insights into the optimal balance between model size and dataset size, and how to manage compute budgets effectively.

## Core Concepts Breakdown

### Chinchilla Scaling Laws

Chinchilla scaling laws are a set of empirical findings that suggest an optimal relationship between model size and dataset size for pre-training LLMs. The key insight is that there is a sweet spot where increasing the model size and dataset size in proportion leads to the most efficient use of computational resources.

> [!KEY-INSIGHT]
> The Chinchilla scaling laws indicate that the optimal number of model parameters is proportional to the number of tokens in the dataset, following a power law relationship.

> [!BEST-PRACTICE]
> When pre-training LLMs, aim to maintain a balance between model size and dataset size according to the Chinchilla scaling laws to maximize efficiency and performance.

> [!WARNING]
> Ignoring the Chinchilla scaling laws can lead to suboptimal use of computational resources, resulting in either underutilized models or excessive computational costs.

## Code Demonstration & Runtime Output

```python
import math
import matplotlib.pyplot as plt

def chinchilla_scaling_law(model_size: float, dataset_size: float, exponent: float = 0.34) -> float:
    """
    Calculate the optimal dataset size according to the Chinchilla scaling law.

    Args:
        model_size (float): The size of the model in terms of parameters.
        dataset_size (float): The size of the dataset in terms of tokens.
        exponent (float): The exponent in the power law relationship (default: 0.34).

    Returns:
        float: The optimal dataset size according to the Chinchilla scaling law.
    """
    return model_size ** exponent

def plot_scaling_laws(model_sizes: list, dataset_sizes: list, exponent: float = 0.34) -> None:
    """
    Plot the Chinchilla scaling laws for a range of model and dataset sizes.

    Args:
        model_sizes (list): A list of model sizes.
        dataset_sizes (list): A list of dataset sizes.
        exponent (float): The exponent in the power law relationship (default: 0.34).
    """
    optimal_dataset_sizes = [chinchilla_scaling_law(size, 0, exponent) for size in model_sizes]

    plt.figure(figsize=(10, 6))
    plt.plot(model_sizes, optimal_dataset_sizes, label='Chinchilla Scaling Law')
    plt.scatter(model_sizes, dataset_sizes, color='red', label='Actual Dataset Sizes')
    plt.xlabel('Model Size (Parameters)')
    plt.ylabel('Dataset Size (Tokens)')
    plt.title('Chinchilla Scaling Laws')
    plt.legend()
    plt.grid(True)
    plt.show()

if __name__ == "__main__":
    model_sizes = [1e9, 1e10, 1e11, 1e12]
    dataset_sizes = [1e12, 1e13, 1e14, 1e15]

    plot_scaling_laws(model_sizes, dataset_sizes)
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: The code imports the necessary libraries, including `math` for mathematical operations and `matplotlib.pyplot` for plotting.
2. **chinchilla_scaling_law function**: This function calculates the optimal dataset size according to the Chinchilla scaling law. It takes the model size, dataset size, and an optional exponent as input and returns the optimal dataset size.
3. **plot_scaling_laws function**: This function plots the Chinchilla scaling laws for a range of model and dataset sizes. It takes lists of model sizes and dataset sizes, along with an optional exponent, and generates a plot.
4. **Main block**: The main block defines the model sizes and dataset sizes, then calls the `plot_scaling_laws` function to generate the plot.

> [!ADVANCED]
> The Chinchilla scaling law is implemented as a power law relationship, where the optimal dataset size is proportional to the model size raised to the power of an exponent. The exponent is typically around 0.34, as determined by empirical studies.

> [!QA]
> Q: When should I prefer a larger model over a larger dataset?
> A: You should prefer a larger model when the computational resources are limited and you need to maximize the efficiency of the model. However, according to the Chinchilla scaling laws, a larger dataset is generally more beneficial for improving the performance of the model.
