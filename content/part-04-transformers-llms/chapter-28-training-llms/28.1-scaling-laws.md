# Architectural Intuition & Execution Pipeline

# The Science of Scaling: Kaplan vs Chinchilla

How should compute budget $C$ be allocated between model parameter count $N$ and training dataset tokens $D$?

# The Chinchilla Power-Law Loss Formulation

Hoffmann et al. modeled the cross-entropy pre-training loss $L(N, D)$ as:

$$L(N, D) = E + \frac{A}{N^\alpha} + \frac{B}{D^\beta}$$

| Term | Physical Meaning | Fitted Value |
|---|---|---|
| $E$ | Irreducible entropy of natural language | $\approx 1.69$ nats |
| $A / N^\alpha$ | Parameter bottleneck term | $A \approx 406.4, \ \alpha \approx 0.34$ |
| $B / D^\beta$ | Token dataset bottleneck term | $B \approx 410.7, \ \beta \approx 0.28$ |

Under a fixed compute budget $C = 6ND$, minimizing $L(N, D)$ subject to this constraint yields the **Compute-Optimal Scaling Rule**:

$$N_{\text{opt}} \propto C^a, \quad D_{\text{opt}} \propto C^b, \quad \text{where } a \approx 0.5, \ b \approx 0.5$$

$$\frac{D_{\text{opt}}}{N_{\text{opt}}} \approx 20 \text{ tokens per parameter}$$

# Pre-Training FLOPs Calculation Engine

# Why Modern LLMs "Over-Train" Beyond Chinchilla

Chinchilla optimality assumes you discard the model after training. In reality, an open model like LLaMA-3-8B is queried **billions of times in production**:
- Training an 8B model on 15T tokens requires more training FLOPs than Chinchilla dictates.
- However, serving an 8B model uses **90% less VRAM and compute per token** than serving a Chinchilla-optimal 70B model!
- Over-training dramatically **reduces total inference cost at scale**.

```python
import math
from typing import Tuple, Dict, Optional
import torch
import time

def compute_optimal_model_size(compute_budget: float, dataset_size: int, tokenization_cost: float = 1.0) -> Tuple[int, int]:
    """
    Compute the optimal model size and batch size based on Chinchilla scaling laws.

    Args:
        compute_budget: Total compute budget in FLOPs.
        dataset_size: Size of the dataset in tokens.
        tokenization_cost: Cost of tokenizing a token in FLOPs.

    Returns:
        Tuple containing the optimal model size (number of parameters) and batch size.
    """
    # Constants from Chinchilla scaling laws
    alpha = 0.34
    beta = 0.28

    # Calculate optimal model size
    model_size = (compute_budget / (alpha * dataset_size * tokenization_cost)) ** (1 / beta)

    # Calculate optimal batch size
    batch_size = math.sqrt(compute_budget / (alpha * dataset_size * tokenization_cost))

    return int(model_size), int(batch_size)

def pre_train_model(model_size: int, batch_size: int, num_epochs: int, dataset: torch.Tensor, device: str = 'cuda') -> Dict[str, float]:
    """
    Pre-train a model using the given parameters.

    Args:
        model_size: Number of parameters in the model.
        batch_size: Batch size for training.
        num_epochs: Number of epochs to train.
        dataset: Dataset to train on.
        device: Device to train on.

    Returns:
        Dictionary containing training metrics.
    """
    # Initialize model
    model = torch.nn.Linear(dataset.shape[1], model_size).to(device)
    optimizer = torch.optim.Adam(model.parameters())

    # Training loop
    start_time = time.time()
    for epoch in range(num_epochs):
        for i in range(0, len(dataset), batch_size):
            batch = dataset[i:i+batch_size].to(device)
            optimizer.zero_grad()
            outputs = model(batch)
            loss = outputs.mean()
            loss.backward()
            optimizer.step()

    # Calculate training metrics
    training_time = time.time() - start_time
    flops_per_epoch = model_size * batch_size * len(dataset) * 2  # 2 FLOPs per parameter per batch
    total_flops = flops_per_epoch * num_epochs

    return {
        'training_time': training_time,
        'total_flops': total_flops,
        'flops_per_epoch': flops_per_epoch,
        'model_size': model_size,
        'batch_size': batch_size
    }

if __name__ == "__main__":
    # Example usage
    compute_budget = 1e20  # 1 exaFLOPs
    dataset_size = 1e12  # 1 trillion tokens
    num_epochs = 10

    # Generate a random dataset
    dataset = torch.randn(int(1e6), 100)  # 1 million samples, 100 features each

    # Compute optimal model size and batch size
    model_size, batch_size = compute_optimal_model_size(compute_budget, dataset_size)
    print(f"Optimal model size: {model_size} parameters")
    print(f"Optimal batch size: {batch_size}")

    # Pre-train the model
    metrics = pre_train_model(model_size, batch_size, num_epochs, dataset)
    print(f"Training time: {metrics['training_time']:.2f} seconds")
    print(f"Total FLOPs: {metrics['total_flops']:.2e}")
    print(f"FLOPs per epoch: {metrics['flops_per_epoch']:.2e}")
```
