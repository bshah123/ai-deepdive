# 31.3 — PEFT Implementation & Multi-LoRA Adapter Serving

## Opening Motivation & Context

In the rapidly evolving landscape of natural language processing, the ability to efficiently adapt large language models to specific tasks without extensive retraining is crucial. Parameter-Efficient Fine-Tuning (PEFT) techniques like LoRA (Low-Rank Adaptation) have emerged as game-changers, allowing for significant reductions in computational resources while maintaining high performance. This lesson focuses on implementing PEFT with LoRA and serving multiple LoRA adapters, enabling models to handle diverse tasks with minimal overhead.

## Core Concepts Breakdown

### LoRA (Low-Rank Adaptation)
LoRA is a PEFT technique that introduces low-rank decomposition matrices into the model's weight matrices. This approach significantly reduces the number of trainable parameters, making it feasible to fine-tune large models on limited hardware.

> [!KEY-INSIGHT]
> LoRA works by adding pairs of rank-decomposition matrices to the existing weight matrices, allowing the model to learn task-specific adaptations with minimal computational overhead.

> [!BEST-PRACTICE]
> When implementing LoRA, start with a small rank (e.g., 4 or 8) and gradually increase it if performance is insufficient. This approach balances computational efficiency and model performance.

> [!WARNING]
> LoRA adapters should be initialized with small values to avoid disrupting the pre-trained model's weights. Large initial values can lead to unstable training and poor performance.

### Multi-LoRA Adapter Serving
Serving multiple LoRA adapters allows a single model to handle various tasks by dynamically switching between adapters. This approach is particularly useful in scenarios where a model needs to perform multiple tasks without retraining or fine-tuning for each task individually.

> [!KEY-INSIGHT]
> Multi-LoRA adapter serving leverages the modularity of LoRA adapters, enabling efficient task switching by loading and unloading adapters as needed.

> [!BEST-PRACTICE]
> Organize LoRA adapters in a structured directory to facilitate easy loading and switching. Use a configuration file to map tasks to specific adapters for streamlined management.

> [!WARNING]
> Ensure that the base model remains unchanged when switching between adapters. Modifying the base model can lead to inconsistent behavior and poor performance.

## Code Demonstration & Runtime Output

```python
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer, Trainer, TrainingArguments
from peft import get_peft_model, LoraConfig, TaskType
from datasets import load_dataset
import os

# Define the model and tokenizer
model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=2)

# Define the LoRA configuration
lora_config = LoraConfig(
    task_type=TaskType.SEQ_CLS,
    inference_mode=False,
    r=8,
    lora_alpha=32,
    lora_dropout=0.1,
    target_modules=["query", "value"]
)

# Apply LoRA to the model
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()

# Load the dataset
dataset = load_dataset("imdb")
def tokenize_function(examples):
    return tokenizer(examples["text"], padding="max_length", truncation=True)

tokenized_datasets = dataset.map(tokenize_function, batched=True)
small_train_dataset = tokenized_datasets["train"].shuffle(seed=42).select(range(1000))
small_eval_dataset = tokenized_datasets["test"].shuffle(seed=42).select(range(1000))

# Define the training arguments
training_args = TrainingArguments(
    output_dir="./results",
    evaluation_strategy="epoch",
    learning_rate=2e-5,
    per_device_train_batch_size=4,
    per_device_eval_batch_size=4,
    num_train_epochs=3,
    weight_decay=0.01,
)

# Create the Trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=small_train_dataset,
    eval_dataset=small_eval_dataset,
)

# Train the model
trainer.train()

# Save the LoRA adapter
adapter_dir = "./lora_adapters/imdb"
os.makedirs(adapter_dir, exist_ok=True)
model.save_pretrained(adapter_dir)

# Load the LoRA adapter for inference
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=2)
model = get_peft_model(model, lora_config)
model.load_adapter(adapter_dir, adapter_name="imdb")

# Example inference
inputs = tokenizer("This movie was great!", return_tensors="pt")
outputs = model(**inputs)
print(outputs.logits)

# Switch to another adapter (e.g., sentiment analysis)
another_adapter_dir = "./lora_adapters/sentiment"
model.load_adapter(another_adapter_dir, adapter_name="sentiment")
model.set_adapter("sentiment")

# Example inference with the new adapter
inputs = tokenizer("I love this product!", return_tensors="pt")
outputs = model(**inputs)
print(outputs.logits)
```
