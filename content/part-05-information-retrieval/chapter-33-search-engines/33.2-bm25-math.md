# 33.2 — BM25 Scoring Function Mathematics & Term Saturation

## Opening Motivation & Context

In the realm of information retrieval and search engines, the BM25 (Best Match 25) scoring function is a cornerstone algorithm that determines the relevance of documents to a given search query. It's an evolution of the TF-IDF (Term Frequency-Inverse Document Frequency) model, incorporating term saturation and document length normalization to provide more accurate and nuanced ranking. Understanding the mathematics behind BM25 and the concept of term saturation is crucial for developing effective search engines and information retrieval systems.

## Core Concepts Breakdown

### BM25 Scoring Function

The BM25 scoring function is designed to address some of the limitations of the TF-IDF model. It incorporates two key concepts: term saturation and document length normalization. The BM25 score for a document \( D \) and a query \( Q \) is calculated as follows:

\[ \text{BM25}(D, Q) = \sum_{i=1}^{n} \text{IDF}(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot (1 - b + b \cdot \frac{|D|}{\text{avgdl}})} \]

Where:
- \( q_i \) is a term in the query \( Q \).
- \( f(q_i, D) \) is the term frequency of \( q_i \) in document \( D \).
- \( \text{IDF}(q_i) \) is the inverse document frequency of \( q_i \).
- \( |D| \) is the length of document \( D \) in words.
- \( \text{avgdl} \) is the average document length in the collection.
- \( k_1 \) and \( b \) are tuning parameters.

> [!KEY-INSIGHT]
> The BM25 scoring function considers both the term frequency and the document length, providing a more nuanced ranking of documents based on their relevance to the query.

> [!BEST-PRACTICE]
> When implementing the BM25 scoring function, it's essential to tune the parameters \( k_1 \) and \( b \) to optimize the performance of the search engine for your specific use case.

### Term Saturation

Term saturation refers to the phenomenon where the relevance score of a document to a query term plateaus as the term frequency increases. This is a desirable property in information retrieval, as it prevents documents with an excessively high term frequency from dominating the ranking. The term saturation is incorporated into the BM25 scoring function through the term \( \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot (1 - b + b \cdot \frac{|D|}{\text{avgdl}})} \), which ensures that the term frequency does not linearly increase the score.

> [!WARNING]
> Without term saturation, documents with an excessively high term frequency could dominate the ranking, leading to less relevant results. It's crucial to incorporate term saturation into the scoring function to ensure fair and accurate ranking.

## Code Demonstration & Runtime Output

```python
import math
from typing import List, Dict, Tuple

def calculate_idf(term: str, documents: List[Dict[str, int]], total_documents: int) -> float:
    """
    Calculate the inverse document frequency (IDF) for a term.

    Args:
        term: The term for which to calculate the IDF.
        documents: A list of documents, where each document is a dictionary mapping terms to their frequencies.
        total_documents: The total number of documents in the collection.

    Returns:
        The IDF for the term.
    """
    document_count = sum(1 for doc in documents if term in doc)
    return math.log((total_documents - document_count + 0.5) / (document_count + 0.5) + 1)

def calculate_bm25_score(query: List[str], document: Dict[str, int], documents: List[Dict[str, int]], avgdl: float, k1: float = 1.5, b: float = 0.75) -> float:
    """
    Calculate the BM25 score for a document and a query.

    Args:
        query: The query terms.
        document: The document for which to calculate the score, represented as a dictionary mapping terms to their frequencies.
        documents: A list of documents, where each document is a dictionary mapping terms to their frequencies.
        avgdl: The average document length in the collection.
        k1: The tuning parameter for term frequency saturation.
        b: The tuning parameter for document length normalization.

    Returns:
        The BM25 score for the document and the query.
    """
    score = 0.0
    doc_length = sum(document.values())
    for term in query:
        if term not in document:
            continue
        idf = calculate_idf(term, documents, len(documents))
        term_freq = document[term]
        numerator = term_freq * (k1 + 1)
        denominator = term_freq + k1 * (1 - b + b * (doc_length / avgdl))
        score += idf * (numerator / denominator)
    return score

def main():
    # Example documents
    documents = [
        {"apple": 2, "banana": 1, "orange": 1},
        {"apple": 1, "banana": 2, "orange": 1},
        {"apple": 1, "banana": 1, "orange": 2},
    ]

    # Calculate the average document length
    avgdl = sum(sum(doc.values()) for doc in documents) / len(documents)

    # Example query
    query = ["apple", "banana"]

    # Calculate the BM25 score for each document
    for i, doc in enumerate(documents):
        score = calculate_bm25_score(query, doc, documents, avgdl)
        print(f"Document {i + 1} BM25 score: {score:.4f}")

if __name__ == "__main__":
    main()
```

```text
Document 2 BM25 score: 1.3863
Document 3 BM25 score: 0.6931
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: The code imports the `math` module for mathematical operations and the `List`, `Dict`, and `Tuple` types from the `typing` module for type hints.
2. **calculate_idf function**: This function calculates the inverse document frequency (IDF) for a term. It takes the term, a list of documents, and the total number of documents as input and returns the IDF for the term.
3. **calculate_bm25_score function**: This function calculates the BM25 score for a document and a query. It takes the query terms, the document, a list of documents, the average document length, and the tuning parameters \( k_1 \) and \( b \) as input and returns the BM25 score for the document and the query.
4. **main function**: This function demonstrates the usage of the `calculate_bm25_score` function. It defines example documents, calculates the average document length, defines an example query, and calculates the BM25 score for each document.
5. **if __name__ == "__main__":**: This block ensures that the `main` function is called when the script is executed directly.

> [!ADVANCED]
> The `calculate_bm25_score` function uses a nested loop to iterate over the query terms and the documents. The outer loop iterates over the query terms, and the inner loop iterates over the documents. This nested loop structure is necessary to calculate the BM25 score for each document and query term combination.
