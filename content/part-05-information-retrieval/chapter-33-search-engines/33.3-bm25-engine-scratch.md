# 33.3 — Building a Fast Pure-Python BM25 Engine from Scratch

## Opening Motivation & Context

In the realm of information retrieval, search engines are the backbone of modern web applications. They enable users to find relevant information quickly and efficiently. One of the most popular ranking functions used in search engines is the BM25 algorithm, which stands for Best Match 25. BM25 is a bag-of-words retrieval function that ranks a set of documents based on the query terms appearing in each document, regardless of their proximity within the document.

Building a fast and efficient BM25 engine from scratch is a challenging but rewarding task. In this lesson, we will explore the mechanics of the BM25 algorithm and implement a pure-Python version of it. We will also discuss the best practices and common pitfalls to avoid when implementing such an engine.

## Core Concepts Breakdown

### BM25 Algorithm

The BM25 algorithm is a ranking function used by search engines to estimate the relevance of documents to a given search query. It is based on the probabilistic retrieval framework and is designed to address the limitations of the traditional Boolean retrieval model.

The BM25 score for a document \( D \) and a query \( Q \) is calculated as follows:

\[ \text{score}(D, Q) = \sum_{i=1}^{n} \text{IDF}(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot (1 - b + b \cdot \frac{|D|}{\text{avgdl}})} \]

where:
- \( q_i \) is a term in the query \( Q \)
- \( f(q_i, D) \) is the term frequency of \( q_i \) in document \( D \)
- \( |D| \) is the length of document \( D \) in words
- \( \text{avgdl} \) is the average document length in the document set
- \( k_1 \) and \( b \) are tuning parameters
- \( \text{IDF}(q_i) \) is the inverse document frequency of \( q_i \), calculated as:

\[ \text{IDF}(q_i) = \log \frac{N - n(q_i) + 0.5}{n(q_i) + 0.5} \]

where:
- \( N \) is the total number of documents in the collection
- \( n(q_i) \) is the number of documents containing \( q_i \)

> [!KEY-INSIGHT]
> The BM25 algorithm combines term frequency and document length normalization to produce a relevance score for each document. The IDF component ensures that rare terms contribute more to the score than common terms.

> [!BEST-PRACTICE]
> When implementing the BM25 algorithm, it is important to preprocess the documents and queries to remove stop words, perform stemming, and normalize the text. This will improve the quality of the search results.

> [!WARNING]
> The BM25 algorithm is sensitive to the choice of tuning parameters \( k_1 \) and \( b \). It is recommended to tune these parameters on a held-out validation set to achieve the best performance.

## Code Demonstration & Runtime Output

Let's implement a fast pure-Python BM25 engine from scratch. We will use the following code snippet to demonstrate the concept:

```python
import math
from typing import List, Dict, Tuple

class BM25:
    def __init__(self, k1: float = 1.5, b: float = 0.75):
        self.k1 = k1
        self.b = b
        self.documents: List[str] = []
        self.doc_freqs: Dict[str, int] = {}
        self.idf: Dict[str, float] = {}
        self.doc_len: List[int] = []
        self.avgdl: float = 0.0

    def add_document(self, document: str) -> None:
        self.documents.append(document)
        self.doc_len.append(len(document.split()))
        self.avgdl = sum(self.doc_len) / len(self.doc_len)

        freqs: Dict[str, int] = {}
        for word in document.split():
            if word not in freqs:
                freqs[word] = 0
            freqs[word] += 1

        for word, freq in freqs.items():
            if word not in self.doc_freqs:
                self.doc_freqs[word] = 0
            self.doc_freqs[word] += 1

    def calculate_idf(self) -> None:
        for word, freq in self.doc_freqs.items():
            self.idf[word] = math.log((len(self.documents) - freq + 0.5) / (freq + 0.5))

    def get_scores(self, query: str) -> List[Tuple[int, float]]:
        scores: List[Tuple[int, float]] = []
        query_terms = query.split()

        for idx, document in enumerate(self.documents):
            score = 0.0
            doc_terms = document.split()

            for term in query_terms:
                if term not in self.idf:
                    continue

                tf = doc_terms.count(term)
                idf = self.idf[term]
                score += idf * ((tf * (self.k1 + 1)) / (tf + self.k1 * (1 - self.b + self.b * self.doc_len[idx] / self.avgdl)))

            scores.append((idx, score))

        return sorted(scores, key=lambda x: x[1], reverse=True)

if __name__ == "__main__":
    bm25 = BM25()
    bm25.add_document("The quick brown fox jumps over the lazy dog")
    bm25.add_document("The quick brown fox jumps over the lazy dog and the quick brown fox jumps again")
    bm25.add_document("The lazy dog sleeps in the sun")
    bm25.calculate_idf()

    query = "quick brown fox"
    scores = bm25.get_scores(query)

    for idx, score in scores:
        print(f"Document {idx}: {score}")
```

## How this works (Line-by-Line Breakdown)

1. **Imports**: We import the `math` module for logarithmic calculations and the `List`, `Dict`, and `Tuple` types for type hints.
2. **BM25 Class**: We define the `BM25` class with the `k1` and `b` parameters for tuning the algorithm.
3. **Initialization**: In the `__init__` method, we initialize the `documents`, `doc_freqs`, `idf`, `doc_len`, and `avgdl` attributes.
4. **Adding Documents**: The `add_document` method adds a document to the collection, updates the document frequencies, and calculates the average document length.
5. **Calculating IDF**: The `calculate_idf` method calculates the inverse document frequency for each term in the collection.
6. **Scoring Documents**: The `get_scores` method calculates the BM25 score for each document in the collection based on the query terms.
7. **Main Block**: In the `__main__` block, we create a `BM25` instance, add some documents, calculate the IDF values, and retrieve the scores for a query.
