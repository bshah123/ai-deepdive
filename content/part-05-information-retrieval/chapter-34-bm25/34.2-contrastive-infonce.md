# 34.2 — Contrastive Learning & InfoNCE / MultipleNegativesRanking Loss

## Opening Motivation & Context

Contrastive learning is a powerful technique in the field of machine learning, particularly in the context of representation learning. It aims to learn meaningful representations by comparing similar and dissimilar pairs of data points. This approach has been particularly influential in the development of modern natural language processing (NLP) models and has applications in various domains, including computer vision and recommendation systems.

In this lesson, we will explore two key concepts in contrastive learning: the InfoNCE (Noise Contrastive Estimation) loss and the MultipleNegativesRankingLoss. These loss functions are designed to optimize the learning process by focusing on the relative ordering of similar and dissimilar pairs, rather than absolute values. Understanding these concepts will provide you with a deeper insight into how modern machine learning models learn and generalize from data.

## Core Concepts Breakdown

### InfoNCE Loss

InfoNCE is a loss function used in contrastive learning to maximize the mutual information between the input and the output of a neural network. It works by comparing the similarity of a positive pair (similar data points) to a set of negative pairs (dissimilar data points). The loss is calculated as the negative log-likelihood of the positive pair relative to the sum of the similarities of all pairs.

> [!KEY-INSIGHT]
> InfoNCE loss focuses on the relative ordering of similar and dissimilar pairs, which helps the model learn more discriminative representations.

> [!BEST-PRACTICE]
> When using InfoNCE loss, it is important to carefully select the positive and negative pairs to ensure that the model learns meaningful representations.

### MultipleNegativesRankingLoss

MultipleNegativesRankingLoss is another loss function used in contrastive learning, particularly in the context of information retrieval. It is designed to optimize the ranking of similar and dissimilar pairs by considering multiple negative samples. The loss is calculated as the negative log-likelihood of the positive pair relative to the sum of the similarities of all pairs, including multiple negative samples.

> [!KEY-INSIGHT]
> MultipleNegativesRankingLoss considers multiple negative samples, which helps the model learn more robust and discriminative representations.

> [!WARNING]
> When using MultipleNegativesRankingLoss, it is important to ensure that the negative samples are diverse and representative of the data distribution to avoid overfitting.

## Code Demonstration & Runtime Output

Let's start by implementing the InfoNCE loss function in Python. We will use the PyTorch library for this demonstration.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class InfoNCELoss(nn.Module):
    def __init__(self, temperature: float = 0.1):
        super(InfoNCELoss, self).__init__()
        self.temperature = temperature

    def forward(self, query: torch.Tensor, positive_key: torch.Tensor, negative_keys: torch.Tensor) -> torch.Tensor:
        # Normalize the embeddings
        query = F.normalize(query, p=2, dim=1)
        positive_key = F.normalize(positive_key, p=2, dim=1)
        negative_keys = F.normalize(negative_keys, p=2, dim=1)

        # Calculate the similarity scores
        positive_sim = torch.exp(torch.sum(query * positive_key, dim=1) / self.temperature)
        negative_sims = torch.exp(torch.sum(query * negative_keys, dim=1) / self.temperature)

        # Calculate the loss
        loss = -torch.log(positive_sim / (positive_sim + torch.sum(negative_sims, dim=1)))

        return torch.mean(loss)

if __name__ == "__main__":
    # Create a random query, positive key, and negative keys
    query = torch.randn(1, 128)
    positive_key = torch.randn(1, 128)
    negative_keys = torch.randn(10, 128)

    # Initialize the InfoNCE loss
    infonce_loss = InfoNCELoss(temperature=0.1)

    # Calculate the loss
    loss = infonce_loss(query, positive_key, negative_keys)

    print(f"InfoNCE Loss: {loss.item()}")
```

The bug in the code is that the loss is not being averaged over the batch dimension. To fix this, we need to add `torch.mean(loss)` at the end of the `forward` method.
