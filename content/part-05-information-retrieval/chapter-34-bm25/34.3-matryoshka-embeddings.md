# 34.3 — Matryoshka Representation Learning (MRL) & Truncated Embeddings

## Opening Motivation & Context

Matryoshka Representation Learning (MRL) and truncated embeddings are advanced techniques in the field of information retrieval and vector search. These methods are particularly useful when dealing with high-dimensional data, such as text embeddings, where the computational cost of processing and storing the full embeddings can be prohibitive. MRL and truncated embeddings allow us to work with more manageable representations of the data while still retaining much of the original information.

MRL involves learning a hierarchy of representations, where each level of the hierarchy captures different levels of detail or abstraction. This is analogous to a set of nested Matryoshka dolls, where each doll contains a smaller doll inside it. In the context of embeddings, this means that we can represent the same data at different levels of granularity, allowing us to trade off between computational efficiency and representational power.

Truncated embeddings, on the other hand, involve taking a subset of the original embedding dimensions, effectively "truncating" the embedding to a lower-dimensional space. This can be done in a principled way, such as by selecting the most important dimensions based on some criterion, or in a more ad-hoc manner, such as by simply taking the first N dimensions of the embedding. Truncated embeddings can be particularly useful when working with very high-dimensional data, as they allow us to reduce the dimensionality of the data while still retaining much of the original information.

## Core Concepts Breakdown

### Matryoshka Representation Learning (MRL)

MRL is a technique for learning a hierarchy of representations, where each level of the hierarchy captures different levels of detail or abstraction. This is done by training a series of models, where each model is trained to predict the representation from the previous level of the hierarchy. The result is a set of nested representations, where each level of the hierarchy is a more abstract or coarse-grained version of the previous level.

> [!KEY-INSIGHT]
> MRL allows us to trade off between computational efficiency and representational power by working with different levels of the hierarchy, depending on the specific task or application at hand.

> [!BEST-PRACTICE]
> When using MRL, it is important to carefully consider the trade-off between computational efficiency and representational power, and to choose the appropriate level of the hierarchy for the specific task or application at hand.

### Truncated Embeddings

Truncated embeddings are a technique for reducing the dimensionality of embeddings by taking a subset of the original dimensions. This can be done in a principled way, such as by selecting the most important dimensions based on some criterion, or in a more ad-hoc manner, such as by simply taking the first N dimensions of the embedding. Truncated embeddings can be particularly useful when working with very high-dimensional data, as they allow us to reduce the dimensionality of the data while still retaining much of the original information.

> [!KEY-INSIGHT]
> Truncated embeddings allow us to reduce the dimensionality of embeddings while still retaining much of the original information, making them particularly useful for working with high-dimensional data.

> [!WARNING]
> When using truncated embeddings, it is important to ensure that the selected dimensions are indeed the most important or relevant dimensions for the specific task or application at hand. Otherwise, the truncated embeddings may not capture the most important aspects of the original data.

## Code Demonstration & Runtime Output

```python
import numpy as np
from typing import List, Tuple

def generate_matryoshka_representations(data: np.ndarray, num_levels: int) -> List[np.ndarray]:
    """
    Generate a hierarchy of Matryoshka representations for the given data.

    Args:
        data: The input data, as a numpy array.
        num_levels: The number of levels in the hierarchy.

    Returns:
        A list of numpy arrays, where each array represents a level in the hierarchy.
    """
    representations = [data]
    for i in range(1, num_levels):
        # Generate a new representation by averaging adjacent elements
        new_representation = (representations[i-1][:-1] + representations[i-1][1:]) / 2
        representations.append(new_representation)
    return representations

def truncate_embeddings(embeddings: np.ndarray, num_dimensions: int) -> np.ndarray:
    """
    Truncate the given embeddings to the specified number of dimensions.

    Args:
        embeddings: The input embeddings, as a numpy array.
        num_dimensions: The number of dimensions to retain.

    Returns:
        The truncated embeddings, as a numpy array.
    """
    return embeddings[:, :num_dimensions]

if __name__ == "__main__":
    # Generate some random data
    data = np.random.rand(100, 10)

    # Generate a hierarchy of Matryoshka representations
    representations = generate_matryoshka_representations(data, 5)
    for i, representation in enumerate(representations):
        print(f"Level {i} representation shape: {representation.shape}")

    # Truncate the embeddings to 5 dimensions
    truncated_embeddings = truncate_embeddings(data, 5)
    print(f"Truncated embeddings shape: {truncated_embeddings.shape}")
```

The bug in the code is that the `truncate_embeddings` function is truncating the rows of the input embeddings instead of the columns. To fix the bug, we need to modify the function to truncate the columns of the input embeddings. The fixed code is as follows:
