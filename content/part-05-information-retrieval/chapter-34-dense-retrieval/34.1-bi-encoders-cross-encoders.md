# 34.1 — Dense Embeddings: Sentence-Transformers & Bi-Encoder Architecture

## Opening Motivation & Context

Dense embeddings are a fundamental concept in modern natural language processing (NLP) and information retrieval. They represent words, sentences, or entire documents as dense vectors in a high-dimensional space, where similar items are closer together. The Sentence-Transformers library and the bi-encoder architecture are powerful tools for generating these embeddings. Understanding how they work is crucial for building effective search systems, recommendation engines, and other AI applications.

## Core Concepts Breakdown

### Dense Embeddings

Dense embeddings are continuous vector representations of text. Unlike sparse representations (like bag-of-words), dense embeddings capture semantic relationships and can be used for similarity searches.

> [!KEY-INSIGHT]
> Dense embeddings capture semantic meaning, allowing for more accurate similarity searches compared to traditional keyword-based methods.

### Sentence-Transformers

Sentence-Transformers is a Python framework for state-of-the-art sentence, text, and image embeddings. It builds on top of Hugging Face's Transformers library and provides pre-trained models for generating dense embeddings.

> [!BEST-PRACTICE]
> Use Sentence-Transformers for generating high-quality dense embeddings due to its ease of use and performance.

### Bi-Encoder Architecture

The bi-encoder architecture consists of two identical transformer models, one for the query and one for the document. This architecture is used in information retrieval systems to compute the similarity between a query and a document.

> [!WARNING]
> Bi-encoders can be computationally expensive to train and deploy, especially for large-scale applications.

## Code Demonstration & Runtime Output

```python
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

def generate_embeddings(sentences: list[str], model_name: str = 'all-MiniLM-L6-v2') -> np.ndarray:
    """
    Generate dense embeddings for a list of sentences using a pre-trained Sentence-Transformer model.

    Args:
        sentences: List of sentences to embed.
        model_name: Name of the pre-trained Sentence-Transformer model.

    Returns:
        Numpy array of embeddings.
    """
    model = SentenceTransformer(model_name)
    embeddings = model.encode(sentences)
    return embeddings

def compute_similarity(query_embedding: np.ndarray, document_embeddings: np.ndarray) -> np.ndarray:
    """
    Compute cosine similarity between a query embedding and a set of document embeddings.

    Args:
        query_embedding: Embedding of the query.
        document_embeddings: Embeddings of the documents.

    Returns:
        Numpy array of cosine similarities.
    """
    similarities = cosine_similarity([query_embedding], document_embeddings)
    return similarities.flatten()

if __name__ == "__main__":
    # Example sentences
    sentences = [
        "The cat sits on the mat.",
        "The dog plays in the park.",
        "A cat is sitting on a mat.",
        "Dogs are playing in the park."
    ]

    # Generate embeddings
    embeddings = generate_embeddings(sentences)

    # Example query
    query = "A cat is sitting on a mat."
    query_embedding = generate_embeddings([query])[0]

    # Compute similarities
    similarities = compute_similarity(query_embedding, embeddings)

    # Print results
    for sentence, similarity in zip(sentences, similarities):
        print(f"Sentence: {sentence}")
        print(f"Similarity: {similarity:.4f}\n")
```

### How this works (Line-by-Line Breakdown)

1. **Imports**:
   - `SentenceTransformer` from `sentence_transformers`: Used to generate dense embeddings.
   - `cosine_similarity` from `sklearn.metrics.pairwise`: Used to compute cosine similarity between embeddings.
   - `numpy` as `np`: Used for numerical operations.

2. **`generate_embeddings` function**:
   - **Parameters**:
     - `sentences`: List of sentences to embed.
     - `model_name`: Name of the pre-trained Sentence-Transformer model (default: 'all-MiniLM-L6-v2').
   - **Functionality**:
     - Loads the specified pre-trained Sentence-Transformer model.
     - Encodes the input sentences into dense embeddings.
     - Returns the embeddings as a numpy array.

3. **`compute_similarity` function**:
   - **Parameters**:
     - `query_embedding`: Embedding of the query.
     - `document_embeddings`: Embeddings of the documents.
   - **Functionality**:
     - Computes the cosine similarity between the query embedding and each document embedding.
     - Returns the similarities as a flattened numpy array.

4. **`__main__` block**:
   - **Example sentences**: List of sentences to embed.
   - **Generate embeddings**: Calls `generate_embeddings` to get embeddings for the example sentences.
   - **Example query**: A query sentence to compare against the example sentences.
   - **Query embedding**: Generates an embedding for the query sentence.
   - **Compute similarities**: Calls `compute_similarity` to get the cosine similarities between the query and the example sentences.
   - **Print results**: Prints each sentence along with its similarity to the query.

> [!ADVANCED]
> The `SentenceTransformer` model uses a transformer architecture to generate dense embeddings. The `encode` method processes the input sentences through the transformer layers, applies mean pooling to the output embeddings, and normalizes the resulting vectors. The `cosine_similarity` function computes the cosine of the angle between the query and document vectors, which is a measure of their similarity.

## Summary & Key Takeaways

- Dense embeddings capture semantic meaning and are used for similarity searches.
- Sentence-Transformers is a powerful library for generating high-quality dense embeddings.
- The bi-encoder architecture uses two identical transformer models to compute the similarity between a query and a document.
- Cosine similarity is a common metric for measuring the similarity between dense embeddings.

```python
from sklearn.metrics.pairwise import cosine_similarity

model = SentenceTransformer('all-MiniLM-L6-v2')
sentences = ["This is a sentence.", "This is another sentence."]
embeddings = model.encode(sentences)

query = "This is a query."
query_embedding = model.encode(query)

similarities = cosine_similarity([query_embedding], embeddings)
print(similarities)
```
