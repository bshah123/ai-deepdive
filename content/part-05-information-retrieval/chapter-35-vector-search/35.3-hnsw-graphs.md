# 35.3 — Hierarchical Navigable Small World (HNSW) Graphs Deep Dive

## Opening Motivation & Context

Hierarchical Navigable Small World (HNSW) graphs are a powerful data structure for approximate nearest neighbor search in high-dimensional spaces. They are particularly useful in applications like recommendation systems, image similarity search, and natural language processing. HNSW graphs combine the efficiency of hierarchical structures with the navigability of small-world networks, making them ideal for large-scale vector search applications.

## Core Concepts Breakdown

HNSW graphs are built in a hierarchical manner, with each layer containing a subset of the nodes from the layer below. The top layer contains the fewest nodes and provides a coarse approximation of the data space, while the bottom layer contains all the nodes and provides the most accurate search results.

> [!KEY-INSIGHT]
> HNSW graphs strike a balance between search accuracy and efficiency by leveraging hierarchical navigation and small-world properties.

> [!BEST-PRACTICE]
> When building HNSW graphs, start with a small number of layers and gradually increase the number of layers as the dataset grows. This approach helps maintain search efficiency while improving accuracy.

> [!WARNING]
> HNSW graphs can be sensitive to the choice of hyperparameters, such as the number of layers, the number of neighbors per node, and the search parameters. Poorly chosen hyperparameters can lead to suboptimal search performance.

import numpy as np
from typing import List, Dict, Tuple

class HNSWGraph:
    def __init__(self, M: int, ef_construction: int):
        self.M = M  # Number of neighbors per node
        self.ef_construction = ef_construction  # Size of the dynamic candidate list during construction
        self.layers: List[Dict[int, List[int]]] = [{}]
        self.enter_point = None

    def add_node(self, node_id: int, vector: np.ndarray):
        if not self.enter_point:
            self.enter_point = node_id
            self.layers[0][node_id] = []
            return

        # Find the appropriate layer for the new node
        layer = 0
        while layer < len(self.layers) and np.random.random() < 0.5:
            layer += 1

        # Ensure the layer exists
        while layer >= len(self.layers):
            self.layers.append({})

        # Add the node to the layer
        self.layers[layer][node_id] = []

        # Connect the new node to its neighbors
        self._connect_node(node_id, vector, layer)

    def _connect_node(self, node_id: int, vector: np.ndarray, layer: int):
        # Start from the enter point
        current_node = self.enter_point

        # Navigate down the layers to find the appropriate entry point
        for l in range(len(self.layers) - 1, layer - 1, -1):
            current_node = self._search_layer(current_node, vector, l, 1)

        # Connect the new node to its neighbors in the current layer
        neighbors = self._search_layer(current_node, vector, layer, self.ef_construction)
        self.layers[layer][node_id] = neighbors[:self.M]

        # Update the neighbors' connections
        for neighbor in neighbors[:self.M]:
            if len(self.layers[layer][neighbor]) < self.M:
                self.layers[layer][neighbor].append(node_id)
            else:
                # Replace the farthest neighbor
                farthest_neighbor = max(self.layers[layer][neighbor], key=lambda n: np.linalg.norm(vector - self._get_vector(n)))
                self.layers[layer][neighbor].remove(farthest_neighbor)
                self.layers[layer][neighbor].append(node_id)

    def _search_layer(self, entry_point: int, vector: np.ndarray, layer: int, ef: int) -> List[int]:
        # Initialize the candidate list with the entry point
        candidates = [entry_point]
        visited = set(candidates)

        # Search for the nearest neighbors in the current layer
        while candidates:
            current_node = candidates.pop(0)
            for neighbor in self.layers[layer][current_node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    candidates.append(neighbor)
                    if len(candidates) > ef:
                        # Remove the farthest candidate
                        farthest_candidate = max(candidates, key=lambda n: np.linalg.norm(vector - self._get_vector(n)))
                        candidates.remove(farthest_candidate)

        return candidates

    def _get_vector(self, node_id: int) -> np.ndarray:
        # In a real implementation, this would retrieve the vector associated with the node_id
        # For simplicity, we'll return a random vector here
        return np.random.rand(128)

    def search(self, vector: np.ndarray, ef: int) -> List[int]:
        # Start from the enter point
        current_node = self.enter_point

        # Navigate down the layers to find the appropriate entry point
        for layer in range(len(self.layers) - 1, -1, -1):
            current_node = self._search_layer(current_node, vector, layer, 1)

        # Search for the nearest neighbors in the bottom layer
        return self._search_layer(current_node, vector, 0, ef)

    hnsw = HNSWGraph(M=16, ef_construction=200)

    # Add 1000 nodes to the graph
    for i in range(1000):
        hnsw.add_node(i, np.random.rand(128))

    # Search for the 10 nearest neighbors of a random vector
    query_vector = np.random.rand(128)
    neighbors = hnsw.search(query_vector, ef=10)

    print(f"Nearest neighbors: {neighbors}")
