# 36.2 — Reciprocal Rank Fusion (RRF) & Score Normalization Math

## Opening Motivation & Context

Reciprocal Rank Fusion (RRF) and score normalization are essential techniques in information retrieval and vector search. They help combine results from multiple search algorithms, normalize scores from different systems, and improve the overall relevance of search results. Understanding these concepts is crucial for building effective search systems that can handle complex queries and provide high-quality results.

## Core Concepts Breakdown

### Reciprocal Rank Fusion (RRF)

RRF is a method for combining results from multiple search algorithms. It assigns a score to each result based on its rank in each individual search result list. The RRF score is calculated using the reciprocal of the rank, which gives higher scores to results that appear at higher ranks in the individual result lists.

> [!KEY-INSIGHT]
> RRF helps combine results from multiple search algorithms by considering the rank of each result in each individual result list. Higher-ranked results contribute more to the final score.

> [!BEST-PRACTICE]
> Use RRF when you have multiple search algorithms and want to combine their results in a way that considers the rank of each result. This can help improve the overall relevance of the combined results.

### Score Normalization

Score normalization is the process of adjusting scores from different search algorithms to a common scale. This is necessary because different algorithms may produce scores that are not directly comparable. Normalization helps ensure that the scores from different algorithms can be combined effectively.

> [!KEY-INSIGHT]
> Score normalization adjusts scores from different search algorithms to a common scale, making them comparable and enabling effective combination of results.

> [!BEST-PRACTICE]
> Normalize scores when combining results from multiple search algorithms. This can help ensure that the combined results are relevant and of high quality.

## Code Demonstration & Runtime Output

```python
from typing import List, Dict, Tuple
import math

def reciprocal_rank_fusion(result_lists: List[List[Tuple[str, float]]], k: int = 60) -> List[Tuple[str, float]]:
    """
    Perform Reciprocal Rank Fusion (RRF) on multiple result lists.

    Args:
        result_lists: A list of result lists, where each result list is a list of tuples (document_id, score).
        k: The rank normalization factor.

    Returns:
        A list of tuples (document_id, combined_score) sorted by the combined score in descending order.
    """
    document_scores: Dict[str, float] = {}

    for result_list in result_lists:
        for rank, (doc_id, score) in enumerate(result_list, start=1):
            if doc_id not in document_scores:
                document_scores[doc_id] = 0.0
            document_scores[doc_id] += 1.0 / (k + rank)

    combined_results = sorted(document_scores.items(), key=lambda x: x[1], reverse=True)
    return combined_results

def normalize_scores(scores: List[float]) -> List[float]:
    """
    Normalize a list of scores to a common scale.

    Args:
        scores: A list of scores.

    Returns:
        A list of normalized scores.
    """
    min_score = min(scores)
    max_score = max(scores)

    if min_score == max_score:
        return [0.5 for _ in scores]

    normalized_scores = [(score - min_score) / (max_score - min_score) for score in scores]
    return normalized_scores

if __name__ == "__main__":
    # Example result lists from different search algorithms
    result_list1 = [("doc1", 0.9), ("doc2", 0.8), ("doc3", 0.7)]
    result_list2 = [("doc2", 0.85), ("doc1", 0.75), ("doc4", 0.65)]
    result_list3 = [("doc3", 0.7), ("doc4", 0.6), ("doc1", 0.5)]

    # Perform RRF
    combined_results = reciprocal_rank_fusion([result_list1, result_list2, result_list3])
    print("Combined Results (RRF):")
    for doc_id, score in combined_results:
        print(f"Document: {doc_id}, Score: {score:.4f}")

    # Example scores from different search algorithms
    scores1 = [0.9, 0.8, 0.7]
    scores2 = [0.85, 0.75, 0.65]
    scores3 = [0.7, 0.6, 0.5]

    # Normalize scores
    normalized_scores1 = normalize_scores(scores1)
    normalized_scores2 = normalize_scores(scores2)
    normalized_scores3 = normalize_scores(scores3)

    print("\nNormalized Scores:")
    print("Scores1:", [f"{score:.4f}" for score in normalized_scores1])
    print("Scores2:", [f"{score:.4f}" for score in normalized_scores2])
    print("Scores3:", [f"{score:.4f}" for score in normalized_scores3])
```
