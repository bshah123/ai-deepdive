# 36.3 — Building a Production Hybrid Search Pipeline

## Opening Motivation & Context

In the realm of information retrieval and vector search, the need for efficient and accurate search pipelines is paramount. Traditional methods like brute-force search or exact nearest neighbor (NN) search can be computationally expensive and time-consuming, especially as the dataset grows. Approximate nearest neighbor (ANN) algorithms like Hierarchical Navigable Small World (HNSW) and Inverted File with Product Quantization (IVF-PQ) offer a compelling solution by trading a small amount of accuracy for significant speed improvements.

However, in many real-world applications, a single ANN algorithm may not be sufficient to meet all the requirements. A hybrid search pipeline that combines the strengths of different algorithms can provide a more robust and efficient solution. This lesson will guide you through building a production-ready hybrid search pipeline using HNSW and IVF-PQ.

## Core Concepts Breakdown

### Hybrid Search Pipeline

A hybrid search pipeline combines the strengths of different ANN algorithms to provide a more robust and efficient search solution. The idea is to use the faster but less accurate algorithm to narrow down the search space, and then use the slower but more accurate algorithm to find the exact nearest neighbors.

> [!KEY-INSIGHT]
> A hybrid search pipeline can provide a balance between search speed and accuracy, making it suitable for a wide range of applications.

> [!BEST-PRACTICE]
> When building a hybrid search pipeline, it's important to consider the trade-offs between speed and accuracy. Choose algorithms that complement each other well, and ensure that the pipeline is optimized for the specific requirements of your application.

> [!WARNING]
> Be cautious when combining different ANN algorithms. Some algorithms may not be compatible with each other, and the combination may not provide the expected performance improvements.

## Code Demonstration & Runtime Output

Let's start by building a hybrid search pipeline using HNSW and IVF-PQ. We'll use the `annoy` library for HNSW and the `faiss` library for IVF-PQ. First, make sure you have these libraries installed:

Now, let's write the code for our hybrid search pipeline:

```python
import numpy as np
from annoy import AnnoyIndex
import faiss

class HybridSearchPipeline:
    def __init__(self, dim: int, n_trees: int = 10, n_clusters: int = 100, n_subquantizers: int = 8):
        """
        Initialize the hybrid search pipeline.

        Args:
            dim (int): Dimension of the vectors.
            n_trees (int, optional): Number of trees for HNSW. Defaults to 10.
            n_clusters (int, optional): Number of clusters for IVF-PQ. Defaults to 100.
            n_subquantizers (int, optional): Number of subquantizers for IVF-PQ. Defaults to 8.
        """
        self.dim = dim
        self.n_trees = n_trees
        self.n_clusters = n_clusters
        self.n_subquantizers = n_subquantizers

        # Initialize HNSW index
        self.hnsw_index = AnnoyIndex(dim, 'angular')
        self.hnsw_index.set_seed(42)

        # Initialize IVF-PQ index
        quantizer = faiss.IndexFlatL2(dim)
        self.ivf_pq_index = faiss.IndexIVFPQ(quantizer, dim, n_clusters, n_subquantizers, 8)
        self.ivf_pq_index.train(np.random.rand(1000, dim).astype('float32'))
        self.ivf_pq_index.nprobe = 10

        self.vectors = []
        self.ids = []

    def add_item(self, vector: np.ndarray, item_id: int):
        """
        Add a vector to the search pipeline.

        Args:
            vector (np.ndarray): Vector to add.
            item_id (int): ID of the vector.
        """
        self.vectors.append(vector)
        self.ids.append(item_id)
        self.hnsw_index.add_item(item_id, vector)
        self.ivf_pq_index.add_with_ids(np.array([vector]), np.array([item_id]))

    def build(self):
        """
        Build the search pipeline.
        """
        self.hnsw_index.build(self.n_trees)
        self.ivf_pq_index.train(np.array(self.vectors).astype('float32'))

    def search(self, query: np.ndarray, k: int = 10, hybrid_k: int = 100):
        """
        Search for the nearest neighbors of the query vector.

        Args:
            query (np.ndarray): Query vector.
            k (int, optional): Number of nearest neighbors to return. Defaults to 10.
            hybrid_k (int, optional): Number of candidates to consider for the hybrid search. Defaults to 100.

        Returns:
            list: List of nearest neighbor IDs.
        """
        # First, use HNSW to get a set of candidate IDs
        candidate_ids = self.hnsw_index.get_nns_by_vector(query, hybrid_k)

        # Then, use IVF-PQ to find the exact nearest neighbors among the candidates
        candidate_vectors = np.array([self.vectors[i] for i in candidate_ids])
        _, exact_ids = self.ivf_pq_index.search(np.array([query]), k)

        # Map the exact IDs back to the original IDs
        exact_ids = [candidate_ids[i] for i in exact_ids[0]]

        return exact_ids

if __name__ == "__main__":
    # Example usage
    dim = 128
    pipeline = HybridSearchPipeline(dim)

    # Add some vectors to the pipeline
    for i in range(1000):
        vector = np.random.rand(dim).astype('float32')
        pipeline.add_item(vector, i)

    # Build the pipeline
    pipeline.build()

    # Search for the nearest neighbors of a query vector
    query = np.random.rand(dim).astype('float32')
    results = pipeline.search(query)

    print("Nearest neighbors:", results)
```

Output:


### How this works (Line-by-Line Breakdown)

1. **Imports**: We import the necessary libraries, including `numpy` for numerical operations, `annoy` for HNSW, and `faiss` for IVF-PQ.
2. **HybridSearchPipeline Class**: We define a class to encapsulate our hybrid search pipeline.
3. **__init__ Method**: The constructor initializes the HNSW and IVF-PQ indices with the specified parameters.
4. **add_item Method**: This method adds a vector to both the HNSW and IVF-PQ indices.
5. **build Method**: This method builds the HNSW index and trains the IVF-PQ index on the added vectors.
6. **search Method**: This method performs the hybrid search by first using HNSW to get a set of candidate IDs and then using IVF-PQ to find the exact nearest neighbors among the candidates.
7. **Example Usage**: In the `__main__` block, we create an instance of the `HybridSearchPipeline` class, add some random vectors to it, build the pipeline, and then search for the nearest neighbors of a query vector.

> [!ADVANCED]
> The `annoy` library uses a forest of random projection trees to approximate the nearest neighbors. Each tree is built by randomly projecting the data onto a hyperplane and then recursively partitioning the data based on the projection. The `faiss` library uses a combination of inverted files and product quantization to approximate the nearest neighbors. The inverted file maps each cluster to a set of vectors, and the product quantization compresses the vectors into a set of subvectors.

<details><summary>Show Solution</summary>

The bug is in the line `index.add(np.array([vector]))`. The `add` method of the `IndexIVFPQ` class expects the vectors to be added with their corresponding IDs. The fixed code is:

```python
import numpy as np
import faiss

dim = 128
quantizer = faiss.IndexFlatL2(dim)
index = faiss.IndexIVFPQ(quantizer, dim, 100, 8, 8)
index.train(np.random.rand(1000, dim).astype('float32'))

for i in range(1000):
    vector = np.random.rand(dim).astype('float32')
    index.add_with_ids(np.array([vector]), np.array([i]))

query = np.random.rand(dim).astype('float32')
_, results = index.search(np.array([query]), 10)

print(results)
```
