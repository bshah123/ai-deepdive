# 38.1 — Document Parsing: PDFs, Tables, Markdown & Layout Preservation

## Opening Motivation & Context

Document parsing is a critical component in the Retrieval-Augmented Generation (RAG) pipeline. It involves extracting structured and unstructured data from various document formats such as PDFs, tables, and Markdown. The ability to accurately parse and preserve the layout and structure of these documents is essential for effective information retrieval and generation.

In this lesson, we will explore the mechanics of document parsing, focusing on PDFs, tables, and Markdown. We will cover the core concepts, provide code demonstrations, and offer practical insights to help you understand and implement document parsing in your projects.

## Core Concepts Breakdown

### PDF Parsing

PDF parsing involves extracting text and layout information from Portable Document Format (PDF) files. This can be challenging due to the complex structure of PDFs, which may include images, tables, and mixed content.

> [!KEY-INSIGHT]
> PDF parsing requires specialized libraries to handle the binary format and extract meaningful text and layout information.

> [!BEST-PRACTICE]
> Use libraries like PyPDF2, pdfplumber, or pdfminer.six for PDF parsing. These libraries provide robust tools for extracting text and layout information from PDFs.

> [!WARNING]
> PDF parsing can be error-prone due to the complexity of the PDF format. Always validate the extracted data to ensure accuracy.

### Table Parsing

Table parsing involves extracting structured data from tables within documents. Tables can be found in various formats, including HTML, CSV, and PDFs.

> [!KEY-INSIGHT]
> Table parsing requires understanding the structure of tables, including rows, columns, and headers.

> [!BEST-PRACTICE]
> Use libraries like pandas for table parsing. Pandas provides powerful tools for reading and manipulating tabular data.

> [!WARNING]
> Table parsing can be challenging due to variations in table formats. Ensure that the table structure is consistent before parsing.

### Markdown Parsing

Markdown parsing involves converting Markdown text into structured data. Markdown is a lightweight markup language that is widely used for formatting text.

> [!KEY-INSIGHT]
> Markdown parsing requires understanding the syntax of Markdown, including headers, lists, and links.

> [!BEST-PRACTICE]
> Use libraries like markdown or mistune for Markdown parsing. These libraries provide tools for converting Markdown text into structured data.

> [!WARNING]
> Markdown parsing can be error-prone due to variations in Markdown syntax. Always validate the parsed data to ensure accuracy.

## Code Demonstration & Runtime Output

Let's start with a simple example of PDF parsing using the PyPDF2 library.

```python
import PyPDF2

def parse_pdf(file_path: str) -> str:
    """
    Parse a PDF file and extract text.

    Args:
        file_path (str): Path to the PDF file.

    Returns:
        str: Extracted text from the PDF.
    """
    text = ""
    with open(file_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        for page in reader.pages:
            text += page.extract_text()
    return text

if __name__ == "__main__":
    pdf_path = "example.pdf"
    extracted_text = parse_pdf(pdf_path)
    print(extracted_text)
```

```text
Output:
This is the extracted text from the PDF file.
```

Next, let's demonstrate table parsing using the pandas library.

```python
import pandas as pd

def parse_table(file_path: str) -> pd.DataFrame:
    """
    Parse a table from a CSV file.

    Args:
        file_path (str): Path to the CSV file.

    Returns:
        pd.DataFrame: Parsed table as a DataFrame.
    """
    table = pd.read_csv(file_path)
    return table

if __name__ == "__main__":
    csv_path = "example.csv"
    parsed_table = parse_table(csv_path)
    print(parsed_table)
```

```text
Output:
      Name  Age  Score
0    Alice   25    90
1      Bob   30    85
2  Charlie   35    80
```

Finally, let's demonstrate Markdown parsing using the markdown library.

```python
import markdown

def parse_markdown(markdown_text: str) -> str:
    """
    Parse Markdown text and convert it to HTML.

    Args:
        markdown_text (str): Markdown text to parse.

    Returns:
        str: Converted HTML.
    """
    html = markdown.markdown(markdown_text)
    return html

if __name__ == "__main__":
    markdown_text = "# Heading\n\n- List item 1\n- List item 2\n- List item 3"
    parsed_html = parse_markdown(markdown_text)
    print(parsed_html)
```

```text
Output:
<h1>Heading</h1>
<ul>
<li>List item 1</li>
<li>List item 2</li>
<li>List item 3</li>
</ul>
```
