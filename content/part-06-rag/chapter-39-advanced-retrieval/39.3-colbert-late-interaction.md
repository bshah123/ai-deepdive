# 39.3 — Late Interaction & ColBERT (Token-Level MaxSim Scoring)

## Opening Motivation & Context

Late interaction and ColBERT (Contextualized Late Interaction over BERT) are advanced techniques in information retrieval that aim to improve the relevance of search results. Traditional retrieval methods often rely on simple term matching or early interaction, which may not capture the nuanced semantics of queries and documents. Late interaction, on the other hand, allows for more complex interactions between query and document representations, leading to more accurate and contextually relevant results.

ColBERT, a specific implementation of late interaction, uses token-level maximum similarity scoring to match queries and documents. This approach leverages the contextual embeddings from BERT to create dense representations of queries and documents, enabling more precise matching at the token level. This lesson will explore the mechanics of late interaction and ColBERT, providing a practical demonstration and detailed breakdown of the underlying concepts.

## Core Concepts Breakdown

### Late Interaction

Late interaction refers to the process of interacting between query and document representations at a later stage in the retrieval pipeline. Unlike early interaction, which typically involves simple term matching or basic similarity measures, late interaction allows for more complex interactions between the representations of queries and documents. This can lead to more accurate and contextually relevant results, as it takes into account the semantic relationships between the terms in the query and the document.

> [!KEY-INSIGHT]
> Late interaction enables more complex and contextually aware matching between queries and documents, leading to improved retrieval accuracy.

### ColBERT

ColBERT is a specific implementation of late interaction that uses token-level maximum similarity scoring. It leverages the contextual embeddings from BERT to create dense representations of queries and documents. The key idea behind ColBERT is to compute the maximum similarity between each token in the query and the corresponding tokens in the document. This token-level matching allows for more precise and contextually relevant retrieval.

> [!BEST-PRACTICE]
> Use ColBERT for tasks where semantic understanding and contextual relevance are crucial, such as in advanced information retrieval systems.

> [!WARNING]
> ColBERT requires significant computational resources due to the dense representations and token-level matching. Ensure your hardware can handle the increased computational load.

## Code Demonstration & Runtime Output

```python
import torch
from transformers import BertTokenizer, BertModel

class ColBERT:
    def __init__(self, model_name: str = 'bert-base-uncased'):
        self.tokenizer = BertTokenizer.from_pretrained(model_name)
        self.model = BertModel.from_pretrained(model_name)
        self.model.eval()

    def encode(self, text: str) -> torch.Tensor:
        inputs = self.tokenizer(text, return_tensors='pt', padding=True, truncation=True)
        with torch.no_grad():
            outputs = self.model(**inputs)
        return outputs.last_hidden_state

    def maxsim(self, query_embeddings: torch.Tensor, doc_embeddings: torch.Tensor) -> torch.Tensor:
        # Compute the maximum similarity between query and document embeddings
        max_sim = torch.max(torch.matmul(query_embeddings, doc_embeddings.transpose(1, 2)), dim=2).values
        return max_sim.sum(dim=1)

    def retrieve(self, query: str, documents: list[str]) -> list[tuple[str, float]]:
        query_embeddings = self.encode(query)
        doc_embeddings = [self.encode(doc) for doc in documents]
        scores = [self.maxsim(query_embeddings, doc_embedding) for doc_embedding in doc_embeddings]
        scored_docs = list(zip(documents, scores))
        scored_docs.sort(key=lambda x: x[1], reverse=True)
        return scored_docs

if __name__ == "__main__":
    colbert = ColBERT()
    query = "What is the capital of France?"
    documents = [
        "The capital of France is Paris.",
        "France is a country in Europe.",
        "The Eiffel Tower is located in Paris.",
        "The capital of Germany is Berlin."
    ]
    results = colbert.retrieve(query, documents)
    for doc, score in results:
        print(f"Score: {score:.4f}, Document: {doc}")
```

   - `class ColBERT`: Defines the ColBERT class to encapsulate the late interaction and token-level maximum similarity scoring.

   - `def __init__(self, model_name: str = 'bert-base-uncased')`: Initializes the ColBERT class with a specified BERT model.

   - `self.model.eval()`: Sets the model to evaluation mode.

   - `def encode(self, text: str) -> torch.Tensor`: Encodes the input text into contextual embeddings.
   - `inputs = self.tokenizer(text, return_tensors='pt', padding=True, truncation=True)`: Tokenizes the input text and converts it into input tensors.
   - `with torch.no_grad():`: Disables gradient calculation for inference.
   - `outputs = self.model(**inputs)`: Passes the input tensors through the BERT model.
   - `return outputs.last_hidden_state`: Returns the last hidden state of the BERT model, which contains the contextual embeddings.

4. **Maximum Similarity Scoring**:
   - `def maxsim(self, query_embeddings: torch.Tensor, doc_embeddings: torch.Tensor) -> torch.Tensor`: Computes the maximum similarity between query and document embeddings.
   - `max_sim = torch.max(torch.matmul(query_embeddings, doc_embeddings.transpose(1, 2)), dim=2).values`: Computes the maximum similarity between each token in the query and the corresponding tokens in the document.
   - `return max_sim.sum(dim=1)`: Returns the sum of the maximum similarities for each token in the query.

5. **Retrieval**:
   - `def retrieve(self, query: str, documents: list[str]) -> list[tuple[str, float]]`: Retrieves the most relevant documents for a given query.
   - `query_embeddings = self.encode(query)`: Encodes the query into contextual embeddings.
   - `doc_embeddings = [self.encode(doc) for doc in documents]`: Encodes each document into contextual embeddings.
   - `scores = [self.maxsim(query_embeddings, doc_embedding) for doc_embedding in doc_embeddings]`: Computes the maximum similarity scores between the query and each document.
   - `scored_docs = list(zip(documents, scores))`: Zips the documents with their corresponding scores.
   - `scored_docs.sort(key=lambda x: x[1], reverse=True)`: Sorts the documents by their scores in descending order.
   - `return scored_docs`: Returns the sorted list of documents with their scores.

6. **Main Block**:
   - `if __name__ == "__main__":`: Ensures the code is run as a script.
   - `colbert = ColBERT()`: Initializes the ColBERT class.
   - `query = "What is the capital of France?"`: Defines the query.
   - `documents = [...]`: Defines the list of documents.
   - `results = colbert.retrieve(query, documents)`: Retrieves the most relevant documents for the query.
   - `for doc, score in results: print(f"Score: {score:.4f}, Document: {doc}")`: Prints the scores and documents.

> [!ADVANCED]
> The `encode` method uses the BERT model to generate contextual embeddings for the input text. The `maxsim` method computes the maximum similarity between query and document embeddings using matrix multiplication and the `torch.max` function. The `retrieve` method leverages these methods to retrieve and rank documents based on their relevance to the query.
