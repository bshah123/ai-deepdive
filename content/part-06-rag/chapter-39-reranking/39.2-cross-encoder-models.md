# 39.2 — Cross-Encoder Models: BGE-Reranker, Cohere & MonoT5

## Opening Motivation & Context

Cross-encoder models are a crucial component in Retrieval-Augmented Generation (RAG) systems, particularly in the re-ranking phase. Unlike bi-encoder models that encode queries and documents independently, cross-encoders consider the interaction between a query and a document, providing more nuanced relevance scores. This lesson focuses on three popular cross-encoder models: BGE-Reranker, Cohere, and MonoT5. These models are designed to enhance the quality of retrieved documents by re-ranking them based on their semantic relevance to the query.

## Core Concepts Breakdown

Cross-encoder models are transformer-based architectures that take a query and a document as input and output a relevance score. They are particularly effective in scenarios where the interaction between the query and document is complex and requires a deep understanding of the context.

> [!KEY-INSIGHT]
> Cross-encoders provide more accurate relevance scores by considering the interaction between the query and document, making them ideal for re-ranking tasks in RAG systems.

> [!BEST-PRACTICE]
> Use cross-encoders for re-ranking tasks where the interaction between the query and document is crucial. However, be aware that they are computationally more expensive than bi-encoders and may not be suitable for large-scale retrieval tasks.

> [!WARNING]
> Cross-encoders can be computationally expensive, especially when dealing with large batches of documents. Ensure that your hardware can handle the increased computational load.

## Code Demonstration & Runtime Output

Below is a Python code snippet demonstrating how to use the BGE-Reranker, Cohere, and MonoT5 cross-encoder models for re-ranking documents based on a query.

```python
from transformers import AutoModelForSequenceClassification, AutoTokenizer
import torch

def rerank_documents(query: str, documents: list[str], model_name: str) -> list[tuple[str, float]]:
    """
    Rerank documents based on their relevance to the query using a cross-encoder model.

    Args:
        query: The query string.
        documents: A list of document strings.
        model_name: The name of the cross-encoder model.

    Returns:
        A list of tuples containing the document and its relevance score, sorted by score in descending order.
    """
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    model = AutoModelForSequenceClassification.from_pretrained(model_name)

    inputs = tokenizer(query, documents, padding=True, truncation=True, return_tensors="pt", max_length=512)
    with torch.no_grad():
        outputs = model(**inputs)

    scores = torch.nn.functional.softmax(outputs.logits, dim=1)[:, 1].tolist()
    ranked_documents = sorted(zip(documents, scores), key=lambda x: x[1], reverse=True)

    return ranked_documents

if __name__ == "__main__":
    query = "What is the capital of France?"
    documents = [
        "The capital of France is Paris.",
        "France is known for its rich history and culture.",
        "The Eiffel Tower is located in Paris.",
        "The capital of Germany is Berlin."
    ]

    model_names = ["BAAI/bge-reranker-base", "Cohere/cohere-reranker", "castorini/monot5-base-msmarco-10k"]

    for model_name in model_names:
        print(f"Using model: {model_name}")
        ranked_documents = rerank_documents(query, documents, model_name)
        for doc, score in ranked_documents:
            print(f"Score: {score:.4f}, Document: {doc}")
        print()
```
