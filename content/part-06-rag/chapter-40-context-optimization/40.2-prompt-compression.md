# 40.2 — Prompt Compression: LLMLingua & Extractive Summarization

## Opening Motivation & Context

Prompt compression is a critical technique in the field of Retrieval-Augmented Generation (RAG), where large language models (LLMs) generate responses based on retrieved documents. As context windows expand, the need for efficient prompt compression becomes paramount to optimize performance and reduce costs. This lesson focuses on two key methods: LLMLingua and extractive summarization.

LLMLingua is a technique that leverages the LLM itself to compress prompts by identifying and removing redundant or less important information. Extractive summarization, on the other hand, involves using algorithms to identify and extract the most important sentences or phrases from a document, creating a concise summary.

Understanding and implementing these techniques can significantly enhance the efficiency and effectiveness of RAG systems.

## Core Concepts Breakdown

### LLMLingua

LLMLingua is a method that uses the LLM to compress prompts by identifying and removing redundant or less important information. This technique involves the following steps:

1. **Tokenization**: The input text is tokenized into individual words or subwords.
2. **Importance Scoring**: Each token is scored based on its importance to the overall meaning of the text.
3. **Compression**: Tokens with low importance scores are removed, reducing the overall length of the prompt.

> [!KEY-INSIGHT]
> LLMLingua leverages the LLM's understanding of language to identify and remove redundant information, resulting in more efficient prompts.

> [!BEST-PRACTICE]
> Use LLMLingua when dealing with large documents or when the context window is limited, as it can significantly reduce the prompt size without losing critical information.

### Extractive Summarization

Extractive summarization involves using algorithms to identify and extract the most important sentences or phrases from a document, creating a concise summary. This technique involves the following steps:

1. **Sentence Tokenization**: The input text is split into individual sentences.
2. **Feature Extraction**: Features such as sentence length, position, and keyword frequency are extracted for each sentence.
3. **Scoring**: Each sentence is scored based on its features, with higher scores indicating greater importance.
4. **Selection**: The top-scoring sentences are selected to form the summary.

> [!KEY-INSIGHT]
> Extractive summarization creates a concise summary by identifying and extracting the most important sentences from a document.

> [!BEST-PRACTICE]
> Use extractive summarization when you need a quick and efficient way to compress a document, especially when the document is long and complex.

> [!WARNING]
> Extractive summarization may not always produce coherent summaries, as it relies on the selection of individual sentences rather than generating new text.

## Code Demonstration & Runtime Output

Let's demonstrate the use of LLMLingua and extractive summarization with a Python code snippet. We'll use the `transformers` library for LLMLingua and the `sumy` library for extractive summarization.

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM
from sumy.parsers.plaintext import PlaintextParser
from sumy.nlp.tokenizers import Tokenizer
from sumy.summarizers.lsa import LsaSummarizer
from typing import List

def llm_lingua_compression(text: str, model_name: str = "facebook/bart-large-cnn") -> str:
    """
    Compress the input text using LLMLingua.

    Args:
        text (str): The input text to compress.
        model_name (str): The name of the model to use for compression.

    Returns:
        str: The compressed text.
    """
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    model = AutoModelForSeq2SeqLM.from_pretrained(model_name)

    inputs = tokenizer(text, return_tensors="pt", max_length=1024, truncation=True)
    outputs = model.generate(**inputs, max_length=150, min_length=40, length_penalty=2.0, num_beams=4, early_stopping=True)

    compressed_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
    return compressed_text

def extractive_summarization(text: str, sentences_count: int = 3) -> str:
    """
    Summarize the input text using extractive summarization.

    Args:
        text (str): The input text to summarize.
        sentences_count (int): The number of sentences to include in the summary.

    Returns:
        str: The summarized text.
    """
    parser = PlaintextParser.from_string(text, Tokenizer("english"))
    summarizer = LsaSummarizer()
    summary = summarizer(parser.document, sentences_count)

    summarized_text = " ".join([str(sentence) for sentence in summary])
    return summarized_text

if __name__ == "__main__":
    sample_text = """
    Retrieval-Augmented Generation (RAG) is a technique that combines the strengths of information retrieval and language generation.
    In RAG, a large language model (LLM) is used to generate responses based on retrieved documents. The LLM is provided with a prompt
    that includes the retrieved documents, and it generates a response based on this prompt. RAG has been shown to improve the accuracy
    and relevance of generated responses, making it a valuable technique in various applications such as question answering, dialogue
    systems, and content generation. However, as the context window expands, the need for efficient prompt compression becomes paramount
    to optimize performance and reduce costs. Prompt compression techniques such as LLMLingua and extractive summarization can significantly
    enhance the efficiency and effectiveness of RAG systems.
    """

    print("Original Text:")
    print(sample_text)
    print("\nCompressed Text using LLMLingua:")
    print(llm_lingua_compression(sample_text))
    print("\nSummarized Text using Extractive Summarization:")
    print(extractive_summarization(sample_text))
```

> [!QA]
> Q: When should I prefer LLMLingua over extractive summarization?
> A: LLMLingua is preferred when you need a more accurate and coherent summary, as it leverages the LLM's understanding of language. However, LLMLingua may be more computationally expensive and slower than extractive summarization. Extractive summarization is preferred when you need a quick and efficient way to compress a document, especially when the document is long and complex.

## Summary & Key Takeaways

- Prompt compression is essential for optimizing performance and reducing costs in RAG systems.
- LLMLingua leverages the LLM's understanding of language to identify and remove redundant information.
- Extractive summarization creates a concise summary by identifying and extracting the most important sentences from a document.
- LLMLingua is preferred when you need a more accurate and coherent summary, while extractive summarization is preferred for quick and efficient compression.
- Both techniques can significantly enhance the efficiency and effectiveness of RAG systems.
