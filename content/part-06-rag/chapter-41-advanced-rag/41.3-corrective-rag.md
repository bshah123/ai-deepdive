Corrective RAG (CRAG) scores each retrieved document before the language model reads it, then picks one of three actions: keep the document, repair it, or discard it and search the web. In this lesson you will build that routing logic in pure Python, check each number against a run, and find where a weak scorer breaks the system.

**You need:** basic retrieval-augmented generation (RAG: retrieve documents, then generate an answer from them; Lesson 37.1), the idea of cosine similarity, and Python sets and dictionaries.

## The problem CRAG solves

Standard RAG always conditions the generator on the top-k retrieved documents. A retriever always returns k documents, even when none of them contains the answer. The generator then writes from irrelevant text, and the answer can read as confident and still be unsupported.

Yan et al. (2024) name this failure directly: when a static, limited corpus returns weak documents, the system should notice and look for other evidence. The fix has two parts. A scorer judges whether the retrieved text is usable, and a router decides what to do with the verdict.

## Intuition: score, then route

![Query goes to a top-3 retrieval, then an evaluator scores each document; the result routes to Correct (refine internal strips), Ambiguous (use both sources) or Incorrect (web search and refine)](diagrams/41.3-crag-pipeline.svg "CRAG adds one scoring step and three routes to standard RAG.")

The paper's three parts are as follows (Yan et al., 2024, Sections 4.2 to 4.5):

- A **retrieval evaluator** gives each (question, document) pair a relevance score. The paper fine-tunes a T5-large model (Text-to-Text Transfer Transformer, 0.77 billion parameters) to output a score in [−1, 1] (Appendix B.3).
- An **action trigger** uses two thresholds. A document above the upper threshold is Correct; below the lower threshold it is Incorrect; in between it is Ambiguous. The retrieval as a whole is Correct if any document is above the upper threshold, Incorrect if every document is below the lower threshold, and Ambiguous otherwise.
- **Routes.** Correct: split documents into strips (sentences or short groups), score each strip, drop the weak ones, and keep the rest in order. Incorrect: discard the local documents, rewrite the question into at most three keywords, search the web, and select relevant paragraphs with the same evaluator. Ambiguous: use both sets of strips. Our stand-in splits web pages into sentences; the paper does not split them further.

The paper's thresholds, such as (0.59, −0.99) for PopQA, are set empirically on that evaluator's scale (Appendix B.3). They do not transfer to another scorer. Keep the routing rule, not the numbers.

![Score line from minus one to one: below minus 0.5 is Incorrect, between minus 0.5 and 0.5 is Ambiguous, above 0.5 is Correct; dots mark the document scores from the run](diagrams/41.3-threshold-line.svg "Where a document's score falls decides its action. A score exactly on a threshold is Ambiguous.")

## Worked example by hand

No 0.77-billion-parameter evaluator is available here, so we use a stand-in: a keyword-coverage score that also lies in [−1, 1]:

$$
s(q, d) = 2 \cdot \frac{|T(q) \cap T(d)|}{|T(q)|} - 1
$$

Here $T(x)$ is the set of content words in $x$, after removing stop words and applying a crude suffix stripper. Full coverage gives $s = 1$, no coverage gives $s = -1$, and half the terms give $s = 0$. It is a lexical rule, not a learned model, so treat its failures as informative.

Take the question "What thrust does the Tarn engine produce?", with $T(q) = \{\text{thrust, tarn, engine, produce}\}$. Document C contains tarn, engine and thrust but not produce, so $s = 2 \cdot 3/4 - 1 = 0.5$. Its second sentence, "Its thrust is rated at 900 kilonewtons.", contains one term, so $s = 2 \cdot 1/4 - 1 = -0.5$.

Apply the rule with upper threshold 0.5 and lower threshold −0.5. Document C scores exactly 0.5, which is not above 0.5, so nothing is Correct. Not every document is below −0.5, so the result is Ambiguous, and both sources are used. The sentence that answers the question scores −0.5, so the strip filter will drop it. The rest of the lesson follows from these two numbers.

## Code: the routing pipeline

The code uses only the standard library, so it runs in the browser. The corpus is a toy: five local documents, four web pages, and twelve queries in three groups (answerable locally, answerable only on the web, and answerable from neither). "Gold" means the sentence that answers the question. Nothing is fetched; the web is a second dictionary.

```python
import math
import re
from collections import Counter

STOP = {"a", "an", "the", "was", "were", "is", "are", "did", "does", "do", "of", "in",
        "on", "at", "to", "for", "by", "and", "what", "when", "where", "which", "who",
        "how", "long", "why", "it", "its", "from", "s", "each", "have", "has"}

def terms(text):
    out = []
    for w in re.findall(r"[a-z0-9]+", text.lower()):
        if w in STOP:
            continue
        if w.endswith("ing") and len(w) > 5:
            w = w[:-3]
        elif w.endswith("ed") and len(w) > 4:
            w = w[:-2]
        elif w.endswith("ies") and len(w) > 4:
            w = w[:-3] + "y"
        elif w.endswith("es") and len(w) > 4:
            w = w[:-2]
        elif w.endswith("s") and len(w) > 3:
            w = w[:-1]
        elif w.endswith("e") and len(w) > 3:
            w = w[:-1]
        out.append(w)
    return out

KB = {
    "A": ["The Lumen probe was launched in 2031 from Station Kilo.",
          "It carries a spectrometer tuned to methane.",
          "Its primary mission ended in 2036."],
    "B": ["Station Kilo is a relay base on the northern ridge.",
          "The base has four solar arrays.",
          "Supply ships dock every six weeks."],
    "C": ["The Tarn engine burns liquid oxygen and kerosene.",
          "Its thrust is rated at 900 kilonewtons.",
          "Engineers replaced its injector in 2033."],
    "D": ["Mossgrove is a river town known for paper mills.",
          "The mills closed in the late 1980s.",
          "The town museum opened in 2002."],
    "E": ["Photosynthesis converts light into chemical energy in chloroplasts.",
          "The light reactions produce ATP and NADPH.",
          "The Calvin cycle fixes carbon dioxide into sugar."],
}
WEB = {
    "W1": ["The Lumen probe carries a spectrometer tuned to methane and water vapour.",
           "Mission controllers at Harbor Ring received its last signal in 2036."],
    "W2": ["Marrow Lake lies at 2,300 metres in the eastern range.",
           "Its water freezes for five months each year."],
    "W3": ["The Quill rover was designed for dust storms and has six wheels.",
           "It landed on Ceres Plain in 2041."],
    "W4": ["Harbor Ring is the orbital dock that services the Lumen probe after launch."],
}
KB_TEXT = {d: " ".join(s) for d, s in KB.items()}
WEB_TEXT = {d: " ".join(s) for d, s in WEB.items()}

# (query, category, gold sentence or None)
QUERIES = [
    ("When was the Lumen probe launched?", "kb", KB["A"][0]),
    ("What thrust does the Tarn engine produce?", "kb", KB["C"][1]),
    ("Which spectrometer does the Lumen probe carry?", "kb", KB["A"][1]),
    ("How often do supply ships dock at Station Kilo?", "kb", KB["B"][2]),
    ("What fixes carbon dioxide into sugar in photosynthesis?", "kb", KB["E"][2]),
    ("When did the Mossgrove town museum open?", "kb", KB["D"][2]),
    ("When did engineers replace the Tarn injector?", "kb", KB["C"][2]),
    ("Why did the Mossgrove paper mills close?", "neither", None),
    ("How long does Marrow Lake's water stay frozen each year?", "web", WEB["W2"][1]),
    ("Which orbital dock services the Lumen probe?", "web", WEB["W4"][0]),
    ("What wheel design does the Quill rover have?", "web", WEB["W3"][0]),
    ("What is the altitude of the Harbor Ring dock?", "neither", None),
]

def tfidf_rank(query_terms, docs):
    ids = list(docs)
    bags = {d: Counter(terms(docs[d])) for d in ids}
    df = Counter(t for d in ids for t in set(bags[d]))
    idf = {t: math.log(len(ids) / df[t]) for t in df}
    vec = lambda bag: {t: c * idf.get(t, 0.0) for t, c in bag.items()}
    def cos(a, b):
        dot = sum(v * b.get(t, 0.0) for t, v in a.items())
        na = math.sqrt(sum(v * v for v in a.values()))
        nb = math.sqrt(sum(v * v for v in b.values()))
        return dot / (na * nb) if na and nb else 0.0
    qv = vec(Counter(query_terms))
    sims = {d: cos(qv, vec(bags[d])) for d in ids}
    return sorted(ids, key=lambda d: -sims[d])

def score(query_terms, text):
    """Stand-in evaluator: 2 * (fraction of query terms found) - 1, in [-1, 1]."""
    q = set(query_terms)
    doc = set(terms(text))
    return 2 * sum(t in doc for t in q) / len(q) - 1

def decide(doc_scores, upper, lower):
    if max(doc_scores.values()) > upper:
        return "Correct"
    if all(v < lower for v in doc_scores.values()):
        return "Incorrect"
    return "Ambiguous"

def refine(qt, docs, keep=0.0):
    strips = []
    for d_id, sents in docs:
        for s in sents:
            if score(qt, s) >= keep:
                strips.append(s)
    return strips

def rewrite(qt, web_docs, k=3):
    df = Counter(t for d in web_docs.values() for t in set(terms(d)))
    cand = [t for t in dict.fromkeys(qt) if df[t] > 0]
    cand.sort(key=lambda t: df[t])          # rarer in the web index = more specific
    return cand[:k]

def web_search(keywords, web_docs, k=2):
    hits = {d: sum(t in set(terms(x)) for t in keywords) for d, x in web_docs.items()}
    return sorted(web_docs, key=lambda d: -hits[d])[:k]

def crag(query, upper, lower):
    qt = terms(query)
    top = tfidf_rank(qt, KB_TEXT)[:3]
    doc_scores = {d: score(qt, KB_TEXT[d]) for d in top}
    action = decide(doc_scores, upper, lower)
    ctx = []
    if action in ("Correct", "Ambiguous"):
        ctx += refine(qt, [(d, KB[d]) for d in top if doc_scores[d] > lower])
    if action in ("Incorrect", "Ambiguous"):
        ids = web_search(rewrite(qt, WEB_TEXT), WEB_TEXT)
        ctx += refine(qt, [(w, WEB[w]) for w in ids])
    return action, doc_scores, ctx

def plain_rag(query):
    qt = terms(query)
    top = tfidf_rank(qt, KB_TEXT)[:3]
    return "-", {}, [s for d in top for s in KB[d]]

def run(name, fn):
    print(f"== {name}")
    counts = Counter()
    hits = noise = abstain = n_gold = 0
    for i, (q, cat, gold) in enumerate(QUERIES, 1):
        action, dsc, ctx = fn(q)
        counts[action] += 1
        hit = None if gold is None else gold in ctx
        n_noise = len(ctx) - (1 if hit else 0)
        if gold is not None:
            n_gold += 1
            hits += hit
        else:
            abstain += len(ctx) == 0
        noise += n_noise
        dstr = "[" + ", ".join(f"{v:.2f}" for v in dsc.values()) + "]"
        print(f"{i:>2} {cat:<7} {action:<10} docs={dstr:<22} "
              f"gold={str(hit):<5} ctx={len(ctx)} noise={n_noise}")
    print(f"actions: {dict(counts)}")
    print(f"gold recall: {hits}/{n_gold}   noise strips: {noise}   abstain on unanswerable: {abstain}/2")
    print()

run("plain RAG (top-3 docs, no evaluator)", plain_rag)
for up, lo in [(0.5, -0.5), (1.0, -0.5), (0.5, 0.0)]:
    run(f"CRAG-sim upper={up} lower={lo}", lambda q, u=up, l=lo: crag(q, u, l))
```

- **Query 9** (Marrow Lake's frozen water) is Incorrect, and both web strips are dropped. The web text says "freezes" and the question says "frozen", so the lexical rule misses the match. The context is empty.

## Common traps

> [!TRAP]
> A high evaluator score means relevant, not answering. Query 8 scored 1.00 on a document that never says why the mills closed. A relevance scorer can pass text that is on topic but silent on the question.

> [!TRAP]
> Do not copy the paper's thresholds into a different system. The paper's values are tied to its T5 evaluator's output distribution. Calibrate on your own labelled queries before you pick a threshold.

> [!TRAP]
> Strip filtering breaks pronouns. The answer strip "Its thrust is rated at 900 kilonewtons." loses its subject once split off, so a scorer that looks only at that strip rejects it.

> [!TRAP]
> An empty context is not an abstention. Query 9 gives the generator nothing, and a model left without context may answer from its own memory. Instruct the generator to abstain when the context is empty, and test that it does.

> [!TRAP]
> Ambiguous is not a safe default. At upper 1.0, ten of twelve queries became Ambiguous, and the context grew to 1.58 strips per query with the same gold recall (8 of 10) as the fixed configuration.

## Summary

- CRAG places a scorer between retrieval and generation, so weak retrieval triggers a different action instead of being passed on.
- Two thresholds split documents into Correct, Ambiguous and Incorrect. Only the Incorrect and Ambiguous routes search the web.
- The strip filter removes low-scoring sentences, but it can also remove the answer when the answer depends on earlier context.
- A lexical stand-in shows the routing logic clearly, but its failures (topic match without an answer, paraphrase misses) are the ones to test before trusting any evaluator.

## Quiz time

### Question 1: Calculation

Use the stand-in rule $s(q, d) = 2 |T(q) \cap T(d)| / |T(q)| - 1$. For the query "What is the Tarn engine thrust?" (terms: tarn, engine, thrust) and the sentence "Its thrust is rated at 900 kilonewtons.", what is $s$?

<details><summary>Show Solution</summary>

The sentence contains one of the three query terms (thrust), so $s = 2 \cdot 1/3 - 1 = -1/3 \approx -0.33$. That is below the strip threshold of 0 used in the code, so the strip is dropped. The threshold, not the sign of the score, decides what is kept.

</details>

### Question 2: Prediction

With upper threshold 0.5 and lower threshold −0.5, what action does the retrieval get if the document scores are [0.50, −0.50, −1.00]? Explain.

<details><summary>Show Solution</summary>

Ambiguous. No score is strictly above 0.5, so the retrieval is not Correct. Not every score is below −0.5 (the first is 0.50), so it is not Incorrect. Both sources are used, which is what the run does for query 2.

</details>

### Question 3: Explanation

Why does CRAG need a separate Ambiguous action rather than a single threshold that chooses between internal knowledge and the web?

<details><summary>Show Solution</summary>

The scorer is uncertain near the decision boundary. A single threshold forces a hard switch, so a small score error flips the whole answer's source. The Ambiguous band uses both sources when the scorer is unsure, which limits the damage from a wrong hard decision. The paper reports an ablation in which removing the Ambiguous action lowers PopQA accuracy slightly for both LLaMA2-hf-7b and SelfRAG-LLaMA2-7b (Table 2). The effect is small, and this is the authors' claim, not something we tested.

</details>

### Question 4: Bug-spotting

A colleague writes `keep = [s for s in strips if score(q, s) > 0]` to filter strips. What does this do to the Tarn thrust example, and what would you change?

<details><summary>Show Solution</summary>

The strip "The Tarn engine burns..." scores exactly 0.00, so the strict inequality drops it. The other strips are also dropped, which leaves the context empty. The code uses `>= 0`, so the zero-scoring strip is kept. Strict and non-strict comparisons at a boundary change results, so decide the boundary on purpose and test it.

</details>
