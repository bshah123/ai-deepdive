# 41.3 — Corrective RAG (CRAG) & Web Search Fallback Routing

## Opening Motivation & Context

Corrective Retrieval-Augmented Generation (CRAG) and web search fallback routing are advanced techniques in the field of natural language processing and information retrieval. These methods enhance the performance of RAG systems by incorporating corrective mechanisms and intelligent routing to external web searches when the local knowledge base is insufficient. This lesson will explore the core concepts, implementation, and best practices of CRAG and web search fallback routing.

## Core Concepts Breakdown

### Corrective RAG (CRAG)

CRAG is an advanced RAG technique that incorporates a corrective mechanism to improve the accuracy of the generated responses. It involves two main steps: retrieval and generation. The retrieval step fetches relevant documents from the knowledge base, and the generation step produces a response based on these documents. The corrective mechanism ensures that the generated response is accurate and factually consistent.

> [!KEY-INSIGHT]
> CRAG enhances the accuracy of RAG by incorporating a corrective mechanism that verifies the generated response against the retrieved documents.

> [!BEST-PRACTICE]
> Always validate the generated response against the retrieved documents to ensure factual consistency.

> [!WARNING]
> Without a corrective mechanism, CRAG may produce inaccurate responses that are not factually consistent with the retrieved documents.

### Web Search Fallback Routing

Web search fallback routing is a technique that routes queries to external web searches when the local knowledge base is insufficient to provide a satisfactory response. This technique ensures that the system can handle a wide range of queries by leveraging the vast amount of information available on the web.

> [!KEY-INSIGHT]
> Web search fallback routing enhances the coverage of RAG systems by routing queries to external web searches when the local knowledge base is insufficient.

> [!BEST-PRACTICE]
> Implement a fallback mechanism that routes queries to external web searches when the local knowledge base is insufficient.

> [!WARNING]
> Without a fallback mechanism, RAG systems may fail to provide satisfactory responses for queries that are not covered by the local knowledge base.

## Code Demonstration & Runtime Output

```python
import requests
from typing import List, Dict, Optional

class CRAGSystem:
    def __init__(self, knowledge_base: List[Dict[str, str]]):
        self.knowledge_base = knowledge_base

    def retrieve_documents(self, query: str) -> List[Dict[str, str]]:
        """Retrieve relevant documents from the knowledge base."""
        relevant_docs = [doc for doc in self.knowledge_base if query.lower() in doc['content'].lower()]
        return relevant_docs

    def generate_response(self, query: str, documents: List[Dict[str, str]]) -> str:
        """Generate a response based on the retrieved documents."""
        if not documents:
            return "I don't have enough information to answer your question."

        response = f"Based on the information I found, here's what I can tell you about {query}:\n"
        for doc in documents:
            response += f"- {doc['content']}\n"
        return response

    def correct_response(self, query: str, response: str) -> str:
        """Correct the generated response to ensure factual consistency."""
        if "I don't have enough information" in response:
            return self.web_search_fallback(query)
        return response

    def web_search_fallback(self, query: str) -> str:
        """Route the query to external web searches."""
        try:
            response = requests.get(f"https://api.example.com/search?q={query}")
            if response.status_code == 200:
                return f"Based on the web search results, here's what I found about {query}:\n{response.text}"
            else:
                return "I couldn't find any relevant information on the web."
        except Exception as e:
            return f"An error occurred while searching the web: {e}"

    def answer_query(self, query: str) -> str:
        """Answer a query using the CRAG system."""
        documents = self.retrieve_documents(query)
        response = self.generate_response(query, documents)
        corrected_response = self.correct_response(query, response)
        return corrected_response

if __name__ == "__main__":
    knowledge_base = [
        {"id": 1, "content": "Python is a high-level programming language."},
        {"id": 2, "content": "CRAG is an advanced RAG technique."},
        {"id": 3, "content": "Web search fallback routing enhances the coverage of RAG systems."}
    ]

    crag_system = CRAGSystem(knowledge_base)

    queries = [
        "What is Python?",
        "Explain CRAG",
        "What is the capital of France?",
        "What is the weather today?"
    ]

    for query in queries:
        print(f"Query: {query}")
        print(f"Response: {crag_system.answer_query(query)}\n")
```
