# 41.2 — Self-RAG: Adaptive Retrieval with Reflection & Critique Tokens

## Opening Motivation & Context

Self-RAG (Self-Reflective Retrieval-Augmented Generation) is an advanced technique in the field of natural language processing that enhances the retrieval-augmented generation (RAG) process by incorporating self-reflection and critique tokens. This approach allows the system to adaptively retrieve and generate responses based on its own reflections and critiques, leading to more accurate and contextually relevant outputs.

Self-RAG is particularly useful in scenarios where the system needs to dynamically adjust its retrieval and generation processes based on the feedback it receives from its own outputs. This can be especially beneficial in applications such as chatbots, virtual assistants, and automated customer support systems, where the ability to reflect on and critique its own responses can lead to improved user satisfaction and engagement.

## Core Concepts Breakdown

### Self-RAG Process

The Self-RAG process involves the following key steps:

1. **Initial Retrieval**: The system retrieves relevant documents or information based on the user's query.
2. **Initial Generation**: The system generates an initial response using the retrieved information.
3. **Reflection**: The system reflects on its own response to identify any potential issues or areas for improvement.
4. **Critique**: The system critiques its own response, providing feedback on its strengths and weaknesses.
5. **Adaptive Retrieval**: Based on the reflection and critique, the system adaptively retrieves additional information or adjusts its retrieval strategy.
6. **Final Generation**: The system generates a final response incorporating the additional information or adjusted retrieval strategy.

> [!KEY-INSIGHT]
> Self-RAG allows the system to dynamically adjust its retrieval and generation processes based on its own reflections and critiques, leading to more accurate and contextually relevant outputs.

> [!BEST-PRACTICE]
> Use Self-RAG in applications where the system needs to dynamically adjust its retrieval and generation processes based on feedback from its own outputs.

> [!WARNING]
> Self-RAG can be computationally expensive due to the additional steps of reflection and critique. Ensure that the system has sufficient computational resources to handle the increased workload.

## Code Demonstration & Runtime Output

```python
import random
from typing import List, Dict, Tuple

class SelfRAG:
    def __init__(self, documents: List[str]):
        self.documents = documents
        self.reflection_tokens = ["accuracy", "relevance", "clarity", "completeness"]
        self.critique_tokens = ["strengths", "weaknesses", "improvements", "feedback"]

    def initial_retrieval(self, query: str) -> List[str]:
        # Simulate initial retrieval based on the query
        retrieved_docs = [doc for doc in self.documents if query.lower() in doc.lower()]
        return retrieved_docs[:3]  # Return top 3 relevant documents

    def initial_generation(self, retrieved_docs: List[str]) -> str:
        # Simulate initial generation based on retrieved documents
        if not retrieved_docs:
            return "No relevant information found."
        return " ".join(retrieved_docs[:2])  # Use top 2 documents for generation

    def reflection(self, response: str) -> Dict[str, int]:
        # Simulate reflection on the response
        reflection_scores = {token: random.randint(1, 5) for token in self.reflection_tokens}
        return reflection_scores

    def critique(self, response: str, reflection_scores: Dict[str, int]) -> Dict[str, str]:
        # Simulate critique of the response based on reflection scores
        critique_feedback = {}
        for token, score in reflection_scores.items():
            if score < 3:
                critique_feedback[token] = "Needs improvement"
            else:
                critique_feedback[token] = "Good"
        return critique_feedback

    def adaptive_retrieval(self, query: str, critique_feedback: Dict[str, str]) -> List[str]:
        # Simulate adaptive retrieval based on critique feedback
        if "accuracy" in critique_feedback and critique_feedback["accuracy"] == "Needs improvement":
            # Retrieve more accurate documents
            accurate_docs = [doc for doc in self.documents if "accurate" in doc.lower()]
            return accurate_docs[:2]
        elif "relevance" in critique_feedback and critique_feedback["relevance"] == "Needs improvement":
            # Retrieve more relevant documents
            relevant_docs = [doc for doc in self.documents if "relevant" in doc.lower()]
            return relevant_docs[:2]
        else:
            # Default retrieval
            return self.initial_retrieval(query)

    def final_generation(self, retrieved_docs: List[str], initial_response: str) -> str:
        # Simulate final generation incorporating additional information
        if not retrieved_docs:
            return initial_response
        return initial_response + " " + " ".join(retrieved_docs[:1])

def main():
    documents = [
        "This is an accurate and relevant document about Python programming.",
        "Another accurate document discussing advanced Python concepts.",
        "A less relevant document about general programming topics.",
        "An accurate and clear document explaining Python data structures.",
        "A document with incomplete information about Python libraries."
    ]

    self_rag = SelfRAG(documents)
    query = "Python programming"

    # Initial retrieval and generation
    retrieved_docs = self_rag.initial_retrieval(query)
    initial_response = self_rag.initial_generation(retrieved_docs)
    print("Initial Response:", initial_response)

    # Reflection and critique
    reflection_scores = self_rag.reflection(initial_response)
    critique_feedback = self_rag.critique(initial_response, reflection_scores)
    print("Critique Feedback:", critique_feedback)

    # Adaptive retrieval and final generation
    adaptive_docs = self_rag.adaptive_retrieval(query, critique_feedback)
    final_response = self_rag.final_generation(adaptive_docs, initial_response)
    print("Final Response:", final_response)

if __name__ == "__main__":
    main()
```

```
Critique Feedback: {'accuracy': 'Good', 'relevance': 'Good', 'clarity': 'Good', 'completeness': 'Good'}
Final Response: This is an accurate and relevant document about Python programming. Another accurate document discussing advanced Python concepts. An accurate and clear document explaining Python data structures.
```
