# 42.2 — Microsoft GraphRAG: Hierarchical Leiden Community Detection

## Opening Motivation & Context

Hierarchical Leiden Community Detection is a crucial technique in the field of network analysis and knowledge graph construction. It helps in identifying communities within a graph, which are groups of nodes that are more densely connected to each other than to the rest of the graph. This is particularly important in the context of Retrieval-Augmented Generation (RAG) and Knowledge Graphs, where understanding the structure and relationships within the data is essential for effective information retrieval and generation.

## Core Concepts Breakdown

### What is Hierarchical Leiden Community Detection?

Hierarchical Leiden Community Detection is a method for detecting communities in large networks. It is an extension of the Leiden algorithm, which is a popular community detection algorithm that is more efficient and can find better communities than the Louvain algorithm. The hierarchical aspect means that the algorithm can detect communities at different levels of granularity, from fine-grained to coarse-grained.

> [!KEY-INSIGHT]
> Hierarchical Leiden Community Detection helps in understanding the multi-level structure of a graph, which is crucial for building effective knowledge graphs.

> [!BEST-PRACTICE]
> Always visualize the communities detected by the algorithm to ensure that they make sense in the context of your data.

> [!WARNING]
> Hierarchical Leiden Community Detection can be computationally intensive, especially for large graphs. Make sure to optimize your code and use appropriate hardware resources.

## Code Demonstration & Runtime Output

Here is a Python code snippet demonstrating how to perform Hierarchical Leiden Community Detection using the `igraph` library:

```python
import igraph as ig
import matplotlib.pyplot as plt

def hierarchical_leiden_community_detection(graph: ig.Graph, resolution_parameter: float = 1.0) -> list:
    """
    Perform hierarchical Leiden community detection on a graph.

    Args:
        graph (ig.Graph): The input graph.
        resolution_parameter (float): The resolution parameter for the Leiden algorithm.

    Returns:
        list: A list of community assignments for each node.
    """
    # Create a copy of the graph to avoid modifying the original graph
    g = graph.copy()

    # Perform hierarchical Leiden community detection
    communities = g.community_leiden(resolution_parameter=resolution_parameter, objective_function='modularity')

    # Get the community assignments for each node
    community_assignments = communities.membership

    return community_assignments

def visualize_communities(graph: ig.Graph, community_assignments: list) -> None:
    """
    Visualize the communities detected by the Leiden algorithm.

    Args:
        graph (ig.Graph): The input graph.
        community_assignments (list): A list of community assignments for each node.
    """
    # Create a layout for the graph
    layout = graph.layout("kk")

    # Plot the graph with communities colored differently
    ig.plot(graph, layout=layout, vertex_color=community_assignments, vertex_size=20, edge_width=0.5)

if __name__ == "__main__":
    # Create a sample graph
    g = ig.Graph.Famous("Zachary")

    # Perform hierarchical Leiden community detection
    community_assignments = hierarchical_leiden_community_detection(g)

    # Print the community assignments
    print("Community Assignments:", community_assignments)

    # Visualize the communities
    visualize_communities(g, community_assignments)
```

### How this works (Line-by-Line Breakdown)

1. **Importing Libraries**: We import the `igraph` library for graph manipulation and `matplotlib` for visualization.
2. **Function Definition**: We define a function `hierarchical_leiden_community_detection` that takes a graph and a resolution parameter as input and returns the community assignments for each node.
3. **Graph Copy**: We create a copy of the input graph to avoid modifying the original graph.
4. **Community Detection**: We perform hierarchical Leiden community detection using the `community_leiden` method of the graph object. The `resolution_parameter` controls the size of the communities, and the `objective_function` specifies the modularity function to use.
5. **Community Assignments**: We extract the community assignments for each node from the communities object.
6. **Visualization Function**: We define a function `visualize_communities` that takes a graph and community assignments as input and visualizes the communities.
7. **Graph Layout**: We create a layout for the graph using the Kamada-Kawai layout algorithm.
8. **Graph Plotting**: We plot the graph with nodes colored according to their community assignments.
9. **Main Block**: In the main block, we create a sample graph, perform community detection, print the community assignments, and visualize the communities.

> [!ADVANCED]
> The `community_leiden` method in the `igraph` library uses a multi-level approach to detect communities. It first partitions the graph into small communities, then aggregates the nodes within each community into a single node, and repeats the process until the graph is reduced to a single node. The community assignments are then propagated back to the original nodes.
