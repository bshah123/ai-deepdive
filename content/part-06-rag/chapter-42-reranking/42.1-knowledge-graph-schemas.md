# 42.1 — Knowledge Graphs & Property Graph Schemas for AI

## Opening Motivation & Context

Knowledge Graphs (KGs) and Property Graph Schemas are fundamental concepts in the field of Artificial Intelligence, particularly in the context of Retrieval-Augmented Generation (RAG). They provide a structured way to represent and manage knowledge, which is crucial for building intelligent systems that can understand and reason about the world.

Knowledge Graphs are a type of graph database that uses nodes, edges, and properties to represent and store data. They are widely used in various AI applications, including recommendation systems, semantic search, and question answering. Property Graph Schemas define the structure of the Knowledge Graph, specifying the types of nodes, edges, and properties that can exist within the graph.

Understanding Knowledge Graphs and Property Graph Schemas is essential for anyone working in the field of AI, as they provide the foundation for building intelligent systems that can leverage structured knowledge to make better decisions and provide more accurate responses.

## Core Concepts Breakdown

### Knowledge Graphs

Knowledge Graphs are a type of graph database that uses nodes, edges, and properties to represent and store data. Nodes represent entities, such as people, places, or things, while edges represent relationships between these entities. Properties are used to store additional information about nodes and edges.

> [!KEY-INSIGHT]
> Knowledge Graphs provide a structured way to represent and manage knowledge, which is crucial for building intelligent systems that can understand and reason about the world.

> [!BEST-PRACTICE]
> When designing a Knowledge Graph, it is important to carefully consider the types of entities and relationships that will be included, as well as the properties that will be used to store additional information.

> [!WARNING]
> One common footgun when working with Knowledge Graphs is not properly validating the data being added to the graph. This can lead to inconsistencies and errors in the graph structure.

### Property Graph Schemas

Property Graph Schemas define the structure of the Knowledge Graph, specifying the types of nodes, edges, and properties that can exist within the graph. They provide a way to enforce consistency and ensure that the graph follows a specific structure.

> [!KEY-INSIGHT]
> Property Graph Schemas provide a way to define the structure of the Knowledge Graph, ensuring consistency and enforcing a specific structure.

> [!BEST-PRACTICE]
> When designing a Property Graph Schema, it is important to carefully consider the types of nodes, edges, and properties that will be included, as well as the constraints and relationships between them.

> [!WARNING]
> One common footgun when working with Property Graph Schemas is not properly validating the data being added to the graph against the schema. This can lead to inconsistencies and errors in the graph structure.

## Code Demonstration & Runtime Output

```python
from typing import Dict, List, Optional, Tuple

class Node:
    def __init__(self, id: int, label: str, properties: Optional[Dict[str, str]] = None):
        self.id = id
        self.label = label
        self.properties = properties if properties is not None else {}

    def __repr__(self):
        return f"Node(id={self.id}, label='{self.label}', properties={self.properties})"

class Edge:
    def __init__(self, id: int, source: int, target: int, label: str, properties: Optional[Dict[str, str]] = None):
        self.id = id
        self.source = source
        self.target = target
        self.label = label
        self.properties = properties if properties is not None else {}

    def __repr__(self):
        return f"Edge(id={self.id}, source={self.source}, target={self.target}, label='{self.label}', properties={self.properties})"

class KnowledgeGraph:
    def __init__(self):
        self.nodes: Dict[int, Node] = {}
        self.edges: Dict[int, Edge] = {}

    def add_node(self, id: int, label: str, properties: Optional[Dict[str, str]] = None) -> None:
        if id in self.nodes:
            raise ValueError(f"Node with id {id} already exists")
        self.nodes[id] = Node(id, label, properties)

    def add_edge(self, id: int, source: int, target: int, label: str, properties: Optional[Dict[str, str]] = None) -> None:
        if id in self.edges:
            raise ValueError(f"Edge with id {id} already exists")
        if source not in self.nodes:
            raise ValueError(f"Source node with id {source} does not exist")
        if target not in self.nodes:
            raise ValueError(f"Target node with id {target} does not exist")
        self.edges[id] = Edge(id, source, target, label, properties)

    def get_node(self, id: int) -> Optional[Node]:
        return self.nodes.get(id)

    def get_edge(self, id: int) -> Optional[Edge]:
        return self.edges.get(id)

    def get_nodes_by_label(self, label: str) -> List[Node]:
        return [node for node in self.nodes.values() if node.label == label]

    def get_edges_by_label(self, label: str) -> List[Edge]:
        return [edge for edge in self.edges.values() if edge.label == label]

    def __repr__(self):
        return f"KnowledgeGraph(nodes={self.nodes}, edges={self.edges})"

class PropertyGraphSchema:
    def __init__(self):
        self.node_labels: Dict[str, Dict[str, str]] = {}
        self.edge_labels: Dict[str, Dict[str, str]] = {}

    def add_node_label(self, label: str, properties: Dict[str, str]) -> None:
        if label in self.node_labels:
            raise ValueError(f"Node label '{label}' already exists")
        self.node_labels[label] = properties

    def add_edge_label(self, label: str, properties: Dict[str, str]) -> None:
        if label in self.edge_labels:
            raise ValueError(f"Edge label '{label}' already exists")
        self.edge_labels[label] = properties

    def validate_node(self, node: Node) -> bool:
        if node.label not in self.node_labels:
            return False
        for prop, prop_type in self.node_labels[node.label].items():
            if prop not in node.properties:
                return False
            if not isinstance(node.properties[prop], eval(prop_type)):
                return False
        return True

    def validate_edge(self, edge: Edge) -> bool:
        if edge.label not in self.edge_labels:
            return False
        for prop, prop_type in self.edge_labels[edge.label].items():
            if prop not in edge.properties:
                return False
            if not isinstance(edge.properties[prop], eval(prop_type)):
                return False
        return True

    def __repr__(self):
        return f"PropertyGraphSchema(node_labels={self.node_labels}, edge_labels={self.edge_labels})"

def main():
    # Create a Knowledge Graph
    kg = KnowledgeGraph()

    # Add nodes to the Knowledge Graph
    kg.add_node(1, "Person", {"name": "Alice", "age": "30"})
    kg.add_node(2, "Person", {"name": "Bob", "age": "25"})
    kg.add_node(3, "City", {"name": "New York", "population": "8,419,000"})

    # Add edges to the Knowledge Graph
    kg.add_edge(1, 1, 3, "LivesIn", {"since": "2010"})
    kg.add_edge(2, 2, 3, "LivesIn", {"since": "2015"})

    # Print the Knowledge Graph
    print("Knowledge Graph:")
    print(kg)

    # Create a Property Graph Schema
    schema = PropertyGraphSchema()

    # Add node labels to the Property Graph Schema
    schema.add_node_label("Person", {"name": "str", "age": "int"})
    schema.add_node_label("City", {"name": "str", "population": "int"})

    # Add edge labels to the Property Graph Schema
    schema.add_edge_label("LivesIn", {"since": "int"})

    # Print the Property Graph Schema
    print("\nProperty Graph Schema:")
    print(schema)

    # Validate nodes and edges in the Knowledge Graph against the Property Graph Schema
    print("\nValidating nodes and edges in the Knowledge Graph against the Property Graph Schema:")
    for node in kg.nodes.values():
        print(f"Node {node.id} is valid: {schema.validate_node(node)}")
    for edge in kg.edges.values():
        print(f"Edge {edge.id} is valid: {schema.validate_edge(edge)}")

if __name__ == "__main__":
    main()
```
