# 42.3 — Hybrid Vector + Cypher Graph Traversal Pipelines

## Opening Motivation & Context

In the realm of Retrieval-Augmented Generation (RAG), the ability to seamlessly integrate vector embeddings with graph traversal is a game-changer. This hybrid approach leverages the strengths of both vector similarity search and graph-based reasoning to create more intelligent and context-aware systems. GraphRAG, in particular, combines the power of knowledge graphs with vector embeddings to provide a robust framework for information retrieval and generation.

## Core Concepts Breakdown

### Hybrid Vector + Cypher Graph Traversal Pipelines

Hybrid vector + Cypher graph traversal pipelines are designed to combine the best of both worlds: the efficiency of vector similarity search and the expressive power of graph traversal. This approach allows for more nuanced and context-aware information retrieval, making it ideal for applications that require both semantic understanding and relational reasoning.

> [!KEY-INSIGHT]
> Hybrid pipelines leverage vector embeddings to quickly narrow down the search space and then use Cypher queries to perform more complex graph traversals and reasoning.

> [!BEST-PRACTICE]
> Always validate the results of your hybrid pipeline to ensure that the combination of vector search and graph traversal is providing the expected results.

> [!WARNING]
> Be cautious when combining vector search and graph traversal, as the results can be sensitive to the parameters and thresholds used in each step.

## Code Demonstration & Runtime Output

```python
import numpy as np
from typing import List, Dict, Tuple
from neo4j import GraphDatabase

class HybridPipeline:
    def __init__(self, uri: str, user: str, password: str):
        self.driver = GraphDatabase.driver(uri, auth=(user, password))

    def vector_search(self, query_embedding: np.ndarray, k: int = 5) -> List[Dict]:
        # In a real implementation, this would query a vector database
        # For demonstration purposes, we'll use a mock function
        mock_results = [
            {"id": 1, "embedding": np.random.rand(128), "label": "Node1"},
            {"id": 2, "embedding": np.random.rand(128), "label": "Node2"},
            {"id": 3, "embedding": np.random.rand(128), "label": "Node3"},
            {"id": 4, "embedding": np.random.rand(128), "label": "Node4"},
            {"id": 5, "embedding": np.random.rand(128), "label": "Node5"}
        ]
        similarities = [np.dot(query_embedding, node["embedding"]) for node in mock_results]
        top_k_indices = np.argsort(similarities)[-k:][::-1]
        return [mock_results[i] for i in top_k_indices]

    def graph_traversal(self, node_ids: List[int]) -> List[Dict]:
        with self.driver.session() as session:
            query = """
            MATCH (n)
            WHERE n.id IN $node_ids
            OPTIONAL MATCH (n)-[r]->(m)
            RETURN n.id AS node_id, n.label AS node_label,
                   r.type AS relationship_type, m.id AS related_node_id, m.label AS related_node_label
            """
            result = session.run(query, node_ids=node_ids)
            return [dict(record) for record in result]

    def hybrid_pipeline(self, query_embedding: np.ndarray, k: int = 5) -> List[Dict]:
        vector_results = self.vector_search(query_embedding, k)
        node_ids = [node["id"] for node in vector_results]
        graph_results = self.graph_traversal(node_ids)
        return graph_results

if __name__ == "__main__":
    uri = "bolt://localhost:7687"
    user = "neo4j"
    password = "password"
    pipeline = HybridPipeline(uri, user, password)
    query_embedding = np.random.rand(128)
    results = pipeline.hybrid_pipeline(query_embedding)
    for result in results:
        print(result)
```

## How this works (Line-by-Line Breakdown)

1. **Imports**: We import necessary libraries, including `numpy` for vector operations and `GraphDatabase` from `neo4j` for graph database connectivity.
2. **HybridPipeline Class**: This class encapsulates the hybrid pipeline functionality.
3. **__init__ Method**: Initializes the Neo4j driver with the provided URI, username, and password.
4. **vector_search Method**: Performs a vector similarity search. In a real implementation, this would query a vector database, but here we use a mock function for demonstration.
5. **graph_traversal Method**: Executes a Cypher query to perform graph traversal based on the node IDs obtained from the vector search.
6. **hybrid_pipeline Method**: Combines the vector search and graph traversal steps to create a hybrid pipeline.
7. **__main__ Block**: Demonstrates the usage of the HybridPipeline class by creating an instance, generating a random query embedding, and executing the hybrid pipeline.

> [!ADVANCED]
> The `vector_search` method uses cosine similarity to measure the similarity between the query embedding and the node embeddings. The `graph_traversal` method uses a Cypher query to traverse the graph and retrieve relationships between nodes. The `hybrid_pipeline` method combines these two steps to create a hybrid pipeline that leverages both vector similarity search and graph traversal.
