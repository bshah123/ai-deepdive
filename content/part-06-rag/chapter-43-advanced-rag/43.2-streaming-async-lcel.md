# 43.2 — Streaming, Async Execution & Batching with RunnableParallel

## Opening Motivation & Context

In the realm of Retrieval-Augmented Generation (RAG), the ability to process data efficiently and asynchronously is crucial. LangChain's `RunnableParallel` class provides a powerful way to execute multiple runnables in parallel, enabling streaming, asynchronous execution, and batching. This lesson will explore how to leverage `RunnableParallel` to enhance the performance and flexibility of your RAG applications.

## Core Concepts Breakdown

### [!KEY-INSIGHT]
`RunnableParallel` allows you to run multiple runnables concurrently, which can significantly improve the throughput of your application. It supports streaming, asynchronous execution, and batching, making it a versatile tool for handling various data processing tasks.

### [!BEST-PRACTICE]
When using `RunnableParallel`, ensure that the runnables you are running in parallel are independent of each other. This will help avoid race conditions and ensure that your application runs efficiently.

### [!WARNING]
Be cautious when running runnables in parallel, as this can consume more system resources. Monitor your application's resource usage to avoid overloading your system.

## Code Demonstration & Runtime Output

```python
from typing import Dict, Any
from langchain_core.runnables import RunnableParallel, RunnableLambda
import asyncio

# Define some simple runnables
def fetch_data() -> Dict[str, Any]:
    return {"data": "sample data"}

async def process_data(data: Dict[str, Any]) -> Dict[str, Any]:
    await asyncio.sleep(1)  # Simulate async processing
    return {"processed_data": f"processed {data['data']}"}

def analyze_data(data: Dict[str, Any]) -> Dict[str, Any]:
    return {"analysis": f"analyzed {data['processed_data']}"}

# Create RunnableParallel instance
parallel_runnables = RunnableParallel(
    fetch=RunnableLambda(fetch_data),
    process=RunnableLambda(process_data),
    analyze=RunnableLambda(analyze_data)
)

# Define a function to run the parallel runnables
async def run_parallel() -> Dict[str, Any]:
    result = await parallel_runnables.ainvoke({})
    return result

# Main block
if __name__ == "__main__":
    result = asyncio.run(run_parallel())
    print(result)
```

```text
Output:
{'fetch': {'data': 'sample data'}, 'process': {'processed_data': 'processed sample data'}, 'analyze': {'analysis': 'analyzed processed sample data'}}
```

## How this works (Line-by-Line Breakdown)

1. **Imports**: We import necessary modules and classes from LangChain and the standard library.
2. **Runnable Definitions**: We define three simple runnables:
   - `fetch_data`: A synchronous function that returns sample data.
   - `process_data`: An asynchronous function that simulates processing data.
   - `analyze_data`: A synchronous function that analyzes processed data.
3. **RunnableParallel Instance**: We create an instance of `RunnableParallel` with the defined runnables.
4. **Run Function**: We define an asynchronous function `run_parallel` to run the parallel runnables.
5. **Main Block**: We run the parallel runnables using `asyncio.run` and print the result.

### [!ADVANCED]
When `RunnableParallel` is invoked, it creates a task for each runnable and runs them concurrently. The results are collected and returned as a dictionary. The asynchronous execution allows other tasks to run while waiting for I/O operations to complete, improving overall efficiency.

## [!QA]
Q: When should I prefer `RunnableParallel` over sequential execution?
A: You should prefer `RunnableParallel` when you have independent tasks that can be executed concurrently. This can significantly improve the throughput of your application, especially when dealing with I/O-bound tasks. However, be aware of the increased resource usage and potential race conditions when running tasks in parallel.

## Summary & Key Takeaways

- `RunnableParallel` allows you to run multiple runnables concurrently.
- It supports streaming, asynchronous execution, and batching.
- Ensure that the runnables you run in parallel are independent to avoid race conditions.
- Monitor resource usage when running runnables in parallel to avoid overloading your system.

```python
from langchain_core.runnables import RunnableParallel, RunnableLambda

def task1():
    return {"task1": "completed"}

def task2():
    return {"task2": "completed"}

parallel_runnables = RunnableParallel(
    task1=RunnableLambda(task1),
    task2=RunnableLambda(task2)
)

result = parallel_runnables.invoke({})
print(result)
```
