# 43.1 — LangChain 0.3 Core: Runnable Interface & LCEL Pipeline Composition

## Opening Motivation & Context

In the rapidly evolving landscape of AI and machine learning, the ability to create flexible, modular, and efficient pipelines is crucial. LangChain, a popular framework for building applications with large language models, has introduced the Runnable interface and LCEL (LangChain Expression Language) pipeline composition in version 0.3. These features allow developers to create complex workflows with ease, combining various components into a cohesive system.

The Runnable interface provides a standardized way to interact with different components in a pipeline, ensuring consistency and simplicity. LCEL, on the other hand, enables the composition of these components into pipelines, allowing for the creation of sophisticated AI applications. Understanding and mastering these concepts is essential for any developer working with LangChain.

## Core Concepts Breakdown

### Runnable Interface

The Runnable interface is a core concept in LangChain 0.3. It provides a consistent way to interact with various components in a pipeline, such as models, prompts, and output parsers. This interface ensures that all components can be invoked in a similar manner, making it easier to compose them into complex workflows.

> [!KEY-INSIGHT]
> The Runnable interface abstracts away the underlying complexity of different components, providing a unified way to interact with them.

> [!BEST-PRACTICE]
> Always use the Runnable interface when working with LangChain components to ensure consistency and simplicity in your code.

### LCEL Pipeline Composition

LCEL (LangChain Expression Language) pipeline composition allows developers to combine various components into a single, cohesive pipeline. This feature enables the creation of complex AI applications by chaining together different components, such as models, prompts, and output parsers.

> [!KEY-INSIGHT]
> LCEL pipeline composition enables the creation of complex workflows by chaining together different components.

> [!WARNING]
> Be careful when composing pipelines to ensure that the output of one component is compatible with the input of the next component. Mismatched inputs and outputs can lead to errors and unexpected behavior.

## Code Demonstration & Runtime Output

```python
from typing import Dict, Any
from langchain_core.runnables import RunnableLambda, RunnablePassthrough
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

def get_model_response(input_text: str) -> str:
    """Simulate a model response."""
    return f"Model processed: {input_text}"

def parse_output(output: str) -> Dict[str, Any]:
    """Parse the output into a dictionary."""
    return {"parsed_output": output}

def main():
    # Create a prompt template
    prompt_template = PromptTemplate.from_template("Process this input: {input_text}")

    # Create a runnable lambda for the model
    model_runnable = RunnableLambda(get_model_response)

    # Create a runnable lambda for parsing the output
    parser_runnable = RunnableLambda(parse_output)

    # Create a runnable passthrough for the prompt
    prompt_runnable = RunnablePassthrough()

    # Compose the pipeline
    pipeline = (
        {"input_text": prompt_runnable}
        | prompt_template
        | model_runnable
        | parser_runnable
    )

    # Invoke the pipeline
    result = pipeline.invoke({"input_text": "Hello, LangChain!"})

    print(result)

if __name__ == "__main__":
    main()
```


## How this works (Line-by-Line Breakdown)

1. **Imports**: The necessary modules and classes are imported, including `RunnableLambda`, `RunnablePassthrough`, `PromptTemplate`, and `StrOutputParser`.
2. **get_model_response**: A function that simulates a model response. It takes an input text and returns a processed string.
3. **parse_output**: A function that parses the output into a dictionary. It takes a string and returns a dictionary with the parsed output.
4. **main**: The main function where the pipeline is created and invoked.
5. **Prompt Template**: A prompt template is created using `PromptTemplate.from_template`. This template will be used to format the input text.
6. **Runnable Lambda**: A `RunnableLambda` is created for the model using the `get_model_response` function. This allows the model to be invoked as part of the pipeline.
7. **Parser Runnable**: Another `RunnableLambda` is created for parsing the output using the `parse_output` function.
8. **Prompt Runnable**: A `RunnablePassthrough` is created for the prompt. This allows the input to be passed through the pipeline.
9. **Pipeline Composition**: The pipeline is composed by chaining together the prompt runnable, prompt template, model runnable, and parser runnable.
10. **Invoke Pipeline**: The pipeline is invoked with an input text, and the result is printed.

### Question #3: Find and fix the bug

```python
from langchain_core.runnables import RunnableLambda
from langchain_core.prompts import PromptTemplate

def get_model_response(input_text: str) -> str:
    return f"Model processed: {input_text}"

def main():
    prompt_template = PromptTemplate.from_template("Process this input: {input_text}")
    model_runnable = RunnableLambda(get_model_response)
    pipeline = prompt_template | model_runnable
    result = pipeline.invoke("Hello, LangChain!")
    print(result)

if __name__ == "__main__":
    main()
```

<details><summary>Show Solution</summary>

The bug in the code is that the `prompt_template` expects a dictionary input with the key `input_text`, but the pipeline is invoked with a string. To fix this, the pipeline should be invoked with a dictionary containing the input text.

```python
from langchain_core.runnables import RunnableLambda
from langchain_core.prompts import PromptTemplate

def get_model_response(input_text: str) -> str:
    return f"Model processed: {input_text}"

def main():
    prompt_template = PromptTemplate.from_template("Process this input: {input_text}")
    model_runnable = RunnableLambda(get_model_response)
    pipeline = prompt_template | model_runnable
    result = pipeline.invoke({"input_text": "Hello, LangChain!"})
    print(result)

if __name__ == "__main__":
    main()
```

</details>
