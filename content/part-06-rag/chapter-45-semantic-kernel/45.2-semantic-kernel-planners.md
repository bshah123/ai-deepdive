# 45.2 — Semantic Kernel Planners & Automatic Function Orchestration

## Opening Motivation & Context

In the realm of AI and computing, the ability to automatically orchestrate functions based on semantic understanding is a game-changer. Semantic Kernel Planners are tools that enable this orchestration by understanding the context and semantics of the tasks at hand. This lesson will delve into the mechanics of Semantic Kernel Planners and how they can automatically orchestrate functions to achieve complex goals.

## Core Concepts Breakdown

### [!KEY-INSIGHT]
Semantic Kernel Planners leverage semantic understanding to automatically select and sequence functions, enabling complex task automation without manual intervention.

### [!BEST-PRACTICE]
Always validate the inputs and outputs of functions orchestrated by the planner to ensure robustness and reliability.

### [!WARNING]
Over-reliance on automatic orchestration can lead to unexpected behavior if the planner's understanding of the context is incomplete or incorrect.

## Code Demonstration & Runtime Output

```python
from typing import List, Dict, Callable, Optional
import json

class Function:
    def __init__(self, name: str, description: str, execute: Callable):
        self.name = name
        self.description = description
        self.execute = execute

class SemanticKernelPlanner:
    def __init__(self, functions: List[Function]):
        self.functions = functions

    def plan(self, goal: str) -> List[Function]:
        # In a real-world scenario, this would involve semantic understanding and planning
        # For simplicity, we'll use a basic heuristic to select functions
        planned_functions = []
        for function in self.functions:
            if function.name.lower() in goal.lower():
                planned_functions.append(function)
        return planned_functions

    def execute_plan(self, plan: List[Function], context: Optional[Dict] = None) -> Dict:
        results = {}
        for function in plan:
            if context:
                result = function.execute(**context)
            else:
                result = function.execute()
            results[function.name] = result
        return results

def greet(name: str) -> str:
    return f"Hello, {name}!"

def calculate_sum(a: int, b: int) -> int:
    return a + b

def save_to_file(data: Dict, filename: str) -> str:
    with open(filename, 'w') as f:
        json.dump(data, f)
    return f"Data saved to {filename}"

if __name__ == "__main__":
    functions = [
        Function("greet", "Greets the user by name", greet),
        Function("calculate_sum", "Calculates the sum of two numbers", calculate_sum),
        Function("save_to_file", "Saves data to a file", save_to_file)
    ]

    planner = SemanticKernelPlanner(functions)
    goal = "Greet the user and calculate the sum of 5 and 7, then save the result to a file"

    plan = planner.plan(goal)
    context = {"name": "Alice", "a": 5, "b": 7, "filename": "result.json"}
    results = planner.execute_plan(plan, context)

    print("Plan Execution Results:")
    for function_name, result in results.items():
        print(f"{function_name}: {result}")
```

## How this works (Line-by-Line Breakdown)

1. **Imports and Type Hints**: We import necessary modules and define type hints for better code clarity.
2. **Function Class**: This class represents a function that can be orchestrated by the planner. It includes the function's name, description, and the executable function.
3. **SemanticKernelPlanner Class**: This class is responsible for planning and executing the orchestration of functions.
   - **`__init__`**: Initializes the planner with a list of functions.
   - **`plan`**: Creates a plan based on the goal. In this simplified example, it checks if the function's name is in the goal string.
   - **`execute_plan`**: Executes the planned functions with the provided context.
4. **Example Functions**: We define three example functions: `greet`, `calculate_sum`, and `save_to_file`.
5. **Main Block**: We create a list of functions, initialize the planner, define a goal, create a plan, and execute it with a context. The results are printed.

### [!ADVANCED]
In a real-world scenario, the `plan` method would involve more sophisticated semantic understanding and planning algorithms, possibly using natural language processing techniques to interpret the goal and select the most appropriate functions.

### [!QA]
**Q: When should I prefer manual function orchestration over automatic orchestration?**
A: Manual function orchestration is preferable when you need precise control over the sequence and execution of functions, or when the context and semantics are too complex for the planner to understand accurately.
