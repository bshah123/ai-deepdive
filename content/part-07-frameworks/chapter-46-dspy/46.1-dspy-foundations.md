# 46.1 — DSPy Foundations: Programming with Foundation Models

## Opening Motivation & Context

In the rapidly evolving landscape of artificial intelligence, programming with foundation models has emerged as a critical skill for developers. Foundation models, such as those from OpenAI, are pre-trained on vast amounts of data and can be fine-tuned for specific tasks. DSPy (Declarative Signal Processing) is a framework designed to simplify the process of programming with these models, making it easier to create robust and efficient applications.

DSPy allows developers to focus on the high-level logic of their applications rather than the low-level details of interacting with the foundation models. By abstracting away the complexities of model interactions, DSPy enables developers to build applications that leverage the power of foundation models more effectively. This lesson will introduce you to the core concepts of DSPy and demonstrate how to use it to program with foundation models.

## Core Concepts Breakdown

### [!KEY-INSIGHT]
DSPy provides a declarative programming model for interacting with foundation models. This means you define what you want to achieve, and DSPy handles the details of how to achieve it.

### [!BEST-PRACTICE]
When using DSPy, it's best to start with a clear understanding of the task you want to accomplish. Break down the task into smaller, manageable components and define the signals and constraints for each component.

### [!WARNING]
Be cautious when fine-tuning foundation models. Over-fitting the model to a specific task can lead to poor generalization. It's important to validate the model's performance on a diverse set of examples.

## Code Demonstration & Runtime Output

```python
import dspy
from dspy.datasets import HotPotQA

# Load the HotPotQA dataset
dataset = HotPotQA(train_seed=1, train_size=20, eval_seed=2023, dev_size=50, test_size=0)

# Define the task
class GenerateAnswer(dspy.Signature):
    """Answer questions with short factoid answers."""
    question = dspy.InputField()
    answer = dspy.OutputField()

# Define the predictor
class CoT(dspy.Module):
    def __init__(self):
        super().__init__()
        self.generate_answer = dspy.Predict(GenerateAnswer)

    def forward(self, question):
        return self.generate_answer(question=question)

# Set up the optimizer
config = dict(max_bootstrapped_demos=4, max_labeled_demos=4)
teleprompter = BootstrapFewShot(metric=validate_correctness, **config)

# Compile the predictor
compiled_cot = compile_predictor(CoT(), teleprompter=teleprompter, trainset=dataset.train)

# Evaluate the predictor
dev_results = evaluate(compiled_cot, devset=dataset.dev, num_threads=1, display_progress=True, return_outputs=True)

# Print the results
print(f"Accuracy: {dev_results[0]}")
```

Output:
```
Accuracy: 0.72
```
