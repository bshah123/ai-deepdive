# 48.3 — Self-Reflection, Reflexion & Evaluator-Optimizer Loops

## Opening Motivation & Context

Self-reflection, reflexion, and evaluator-optimizer loops are fundamental concepts in the design of intelligent agents. These mechanisms enable agents to learn from their experiences, adapt to new environments, and improve their performance over time. In this lesson, we will explore these concepts in detail, understand their importance, and see how they can be implemented in Python.

## Core Concepts Breakdown

### Self-Reflection

Self-reflection is the process by which an agent examines its own actions and decisions to understand why they were taken and what the outcomes were. This process is crucial for learning and improving performance.

> [!KEY-INSIGHT]
> Self-reflection allows agents to identify patterns in their behavior and make informed decisions based on past experiences.

### Reflexion

Reflexion is a more advanced form of self-reflection that involves not only examining past actions but also predicting future outcomes based on those actions. This allows agents to make more informed decisions and adapt more effectively to new environments.

> [!BEST-PRACTICE]
> Use reflexion to predict the outcomes of potential actions before committing to them. This can help agents avoid costly mistakes and improve their overall performance.

### Evaluator-Optimizer Loops

Evaluator-optimizer loops are iterative processes where an agent evaluates its current performance and then optimizes its behavior based on that evaluation. This loop is essential for continuous learning and improvement.

> [!WARNING]
> Without proper evaluation, the optimizer may not be able to make meaningful improvements. Ensure that your evaluation metrics are accurate and relevant to the agent's goals.

## Code Demonstration & Runtime Output

```python
import random
from typing import List, Tuple, Dict, Callable

class Agent:
    def __init__(self, environment: Dict):
        self.environment = environment
        self.memory: List[Tuple] = []
        self.performance_history: List[float] = []

    def act(self, action: str) -> float:
        # Simulate the action in the environment and return the reward
        reward = self.environment.get(action, 0)
        self.memory.append((action, reward))
        return reward

    def reflect(self) -> Dict[str, float]:
        # Analyze past actions and their outcomes
        action_counts: Dict[str, int] = {}
        action_rewards: Dict[str, float] = {}

        for action, reward in self.memory:
            action_counts[action] = action_counts.get(action, 0) + 1
            action_rewards[action] = action_rewards.get(action, 0) + reward

        action_averages = {action: reward / count for action, count in action_counts.items() for reward in [action_rewards[action]]}

        return action_averages

    def reflex(self, action: str) -> float:
        # Predict the outcome of a potential action
        action_averages = self.reflect()
        return action_averages.get(action, 0)

    def evaluate(self) -> float:
        # Evaluate current performance based on recent actions
        recent_actions = self.memory[-5:]  # Consider the last 5 actions
        total_reward = sum(reward for _, reward in recent_actions)
        performance = total_reward / len(recent_actions)
        self.performance_history.append(performance)
        return performance

    def optimize(self, action_space: List[str]) -> str:
        # Choose the best action based on past performance
        action_averages = self.reflect()
        best_action = max(action_space, key=lambda action: action_averages.get(action, 0))
        return best_action

def evaluator_optimizer_loop(agent: Agent, action_space: List[str], iterations: int) -> None:
    for _ in range(iterations):
        current_performance = agent.evaluate()
        best_action = agent.optimize(action_space)
        reward = agent.act(best_action)
        print(f"Action: {best_action}, Reward: {reward}, Performance: {current_performance:.2f}")

if __name__ == "__main__":
    environment = {
        "explore": 1,
        "exploit": 2,
        "rest": 0.5
    }
    agent = Agent(environment)
    action_space = ["explore", "exploit", "rest"]
    evaluator_optimizer_loop(agent, action_space, 10)
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: We import necessary modules, including `random` for generating random numbers and typing for type hints.
2. **Agent Class**: We define the `Agent` class, which represents an intelligent agent.
   - `__init__`: Initializes the agent with an environment and empty memory and performance history.
   - `act`: Simulates an action in the environment and records the reward.
   - `reflect`: Analyzes past actions and their outcomes to identify patterns.
   - `reflex`: Predicts the outcome of a potential action based on past experiences.
   - `evaluate`: Evaluates current performance based on recent actions.
   - `optimize`: Chooses the best action based on past performance.
3. **evaluator_optimizer_loop**: This function runs the evaluator-optimizer loop for a specified number of iterations.
4. **Main Block**: We create an environment, an agent, and an action space. We then run the evaluator-optimizer loop for 10 iterations.

```python
def evaluate(self) -> float:
    if not self.memory:

    recent_actions = self.memory[-5:]
    total_reward = sum(reward for _, reward in recent_actions)
    performance = total_reward / len(recent_actions)
```
