# 49.1 — Short-Term Context Window Management & Sliding Summarization

## Opening Motivation & Context

In the realm of autonomous agents and tool calling, managing the context window is crucial for maintaining efficient and effective interactions. The context window refers to the limited amount of information that an agent can consider at any given time. As conversations grow longer, it becomes increasingly difficult for the agent to maintain a coherent understanding of the entire conversation. This is where short-term context window management and sliding summarization come into play.

Short-term context window management involves focusing on the most recent and relevant parts of the conversation, while sliding summarization allows for the creation of concise summaries of past interactions. These techniques help agents maintain a clear understanding of the current context while still having access to the broader conversation history when needed.

## Core Concepts Breakdown

### Short-Term Context Window Management

Short-term context window management is the practice of focusing on the most recent and relevant parts of a conversation. This is particularly important in autonomous agents, where the agent needs to maintain a clear understanding of the current context to provide accurate and relevant responses.

> [!KEY-INSIGHT]
> The key insight here is that the most recent information is often the most relevant, and focusing on this can help the agent maintain a clear understanding of the current context.

> [!BEST-PRACTICE]
> To effectively manage the short-term context window, it's important to regularly review and update the agent's understanding of the current context. This can be done by periodically summarizing the most recent parts of the conversation and using this summary to guide the agent's responses.

### Sliding Summarization

Sliding summarization is a technique that involves creating concise summaries of past interactions as the conversation progresses. This allows the agent to maintain a clear understanding of the broader conversation history while still focusing on the most recent and relevant parts of the conversation.

> [!KEY-INSIGHT]
> The key insight here is that creating concise summaries of past interactions can help the agent maintain a clear understanding of the broader conversation history.

> [!BEST-PRACTICE]
> To effectively use sliding summarization, it's important to regularly create and update these summaries. This can be done by periodically summarizing the most recent parts of the conversation and using this summary to guide the agent's responses.

> [!WARNING]
> One common footgun when using sliding summarization is not regularly updating the summaries. This can lead to the agent having an outdated understanding of the broader conversation history, which can result in inaccurate and irrelevant responses.

## Code Demonstration & Runtime Output

```python
from typing import List, Dict, Tuple
import textwrap

class ConversationManager:
    def __init__(self, context_window_size: int = 5):
        self.context_window_size = context_window_size
        self.conversation_history: List[Dict[str, str]] = []
        self.current_context: List[Dict[str, str]] = []

    def add_message(self, role: str, content: str) -> None:
        message = {"role": role, "content": content}
        self.conversation_history.append(message)
        self._update_context_window()

    def _update_context_window(self) -> None:
        if len(self.conversation_history) > self.context_window_size:
            self.current_context = self.conversation_history[-self.context_window_size:]
        else:
            self.current_context = self.conversation_history.copy()

    def get_current_context(self) -> List[Dict[str, str]]:
        return self.current_context

    def generate_summary(self) -> str:
        summary = []
        for message in self.conversation_history:
            summary.append(f"{message['role']}: {message['content']}")
        return "\n".join(summary)

    def sliding_summarization(self, summary_length: int = 3) -> str:
        if len(self.conversation_history) <= summary_length:
            return self.generate_summary()

        summary = []
        for i in range(len(self.conversation_history) - summary_length, len(self.conversation_history)):
            message = self.conversation_history[i]
            summary.append(f"{message['role']}: {message['content']}")
        return "\n".join(summary)

if __name__ == "__main__":
    manager = ConversationManager(context_window_size=3)

    messages = [
        ("user", "Hello, how are you?"),
        ("assistant", "I'm doing well, thank you. How can I assist you today?"),
        ("user", "I need help with a problem I'm having."),
        ("assistant", "I'm sorry to hear that. Can you please provide more details about the problem?"),
        ("user", "I'm having trouble with my computer."),
        ("assistant", "I see. Have you tried restarting your computer?"),
        ("user", "Yes, I have tried that, but it didn't work."),
        ("assistant", "I understand. Let's try to troubleshoot the issue together."),
    ]

    for role, content in messages:
        manager.add_message(role, content)

    print("Current Context:")
    for message in manager.get_current_context():
        print(f"{message['role']}: {message['content']}")

    print("\nFull Summary:")
    print(manager.generate_summary())

    print("\nSliding Summary:")
    print(manager.sliding_summarization(summary_length=3))
```

> [!QA]
> Q: When should I prefer short-term context window management over sliding summarization?
> A: Short-term context window management is preferable when you want to focus on the most recent and relevant parts of the conversation. Sliding summarization is preferable when you want to maintain a clear understanding of the broader conversation history.
