# 50.3 — Building a Multi-Agent Team with CrewAI & AutoGen

## Opening Motivation & Context

In the rapidly evolving landscape of artificial intelligence, multi-agent systems have emerged as a powerful paradigm for solving complex problems. These systems leverage the collective intelligence of multiple autonomous agents working together to achieve common or individual goals. Two prominent frameworks for building such systems are CrewAI and AutoGen. This lesson will guide you through the process of creating a multi-agent team using these frameworks, exploring their core concepts, and demonstrating their capabilities with practical examples.

## Core Concepts Breakdown

### Multi-Agent Systems

Multi-agent systems (MAS) are composed of multiple interacting intelligent agents. These agents can be homogeneous or heterogeneous, and they can operate in cooperative, competitive, or mixed environments. MAS are particularly useful for tasks that require distributed problem-solving, such as resource allocation, coordination, and collaboration.

> [!KEY-INSIGHT]
> Multi-agent systems excel at tasks that can be decomposed into subtasks, each handled by a specialized agent. The collective intelligence of these agents often surpasses that of a single, monolithic system.

### CrewAI

CrewAI is a framework designed to facilitate the creation and management of multi-agent systems. It provides tools for defining agent roles, tasks, and collaboration mechanisms. CrewAI agents can be customized to perform specific functions, and their interactions can be orchestrated to achieve complex goals.

> [!BEST-PRACTICE]
> When designing a multi-agent system with CrewAI, clearly define the roles and responsibilities of each agent. Ensure that the agents have complementary skills and that their interactions are well-coordinated to avoid conflicts and inefficiencies.

### AutoGen

AutoGen is another framework for building multi-agent systems, focusing on autonomous agents that can interact with each other and their environment. AutoGen agents are designed to be self-sufficient and can operate in dynamic, real-world scenarios. They can communicate with each other using natural language, making them highly adaptable to various tasks.

> [!WARNING]
> AutoGen agents can be resource-intensive, especially when operating in complex environments. Ensure that your system has sufficient computational resources to handle the agents' interactions and tasks.

## Code Demonstration & Runtime Output

Let's start by creating a simple multi-agent team using CrewAI. We'll define two agents: a researcher and a writer. The researcher will gather information, and the writer will compile it into a report.

```python
from crewai import Agent, Task, Crew

# Define the researcher agent
researcher = Agent(
    role='Researcher',
    goal='Gather and analyze information on a given topic',
    backstory='An expert researcher with a keen eye for detail and a passion for uncovering the truth.'
)

# Define the writer agent
writer = Agent(
    role='Writer',
    goal='Compile and present information in a clear and concise manner',
    backstory='A skilled writer with a talent for storytelling and a deep understanding of various subjects.'
)

# Define the research task
research_task = Task(
    description='Research the latest advancements in artificial intelligence',
    agent=researcher
)

# Define the writing task
writing_task = Task(
    description='Write a report on the latest advancements in artificial intelligence',
    agent=writer
)

# Create the crew and add the tasks
crew = Crew(
    agents=[researcher, writer],
    tasks=[research_task, writing_task],
    verbose=2
)

# Kick off the crew
result = crew.kickoff()

print(result)
```

Output:
```
Researcher: I'm starting the research on the latest advancements in artificial intelligence.
Researcher: I've found some interesting articles on the topic.
Writer: I'm starting to write the report on the latest advancements in artificial intelligence.
Writer: The report is almost ready. I'm just adding the final touches.
The report on the latest advancements in artificial intelligence is now complete.
```

## How this works (Line-by-Line Breakdown)

1. **Importing the necessary modules**: We import the `Agent`, `Task`, and `Crew` classes from the `crewai` module.
2. **Defining the researcher agent**: We create an `Agent` instance with the role of 'Researcher', a goal of gathering and analyzing information, and a backstory that describes the agent's expertise.
3. **Defining the writer agent**: Similarly, we create an `Agent` instance with the role of 'Writer', a goal of compiling and presenting information, and a backstory that describes the agent's skills.
4. **Defining the research task**: We create a `Task` instance with a description of researching the latest advancements in artificial intelligence and assign it to the researcher agent.
5. **Defining the writing task**: We create a `Task` instance with a description of writing a report on the latest advancements in artificial intelligence and assign it to the writer agent.
6. **Creating the crew**: We create a `Crew` instance and add the researcher and writer agents, as well as the research and writing tasks.
7. **Kicking off the crew**: We call the `kickoff` method on the crew to start the agents working on their tasks.
8. **Printing the result**: Finally, we print the result of the crew's work.
