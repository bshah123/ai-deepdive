# 52.2 — Architecting a Deep Research & Report Generation Agent

## Opening Motivation & Context

In the realm of AI and machine learning, the ability to autonomously gather, analyze, and synthesize information is a powerful capability. This lesson focuses on architecting a deep research and report generation agent. Such an agent can be used in various applications, from academic research to business intelligence, where the ability to automatically generate comprehensive reports based on a given topic is invaluable.

## Core Concepts Breakdown

### [!KEY-INSIGHT]
The architecture of a deep research and report generation agent involves several key components: a research module, a report generation module, and a coordination module. The research module is responsible for gathering and analyzing information, while the report generation module is responsible for synthesizing the information into a coherent report. The coordination module ensures that these modules work together seamlessly.

### [!BEST-PRACTICE]
When designing the research module, it's important to consider the sources of information. Web scraping, API calls, and database queries are all valid methods for gathering information. However, it's crucial to ensure that the information gathered is accurate and up-to-date.

### [!WARNING]
When designing the report generation module, it's important to avoid overcomplicating the report. A well-structured report should be clear, concise, and easy to understand. Overcomplicating the report can lead to confusion and make it difficult for the reader to extract the relevant information.

## Code Demonstration & Runtime Output

```python
import requests
from bs4 import BeautifulSoup
from transformers import pipeline

class ResearchModule:
    def __init__(self, topic: str):
        self.topic = topic

    def gather_information(self) -> list:
        # Simulate gathering information from a web page
        url = f"https://en.wikipedia.org/wiki/{self.topic}"
        response = requests.get(url)
        soup = BeautifulSoup(response.text, 'html.parser')
        paragraphs = soup.find_all('p')
        information = [paragraph.text for paragraph in paragraphs]
        return information

class ReportGenerationModule:
    def __init__(self, information: list):
        self.information = information
        self.summarizer = pipeline("summarization")

    def generate_report(self) -> str:
        # Summarize the gathered information
        summary = self.summarizer(self.information, max_length=130, min_length=30, do_sample=False)
        return summary[0]['summary_text']

class CoordinationModule:
    def __init__(self, topic: str):
        self.topic = topic

    def generate_report(self) -> str:
        research_module = ResearchModule(self.topic)
        information = research_module.gather_information()
        report_generation_module = ReportGenerationModule(information)
        report = report_generation_module.generate_report()
        return report

if __name__ == "__main__":
    coordination_module = CoordinationModule("Artificial_Intelligence")
    report = coordination_module.generate_report()
    print(report)
```

## How this works (Line-by-Line Breakdown)

1. **Imports**: The necessary libraries are imported. `requests` is used for making HTTP requests, `BeautifulSoup` is used for web scraping, and `pipeline` from the `transformers` library is used for text summarization.

2. **ResearchModule Class**: This class is responsible for gathering information about a given topic.
   - `__init__`: The constructor initializes the topic.
   - `gather_information`: This method simulates gathering information from a web page. It uses `requests` to fetch the web page and `BeautifulSoup` to parse the HTML and extract the text from the paragraphs.

3. **ReportGenerationModule Class**: This class is responsible for generating a report based on the gathered information.
   - `__init__`: The constructor initializes the information and the summarizer.
   - `generate_report`: This method uses the summarizer to generate a summary of the gathered information.

4. **CoordinationModule Class**: This class coordinates the research and report generation modules.
   - `__init__`: The constructor initializes the topic.
   - `generate_report`: This method creates instances of the research and report generation modules, gathers the information, and generates the report.

5. **Main Block**: The main block creates an instance of the coordination module, generates a report about the topic "Artificial_Intelligence", and prints the report.

## [!ADVANCED]

The `pipeline` function from the `transformers` library is a high-level API that allows you to easily use pre-trained models for various NLP tasks. In this case, it's used for text summarization. The `pipeline` function handles the tokenization, model loading, and inference, making it easy to use pre-trained models without having to worry about the underlying details.

## [!QA]

Q: When should I prefer using a pre-trained model for text summarization over training a custom model?

A: Pre-trained models are a good choice when you don't have a large amount of labeled data or when you want to get started quickly. They have been trained on large datasets and can provide good performance out of the box. However, if you have a specific domain or a unique dataset, training a custom model might provide better performance.

The bug in the code is that it doesn't handle the case where the web page doesn't exist or the request fails. To fix this, you can add a try-except block to handle these cases.

```python
import requests
from bs4 import BeautifulSoup

class ResearchModule:
    def __init__(self, topic: str):
        self.topic = topic

    def gather_information(self) -> list:
        url = f"https://en.wikipedia.org/wiki/{self.topic}"
        try:
            response = requests.get(url)
            response.raise_for_status()  # Raises an HTTPError for bad responses
            soup = BeautifulSoup(response.text, 'html.parser')
            paragraphs = soup.find_all('p')
            information = [paragraph.text for paragraph in paragraphs]
            return information
        except requests.exceptions.RequestException as e:
            print(f"An error occurred while making the request: {e}")
            return []
        except Exception as e:
            print(f"An unexpected error occurred: {e}")
            return []

if __name__ == "__main__":
    research_module = ResearchModule("Artificial_Intelligence")
    information = research_module.gather_information()
    print(information)
```
