# 54.3 — Ollama, Local Inference & Edge Model Deployment

## Opening Motivation & Context

In the rapidly evolving landscape of artificial intelligence, the ability to deploy models locally and efficiently is becoming increasingly important. This is particularly true for edge devices and scenarios where privacy, latency, and bandwidth are critical concerns. Ollama is a powerful tool that enables local inference and edge model deployment, allowing developers to run AI models on their own hardware without relying on cloud-based services.

## Core Concepts Breakdown

### Ollama Overview

Ollama is an open-source project that provides a framework for running large language models locally. It is designed to be lightweight, efficient, and easy to use, making it an ideal choice for edge deployment scenarios. Ollama supports a variety of popular models, including those from Hugging Face, and provides tools for fine-tuning and optimizing these models for local inference.

> [!KEY-INSIGHT]
> Ollama enables local inference by leveraging optimized model architectures and efficient inference engines, reducing the need for cloud-based services and improving privacy and latency.

> [!BEST-PRACTICE]
> When deploying models with Ollama, consider the hardware constraints of your edge devices and choose models that are optimized for these constraints. Additionally, use Ollama's built-in tools for model optimization and quantization to further improve performance.

> [!WARNING]
> Running large language models locally can be resource-intensive. Ensure that your edge devices have sufficient CPU, GPU, and memory resources to handle the models you intend to deploy.

## Code Demonstration & Runtime Output

```python
import ollama
import time

def load_model(model_name: str) -> None:
    """Load a model into memory."""
    print(f"Loading model: {model_name}")
    start_time = time.time()
    ollama.load_model(model_name)
    end_time = time.time()
    print(f"Model loaded in {end_time - start_time:.2f} seconds")

def generate_text(model_name: str, prompt: str, max_tokens: int = 50) -> str:
    """Generate text using a loaded model."""
    print(f"Generating text with model: {model_name}")
    start_time = time.time()
    response = ollama.generate(model_name, prompt, max_tokens=max_tokens)
    end_time = time.time()
    print(f"Text generated in {end_time - start_time:.2f} seconds")
    return response['text']

if __name__ == "__main__":
    model_name = "llama2"
    prompt = "Once upon a time"

    load_model(model_name)
    generated_text = generate_text(model_name, prompt)
    print(f"Generated text: {generated_text}")
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: The `ollama` module is imported to interact with the Ollama framework, and the `time` module is imported to measure the time taken for model loading and text generation.
2. **`load_model` function**: This function takes a `model_name` as input and loads the specified model into memory. It measures and prints the time taken to load the model.
3. **`generate_text` function**: This function takes a `model_name`, `prompt`, and optional `max_tokens` as input. It generates text using the loaded model, measures and prints the time taken for text generation, and returns the generated text.
4. **`__main__` block**: The `model_name` and `prompt` are defined. The `load_model` function is called to load the specified model, and the `generate_text` function is called to generate text using the loaded model. The generated text is printed.

> [!ADVANCED]

The `ollama.load_model` function loads the model into memory, while the `ollama.generate` function uses the loaded model to generate text. The time taken for model loading and text generation is measured using the `time` module.

### Question #3: Find and fix the bug

```python
import ollama

def generate_text(model_name: str, prompt: str) -> str:
    response = ollama.generate(model_name, prompt)
    return response['generated_text']

if __name__ == "__main__":
    model_name = "llama2"
    prompt = "The quick brown fox"
    generated_text = generate_text(model_name, prompt)
    print(generated_text)
```

<details><summary>Show Solution</summary>

The bug in the code is that it tries to access the `generated_text` key in the response dictionary, which does not exist. The correct key is `text`. Here is the fixed code:

```python
import ollama

def generate_text(model_name: str, prompt: str) -> str:
    response = ollama.generate(model_name, prompt)
    return response['text']

if __name__ == "__main__":
    model_name = "llama2"
    prompt = "The quick brown fox"
    generated_text = generate_text(model_name, prompt)
    print(generated_text)
```
