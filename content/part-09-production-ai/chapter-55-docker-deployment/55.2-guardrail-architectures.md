# 55.2 — Guardrail Architectures: Llama-Guard, NeMo Guardrails & Regex Filters

## Opening Motivation & Context

In the rapidly evolving landscape of AI, ensuring the security and reliability of Large Language Models (LLMs) is paramount. Guardrails are essential mechanisms that prevent LLMs from generating harmful, biased, or inappropriate content. This lesson explores three key guardrail architectures: Llama-Guard, NeMo Guardrails, and Regex Filters. Understanding these architectures will help you implement robust safety measures in your AI applications.

## Core Concepts Breakdown

### Llama-Guard

Llama-Guard is a lightweight, fine-tuned version of the Llama model designed specifically for safety classification. It is trained to identify and categorize potentially harmful content, making it an effective tool for content moderation.

> [!KEY-INSIGHT]
> Llama-Guard leverages the power of fine-tuning to specialize in safety classification, ensuring high accuracy in identifying harmful content.

> [!BEST-PRACTICE]
> Use Llama-Guard in conjunction with other guardrails for comprehensive safety checks.

> [!WARNING]
> Llama-Guard may produce false positives or negatives, so always validate its outputs with human review.

### NeMo Guardrails

NeMo Guardrails is a flexible framework for implementing guardrails in AI applications. It allows you to define custom rules and policies to ensure that your AI models adhere to safety and ethical guidelines.

> [!KEY-INSIGHT]
> NeMo Guardrails provides a modular and extensible approach to implementing guardrails, allowing for customization based on specific requirements.

> [!BEST-PRACTICE]
> Use NeMo Guardrails to define and enforce custom safety rules and policies in your AI applications.

> [!WARNING]
> NeMo Guardrails requires careful configuration to ensure that the defined rules are effective and do not introduce new vulnerabilities.

### Regex Filters

Regex Filters are simple yet powerful tools for identifying and filtering out harmful or inappropriate content based on predefined patterns. They are particularly useful for detecting specific keywords or phrases that may indicate harmful content.

> [!KEY-INSIGHT]
> Regex Filters are efficient and can be used to quickly identify and filter out harmful content based on predefined patterns.

> [!BEST-PRACTICE]
> Use Regex Filters in combination with other guardrails for comprehensive content moderation.

> [!WARNING]
> Regex Filters may produce false positives or negatives, so always validate their outputs and refine the patterns as needed.

## Code Demonstration & Runtime Output

```python
import re
from typing import List, Dict, Optional

class LlamaGuard:
    def __init__(self, model_path: str):
        self.model = self._load_model(model_path)

    def _load_model(self, model_path: str):
        # Simulate loading a Llama-Guard model
        print(f"Loading Llama-Guard model from {model_path}")
        return {"loaded": True}

    def classify(self, text: str) -> Dict[str, float]:
        # Simulate classification using Llama-Guard
        print(f"Classifying text: {text}")
        return {"harmful": 0.1, "safe": 0.9}

class NeMoGuardrails:
    def __init__(self, rules: List[Dict[str, str]]):
        self.rules = rules

    def check(self, text: str) -> Dict[str, bool]:
        # Simulate checking text against NeMo Guardrails rules
        print(f"Checking text against NeMo Guardrails rules: {text}")
        results = {}
        for rule in self.rules:
            results[rule["name"]] = self._apply_rule(text, rule["pattern"])
        return results

    def _apply_rule(self, text: str, pattern: str) -> bool:
        # Simulate applying a rule
        print(f"Applying rule: {pattern}")
        return bool(re.search(pattern, text))

class RegexFilter:
    def __init__(self, patterns: List[str]):
        self.patterns = [re.compile(pattern) for pattern in patterns]

    def filter(self, text: str) -> bool:
        # Simulate filtering text using Regex patterns
        print(f"Filtering text: {text}")
        for pattern in self.patterns:
            if pattern.search(text):
                return True
        return False

def main():
    # Initialize guardrails
    llama_guard = LlamaGuard("path/to/llama_guard_model")
    nemo_rules = [
        {"name": "profanity", "pattern": r"\b(?:fuck|shit|bitch)\b"},
        {"name": "hate_speech", "pattern": r"\b(?:hate|kill|murder)\b"}
    ]
    nemo_guardrails = NeMoGuardrails(nemo_rules)
    regex_patterns = [r"\b(?:fuck|shit|bitch)\b", r"\b(?:hate|kill|murder)\b"]
    regex_filter = RegexFilter(regex_patterns)

    # Test text
    test_text = "This is a test text with some harmful words like fuck and hate."

    # Classify text using Llama-Guard
    classification = llama_guard.classify(test_text)
    print(f"Llama-Guard classification: {classification}")

    # Check text against NeMo Guardrails rules
    nemo_results = nemo_guardrails.check(test_text)
    print(f"NeMo Guardrails results: {nemo_results}")

    # Filter text using Regex patterns
    regex_result = regex_filter.filter(test_text)
    print(f"Regex Filter result: {regex_result}")

if __name__ == "__main__":
    main()
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: The necessary modules `re` for regular expressions and `typing` for type hints are imported.
2. **LlamaGuard Class**: This class simulates the Llama-Guard model.
   - `__init__`: Initializes the model by loading it from the specified path.
   - `_load_model`: Simulates loading the model.
   - `classify`: Simulates classifying the input text as harmful or safe.
3. **NeMoGuardrails Class**: This class simulates the NeMo Guardrails framework.
   - `__init__`: Initializes the guardrails with a list of rules.
   - `check`: Simulates checking the input text against the defined rules.
   - `_apply_rule`: Simulates applying a single rule to the input text.
4. **RegexFilter Class**: This class simulates a simple regex filter.
   - `__init__`: Initializes the filter with a list of regex patterns.
   - `filter`: Simulates filtering the input text using the defined patterns.
5. **main Function**: Demonstrates the usage of the guardrails.
   - Initializes instances of `LlamaGuard`, `NeMoGuardrails`, and `RegexFilter`.
   - Defines a test text and applies the guardrails to it.
   - Prints the results of the classification, rule checks, and filtering.
6. **`__main__` Block**: Ensures the `main` function is called when the script is executed.

> [!ADVANCED]
> The `LlamaGuard` class uses a simulated model loading process. In a real-world scenario, this would involve loading a pre-trained model using a library like Hugging Face's Transformers. The `NeMoGuardrails` class uses regex patterns to simulate rule application. In practice, these rules could be more complex and involve additional logic or external services. The `RegexFilter` class uses compiled regex patterns for efficient matching. The `main` function demonstrates the integration of these guardrails in a simple workflow.
