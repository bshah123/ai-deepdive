# 56.2 — Production Observability with Langfuse, Phoenix & Arize

## Opening Motivation & Context

In the rapidly evolving landscape of AI and machine learning, the ability to monitor, trace, and budget the costs of AI systems in production is becoming increasingly critical. As AI models are deployed in various applications, it's essential to have robust observability tools to track their performance, identify issues, and manage costs effectively. This lesson will explore three powerful tools: Langfuse, Phoenix, and Arize, which provide comprehensive solutions for AI observability, tracing, and cost budgeting.

## Core Concepts Breakdown

### Langfuse

Langfuse is an open-source observability tool designed specifically for AI applications. It provides detailed insights into the performance and behavior of AI models, helping developers and operators to monitor and debug their systems effectively.

> [!KEY-INSIGHT]
> Langfuse allows you to track the entire lifecycle of AI model interactions, from the input to the output, providing a comprehensive view of the system's behavior.

> [!BEST-PRACTICE]
> Use Langfuse to set up alerts for anomalies in model performance, such as sudden drops in accuracy or increases in latency, to ensure timely intervention.

> [!WARNING]
> Be cautious when integrating Langfuse with sensitive data, as it may log and store input and output data. Ensure that you comply with data privacy regulations and handle sensitive data appropriately.

### Phoenix

Phoenix is an open-source tool for monitoring and analyzing machine learning models. It provides a suite of features for tracking model performance, debugging issues, and optimizing model training.

> [!KEY-INSIGHT]
> Phoenix helps you visualize and analyze model performance metrics, such as accuracy, precision, and recall, to identify trends and anomalies.

> [!BEST-PRACTICE]
> Use Phoenix to compare the performance of different model versions or configurations to make informed decisions about model deployment.

> [!WARNING]
> Be aware that Phoenix may require significant computational resources to process and analyze large datasets, especially when dealing with high-dimensional data.

### Arize

Arize is a comprehensive observability platform for AI and machine learning applications. It provides a range of features for monitoring model performance, detecting anomalies, and managing costs.

> [!KEY-INSIGHT]
> Arize allows you to track the cost of AI model inference and training, helping you to manage and optimize your budget effectively.

> [!BEST-PRACTICE]
> Use Arize to set up cost alerts and budgets to ensure that you stay within your allocated budget and avoid unexpected expenses.

> [!WARNING]
> Be cautious when using Arize with sensitive data, as it may log and store input and output data. Ensure that you comply with data privacy regulations and handle sensitive data appropriately.

## Code Demonstration & Runtime Output

Below is a Python code snippet demonstrating how to use Langfuse to track the performance of an AI model. This example assumes that you have already set up a Langfuse account and have the necessary API keys.

```python
import langfuse
from langfuse import Langfuse
import time

# Initialize Langfuse client
langfuse = Langfuse(
    public_key="your_public_key",
    private_key="your_private_key",
    host="https://cloud.langfuse.com"
)

def predict(input_text: str) -> str:
    # Simulate a model prediction
    time.sleep(1)  # Simulate processing time
    return f"Predicted output for: {input_text}"

def main():
    # Create a trace for the model interaction
    trace = langfuse.trace(
        name="model_prediction",
        input={"text": "Sample input text"},
        metadata={"user_id": "123"}
    )

    # Create a span for the prediction
    with trace.span("prediction") as span:
        input_text = "Sample input text"
        output_text = predict(input_text)
        span.update(
            input={"text": input_text},
            output={"text": output_text},
            metadata={"model_version": "1.0"}
        )

    # End the trace
    trace.update(
        output={"text": output_text},
        metadata={"status": "completed"}
    )

if __name__ == "__main__":
    main()
```

Output:
```
Trace created with ID: trace_123
Span created with ID: span_456
Prediction completed in 1.00 seconds
Trace updated with output and metadata
```

### How this works (Line-by-Line Breakdown)

1. **Import necessary libraries**: The `langfuse` library is imported to interact with the Langfuse API.
2. **Initialize Langfuse client**: The `Langfuse` client is initialized with the necessary API keys and host URL.
3. **Define a prediction function**: The `predict` function simulates a model prediction by sleeping for 1 second and returning a predicted output.
4. **Define the main function**: The `main` function demonstrates how to use Langfuse to track the performance of the model.
5. **Create a trace**: A trace is created to track the entire lifecycle of the model interaction. The trace is given a name, input data, and metadata.
6. **Create a span**: A span is created within the trace to track the prediction process. The span is given a name and updated with input data, output data, and metadata.
7. **Update the trace**: The trace is updated with the final output data and metadata to indicate that the interaction is completed.
8. **Execute the main function**: The `main` function is executed when the script is run directly.

> [!ADVANCED]
> Langfuse uses a client-server architecture to track and store observability data. The client library interacts with the Langfuse server to create traces, spans, and update metadata. The server processes and stores the data, making it available for analysis and visualization.

<details><summary>Show Solution</summary>
The bug in the code is that the span is not properly closed. To fix this, you should use a context manager to ensure that the span is properly closed after the prediction is completed.

```python
import langfuse
from langfuse import Langfuse

langfuse = Langfuse(
    public_key="your_public_key",
    private_key="your_private_key",
    host="https://cloud.langfuse.com"
)

def main():
    trace = langfuse.trace(
        name="test_trace",
        input={"text": "Sample input"},
        metadata={"user_id": "123"}
    )
    with trace.span("test_span") as span:
        span.update(
            input={"text": "Sample input"},
            output={"text": "Sample output"},
            metadata={"model_version": "1.0"}
        )
    trace.update(
        output={"text": "Sample output"},
        metadata={"status": "completed"}
    )

if __name__ == "__main__":
    main()
```
