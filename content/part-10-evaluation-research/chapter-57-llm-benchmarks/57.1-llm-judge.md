# 57.1 — The RAG Triad: Context Relevance, Groundedness & Answer Relevance

## Opening Motivation & Context

In the realm of Retrieval-Augmented Generation (RAG), evaluating the quality of generated responses is crucial for ensuring the reliability and usefulness of AI systems. The RAG Triad consists of three key metrics: Context Relevance, Groundedness, and Answer Relevance. These metrics help assess whether the generated responses are not only accurate but also contextually appropriate and grounded in the provided information.

## Core Concepts Breakdown

### Context Relevance

Context Relevance measures how well the retrieved context aligns with the user's query. A high context relevance score indicates that the retrieved information is pertinent to the user's question.

> [!KEY-INSIGHT]
> Context Relevance is essential for ensuring that the retrieved information is relevant to the user's query, thereby improving the quality of the generated response.

> [!BEST-PRACTICE]
> Use advanced retrieval techniques such as semantic search and dense retrieval to improve context relevance.

### Groundedness

Groundedness evaluates whether the generated response is grounded in the retrieved context. A high groundedness score means that the response is supported by the provided information.

> [!KEY-INSIGHT]
> Groundedness is crucial for maintaining the accuracy and reliability of the generated responses.

> [!WARNING]
> Without proper evaluation of groundedness, the generated responses may contain hallucinations or inaccuracies.

### Answer Relevance

Answer Relevance assesses how well the generated response addresses the user's query. A high answer relevance score indicates that the response is relevant and useful to the user.

> [!KEY-INSIGHT]
> Answer Relevance is vital for ensuring that the generated responses are useful and relevant to the user's needs.

> [!BEST-PRACTICE]
> Use techniques such as reinforcement learning and human feedback to improve answer relevance.

## Code Demonstration & Runtime Output

```python
from typing import List, Dict, Tuple
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

class RAGEvaluator:
    def __init__(self, context_embeddings: List[np.ndarray], answer_embeddings: List[np.ndarray]):
        self.context_embeddings = context_embeddings
        self.answer_embeddings = answer_embeddings

    def calculate_context_relevance(self, query_embedding: np.ndarray) -> float:
        similarities = cosine_similarity([query_embedding], self.context_embeddings)
        return np.max(similarities)

    def calculate_groundedness(self, answer_embedding: np.ndarray) -> float:
        similarities = cosine_similarity([answer_embedding], self.context_embeddings)
        return np.max(similarities)

    def calculate_answer_relevance(self, query_embedding: np.ndarray, answer_embedding: np.ndarray) -> float:
        similarity = cosine_similarity([query_embedding], [answer_embedding])
        return similarity[0][0]

def generate_embeddings(texts: List[str]) -> List[np.ndarray]:
    # In a real scenario, you would use a pre-trained model to generate embeddings
    # For simplicity, we will use random embeddings here
    return [np.random.rand(100) for _ in texts]

if __name__ == "__main__":
    # Example usage
    queries = ["What is the capital of France?"]
    contexts = ["The capital of France is Paris.", "France is a country in Europe."]
    answers = ["Paris is the capital of France."]

    query_embeddings = generate_embeddings(queries)
    context_embeddings = generate_embeddings(contexts)
    answer_embeddings = generate_embeddings(answers)

    evaluator = RAGEvaluator(context_embeddings, answer_embeddings)

    context_relevance = evaluator.calculate_context_relevance(query_embeddings[0])
    groundedness = evaluator.calculate_groundedness(answer_embeddings[0])
    answer_relevance = evaluator.calculate_answer_relevance(query_embeddings[0], answer_embeddings[0])

    print(f"Context Relevance: {context_relevance:.2f}")
    print(f"Groundedness: {groundedness:.2f}")
    print(f"Answer Relevance: {answer_relevance:.2f}")
```

### How this works (Line-by-Line Breakdown)

1. **Imports**: We import necessary libraries including `numpy` for numerical operations and `cosine_similarity` from `sklearn.metrics.pairwise` for calculating cosine similarity.
2. **RAGEvaluator Class**: This class is responsible for evaluating the RAG Triad metrics.
   - **`__init__`**: Initializes the evaluator with context and answer embeddings.
   - **`calculate_context_relevance`**: Calculates the context relevance by finding the maximum cosine similarity between the query embedding and the context embeddings.
   - **`calculate_groundedness`**: Calculates the groundedness by finding the maximum cosine similarity between the answer embedding and the context embeddings.
   - **`calculate_answer_relevance`**: Calculates the answer relevance by finding the cosine similarity between the query embedding and the answer embedding.
3. **`generate_embeddings` Function**: Generates random embeddings for the given texts. In a real scenario, you would use a pre-trained model to generate embeddings.
4. **Main Block**: Demonstrates the usage of the `RAGEvaluator` class.
   - **Embeddings Generation**: Generates embeddings for queries, contexts, and answers.
   - **Evaluator Initialization**: Initializes the `RAGEvaluator` with the generated embeddings.
   - **Metrics Calculation**: Calculates the context relevance, groundedness, and answer relevance.
   - **Output**: Prints the calculated metrics.

> [!ADVANCED]
> The `cosine_similarity` function from `sklearn.metrics.pairwise` is used to calculate the cosine similarity between vectors. Cosine similarity is a measure of similarity between two non-zero vectors of an inner product space that measures the cosine of the angle between them. It is often used in text analysis and information retrieval.

> [!QA]
> Q: When should I prefer cosine similarity over other similarity measures like Euclidean distance?
> A: Cosine similarity is preferred over Euclidean distance when the magnitude of the vectors is not important, and you are more interested in the angle between the vectors. Cosine similarity is also more robust to differences in vector magnitudes, making it suitable for high-dimensional data like text embeddings.
