# 59.2 — Test-Time Compute & Search: Tree-of-Thoughts, MCTS & Process Rewards

## Opening Motivation & Context

In the realm of artificial intelligence, the ability to make decisions and solve complex problems is paramount. Traditional approaches often rely on a single, optimal path to a solution, but this can be limiting, especially in scenarios where multiple reasoning paths need to be explored. This is where advanced search and reasoning techniques come into play.

Test-time compute and search refer to the methods used to explore and evaluate multiple reasoning paths during the inference or decision-making phase of an AI model. These techniques are crucial for enhancing the model's ability to handle complex, multi-step problems, such as those encountered in game playing, planning, and creative tasks.

In this lesson, we will explore three key techniques: Tree-of-Thoughts (ToT), Monte Carlo Tree Search (MCTS), and Process Rewards. These methods are designed to improve the reasoning capabilities of AI models by systematically exploring and evaluating different paths to a solution.

## Core Concepts Breakdown

### Tree-of-Thoughts (ToT)

Tree-of-Thoughts is a reasoning framework that generalizes over chains of thought to trees of thoughts. It allows the exploration of multiple reasoning paths, enabling the model to consider different sequences of thought and their implications.

> [!KEY-INSIGHT]
> ToT enables the exploration of multiple reasoning paths, enhancing the model's ability to handle complex, multi-step problems.

> [!BEST-PRACTICE]
> Use ToT when the problem requires exploring multiple reasoning paths and considering the implications of different sequences of thought.

### Monte Carlo Tree Search (MCTS)

Monte Carlo Tree Search is a heuristic search algorithm that combines random sampling with tree search. It is particularly effective in games and planning problems where the state space is large and complex.

> [!KEY-INSIGHT]
> MCTS balances exploration and exploitation, making it suitable for problems with large and complex state spaces.

> [!BEST-PRACTICE]
> Use MCTS when the problem involves a large and complex state space, and you need to balance exploration and exploitation.

### Process Rewards

Process Rewards involve evaluating the intermediate steps of a reasoning process, not just the final outcome. This approach provides a more nuanced understanding of the reasoning path and can lead to better decision-making.

> [!KEY-INSIGHT]
> Process Rewards provide a more nuanced understanding of the reasoning path, leading to better decision-making.

> [!BEST-PRACTICE]
> Use Process Rewards when the intermediate steps of the reasoning process are crucial for understanding the problem and making informed decisions.

## Code Demonstration & Runtime Output

```python
import random
from typing import List, Dict, Tuple, Optional

class Node:
    def __init__(self, state: str, parent: Optional['Node'] = None):
        self.state = state
        self.parent = parent
        self.children: List['Node'] = []
        self.visits = 0
        self.value = 0.0

    def add_child(self, child_state: str) -> 'Node':
        child = Node(child_state, self)
        self.children.append(child)
        return child

    def update(self, value: float):
        self.visits += 1
        self.value += value

    def ucb1(self, exploration_weight: float = 1.414) -> float:
        if self.visits == 0:
            return float('inf')
        return self.value / self.visits + exploration_weight * (2 * (self.parent.visits ** 0.5) / self.visits) ** 0.5

def mcts(root: Node, iterations: int, exploration_weight: float = 1.414) -> Node:
    for _ in range(iterations):
        node = root
        # Selection
        while node.children and all(child.visits > 0 for child in node.children):
            node = max(node.children, key=lambda child: child.ucb1(exploration_weight))
        # Expansion
        if node.visits > 0:
            child_state = f"{node.state}_{len(node.children)}"
            node = node.add_child(child_state)
        # Simulation
        value = random.random()
        # Backpropagation
        while node is not None:
            node.update(value)
            node = node.parent
    return max(root.children, key=lambda child: child.visits)

def tree_of_thoughts(root: Node, depth: int) -> List[Node]:
    if depth == 0:
        return [root]
    thoughts = []
    for child in root.children:
        thoughts.extend(tree_of_thoughts(child, depth - 1))
    return thoughts

def process_rewards(thoughts: List[Node]) -> Dict[str, float]:
    rewards = {}
    for thought in thoughts:
        path = []
        node = thought
        while node is not None:
            path.append(node.state)
            node = node.parent
        rewards[' -> '.join(reversed(path))] = thought.value / thought.visits
    return rewards

if __name__ == "__main__":
    root = Node("root")
    for i in range(3):
        child = root.add_child(f"child_{i}")
        for j in range(2):
            child.add_child(f"grandchild_{i}_{j}")

    best_node = mcts(root, 1000)
    print(f"Best node found by MCTS: {best_node.state}")

    thoughts = tree_of_thoughts(root, 2)
    print(f"Number of thoughts generated: {len(thoughts)}")

    rewards = process_rewards(thoughts)
    print("Process Rewards:")
    for path, reward in rewards.items():
        print(f"{path}: {reward:.2f}")
```

### How this works (Line-by-Line Breakdown)

1. **Node Class**: Defines the structure of a node in the tree, including its state, parent, children, visits, and value.
2. **add_child Method**: Adds a child node to the current node.
3. **update Method**: Updates the node's visits and value.
4. **ucb1 Method**: Calculates the Upper Confidence Bound (UCB1) for the node, balancing exploration and exploitation.
5. **mcts Function**: Implements the Monte Carlo Tree Search algorithm, including selection, expansion, simulation, and backpropagation.
6. **tree_of_thoughts Function**: Generates a tree of thoughts by recursively exploring the children of each node up to a specified depth.
7. **process_rewards Function**: Calculates the rewards for each path in the tree of thoughts.
8. **Main Block**: Creates a sample tree, runs MCTS to find the best node, generates a tree of thoughts, and calculates the process rewards.

> [!ADVANCED]
> The Node class uses a tree structure to represent the state space, with each node containing information about its state, parent, children, visits, and value. The MCTS algorithm uses this tree structure to explore and evaluate different paths, balancing exploration and exploitation. The tree_of_thoughts function recursively explores the tree to generate a tree of thoughts, and the process_rewards function calculates the rewards for each path in the tree of thoughts.

> [!QA]
> Q: When should I prefer Tree-of-Thoughts over Monte Carlo Tree Search?
> A: Tree-of-Thoughts is preferable when you need to explore multiple reasoning paths and consider the implications of different sequences of thought. MCTS is better suited for problems with large and complex state spaces where you need to balance exploration and exploitation.
