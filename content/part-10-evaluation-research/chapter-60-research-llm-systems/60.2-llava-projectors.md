# 60.2 — Cross-Attention & Projector Architectures: LLaVA, MLP vs Q-Former

## Opening Motivation & Context

In the rapidly evolving landscape of multimodal AI, the ability to seamlessly integrate vision and language processing is a critical frontier. This lesson explores two key architectures that enable this integration: Cross-Attention and Projector Architectures, specifically focusing on the LLaVA model and comparing Multi-Layer Perceptrons (MLPs) with Q-Formers.

Cross-attention mechanisms allow models to attend to relevant features in both vision and language modalities, while projector architectures serve as bridges between these modalities. The LLaVA model exemplifies how these concepts are implemented in practice, and understanding the differences between MLPs and Q-Formers is crucial for designing effective multimodal systems.

## Core Concepts Breakdown

### Cross-Attention

Cross-attention is a mechanism that allows a model to attend to relevant features in one modality while processing another. In the context of vision and language, cross-attention enables the model to focus on specific regions of an image while generating text, or vice versa.

> [!KEY-INSIGHT]
> Cross-attention enables the model to dynamically attend to relevant features in both modalities, improving the coherence and relevance of the generated output.

### Projector Architectures

Projector architectures are used to bridge the gap between different modalities. They transform features from one modality into a space that is compatible with another. In the context of vision and language, projectors can be used to transform image features into a space that is compatible with language features, or vice versa.

> [!BEST-PRACTICE]
> When designing projector architectures, consider the dimensionality of the input and output spaces, and ensure that the projector can effectively capture the relevant features.

### LLaVA Model

The LLaVA model is a multimodal AI model that combines vision and language processing. It uses cross-attention mechanisms to enable the model to attend to relevant features in both modalities, and projector architectures to bridge the gap between them.

> [!WARNING]
> When implementing cross-attention mechanisms, be careful to ensure that the model can effectively attend to relevant features in both modalities. Poorly designed cross-attention mechanisms can lead to suboptimal performance.

## Code Demonstration & Runtime Output

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CrossAttention(nn.Module):
    def __init__(self, embed_dim: int, num_heads: int):
        super().__init__()
        self.embed_dim = embed_dim
        self.num_heads = num_heads
        self.head_dim = embed_dim // num_heads

        self.query = nn.Linear(embed_dim, embed_dim)
        self.key = nn.Linear(embed_dim, embed_dim)
        self.value = nn.Linear(embed_dim, embed_dim)
        self.out = nn.Linear(embed_dim, embed_dim)

    def forward(self, x: torch.Tensor, context: torch.Tensor) -> torch.Tensor:
        batch_size = x.size(0)

        # Linear projections
        q = self.query(x).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        k = self.key(context).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        v = self.value(context).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)

        # Scaled dot-product attention
        scores = torch.matmul(q, k.transpose(-2, -1)) / (self.head_dim ** 0.5)
        attn_weights = F.softmax(scores, dim=-1)
        output = torch.matmul(attn_weights, v)

        # Concatenate heads and apply final linear projection
        output = output.transpose(1, 2).contiguous().view(batch_size, -1, self.embed_dim)
        output = self.out(output)

        return output

class Projector(nn.Module):
    def __init__(self, input_dim: int, output_dim: int):
        super().__init__()
        self.fc = nn.Linear(input_dim, output_dim)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.fc(x)

class LLaVA(nn.Module):
    def __init__(self, embed_dim: int, num_heads: int, vision_dim: int, text_dim: int):
        super().__init__()
        self.cross_attention = CrossAttention(embed_dim, num_heads)
        self.vision_projector = Projector(vision_dim, embed_dim)
        self.text_projector = Projector(text_dim, embed_dim)

    def forward(self, vision_features: torch.Tensor, text_features: torch.Tensor) -> torch.Tensor:
        # Project vision and text features to the same dimension
        vision_projected = self.vision_projector(vision_features)
        text_projected = self.text_projector(text_features)

        # Apply cross-attention
        output = self.cross_attention(text_projected, vision_projected)

        return output

if __name__ == "__main__":
    # Example usage
    embed_dim = 512
    num_heads = 8
    vision_dim = 2048
    text_dim = 768

    model = LLaVA(embed_dim, num_heads, vision_dim, text_dim)

    # Dummy input tensors
    batch_size = 4
    vision_features = torch.randn(batch_size, 196, vision_dim)  # 196 is the number of patches in a 14x14 grid
    text_features = torch.randn(batch_size, 50, text_dim)  # 50 is the sequence length

    output = model(vision_features, text_features)
    print(output.shape)
```

2. **CrossAttention Class**: This class implements the cross-attention mechanism.
   - **Initialization**: The `embed_dim` and `num_heads` are set, and the `head_dim` is calculated as the division of `embed_dim` by `num_heads`.
   - **Linear Projections**: Three linear layers are defined for the query, key, and value projections.
   - **Forward Method**: The input tensors `x` and `context` are projected using the linear layers, reshaped, and transposed to prepare for the attention mechanism. The scaled dot-product attention is computed, and the output is concatenated and projected using a final linear layer.

   - **Forward Method**: The input tensor is projected using the linear layer.

## Q&A

### Q: When should I prefer cross-attention over simple concatenation of features?

<details><summary>Show Solution</summary>

Cross-attention should be preferred over simple concatenation when you need the model to dynamically attend to relevant features in both modalities. Cross-attention allows the model to focus on specific regions of an image while generating text, or vice versa, which can lead to more coherent and relevant outputs. Simple concatenation, on the other hand, treats all features equally, which may not be optimal for all tasks.

</details>
